## 研究背景

-   以往研究已证实，单独的盈余公告或分红公告均能对股票价格产生显著影响。
    
-   盈余公告对股价的影响由Ball和Brown、Foster、Brown、Watts等人的研究证实。
    
-   分红公告对股价的影响由Pettit、Charest、Aharony和Swary等人的研究证实。
    
-   然而，以往研究大多孤立地考察分红或盈余公告的影响，未探讨投资者是否将两者联系起来进行评估。
    

## 研究目的

-   本文旨在检验投资者是否将盈余公告和分红公告联系起来进行评估，即是否存在“相互印证效应”。
    
-   例如，当盈余超出预期时，投资者是否会更相信意外的分红增加，反之亦然。
    

## 研究方法

### 数据与样本选择

-   样本包括1979年第四季度至1981年第二季度之间的352个季度盈余和分红公告。
    
-   选择标准：
    

-   公司在芝加哥大学CRSP磁带和标准普尔COMPUSTAT磁带中均有记录（1973-1981年）。
    
-   主营业务为制造业（SIC代码2000-3999）。
    
-   盈余和分红公告在样本期内被《华尔街日报》报道。
    
-   两次公告时间间隔不超过10天。
    
-   财年结束于3月、6月、9月或12月。
    

-   样本中排除了非制造业公司，因为这些公司可能受到监管，分红决策可能受限。
    

### 预期模型

-   **分红预期模型**：采用Aharony和Swary的模型，假设下一季度分红与上一季度相同，即 ( D\_q = D\_{q-1} )。未预期分红（DU）计算为与上一季度分红的百分比变化。
    
-   **盈余预期模型**：采用Foster的模型，考虑季节性、趋势增长和经济周期影响，公式为 ( E\_q = E\_{q-4} + a + b(E\_{q-1} - E\_{q-5}) )。未预期盈余（EU）计算为盈余预测误差的百分比。
    

### 异常收益计算

-   异常收益（AR）计算公式为 ( AR\_{jt} = R\_{jt} - \[R\_{ft} + \\beta\_j (R\_{mt} - R\_{ft})\] )，其中 ( R\_{jt} ) 为公司j在t日的总收益，( R\_{mt} ) 为市场收益（以标普500指数衡量），( R\_{ft} ) 为t日的无风险利率（国库券利率），( \\beta\_j ) 为公司j的贝塔值。
    
-   累计异常收益（CAR）计算区间为首次公告前10天至第二次公告后10天。
    

### 回归模型

-   采用包含交互项的回归模型： ( CAR = b\_0 + b\_1 DU + b\_2 EU + b\_3 I(-0) + b\_4 I(-+) + b\_5 I(+-) + b\_6 I(+0) + b\_7 I(++) )，其中I为交互虚拟变量，表示不同盈余和分红信号组合。
    

## 研究结果

### 回归结果

-   **不含交互项的回归**（列1）：
    

-   盈余和分红的系数均为正且显著（1%水平），表明单独的盈余或分红惊喜均能引发股票异常收益。
    
-   盈余1%的惊喜导致股价上涨0.034%，分红1%的惊喜导致股价上涨0.07%。
    

-   **包含交互项的回归**（列2）：
    

-   交互项的系数均为正且大多显著，表明盈余和分红公告的组合对股价有显著影响。
    
-   例如，当盈余和分红均为正惊喜时（I(++)），股价上涨1.03%。
    
-   当盈余或分红中有一个为负惊喜时（如I(-+)或I(+-)），股价表现较差。
    
-   盈余和分红的单独系数在加入交互项后变得不显著，表明其单独影响被交互效应所掩盖。
    

### F检验

-   交互项的F统计量显著，支持存在相互印证效应的假设。
    
-   盈余和分红惊喜变量的联合显著性检验不显著，进一步表明交互项是关键解释变量。
    

## 研究结论

-   盈余和分红公告之间存在显著的相互印证效应。
    
-   投资者在评估公告时会将两者联系起来，而非孤立地看待。
    
-   这一发现表明，盈余和分红公告共同向市场传递信息，且两者的一致性对股价有重要影响。
    

## 研究意义

-   本文填补了以往研究的空白，揭示了盈余和分红公告之间的相互关系对股价的影响。
    
-   对理解市场如何整合不同类型的信息具有重要意义。
