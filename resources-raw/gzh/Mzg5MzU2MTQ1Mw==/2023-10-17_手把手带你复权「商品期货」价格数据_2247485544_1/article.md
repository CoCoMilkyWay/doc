下面是鸡蛋🥚主力合约的Dataframe，每个交易日对应着当日主力合约的代码symbol和高开低收价格，在2023年4月13日这一天，主力合约发生了换月，从2305切换到了2309，在这个日期我们进行复权计算。  

![](assets/001.jpg)

期货价格的复权和股票一样，也有前后复权，在回测数据中建议用_**后复权**_，也就是后面的价格变，前面的价格不变。前复权可能会导致价格为负数的情况出现。

期货价格复权一般有2种方式：_**等差复权和等比复权，**_建议采用等比复权的方式。

**1、等差复权**

等差复权，顾名思义就是计算切换前后2个主力合约的价差。  

现在有一个dataframe，每一个交易日对应着当日的主力合约代码symbol，和主力合约的高开低收价格数据。

在这个dataframe里👇，4月12日的主力合约是jd2305，4月13日切换到了jd2309，4月12日的收盘价是4329，4月13日的开盘价是4215。

![](assets/002.jpg)

我们采用后复权，用前一天(4月12日)的收盘价4329，减去当天(4月13日)的开盘价4215，得到的差作为等差复权系数:

_**4329 - 4215 = 114**_

然后在dataframe中新建一个列，命名为「adjust」，这一列用来储存复权系数。_**在合约没切换的时候，等差复权系数为0，在合约切换时，系数为前一天收盘价和当天开盘价的价差，也就是114，用这种方式把不同主力合约的价格整合到一条基准线上**_。

代码：

```
adjust = df['close'].shift() - df['open']
```

![](assets/003.jpg)

计算好复权系数这一列后，当我们计算某一天的复权价格时，就直接用_**累加**_的复权系数，加上当天的价格。  

代码：

```
df['open_adj'] = df['open'] + adjust.cumsum()
```

  

**2、等比复权**

等比复权和等差复权的方式一样，只是我们把前后2个主力合约的价差换成了价格之比。  

还是这个鸡蛋🥚的Dataframe，4月13日主力合约切换到了jd2309，4月12日的收盘价是4329，4月13日的开盘价是4215。  

![](assets/002.jpg)

现在用前一天(4月12日)的收盘价4329，除以当天(4月13日)的开盘价4215，得到的比值作为等比复权系数:

_**4329 ➗ 4215 = 1.027**_  

这个1.027就是等比复权系数，我们还是在dataframe中新建一个列，命名为「adjust」，这一列用来储存复权系数。在合约没切换的时候，等比复权系数为1，在合约切换时，系数为前一天收盘价和当天开盘价的比值，也就是1.027。看，完全和之前的等差复权一毛一样。

![](assets/004.jpg)

和等差复权的累加一样，**等比复权直接累乘就好了**～

完整代码：

```
adjust = df['close'].shift() / df['open']
```
