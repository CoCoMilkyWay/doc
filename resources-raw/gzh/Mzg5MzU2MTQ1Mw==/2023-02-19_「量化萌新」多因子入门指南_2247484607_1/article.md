量化策略分为两类，一类是规则类策略，另一类是多因子策略。

规则类策略好上手入门，把策略用代码描述，找个量化平台就能跑起来。比如一个简单的双均线策略，很多商业量化平台上已经有现成的代码，做一下特征过滤，可以直接拿来用。

另一种多因子策略，简单来说就是挖一箩筐和收益率有关系的因子，再把这些因子用模型串起来，然后产生交易信号。

多因子和规则类策略本质上一样的，规则类是多因子的高层实现，它的底层也是因子，只不过越过了因子挖掘这一步，直接把肉眼可见的规律拿来用了。无论是因子类还是规则类策略，都能赚钱，没有高下之分。

本文用新手友好的方式，把多因子流程讲明白。

###

②会运用相关性检验和线性回归的知识。

**0****1**

**采集数据**

第一关要采集原始数据，目的是生成因子。例如我们采集15分钟周期上的MA移动平均线的数值，作为技术因子。

因子的生成依据是：因子和收益率在逻辑上存在相关性，而不是凭空捏造，瞎G8掰的。

**02**

**处理数据**

  

然后就是对数据的一些异常值处理，包括**去除空值、去极值和标准化**。为什么要对数据进行去极值处理呢？因为极端值的存在会干扰我们发现数据的规律。

下面这幅图是去除了极值的数据，可以看出直线A很好的拟合了数据，x和y呈现明显的线性关系。

![](assets/001.png)

如果没有去除极值点呢？下图2个黄点就是极值点，把这两个点和其他正常点用线性回归拟合后得到了B，但是B并不能很好解释x和y之间的关系，**这就是我们要对数据做去极值处理的原因，让模型更好的解释数据中的关系**。常用的去极值法是中位数去极值。

![](assets/002.png)

接下来就是数据的标准化处理，量化交易中用z-score对数据标准化，将不同量级的数据统一转化为同一个量级，以保证数据之间的可比性。

举个栗子：A考了70分(满分100分)，B也考了70分(满分120分)，因为满分不同，A的考分和B的考分明显代表不同的意义，但是从绝对数来看A和B的考分是一模一样的，数据标准化要做的就是用同一个标准来比较A和B的成绩。

Z-Score标准化的公式：

_**z-Score = (x-μ)/σ**_

x是实测值，μ是平均数，σ是标准差。

去极值、标准化处理完毕后，对A股的数据我们还要再走一步，那就是**市值和行业的中性化处理**。这一步是因子提纯，把市值和行业的影响剔除掉。比如成交额这个因子，大市值的股票成交额肯定比小市值的票大，再比如股息率这个因子，银行和食品行业的股息率就比其他行业高。

**03**

**识别有效因子**

  

这一步的目的是找到确实有用的因子。我们要确定因子确实和收益率存在明显的相关性，同时计算因子可能获得收益的大小。用收益率检验因子**可能获得收益的大小**，用IC检验因子和收益率的**线性相关程度**：

### 

**收益率检验:**

  

先来看因子能获得收益率的大小，barra文档里的标准做法是把因子作为自变量，下一期的收益率作为因变量，构建回归方程(这里是wls加权最小二乘法回归)，回归得到的系数就是因子的收益率。

### 

**因子IC值：**

  

接下来看因子和收益率的相关性，IC检验是常见的检验相关性的做法。学术解释：因子 IC 值反映的是下期收益率和本期因子暴露度的线性相关程度。

简单说就是本期因子值和下期收益率的相关性，比如2月1号的因子值和2月2号收益率的相关性。

还有一种是RankIC，计算的是某时点某因子在全部股票暴露值排名与其下期回报排名的截面相关系数。一句话总结，IC算的是因子和收益率的相关性，RankIC算的是因子排名和收益率排名的的相关性。

IC和RankIC越大越好，越小也越好，越大越小说明因子和收益率的相关性强，可以作为正向/反向的选股指标。

我们对因子和收益率的滚动窗口回测，就得到了IC值序列，从IC 值序列的标准差可以看出因子的稳定性，我们据此来判断因子在历史上的表现是比较稳定的，还是波动幅度比较大的？从IC值序列的均值可以判断因子表现显不显著？等等。

就个人经验来讲，用2-3年作为检验周期，能挖到很多夏普7-8的因子，但是一拉长周期，IC值就唰唰往下掉了。这也很容易理解，短时间内相关度高的因子，时间一拉长，在其他行情里和收益率就不那么相关了，因此IC会降低。

### 

**IC检验的是相关性，收益率检验的是成绩，这两者有什么区别呢？**

  

华泰多因子研报举了个形象的例子：票池里5只个股第T期在动量因子上的暴露度为-2、-1、0、1、2，假设它们第T+1期收益率为-0.2、-0.1、0、0.1、0.2，则因子 IC 值为1， 因子收益率为0.1；假设它们第T+1期收益率为-0.4、-0.2、0、0.2、0.4，那么因子 IC 值为1， 因子收益率为0.2。**IC告诉我们因子和收益率有没有关系，收益率检验告诉我们因子能带来多大收益**。

现在A股因子的挖掘非常残酷，常见的能想到的因子都被挖的只剩地皮了。

**04**

**处理因子共线性**

  

因子共线性的意思是两种因子之间有关系，比如我们在分析一个地区粮食产量时，找了几个可能影响的产量的变量：化肥用量、农业投入资金、农业从业人数、浇灌面积，可以看出农业投入资金和化肥用量、浇灌面积是高度相关的，这种因子之间的相关性，就被称为因子共线性，如果纵容共线性存在，我们的回归方程结果会非常大的偏离真实情况。

![](assets/003.png)

那么接下来的任务就是对效因子进行因子间的相关性检验，主要有2种检验方式：

1.  **VIF方差膨胀系数：**
    
      
    

我们现在有两种可能存在共线性的因子：x因子和y因子，然后对它俩做线性回归，得到R方（R方是一个衡量线性模型好不好的指标，R方越大，模型预测能力越好，在x因子和y因子的线性回归模型里，R方大说明X和Y线性关系强。），用下面这个公式就得到了VIF值：

![](assets/004.jpg)

R方越大，VIF越高，x和y这两种因子越是线性相关。经验上来看，VIF＞10说明因子间有很强的多重共线性。  

**2****.相关系数检验**

一种简单的检验方式，用pandas中的dataframe.corr()就能实现。打个比方，我们有两组因子fct\_1和fct\_2，我们用data.corr()计算两组因子的相关性：

```
import pandas as pd
```

```
        fct_1   fct_2
```

  

对于相关性高的因子，我们可以只保留最有效的那一个，也可以进行因子合成。因子合成有几种方法，这里介绍两种常用的：**等权法和历史收益率加权法**。  

### 

**等权法：**

  

这种方法是把相关性高的因子等权重进行合成，变成一个复合的因子。比如最近1个月换手率，最近2个月换手率和最近3个月换手率有较高的相关性，它们的因子均值分别是0.5，0.75和0.8，各占1/3的权重，对它们加权后合成后：

```
0.5*1/3 + 0.75*1/3 + 0.8*1/3 = 0.68
```

**历史收益率加权法：**

把因子一段时期的历史收益率作为权重进行加权，变成一个复合因子。依然用上面的例子举例，最近1个月换手率，最近2个月换手率和最近3个月换手率的历史收益率分别为0.3，0.25，0.18，那么各自的权重分别是：41%,34%和25%。

**05**

**总结**

  

因子从诞生到出炉，大体可以分为以上四个步骤：从原始数据中挖掘可能有用的因子、去极值/标准化处理、有效因子检验、处理因子共线性，其中用的最多的统计学知识是相关性检验，建议新手在多因子挖掘前，先补充这一部分知识。

因子挖掘属于量化流程里“特征工程”的环节，后面的建模依赖于因子的质量，因此我们经常听到因子好坏决定了最终成绩天花板的说法，我们后面选用模型组合因子（机器学习各类模型），参数调优等等都是努力逼近这个天花板的过程。
