我们每天打交道的K线，实际上是在某个时间级别的采样，比如5分钟k线就是对一段5分钟内的价格数据进行“最高价”、“最低价”、“开盘价”、“收盘价”的采样。

采样数据的最大影响是会导致“混叠效应“(aliasing)，“混叠效应”是一个物理学的名词，拿声音采样来说，混叠是指在进行取样时生成了错误的频率(杂音)。上世纪早期的电影采样率只有每秒16帧，太低的采样频率让车轮子看起来像往后滚一样，非常怪异。

“混叠效应”同样会出现在对价格数据的采样中。采样理论认为，我们在1个采样周期至少要采样2次，否则就会出现“混叠效应”，所以为了不失真地还原，一个周期内采样的次数越多越好。**一个采样周期恰好采样2次叫做Nyquist频率，这是避免信号“混叠”的最小采样频率**。Nyquist频率这个专用名词会在后文频繁露脸，我们简称它为Ny频率。

1个周期采样3次、6次、8次...都是高于Ny频率采样次数的，也就是说这些采样都或多或少避免了“混叠”效应。

前面我们知道了“混叠效应“会导致噪音，会很大程度干扰我们的判断。那这种噪音会产生多大的影响呢？我们现在来定量的估计一下这种噪音大小。

**首先，市场数据是分形的**，意思是分钟线图看起来就像日线图，日线图看起来就像周线图，每个小周期的走势图看起来就像大周期走势图的缩小版。大周期的波动更大，小周期的波动更小。

下面这幅图中下面的**蓝线**是时间周期和波动的关系，可以看到时间周期每增加一倍，波动也会放大一倍，对应到k线图上就是10分钟波动是5分钟波动的2倍。上面的**红色线**是加了噪音后，时间周期和波动的关系，**可以非常明显看到加了噪音后，时间周期越小，叠加了噪音后的波动越大，或者说时间周期越小，噪音的影响更明显**。但是更大的时间周期上，噪音几乎没有了，两条线近似重合。

![](assets/005.png)

上面说的这些，对交易有什么启示呢？

**如果你追踪的是50天或者200天的趋势，你可以完全忽略掉“混淆”效应带来的噪声，因为采样次数远高于Ny频率的采样次数了。**但如果你是个短期趋势交易者，看的是2-5个k线的走势，噪声很可能极大干扰你的决策。

## 

有什么办法解决噪音问题吗？

  

**最直接的答案是不要用小于Ny频率的采样数量**。日线的话不要用短于8个bar的交易周期(2-5个bar的交易周期会带来非常大的“混叠”效应)，但是即便加上了这样的限制，还是会有噪音存在，解决办法用低波过滤器来过滤掉这些噪音，一般而言双均线就足够了。

我们再往前走一步，市场的噪音究竟是什么形式的呢？

市场价格的表现和**粉色****噪音**很相似，**粉色****噪音**是一种温和的噪音，催眠曲、风吹过树叶的沙沙声就属于这类噪音。用**粉噪音**对市场数据建模，发现结果和真实的价格走势高度一致：  

![](assets/007.jpg)

市场价格和**粉色噪音**相似的发现早已不新鲜，数学家Benoit Mandelbrot把市场价格描述成一种自我复制的分形。

我们用下面这行代码来表示**粉色噪音**：

```
Pink = .004*Random(100) + .996*Pink [1]；
```

**粉色噪音**和市场价格很相似，因此用Close收盘价替换掉Pink；

Random(100)是一段无序的数字，和白噪音很相似，因此用WhiteSpectrum替换掉Random(100):

```
Close = .004*WhiteSpectrum + .996*Close[1];
```

0.996接近于1，而0.004是白噪声的比例因子，因此WhiteSpectrum可以表示成：

```
WhiteSpectrum = Close – Close[1] = (Close – Close[2]) / 2;
```
