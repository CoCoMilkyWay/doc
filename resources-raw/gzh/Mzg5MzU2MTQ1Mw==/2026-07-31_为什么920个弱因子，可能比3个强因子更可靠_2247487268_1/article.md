有一个业界争论了许久的问题：

  

**金融市场中的可预测性，究竟是由少数强因子构成，还是由大量微弱因子共同构成？**

  

这篇文章给出了反直觉的答案：一个能赚钱的预测模型，是由大量微弱因子共同构成的。

  

如果“微弱因子”效用大于强因子成立，那么将会改变一系列问题的答案：

  

-   因子应该保留还是筛选？
    
-   参数是否应该离散化？
    
-   为什么Lasso可能不适合金融预测？
    
-   为什么传统线性模型仍然有生命力？
    

  

  

真实金融世界的真相可能是“微弱因子”

假设我们有920个股票特征：

  

X1,X2,…,X920

  

未来收益率为：

  

r(t+1) = β1·X1 + β2·X2 + … + β920·X920 + ε(t+1)

  

但因为每个因子的预测力很微弱，所以每个因子的系数都非常小：

  

∣βj∣≈0

  

单独检验任何一个因子，可能都得到：

  

-   IC很低；
    
-   t值不高；
-   样本外预测能力几乎看不见；
    
-   看起来像噪声。
    

  

但如果这些因子的有效信息没有完全重合，将它们组合起来仍可能形成可预测性，即单个因子弱，不等于因子集合没有信息。（大概在4年前，公众号发表过一篇描述类似情况的文章因子挖掘中的“PJ塔克效应”）

Lasso的短板

Lasso解决的问题是：

  

min(beta)\[sum\_t(y(t)−X(t)·beta)^2+lambda·sum\_j |beta(j)| \]

  

一句话讲，Lasso解决的是：选择一组 β，使“预测误差平方和 + λ × 系数绝对值之和”最小。Lasso在两件事间做权衡：

  

-   预测要准确(误差平方和尽可能小)
    
-   系数不能太大、太多(λ × 系数绝对值之和尽可能小)
    

  

所以在Lasso的世界观里，真正有用的因子只有少数几个，那么把这几个因子找出来就足够了。

  

这适合“稀疏强信号”环境，例如：

  

r(t+1) = 0.5X₁ + 0.3X₂ + 0.2X₃ + ε

  

其余917个变量全部无效。

  

但金融市场更可能是：

  

r(t+1) = 0.01X1 + 0.008X2 + … + 0.003X920 + ε

  

在真实的金融市场情况中，没有任何一个因子特别强，但许多因子都携带一点信息。此时Lasso会认为：

  

每个变量的边际贡献都不足以抵消惩罚，那就全部删除。

  

最后得到的结果甚至比预测零还差，因为它可能保留了少数偶然表现较好的噪声变量。因此文章作者得出结论：Lasso模型预测能力不如直接预测0。

  

  

Ridge相对于Lasso的优势

Ridge使用L2正则：

  

min(beta)\[sum\_t(y(t)−X(t)·beta)^2+lambda·sum\_j beta(j)^2\]

  

它不会轻易把变量系数压缩到零，而是将所有系数缩小。

  

```
Lasso：这个因子太弱，删除。Ridge：这个因子很弱，给它一个很小的权重
```

来看一个例子。

  

假设真实系数为：(0.03,0.02,0.01,0.01,…)，  

Lasso可能估计为：(0.04,0,0,0,…)，  

Ridge则可能估计为：(0.015,0.012,0.006,0.005,…)  

  

我们用样本外误差来衡量一个模型的好坏：

  

样本外误差 = 偏差² + 方差 + 不可约噪声

  

偏差是模型预测的平均值与真实规律之间的距离，偏差大说明模型本身没有学到真实规律。方差则说的是：换一批训练数据，模型预测结果会变化多大。如果训练样本稍微改变，模型的系数和预测就剧烈变化，说明模型方差很高。最后的不可约噪声是任何模型都无法预测的部分。

  

Ridge牺牲了系数估计的无偏性，却换来了更低的样本外方差。

作者进一步实验发现，在大量弱信号并存的环境中，随机森林通常比梯度提升树表现得更加稳健；当这些弱信号之间还存在复杂的非线性关系时，加入 L2 正则的神经网络更有优势。

  

现实世界中的预测信息究竟集中在“少数强信号”中，还是分散在“大量弱信号”中，是决定模型表现的前置条件。
