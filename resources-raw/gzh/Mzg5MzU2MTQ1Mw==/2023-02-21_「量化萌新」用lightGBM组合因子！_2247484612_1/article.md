现在我们已经有了食材——一篮子夏普显著的因子，那么现在的问题是怎么把这些因子组合起来，从而获取更大的收益呢？

  

把因子比做食材，下一步就是怎么把这些食材做成好菜佳肴。主流的办法是用机器学习模型组合因子，下面我们一步步来看具体是怎么做的。

  

**02**

**打标 labeling**

  

  

  

第一个问题，就是打标。在量化网红lopez的书《advances in financial machine learning》用大篇幅讲了打标的技巧，可见打标真的是个头等大问题。

  

如果你不晓得啥是打标，我来通俗的解释一下机器学习模型预测的原理：

  

这里有一幅猫和老鼠的画，属于猫的像素标记为0，属于老鼠的像素标记为1，0和1就是标签，老鼠和猫的像素就是特征，我们把这些“特征”和“标签”一起丢进机器学习模型，让它学习到其中的规律，这样下次再遇到一幅画，模型就能直接告诉我们画上是老鼠还是猫了。其中把老鼠标记为1，猫标记为0的行为，就是“打标”。

  

![](assets/001.jpg)

  

**这种直接给出明确标签的做法，叫做“监督学习”**。此外还有“无监督学习”，就是不给出明确标签(哪些像素是猫，哪些像素是狗)，让模型自己去寻找规律。

  

在股票走势的预测上，特征就是我们筛选出来的因子，标签就是收益率，换言之我们要对收益率打标。

  

最简单直接的打标办法是计算出一段时期的收益率。比如说对60分钟过后的涨跌做预测，收益率大于0标记为1，收益率小于0标记为0。如果预测为涨，就在当下开多仓，反之开空仓。听起来似乎还不错。

  

**但是实践起来一定会遇到问题。比如我们在下图圆圈处对60分钟后的价格做预测，预测结果的确会上涨，但是别忽略了黄色框框里一大段下跌！**

  

![](assets/002.png)

  

  

在这一段下跌趋势里，价格很可能打到了止损位，更惨点可能爆仓了，很难说在大幅回撤的情况下还能赚到后面的钱。这种打标方式只考虑了**起点和终点**，完全忽略了**价格的运动轨迹**，而价格的运动轨迹中包含了很多重要的信息，例如价格的波动，止盈止损价位等等。  

  

因此我们要考虑其他的打标方式，要把**价格运动的整个过程**考虑进去。Lopez在书里讲了一种三重障碍打标法(triple barrier method)，解决了这个难题。

  

三重障碍打标法具体是这样操作的：

  

-   如果价格先触发止盈，那么标记为1；
    
-   如果先触发止损，那么标记为-1。
    
-   什么都没有触发，标记为0
    
      
    

这种三分类打标法更接近实际，更符合我们实盘操作时的情况，传统打标法重点落在“一段时期后的收益率”上，障碍打标法重点落在“一段时间内，遇到啥，处理啥”，逢山开路遇水架桥。  

  

接下来要考虑的问题是仓位管理，每次模型给你了一个预测结果，你要下多少注呢？**这里可以再训练一个模型专****门来预测下注多少，第一个模型预测涨跌，第二个模型预测确定。比如第一个模型告诉你：价格10分钟后会触发止盈，第二个模型告诉你：概率只有0.05%哦**！

  

![](assets/003.jpg)

  

  

**其他关于打标的群友交流讨论****：**  

  

“还有一种打标法可以试试哈。把计算收益率的价格从后往前算ema 然后 用ema/当前价格-1作为收益率的代理变量。和这个也差不多意思。可以理解为近期的收益率权重大一点 远期的权重小一点。根据ema参数来调整。”

  

“还有一种打标方式是把未来n天的收益率做了一个平均，说可以大幅提高预测能力 。当时觉得很难落地，因为比如即使预测未来n天的平均收益率是涨的  但是不代表未来n天都是涨，很难应用。”

  

**03**

**划分数据集**

  

  

  

除了打标，划分数据集也很有讲究。标准做法是把数据集随机分为训练集，验证集和测试集。  

  

训练集的作用是**【训练模型】**，这个很好理解。验证集的作用是**【调整超参数】**，找到性能最好的超参数组合。而测试集则是一个从没有见过的数据集，作用是**【判断】**模型的好坏。

  

用一个形象的比喻来描述这三个集合的区别：

  

![](assets/004.png)

  

我的做法是把60%的数据划为训练集，20%的数据划为验证集，20%的数据划为测试集。  

  

股价预测的数据集是收益率序列。与图像识别样本的数据集划分不一样，股票收益率是一个是时间序列，时序序列有自相关性，t时刻的收益率和t+1时刻的收益率是相关的。打乱了图像识别样本的顺序，对结果可能没啥影响，**但是收益率序列呢？可不可以打乱时间的连续性，把集合打散后与其他集合在时间上形成穿插**？  
  

只有训练集内部可以适度shuffle数据，**验证集和测试集必须严格按照时间顺序来**。时间中蕴含有重要信息，不能把之后的信息引入到模型里，一个带有穿越性质的模型，做出来的结果只是“看起来好”。

  

**04**

**lightGBM建模**

  

  

  

选择哪种机器学习模型来组合因子呢？我们可以先多尝试几种模型，然后选择表现最好的那个模型。在这里我们用lightGBM举例。  

  

lightGBM一直是机器学习界的明星，Kaggle的比赛有一半以上的冠军方案都是lightGBM，关于lightGBM其中的数学原理就不做多解释了，直接调包侠：

```
import lightgbm as lgb  
```

  

另外，一定要用机器学习模型来整合因子吗？其实不然，简单地用单个因子选取品种，然后把持仓组合起来也是一种行之有效的办法。

  

量化的标准流程到这里就算讲完了，我们来回顾一下所有步骤：因子挖掘—打标—划分数据集—选择模型组合因子。高度概括就是2个步骤，找到因子和组合因子。**找到因子也就是特征工程环节，这一部分决定了最终成绩的天花板。组合因子是用模型对因子进行组合，这一部分最重要的是打标，其次才是模型选择和参数调优**。
