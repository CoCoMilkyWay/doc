# 1.策略概念和理由

尾部风险套期保值是指保护投资组合免受罕见但严重的市场崩溃（“黑天鹅”事件）。在股市动荡期间，波动性急剧上升——标准普尔500指数通常随着VIX（波动性指数）飙升而下跌，反映了其强烈的负相关性。

例如，在2008年金融危机和2020年3月的崩溃中，VIX在几周内从低于20的常规水平飙升到60-80以上的极端值。**这种逆向关系表明，持有长期VIX头寸可以抵消崩溃时的股票损失。**

![](assets/001.png)

_图：2004年至2020年年中的CBOE VIX指数（蓝色），在平静时期波动性低，在危机期间（2008年和2020年）突然飙升到60-80以上。这些波动性飙升对应于重大市场下跌，说明了为什么VIX看涨期权可以作为“崩溃保险”。_

**长期**的**VIX“黑天鹅”策略**涉及购买VIX看涨期权，以便在市场压力期间从波动飙升中获利。理由是**凸回报**：当波动性低时，远价（OTM）VIX看涨期权价格便宜，但如果尾部事件发生，VIX向上爆炸，这些看涨期权的价值可以**非线性**增加**（多次**）。

换句话说，在VIX看涨期权上花费的小额溢价可以在市场恐慌期间产生巨大的收益，有助于**缓冲甚至抵消投资组合的损失**。这使得VIX期权成为有吸引力的对冲工具——通常被称为_“波动性保险”_——对于寻求防止突然崩溃的长期投资者来说。权衡是成本：在大多数时期（没有发生崩溃时），通话过期毫无价值，策略产生稳定损失（保险费）。因此，该策略必须设计成**系统**地**管理这种出血，**这样保护就不会在正常情况下过分拖累投资组合。

在实践中，一个漫长的VIX对冲计划通常分配投资组合的一小部分（例如0.5%-2%）持续购买VIX看涨期权。核心投资组合（例如股票）在牛市期间推动回报，而VIX看涨是休眠的对冲，在波动性冲击中涌现。从长远来看，这可以大幅减少提款。例如，CBOE的VIX尾对冲指数（VXTH）覆盖了标准普尔500指数的动态VIX看涨策略，历来在正常情况下跟踪标准普尔指数，但在2008年遭受了较小的缩跌，实际上**在2020年的崩溃中获得了价值**，如下所示：

![](assets/002.png)

_图：2006-2020年尾对冲投资组合（绿色，CBOE的VXTH指数）与标准普尔500指数（黑色）的表现_

_对冲投资组合在牛市中表现略逊（由于对冲成本），但在2008年经历了较温和的缩水，并在2020年波动爆发期间远远高于标准普尔。_

综上所述，概念是**系统**地**持有长期波动头寸（通过VIX看涨）作为市场崩溃的保险**。对冲会在最需要的时候——在股票尾部事件期间——实现正回报，从而改善投资组合的整体风险/回报情况。接下来，我们讨论如何获取设计和测试这种策略所需的数据。

# 2.数据采集

开发VIX期权策略需要两种数据：**历史VIX指数水平**（了解波动性变动）和**历史VIX期权价格**（模拟策略的交易和市盈率）。

**VIX指数数据：**

VIX指数（CBOE波动指数）由CBOE每天发布，并可从许多来源免费获得。例如，CBOE网站提供可下载的历史VIX数据，以及St.Louis Fed的FRED数据库提供了可以追溯到1990年的VIX时间序列（股票“VIXCLS”）。

此外，雅虎金融等金融数据API和`yfinance`或`pandas_datareader`等Python库可以直接获取VIX每日收盘价。在这个项目中，我们可以使用`yfinance`方便地提取VIX指数和标准普尔500指数数据：

```

**VIX期权数据：**VIX看涨期权的历史期权数据（价格、溢价等）更难获得，还需要数据对齐等处理。

通常需要一个数据供应商或数据库（如OptionMetrics IvyDB、Bloomberg或CBOE的DataShop）来获取每天的期权报价。例如，OptionMetrics的IvyDB提供了很多历史选项数据集。

在这项研究中，由于很难获得完整的历史VIX期权数据集，我们将使用VIX指数和定价模型**近似期权价格**来说明该策略。（在实际实施中，理想情况下会使用供应商的实际历史期权价格来准确回测。）我们将检索必要的VIX指数时间序列，然后对期权回报进行建模。这种方法虽然不准确，但将使我们能够展示战略的机制。

在继续之前，我们将VIX指数数据与标准普尔500指数数据相结合，并执行任何必要的预处理。

# 4.策略建设

**对冲策略规则：**我们设计了一个系统策略来购买VIX看涨期权作为对冲。该策略必须指定_何时_进入对冲头寸，购买_什么_期权，购买_多少_（头寸规模）以及何时退出。我们的长期“黑天鹅”对冲策略将使用以下规则：

**频率/时间：**我们将**定期（每月）**评估对冲。在每个月的间隔（例如，每月的最后一个交易日），我们可能会启动一个新的VIX看涨期权头寸。这确保了对冲随着时间的推移而保持一致，而不是试图操纵市场（这违背了_系统_对冲的目的）。

**进入条件：**进入（或调整）头寸的决定可以是静态的，也可以是根据市场条件决定的。一个简单的方法是_每月始终为对冲分配固定百分比_（确保持续保护）。然而，人们可以通过将对冲大小与波动水平进行调整来完善这一点。

例如，VXTH指数方法使用波动性触发的分配：当VIX处于正常范围时，将投资组合的1%分配给看涨，当VIX已经非常高时（以避免多付），减少分配，当VIX极低或极高时，可能为零。

对于我们的策略，我们将使用类似的启发式方法：

-   **如果VIX低（低于15），我们分配0%（没有对冲，因为波动性很便宜，但非常低的交易量通常表明市场稳定——即使这样，人们也可能选择对冲，但VXTH选择不这样做）。**
-   **如果VIX为中度（15至30），则分配1%的投资组合来购买VIX看涨（全套期保值）。**
-   **如果VIX上升（30到50），则分配0.5%（一半对冲，因为期权价格昂贵，一些危机可能正在展开）。**
-   **如果VIX是极端的（>50），则分配0%（到那时，对冲已经得到回报，或者波动率将达到顶峰——新的对冲非常昂贵，而且可能为时已晚）。**

这些阈值有些随意，但基于**基于波动制度**（管理成本）**的对冲扩展**逻辑。它们反映了VXTH指数规则。

在实践中，即使在低VIX时，投资者也可能总是对冲少量（因为崩溃可能会在低交易量之外发生），但当VIX已经很高时，可能会减少规模。我们将使用上述规则集来说明。

-   **合约选择：**
    
    我们需要选择购买哪个VIX看涨期权。关键参数是执行价格和看涨期到期时间。由于我们正在对冲极端走势，我们通常会使用**深度出价（OTM）看涨期权**，这更便宜，但如果波动性飙升，则会产生很大的百分比收益。例如，人们可以购买delta为~0.10-0.30（10–30 delta）的看涨——这意味着相当远的OTM。CBOE的VXTH指数购买30个delta，1个月的看跌期权，而一些从业者购买更多到期时间更长的自付“末日”看跌期权（例如10-delta）。
    

对于我们的策略，我们将使用**1个月**的**看涨期权**（大约在下月底到期）来快速应对波动性飙升，并选择**比当前VIX水平高约20-50%**的**执行价格**。这通常将呼叫置于深OTM范围内（delta在0.1-0.3左右，取决于VIX本身的波动性）。例如，如果VIX是20，我们可能会在30左右购买罢工的看涨期权（比当前的VIX高50%）。如果VIX是40，20%的OTM呼叫是罢工~48。OTM罢工确保了低廉的成本，这样我们就可以在没有太多资本的情况下购买保护，同时如果VIX在罢工之后真正爆发，仍然可以获得巨大的回报。

**头寸规模：**如进入条件中所述，我们将总投资组合（f%）的一小部分分配给购买VIX看涨期权。例如，如果投资组合价值为1,000,000美元，f% = 1%，我们将在该卷的VIX看涨期权上花费10,000美元。这1万美元根据期权价格购买了一定数量的合同。小规模（<<100%）很重要，因为这些期权到期时通常毫无价值；我们希望**限制**对冲**成本，**以便投资组合能够长期承受它。通常，每月0.5-2%是许多尾对冲策略使用的范围——足以在崩溃中有所作为，但不会在长期平静的市场中扼杀投资组合。

**退出/到期：**我们将保留VIX通话，直到到期（大约一个月）。到期时，如果看涨期权最终以现金支付，它们将以现金支付（VIX期权是现金结清的）。然后，我们立即根据规则为下一个时期推出一组新的1个月的电话。或者，如果对冲在月内变得非常有价值，人们可以选择**提前获利**（例如，如果VIX突然飙升，您可能会在峰值时将看漲货币化，而不是等待）。为了简单起见，我们的基线策略坚持到期——但我们将在回测中每天监控投资组合，因此我们可以添加“如果对冲价值>某个阈值，提前卖出”这样的规则作为增强。

# 5.风险管理

长期对冲策略的一个关键方面是防止对冲在长期良性时期侵蚀过多的价值。我们实施**亏损控制：将对冲的损失限制在投资组合总额的5%。**在实践中，这意味着如果对冲策略表现不佳，以至于将整个投资组合从高位下跌5%以上，我们将暂时减少或停止对冲，以阻止进一步的损失。从本质上讲，我们在**对冲计划中**设置了**“止损”。**

**实施提款控制：**我们保持总投资组合的运行峰值，并监控提款百分比。如果在任何时候，投资组合总价值低于其峰值5%_，并且损失主要是由于对冲出血_（与股票提款相反，这正是我们期望对冲回报的时候），这表明与其收益相比，对冲成本可能太高。在这种情况下，该策略可以暂停新的对冲购买（即将对冲分配设置为0），直到投资组合恢复到某个阈值以上（或重大波动事件重置画面）。这确保了对冲不会在长期的牛市中持续造成复合损失。

在代码中，我们可以通过跟踪`peak_portfolio_value`和`hedge_active`标志来集成它：

```

在上述逻辑中，如果提款超过5%，`hedge_active`将设置为False，这意味着在随后的迭代中`alloc_pct`将被迫为0（没有新的对冲），直到提款改善。我们包括了一个条件，如果提款低于5%，投资组合再次增长，则将其重新打开（根据偏好，您可能需要达到新高值才能重新激活）。这确保了我们不会在一次糟糕的连胜后永久关闭对冲——一旦投资组合恢复，我们就可以恢复对冲。

**额外的风险控制：**除了基于缩用的切换外，还有其他风险管理技术：

**溢价预算：将**每年花费的溢价总额限制在投资组合的一定百分比（例如，“对冲每年不超过2%”）。我们每月1%~每年12%，最坏的支出，这很高；在实践中，你可能会跳过几个月或调整规模以满足年度预算。

**获利：**如果对冲头寸大获利（例如，VIX看涨期在崩溃期间价值增加10倍），人们可能会在到期前将其出售，以锁定利润（因为VIX在涨后可能会迅速下跌）。这确保了对冲收益的实际实现，并可以补充投资组合。我们可以实施一个规则，例如：如果看涨期权的价值高于阈值（例如，溢价翻三倍），请立即出售它，不要等待到期。

**滚动频率：**根据风险偏好，人们可以使用每周期权或长期期权。每周对冲反应更快，但成本更高（更频繁地支付保费）。期限较长的期权（3-6个月）每份合约的成本更高，但您购买它们的频率较低，如果交易量保持低，它们的价值会更好。例如，一些策略购买120天0.10-delta“末日”看跌期权，每年只掷几次，以减少交易频率。

对于我们的系统策略，我们将坚持每月的时间表，并按照描述纳入基于缩机的开/关开关。这应该能防止累计对冲成本在任何时候超过~5%的提款。

# 6.回测方法

在定义了规则和风险管理后，我们建立了一个**回测框架，**以评估该策略在历史上的表现。回测涉及模拟历史数据的策略，核算交易成本和滑点，然后计算绩效指标。

**模拟循环：**我们将从数据集开始逐月模拟。在每个步骤中，我们了解投资组合价值，决定对冲分配（使用当月的VIX），扣除保费，然后转到下个月，根据SPY表现和期权回报更新投资组合价值。适当模拟**现金流**很重要：当我们购买期权时，我们支付溢价（贬值投资组合的现金或价值），当期权到期时，我们会收到回报（如果有的话）。在我们的模拟中，我们将期权的回报直接整合到到期时的投资组合价值中。我们假设投资组合的剩余大部分投资于SPY（或标的股票），其价值会根据市场而变化。

**滑点和交易成本：**VIX期权通常是流动的，但保守地，我们包括交易成本。我们可以通过稍微增加期权的成本来模拟滑点（例如，假设我们以要价购买，该要价可能比理论中价高出几%）。例如，我们可以将模型溢价乘以1.02（2%溢价间接费用），或减去每个选项的固定0.05美元作为佣金/费用。在代码中，在计算溢价后，我们可以做：`premium *= 1.02`来解释滑点。此外，在计算回报时，我们可能会假设我们没有捕获最后一分钱的内在价值（尽管为了简单起见，我们通常在到期时获得全部内在价值）。

**每日与每月粒度：**我们的回测将按月交易步骤操作。这意味着我们不会明确模拟期权在本月内的每日市值波动。然而，如果需要，我们将拥有**每日数据来**更精细地**评估指标**（例如，我们可以插值或假设月份之间的线性移动来估计每日权益曲线）。为了精确度，人们可以切换到每日模拟：每天更新期权值（通过一些模型），并决定是否触发任何规则（如止损或获利）。鉴于选项的路径依赖性，这变得复杂。就我们的范围而言，每月就足以捕捉大局（对冲要么在崩溃的月份得到回报，要么不回报）。

# 7.绩效评估

为了评估VIX对冲策略的有效性，我们考虑关键绩效指标，并将对冲投资组合与未对冲基线（纯股本）进行比较。感兴趣的指标包括：**复合年增长率**（年化回报）、回报**波动性**、**夏普比率**（风险调整回报）、**最大跌幅**（最坏的峰值到低谷跌幅），也许还有**Sortrino比率**或**Calmar比率**（专注于跌幅）。尾部对冲的主要目标不是最大化回报，而是_减少下行风险_——尽管正如2020年所示，及时对冲甚至可以在崩溃期间提高回报。

然而，由于保险成本（例如，在良性时期，对冲复合年增长率略低于未对冲复合年增长率），平均回报可能略低。

除了夏普和提款之外，我们可以查看崩溃年份的**年回报**，以验证对冲的价值。例如，2008年，标准普尔500指数下跌了约37%，但如果对冲大幅回报，适当对冲的投资组合可能会下跌少得多，甚至持平/上。2020年3月，标准普尔500指数在一个月内下跌了~20%以上；我们的模拟显示，对冲收益大致上涨了这一金额，几乎抵消了损失（因此，该月投资组合大致持平，而未对冲的大幅下跌）。

**解释结果：**预计对冲策略会产生更平稳的股权曲线——小幅跌幅，并可能在崩溃后更快地恢复。**在强劲的牛市运行期间**，它可能会**表现略有不足**（因为我们持续在对冲上花费少量资金）。这在VXTH与SPX图表中可见：从2010年到2019年（长期牛市），对冲线（绿色）略低于标准普尔（黑色）。

这是以拖累的形式显示的“保险费”。但作为回报，对冲_在危机中大放异彩_——绿线在2008年下降较小，在2020年飙升，最终高于标准普尔。

为了确保统计稳健性，我们还会检查**Sortino比率**（它与Sharpe一样，但只会惩罚下行波动性）**，**也许对**股市的β**（对冲投资组合将具有较低的β值，这意味着市场上市场上的相关性/上行较少，但这是意料之中的）。我们还应该确认5%的止損是有帮助的：例如，在2017年平静的某个时刻（当时VIX非常低，对冲可能每月亏损）后，该策略是否真的停止流血？如果规则奏效，则由于对冲损失而导致的策略缩减应该上限在5%左右。

总体而言，绩效评估应该表明，**长期VIX对冲策略提供了有意义的尾部保护**。它可能会适度降低长期回报（取决于崩溃的频率——像2010年代这样很少崩溃的十年会使对冲看起来成本高昂，而崩溃沉重的时期会使其看起来很棒），但它的主要好处是提高**风险调整后的回报**。更高的夏普和更低的最大提款意味着投资者可以更有信心地投资，甚至可能有更多的杠杆作用，因为对冲已经到位。
