一个包含 30万个商品代码的金融数据库：Finance Database  

![](assets/001.jpg)

☑️100% 免费。  

☑️这个数据库包含30万多个商品代码，包括股票、ETF、基金、指数、货币、加密货币和货币市场。  

☑️可以广泛了解部门、行业、投资类型等。  

☑️该数据库未提供最新的基本面或股票数据，这些数据可以通过使用**FinanceToolkit**轻松获得（在FinanceDatabase的帮助下）。

  

✅可以在 GitHub 上获取它：https://github.com/JerBouma/FinanceDatabase

![](assets/002.jpg)

  

财务数据库：FinanceToolkit  

  

![](assets/003.jpg)

  

🏢比较任何时期的小额或大量股票代码（高级用户为10年以上，免费用户最多5年）。

👁️‍🗨️财务工具包不仅支持股票。即使对于期权、货币、加密货币、ETF、共同基金、指数、货币市场、商品、关键经济指标等。

📃从财务报表中绘制任何项目，例如资产负债表中的股东权益、损益表中的收入和现金流量表中的运营现金流。

💸比较150多个财务比率、技术指标、绩效指标和风险指标等。

📈显示季度结果、增长率、跟踪十二个月（TTM）以及表格下载。

  

✅可以在 GitHub 上获取它：https://github.com/JerBouma/FinanceToolkit

  

通过利用两者，可以使用从FinanceDatabase中发现的股票代码进行全面的分析，并输入到FinanceToolkit中。

  

更多内容可以参考：https://www.jeroenbouma.com
