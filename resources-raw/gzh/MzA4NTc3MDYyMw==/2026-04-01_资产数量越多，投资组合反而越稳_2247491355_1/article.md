# 资产数量越多，投资组合反而越稳

InfinityQuant 映翡量化 2026-04-01 09:23 上海

> 原文地址: [https://mp.weixin.qq.com/s?\_\_biz=MzA4NTc3MDYyMw==&mid=2247491355&idx=1&sn=7a2d511f10cdddf481837604ef4d8d78&chksm=9ebf90d85638edf1ebff6847d6a3be5b64724492c004434fec09820fdf4b5d5a7533c63eb7cb#rd](https://mp.weixin.qq.com/s?__biz=MzA4NTc3MDYyMw==&mid=2247491355&idx=1&sn=7a2d511f10cdddf481837604ef4d8d78&chksm=9ebf90d85638edf1ebff6847d6a3be5b64724492c004434fec09820fdf4b5d5a7533c63eb7cb#rd)

**几十年来，故事一直很简单：在马科维茨投资组合（教科书式的跨资产最优权重选择方法）中，如果加入太多股票，组合就会崩溃。估计噪声（Estimation noise）会让你血本无归。大家都同意这一点。教科书、论文、从业者，全都这么认为。**

**只是，从来没有人真正尝试过加入“极多”的资产。**

来自耶鲁大学、哥本哈根商学院、AQR 和 EPFL的新论文《Complex Modern Portfolio Theory》（2026年3月20日）展示了当资产数量（N）远远超过训练数据点数量（T）时会发生什么。确实，当 N ≈ T时，表现确实会崩溃。但继续增加资产数量，表现就会开始恢复，然后持续攀升。

其背后的机制：

当 N > T时，用于求逆协方差矩阵的数学方法（伪逆）开始表现得像岭回归收缩（ridge shrinkage）——一种能够抑制噪声估计的技术。而且不需要任何手动调参，系统会自动实现正则化。估计误差从二次增长转为线性增长。他们将其称为隐藏收缩（hidden shrinkage）。

论文的其他发现：

-   最小方差投资组合（MVP，即只最小化风险而不追求最大化收益的组合）在夏普比率（单位风险的回报）上确实优于传统的马科维茨方法。原因在于它完全忽略了那些充满噪声的预期收益估计。
    
-   著名的 1/N 等权重投资组合（简单地把钱平均分配到所有资产上）只在 N ≈ T附近表现最好。当资产数量足够大时，马科维茨方法和 MVP 都会超越它。如果再额外加入一点显式的岭收缩，收益还会进一步提升。
    

作者用随机矩阵理论提供了严谨支撑，清晰地显示了在 c = N/T = 1（即资产数量等于观测数量的临界点）处存在一个明显的相变。在经典情况（N < T）下，你能获得的最佳夏普比率大约只有理论最大值的 1/8。而进入复杂情况后，这一限制被打破。

实证数据：

研究使用了 153 个 JKP 因子组合（Jensen、Kelly 和 Pedersen 提出的已知回报预测因子的大型集合，1972–2023 年），以及 CRSP 的个股数据，涵盖月频和日频，训练窗口从 6 个月到 120 个月不等。

值得注意的是：因子组合本身是多空构造，因此基础资产已经包含了信号。而个股数据中，马科维茨方法的改进相对较弱，尤其是在短期估计窗口下。理论还假设回报在时间上相互独立且统计特性稳定，这是一种简化。现实世界的摩擦（如交易成本和容量限制）并未纳入模型。

尽管如此，过去几十年的文献一直警告我们不要使用过大的 N。结果发现，他们只是从来没把 N推得足够远。
