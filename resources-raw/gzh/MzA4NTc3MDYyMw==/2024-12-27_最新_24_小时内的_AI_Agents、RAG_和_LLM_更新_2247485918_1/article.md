过去 24 小时内的 AI Agents、RAG 和 LLM 更新。  
  
1\. Praison 是一个低代码框架，用于创建和管理具有内置自我反思功能、实时语音交互和工具的 AI 代理。  
→支持 AutoGen 和 CrewAI  
→简单的 YAML 配置  
→无代码和基于代码的工作流程  
  
2.MarinaBox 是一个开源工具包，通过 Docker 容器提供隔离的桌面和浏览器沙箱。  
→现场观看和录制  
→人机交互  
→本地运行一切  
  
3.DeepSeek V3 Base模型已登陆Hugging Face。  
→ 685B 参数混合专家模型  
→每个 token 有 256 个专家(8 ）  
→在 Aider 上优于 Claude 3.5 Sonnet  
千亿私募幻方出品：[DeepSeek-V3 正式发布](https://mp.weixin.qq.com/s?__biz=MzIyODEyNDYzMw==&mid=2652898316&idx=1&sn=8e132ffaf2ed2ea411918cd9c7d59431&scene=21#wechat_redirect)  
  
4.PyTorch 现在提供内置内存可视化工具，可帮助您在模型训练期间跟踪和分析 GPU 内存使用模式。  
  
5\. 微软开源了 PromptWizard，这是一个自动优化提示的框架。它使用来自语言模型的反馈来完善指令和示例。  
  
6.AI Testing Agent 是一个开源 AI 代理，可以自动为您的 API 端点生成测试计划并测试代码。
