# 为什么同一策略，高波产品往往是“结构性劣后”的选择？

很多投资人有一个直觉：

同一个策略，如果有低波版和高波版，那高波不就是更激进、收益更高的版本吗？

但现实往往相反。

长期看，同策略的高波产品，夏普率大概率不如低波产品。这不是管理人水平问题，而是一个纯数学问题。

今天我们把这件事讲清楚。

-     
    
      
    
      
    
    **FUND TALK**
    

  

# 一、一个简单到不能再简单的数学题

假设：

低波产品：1倍杠杆

高波产品：2倍杠杆

T-1

日净值：100

总资产：

低波：100

高波：200（融资100）

到了T日，底层资产突发下跌10%。

结果：

低波：100 → 90

高波：100 −200×10% = 80

此时杠杆率：

低波：100%

高波：180/80 = 225%

如果目标杠杆是200%，高波产品必须被动减仓。

这一步非常关键。

# 二、为什么问题出在“被动去杠杆”？

跌了之后：

低波：什么都不用做

高波：必须卖出资产

等到T+1日，底层反弹11%。

低波：

90 → 99.9

高波：

80 ×（1 + 200% × 11%）= 97.6

你会发现：

低波：1 → 0.9 → 0.999

高波：1 → 0.8 → 0.976

一次震荡，高波就永久落后。

这不是预测问题。

这是路径依赖问题。

# 三、真正的数学本质：波动拖累

连续收益的近似表达式是：

L × μ−0.5 ×L² × σ²

其中：

L =杠杆倍数

μ =收益

σ =波动率

关键在第二项：

0.5 × L² × σ²

这是波动惩罚项。

注意两个点：

杠杆是平方放大的

波动是平方放大的

杠杆翻倍，波动拖累放大四倍。

这意味着：

杠杆不会线性放大夏普,杠杆会平方放大波动损耗

这就是高波产品长期收益质量下降的根源。

# 四、高波产品其实在“卖波动”

很多人以为高波产品只是“收益更弹性”。

但实际上它在做三件事：

回撤时被动卖出

反弹时仓位变小

高频再平衡消耗收益

这在结构上等于：

负gamma卖波动

即使你没有显性卖期权，机制已经帮你卖掉了。

这也是为什么：

震荡市对高波产品伤害最大

趋势单边市高波看起来更猛

但长期震荡占多数

久而久之，夏普自然劣化。

# 五、同策略条件下，理性选择是什么？

如果：

底层策略完全一样

只是波动目标不同

那么理性做法是：

买低波版本在组合层自己加杠杆

而不是：买内部高杠杆版本

为什么？

因为组合层加杠杆有四个优势：

不会在子产品层被动去杠杆

可以跨策略调节风险

可以择时调整风险预算

可以避免内部再平衡摩擦

对子产品加杠杆，是不可控的。

在组合层加杠杆，是可控的。

# 六、对FOF管理人更重要

如果你是FOF管理人，这个问题更致命。

假设：你买三个高波产品,每个内部都有杠杆,每个都有自己的去杠杆机制

当市场突发回撤时：三个产品同时被动减仓,组合风险迅速塌缩,随后反弹跟不上.

这就是典型的：

回撤放大反弹吃不到

从组合角度看，这是结构性劣势。

相反，如果你买的是低波产品：

风险在组合层统一控制,杠杆在顶层调节,不会发生子产品内部“踩踏式去杠杆”,这是完全不同的结构。

# 七、什么时候高波产品是合理的？

只有三种情况：

底层波动极低（如国债套利）

μ >> σ²超高alpha）

产品没有刚性去杠杆机制

但现实世界里，这三条往往难以同时成立。

尤其是CTA和趋势策略，本身波动并不低。

在震荡期，高波几乎必然劣化。

# 八、一个更深的理解：夏普不是靠放大得来的

夏普率的提升来自：

提升胜率

提升盈亏比

降低回撤

提升稳定性

而不是来自：

简单放大波动

高波产品给人的错觉是：

更刺激= 更赚钱

但长期收益质量取决于：净值曲线的“稳定复利”,而复利最怕的，就是波动放大。

# 九、一句话结论

同一策略条件下：

高波版本不是“更强的版本”而是“带波动惩罚的版本”.

从数学结构上：低波是线性结构,高波是带负凸性的结构.

长期看：低波更优杠杆应该在组合层而不是子产品层

这不是偏好问题。

这是结构问题。
