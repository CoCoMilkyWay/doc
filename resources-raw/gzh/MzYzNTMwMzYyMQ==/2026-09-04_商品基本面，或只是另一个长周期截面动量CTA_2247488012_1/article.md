# 商品基本面，或只是另一个长周期截面动量CTA

FundTalk Quantis因子工作室 2026-09-04 14:00 浙江

在FOF尽调中，我们习惯于按照策略使用的信息来源给管理人分类：看价格的是趋势CTA，看库存、供需、利润的是基本面CTA，看期限结构的是Carry策略。按照这样的分类方式，**三者似乎属于完全不同的策略体系，因此把它们放进同一个组合，看起来天然具有分散价值。**

但如果把策略名称拿掉，只观察最终持仓，一个很有意思的问题就出现了：所谓商品基本面量化，**会不会只是用库存、利润和供需数据，重新构造了一遍长周期截面动量？**

这个问题并不是文字游戏。对于FOF而言，它直接关系到一个更重要的问题：**你以为自己配置了三个不同策略，实际上是不是仍然押在同一个风险因子上？**

## **一、商品基本面为什么天然具有“趋势属性”**

股票基本面和商品基本面有一个很大的不同。

一家公司的盈利改善，不意味着另外一家公司的盈利一定恶化。但商品天然受制于物理世界：矿山建设需要时间，油井扩产需要时间，农作物有种植周期，生猪有补栏周期，库存的累积与去化也很少在几天内完成。

因此，**一旦某种商品形成供需缺口，这种状态往往具有明显的持续性。**

库存下降，现货开始紧张；现货紧张推动基差走强；期限结构逐渐进入Backwardation；高价格刺激供给、抑制需求，但新的供应真正释放可能需要数月甚至数年。**换句话说，商品基本面本身就是一种慢变量。**

如果我们把30个商品按照库存、供需缺口、加工利润、产能利用率、进口利润等指标进行排序，今天排名最强的商品，下个月大概率仍然比较强；今天最弱的商品，也很少在一个月之后突然变成最强。

于是，一个截面基本面策略最终自然形成这样的持仓：**长期持有基本面Winner，长期做空基本面Loser**。而这句话如果把“基本面”三个字删掉，几乎就是长周期截面动量策略的描述。

后者所做的，不过是按照过去6个月、12个月的价格表现排序：长期持有价格Winner，长期做空价格Loser。**二者的信息源不同，但策略结构惊人地相似。**

## **二、基本面与动量，可能只是同一个周期的不同观察器**

这种相似并非偶然。

经典商品期货研究表明，库存状态与便利收益、期货基差之间存在系统性联系，而且过去期货收益、现货收益和Basis本身都包含关于库存状态的信息。更重要的是，**Momentum和Backwardation策略的收益，有一部分正来自它们倾向于选择低库存商品。**

这背后对应的是一条很自然的经济链条：供需收紧 → 库存下降 → 现货趋紧 → 基差走强 → Backwardation加深 → 价格上涨 → 长周期Momentum形成。

于是，基本面、Carry和Momentum看上去是三个策略，**实际上可能是在观察同一个潜在变量：商品供需周期的持续性。**

Fundamental观察的是周期上游；Carry观察的是现货与期货市场如何表达这种紧张；Momentum观察的是这种状态最终如何反映到价格上。

所以，在一个成熟的大级别商品趋势中，三种策略极有可能站在同一边。铜库存持续下降、现货升水扩大、期限结构走强，同时过去12个月铜又是涨幅最大的商品之一。此时无论管理人告诉你自己做的是“基本面”“期限结构”还是“截面动量”，最后都有可能是Long Copper。

**这就是FOF最容易被策略标签误导的地方。**

## **三、但基本面并不等于动量**

如果二者完全相同，基本面研究当然就没有意义了。**真正值得研究的，恰恰是两者发生分歧的时候。**

假设一个商品已经上涨了一年。过去12个月收益非常强，因此仍然位于Momentum排名前列。但高价格已经开始刺激供给，下游需求开始受到抑制，库存由去化转向累积，加工利润恶化。此时可能出现：Momentum仍然很强，Fundamental已经转弱。

**这是商品周期后半段最重要的一类信号。**

反过来也一样。某种商品的库存已经开始快速下降，供需缺口扩大，现货市场逐渐收紧，但价格过去一年表现仍然很差。于是出现：Fundamental已经转强，Momentum仍然很弱。

如果随后价格启动，**那么基本面实际上提前识别了下一批Momentum Winner。**

因此，两种策略真正的关系可能不是“谁对谁错”，而是在商品周期中处于不同的位置：基本面变化 → 价格确认 → Fundamental与Momentum共振 → 基本面恶化 → 价格仍有惯性 → Momentum最终反转。

这也解释了为什么两个策略看起来非常相似，长期收益相关性却未必特别高。它们在漫长的趋势中段可能高度重合，但在趋势形成和趋势结束的少数关键阶段发生明显分歧。而拐点附近又往往恰好伴随着较大的市场波动，因此少数分歧月份就足以显著拉低全样本相关系数。

换句话说，一条0.3相关性的基本面CTA和截面动量CTA，并不一定意味着它们每天都在赚不同的钱。真实结构可能是：**大多数时间赚的是类似的钱，只是在最关键的拐点赚得不一样。**这是一种完全不同的分散来源。

## **四、真正的核心矛盾：一个赌经济状态持续，一个赌价格关系持续**

如果一定要用最简单的话概括两种策略，可以这样定义。

**商品截面基本面赚的是Economic State Persistence——经济状态的持续性。**它相信库存紧张不会一天消失，供给约束不会一夜解除，需求变化具有持续性。

**长周期截面动量赚的是Relative Return Persistence——相对价格关系的持续性。**它并不关心价格为什么上涨，只关心过去的Winner未来是否继续跑赢Loser。

因此二者最怕的东西也不一样。

**基本面策略最怕：市场跑得比基本面快。**战争、政策突变、宏观刺激、金融危机，都可能让价格在几天内完成未来几个月经济变化的重新定价，而库存、开工率、产量和进出口数据可能几周以后才反映出来。

**长周期截面动量最怕：市场转得比信号快。**过去一年最强的商品突然成为最弱者，过去最大的Loser突然暴涨。因为长周期信号具有天然惯性，策略很难在第一时间完成方向切换。

所以两类策略在慢速、持续的商品周期中通常最相似；**在趋势启动、周期拐点和突发宏观冲击中最容易分叉。**

## **五、怎么判断一个基本面策略是不是“换皮Momentum”**

这可能比给策略贴什么标签更重要。

最简单的研究方法，**不是看基本面策略和Momentum策略最终净值相关性，而是直接研究信号。**首先看截面相关性：每个月把所有商品的Fundamental Rank与12个月Momentum Rank做相关。

其次看持仓重合率：基本面Top 20%的商品，有多少同时位于Momentum Top 20%？如果长期重合度很高，那么两者共享的风险因子已经非常明显。

然后做一个更严格的检验：把Fundamental对Momentum做正交化。**也就是把基本面信号中能够被过去收益解释的部分剔除，只留下Fundamental Residual。**

如果正交化之后，基本面策略原来的IC和收益大幅消失，**那么所谓基本面Alpha很可能相当一部分只是长周期Momentum的另一种表达。**

反过来，如果Residual Fundamental依然具有稳定的预测能力，尤其能够在“Fundamental强、Momentum弱”的阶段提前识别未来Winner，在“Fundamental弱、Momentum强”的阶段提前识别趋势衰减，那么它才真正提供了Momentum之外的信息。

**这可能才是判断一个商品基本面策略有没有独立价值的关键标准。**

关于动量本身，经典研究也早已表明商品期货存在显著的价格持续性：过去1—12个月的收益具有显著持续性，而更长期又存在一定程度的反转。早期针对商品期货截面Momentum的研究，同样发现按照过去表现买入Winner、卖出Loser具有显著历史收益。

因此，当一个所谓基本面策略表现出非常慢的换手、稳定的截面排序和长期持有基本面强势品种时，FOF至少应该多问一句：**它究竟发现了新的基本面Alpha，还是重新发现了一次Momentum？**

## **六、FOF真正应该警惕的，不是相关性高，而是“共同因子被不同名字掩盖”**

这最终不是一个商品基本面策略是否有效的问题。

基本面策略当然可以有效，长周期截面动量也可以有效。真正的问题是：**在组合配置时，我们到底把它们当成了几个风险源？**

一个组合里可以同时有基本面CTA、Carry CTA、截面动量、长周期趋势。表面上看是四种策略。但到了某个持续数年的全球供需周期里，它们可能同时Long能源、Long有色、Short供给宽松的农产品。

此时所谓“四策略配置”，**可能只是把同一笔交易拆成了四个名字。**

而真正有价值的基本面策略，不应该仅仅在趋势中段与Momentum一起赚钱。**它最有价值的地方，恰恰应该出现在两者发生分歧的时候**：趋势还没形成时，它能不能更早发现？趋势已经过度延伸时，它能不能更早退出？

如果答案都是肯定的，那么商品基本面并不是另一个长周期截面动量CTA。**它更像是一个站在价格趋势上游、帮助判断Momentum生命周期的观察器。**

但如果做完所有正交化和Lead-Lag检验后，剩下的独立Alpha已经寥寥无几，那么我们可能必须接受一个不太令人舒服的结论：**有时候，我们以为自己发现了一种新的策略，其实只是给一个古老的风险因子换了一个名字。**
