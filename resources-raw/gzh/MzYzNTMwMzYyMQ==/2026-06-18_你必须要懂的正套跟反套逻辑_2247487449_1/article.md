# 你必须要懂的正套跟反套逻辑

从股指 Back 到商品 Contango：看懂买近卖远背后的同一个价差逻辑  

![](assets/001.png)

图 1：正套与反套的统一框架

  

****一个最迷惑的问题****

为什么股指正套通常出现在 Back 结构里，而商品正套又常出现在 Contango 结构里？

这件事乍一看很矛盾。股指期货里，常见结构是现货指数高于近月、近月高于远月，也就是远月相对近月更便宜；商品期货里，很多正套机会却来自远月高于近月，也就是远月相对近月更贵。一个是 Backwardation，一个是 Contango，为什么都叫正套？

答案是：正套不是由 Back 或 Contango 定义的，正套由交易方向定义。买近月、卖远月，就是正套。

正套最底层的数学结构

统一设 D = 远月价格 - 近月价格。那么正套 = 买近月 + 卖远月。

正套盈亏 = 近月涨跌 - 远月涨跌 = -ΔD。所以，D 下降，正套赚钱；D 上升，正套亏钱。

这句话特别重要：正套盈利的核心，是远月相较于近月的价差减小。它不是简单等于Back，也不是简单等于Contango，更不是永远等于价差向0收敛。

****为什么股指正套常在 Back 结构里****

股指期货是金融资产定价。理论上，股指期货价格大致受资金成本、分红预期、风险溢价、对冲需求影响。在 A 股股指期货里，尤其是 IC、IM 这类中小盘指数期货，长期容易出现贴水。

原因包括机构需要用期货做空头对冲、远月多头承接不足、中小盘指数风险补偿较高、量化中性等产品带来的空头需求，以及风险偏好较弱时远月贴水加深。

于是期限结构经常表现为：现货指数 > 近月期货 > 远月期货。远月看上去更便宜，但正套仍然是买近卖远，因为正套押的是近月相对远月走强。

近月有一个很强的力量：交割收敛。越接近交割，近月价格越不能长期偏离现货指数，否则期现套利会把价格拉回去。远月离交割还远，仍然可以长期反映风险偏好、对冲压力和空头需求，所以远月贴水可以维持很久。

图2：股指正套和商品正套的结构差异

****为什么商品正套常在 Contango 结构里****

商品期货的逻辑不一样。商品有仓储费、资金利息、保险、损耗、运输、库存管理等现实成本。因此在供给充足、库存不紧张的时候，远月价格高于近月价格是合理的，这就是 Contango。

但合理升水和过高升水不是一回事。如果持有成本只支持 4% 的升水，而市场给了 10% 的远月升水，那么远月就偏贵。此时买近月、卖远月，赚的是远月升水被压缩。

所以商品正套和股指正套看起来方向很反直觉：商品里远月贵，所以卖远月；股指里远月便宜，还是卖远月。底层共同点是一样的：都是希望 D = 远月 - 近月 下降。

****价差减小，有时靠近月，有时靠远月****

正套盈利需要远月 - 近月下降。这个下降可以通过两条路径实现。

第一条路径是近月更强。股指期货里最典型：近月因为临近交割，贴水快速回归；远月因为还远，贴水修复慢。正套赚的是近月贴水回归速度快于远月贴水回归速度。

第二条路径是远月更弱。商品 Contango 里更典型：远月升水偏高，随着时间推移，远月逐渐变近月，过高的持有成本溢价被压缩。正套赚的是远月相对近月走弱。

****正套为什么是价差回归，反套为什么是价差扩散****

类型

交易方向

核心押注

正套

买近月 + 卖远月

D = 远月-近月 下降；期限结构异常被修正

发套

卖近月 + 买远月

D = 远月-近月 上升；期限结构偏离继续扩大

正套通常站在异常定价被修正的一边。商品里，异常可能是远月升水过高；股指里，异常可能是近月贴水过深但临近交割后不可能长期这么深。

反套则相反。反套是卖近月、买远月，它希望远月相对近月走强，也就是 D 上升。在商品 Contango 里，它押远月升水继续扩大；在股指 Back 里，它押远月贴水修复得比近月更快，或者近月相对远月走弱。

**为什么通常说正套风险小、反套风险大**

通常说正套风险小，不是说正套没有风险，而是说它有更多结构性保护。

第一是交割约束。近月越接近交割，越必须向现货靠近。股指期货里，买近月这条腿有交割收敛作为锚。

第二是时间价值。商品里，如果远月升水主要来自持有成本，那么随着时间推移，远月逐渐变近月，升水自然容易被压缩。股指里，近月贴水随着交割临近也更容易回归。

第三是正套通常押异常修复。异常可以持续，但不会无限持续。反套的问题在于，它常常站在这些力量的对面：卖的是最容易回归的近月，买的是最不容易回归的远月，或者买的是已经偏贵的远月。

**最后的判断框架**

不要被 Back 和 Contango 迷惑。真正要问的是：远月 - 近月 这个价差，未来有没有下降的驱动力？

如果下降靠近月完成，就是股指正套常见的近月贴水更快回归；如果下降靠远月完成，就是商品正套常见的远月升水被压缩。方向不同，结构不同，但正套的核心始终是买近卖远，押近月相对远月走强。
