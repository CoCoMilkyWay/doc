# 为什么 Martin 可能比 Sharpe 更好

FundTalk Quantis因子工作室 2026-09-08 14:29 浙江

> 原文地址: [https://mp.weixin.qq.com/s?\_\_biz=MzYzNTMwMzYyMQ==&mid=2247488044&idx=1&sn=9e38027648d015559132666847512ce5&chksm=f13ba7bcbbc658a4997022a8e2d0e48a5fdbdb6f2bbc9faa7a1df0af0aac83515d44a3721d49#rd](https://mp.weixin.qq.com/s?__biz=MzYzNTMwMzYyMQ==&mid=2247488044&idx=1&sn=9e38027648d015559132666847512ce5&chksm=f13ba7bcbbc658a4997022a8e2d0e48a5fdbdb6f2bbc9faa7a1df0af0aac83515d44a3721d49#rd)

如果让我们在两个产品之间做选择：

第一个产品每天都在涨涨跌跌，有时候涨1%，有时候跌1%，看起来并不安静，但净值始终在不断创新高。

第二个产品每天的波动非常小，很少出现超过0.3%的涨跌，但一旦进入回撤，就可能连续半年缓慢阴跌，长时间无法回到前期高点。

**哪一个产品的风险更大？**

如果按照传统波动率衡量，第一个产品的风险可能更高。因为它的日收益率更加分散，标准差更大。但如果问真正持有这两个产品的投资者，答案可能恰恰相反。

这引出了一个比“Sharpe Ratio是否好用”更加根本的问题：我们在评价一个投资策略时，究竟应该如何定义风险？

Sharpe Ratio给出了一个非常经典的答案：风险是波动。而Martin Ratio给出的答案却完全不同：**风险可能不是净值有多抖，而是投资者在水下待得有多深、又有多久。**

**这两种风险观的差异，可能比两个指标本身更加重要。**

一Sharpe的本质，是把风险定义成“不确定性”

  

  

Sharpe Ratio的公式几乎所有投资者都非常熟悉：

Sharpe = (Rp - Rf) / σp

分子是超额收益，分母是收益率标准差。

它背后的逻辑非常优美：如果两个策略获得相同的收益，那么收益波动更小的那个策略风险收益效率更高。

因此，**Sharpe真正衡量的是：每承担一单位收益率的不确定性，我们获得了多少收益。**

从现代投资组合理论的框架来看，这是非常自然的。

问题在于，**标准差对“风险”的定义，与投资者真实感受到的风险并不完全相同。**

假设一个策略今天上涨5%，另一个策略今天下跌5%。从投资者角度看，两件事情显然不同。但对于方差而言，只要它们距离平均收益的幅度相同，两者都会被视为波动。

**换句话说：Sharpe并不知道什么叫“好的波动”。**

上涨过快是波动，下跌过快也是波动。只要收益偏离均值，就会增加分母。

这就产生了一个很有意思的问题。假设一个趋势策略经常出现较大的单日上涨，同时也有不少反向波动，但净值不断创新高；另一个策略每天波动非常小，却长期缓慢阴跌。

按照波动率，第一个策略可能风险更大。但站在投资者角度，**真正令人痛苦的，往往不是净值今天涨了多少、跌了多少，而是自己的账户已经多久没有回到历史高点。**

这就需要另一种风险定义。

二如果风险不是波动，那是不是最大回撤？

  

  

从投资者体验出发，一个非常自然的想法就是：既然波动率不能完全代表痛苦，那就直接看回撤。

于是我们有了Maximum Drawdown，以及非常常用的Calmar Ratio：

Calmar = Annualized Return / Maximum Drawdown

这已经比Sharpe向真实持有体验迈进了一大步，因为最大回撤开始关心投资者真正亏过多少钱。

但最大回撤又存在另一个非常明显的问题：**它几乎把整个历史压缩成了一个最坏的点。**

假设有两个策略。

A策略遭遇一次突发冲击，净值从1.00快速跌到0.90，最大回撤-10%，但两周以后就重新回到1.00。

B策略同样最大回撤-10%，但它是从1.00缓慢跌到0.90，然后在0.90—0.95之间震荡了一整年，始终无法回到前期高点。

如果两者长期收益相同，那么它们的Calmar Ratio可能非常接近。

但持有体验显然完全不同。

A的痛苦是：深，但短。

B的痛苦是：不仅深，而且漫长。

这说明，仅仅知道“最惨的时候亏了多少”，依然不足以描述一条净值路径。

**我们还缺少一个变量：时间。**

三Ulcer Index：把“回撤深度”和“回撤时间”放到了一起

  

  

这正是Ulcer Index非常有意思的地方。

首先计算每一天的回撤：

DDt = NAVt / max(NAVs, s≤t) - 1

如果今天净值创新高，DDt=0；如果今天距离历史最高点低5%，DDt=-5%；如果距离历史最高点低10%，DDt=-10%。

然后把整个统计区间里的所有回撤平方、平均，再开平方：

UI = √\[ (1/N) × Σ(DDt²) \]

这个公式看起来和标准差有一点像，但两者实际上在衡量完全不同的东西。

标准差计算的是：每一天的收益率距离平均收益有多远。

**Ulcer Index计算的是：每一天的净值距离自己曾经达到过的最高点有多远。**

这个区别非常重要。

四Ulcer Index真正聪明的地方，是让“时间”自动进入风险

  

  

继续用刚才两个最大回撤都是-10%的产品。

A跌到-10%以后迅速修复。那么它可能只有很少几个观测点处于-10%、-8%、-5%、-2%……随后很快重新回到DD=0。

但B不同。如果它一年都没有创新高，那么可能连续几百个交易日都是-5%、-6%、-8%、-7%、-9%……

这些数字会一个不少地进入Ulcer Index。

因此即使MDD\_A=MDD\_B，仍然很可能UI\_B>UI\_A。

这就是Ulcer Index相比Maximum Drawdown更贴近持有体验的地方。

它没有单独设置一个所谓的“回撤时间参数”。**时间实际上已经自然包含在公式里。**

因为你在水下多待一天，就会多产生一个非零的DDt²。待一个月，就累计一个月；待一年，就累计一年。

与此同时，它又通过平方对深度进行非线性惩罚。

所以，长期处于-3%，会产生痛苦；长期处于-10%，会产生更大的痛苦；短暂跌到-10%然后迅速修复，与一年都在-10%附近徘徊，也会得到完全不同的结果。

这使得**Ulcer Index实际上同时包含了两个维度：Drawdown Depth × Drawdown Duration。**

回撤有多深，以及回撤持续了多久。

五Martin Ratio其实只是做了一件事：换掉Sharpe的分母

  

  

理解Ulcer Index以后，Martin Ratio就非常容易理解了：

Martin = (Rp - Rf) / Ulcer Index

与Sharpe放在一起看：

Sharpe = (Rp - Rf) / Volatility

Martin = (Rp - Rf) / Ulcer Index

两者分子几乎没有本质区别，真正的区别全部集中在分母。

所以Martin Ratio并不是简单地发明了一个“新的收益风险比”。

**它真正做的事情，是重新定义风险。**

Sharpe问：为了获得这些收益，我承担了多少收益率波动？

Martin问：为了获得这些收益，我经历了多少持续性的回撤痛苦？

这就是两者最根本的区别。

六Martin为什么更接近真实的“持有体验”？

  

  

假设有三个年化收益完全相同的策略。

A策略每天波动很大，但是不断创新高。

B策略波动不大，但是每隔一段时间就进入三个月左右的回撤。

C策略波动最小，但一旦进入回撤，可能一年都无法创新高。

按照Sharpe评价，很可能C的Sharpe最高，因为C的单期收益最稳定。

但如果看Martin，排名完全可能反过来。

因为A虽然“抖”，但它大量时间都在历史高点附近；C虽然“不抖”，却长期处于水下。

这其实揭示了一个很反直觉、但对FOF非常重要的问题：

**低波动，不一定等于低痛苦。**

一个策略每天上下震荡1%，但每隔几周就创新高，投资者未必很难受。

另一个策略每天只跌0.1%，却连续跌半年，投资者反而可能最终选择赎回。

Sharpe更喜欢前者还是后者，取决于收益率分布。

Martin则更加直接地观察：你的钱究竟有多少时间处于亏损状态。

七从FOF角度看，“水下时间”可能比波动率更加现实

  

  

为什么这个问题对FOF尤其重要？

因为**FOF管理的不是一组回测指标，而是真实资金。**

理论上，一个策略最终能够赚钱，并不意味着投资者能够一直拿到它赚钱的那一天。

一个产品五年年化收益15%、Sharpe 1.5，看起来非常优秀。

但如果其中有两年时间都没有创新高，真正的问题可能不是这个策略有没有Alpha，而是：客户能不能坚持两年？管理人自己能不能坚持？FOF基金经理会不会在最差的时候把它赎掉？

这时候风险已经不再只是统计意义上的Volatility Risk。

**它开始变成一种更加现实的Holding Risk——持有风险。**

而Ulcer Index恰恰在试图描述这种风险。

因为对于真实投资者而言，“亏10%”只是一个数字。

“亏10%以后18个月都没有回来”，才是一段真实经历。

八Martin与Sharpe，本质上是两种不同的风险观

  

  

所以，我们其实不需要争论Martin和Sharpe到底谁更科学。

**真正的问题是：你究竟想衡量什么？**

如果你认为风险就是收益的不确定性，那么Sharpe的逻辑非常完整。

如果你在做资产配置、组合优化，需要一个具有良好统计性质的均值—方差框架，Volatility依然非常重要。

但如果你真正想评价一个策略究竟好不好拿、投资者需要忍受多长时间的亏损、净值是不是经常陷入漫长的水下期，那么Martin可能比Sharpe更接近你真正的问题。

这也是为什么更适合把它们理解成两种风险观。

Sharpe的风险观是Uncertainty：收益偏离预期越大，风险越大。

**Martin的风险观是Pain：距离历史高点越远，而且在那里停留越久，风险越大。**

前者更接近统计学。

后者更接近真实投资体验。

九Martin也不是终点

  

  

当然，Martin仍然不是一个完美指标。

例如一条净值长期横盘，最后突然上涨30%。如果整个横盘过程中几乎没有明显回撤，那么Ulcer Index可能非常低，最终Martin反而非常漂亮。

但很多投资者仍然不会认为这是一条非常理想的净值曲线。

因为这里还有另外一个问题：收益兑现是否足够均匀。

Martin很好地回答了“你在水下有多痛苦”，但并没有完整回答“你的财富是不是持续稳定地增长”。

所以Martin仍然不能成为一个所谓的“终极指标”。

但这并不妨碍它提供了一个非常重要的视角。

它提醒我们：**风险不一定只能从收益率出发定义，也可以从投资者实际经历的财富路径出发定义。**

结语风险究竟是“波动”，还是“痛苦”？

  

  

Sharpe Ratio伟大的地方，在于它把收益和风险压缩成了一个极其简单的数字。

但这种简洁也容易让我们忘记：波动率只是风险的一种定义。

一个产品可以波动很大，却不断创新高；也可以波动很小，却让投资者连续一年处于亏损状态。

如果我们真正关心的是“这个策略好不好拿”，那么后者显然不能被称为低风险。

Martin Ratio最值得关注的地方，也正在这里。

它没有试图预测尾部风险，也没有建立一个复杂的时间序列模型。它只是把Sharpe的分母，从“收益率有多不稳定”，换成了“投资者在水下究竟有多痛苦”。

**看起来只是换了一个分母，背后却是完全不同的风险哲学。**

Sharpe把投资者放在概率分布面前，问：“这些收益有多不确定？”

Martin把投资者放回净值曲线上，问：“你距离曾经拥有过的最高财富有多远，而且已经在那里待了多久？”

对于真正需要持有一个产品三年、五年甚至更长时间的投资者而言，后一个问题有时候可能更加重要。

因为真实投资中，风险从来不只是净值有多抖。

**风险也是跌下去以后，你究竟要等多久才能回来。**
