**0****3**

**归因层：是真异质alpha，还是风格参与**

  

  

收益只是表象，来源才决定可持续性。从群体中枢看，私募的优势不只体现在收益，也体现在alpha：在风格剥离后，私募CNE截距alpha中枢仍有6.3%，公募则为-0.7%。

但这也不是“私募完全不靠风格”的故事。私募的CNE解释度R2中枢为0.52，公募为0.50，说明部分私募超额仍带有较强的可解释风格成分。因此，更准确的说法是：私募的赢法里，既有风格参与，也有更扎实的残差alpha；而公募更像是在较低的残差alpha基线上参与。

下图展示的是公募与私募500指增产品在 CNE 风格因子上的中位暴露差异。整体看，私募相较公募更明显地呈现出“下沉 + 高波动 + 高流动性”的风格特征：在 size 与 nonlinear\_size 上负暴露更深，说明组合更偏向中小市值和尾部小盘；同时在 residual\_vol 与 liquidity 上暴露更高，说明其超额获取更依赖高波动、高换手的股票池。相对地，公募在 momentum 与 earnings\_revision 上的正暴露更突出，在 beta 上也更偏负，说明公募整体更像是偏稳健、偏基本面修正和趋势跟随的中盘增强框架。换句话说，这张图支持这样一个判断：私募优势更明显地把风格重心放在中小盘、高波动、高流动性资产上。

  

![](assets/009.png)

**口径说明：**将CNE标准化风格暴露按公募、私募分别取中位数，展示两类产品的中枢风格差异。

  

超额来源地图横轴为 CNE解释度R² ，纵轴为 CNE截距Alpha（年化），从而把不同管理人的超额来源拆成“风格驱动”与“残差Alpha驱动”两部分。越靠右说明超额越容易被 CNE 风格因子解释，越靠上说明即使剔除风格后仍保留较强的独立 alpha。整体看，私募样本更多分布在右上区域，意味着既存在一定风格成分，也保留了更高的残差 alpha；公募则更多落在中下部，说明其超额中枢更低、风格解释后的独立 alpha 相对有限。因而这张图支持的核心判断是：****私募优势不只是****“更偏某类风格”，也来自风格剥离后仍可识别的真实** **alpha** **生产能力。****

  

![](assets/010.png)

CNE风格暴露矩阵热力图展示了各产品相对中证500在 CNE 十个标准风格因子上的标准化暴露，颜色深浅表示暴露方向和强弱，格内星号表示统计显著性。横向看，每一行是一只产品的“风格指纹”；纵向看，可以比较哪些因子在行业里更常见、哪些因子只集中出现在少数管理人身上。整体上，私募样本在市值、非线性市值、残差波动、流动性等因子上的暴露更分散、也更显著，说明私募更容易通过中小盘、高波动、高换手资产去形成超额；公募则在 beta、动量、盈利预期等因子上更常见，风格分布更均衡也更收敛。****这张图更适合回答****“每个管理人的底层风格暴露是什么”，而不是直接回答谁更强。****

  

![](assets/011.png)

如果把Proxy结果和CNE结果放在一起看，研究的重点就更清楚了：不是简单判断它有没有风格暴露，而是判断它到底更依赖哪一种暴露，以及在剥离这些暴露之后，还剩下多少可被视作真实能力的alpha。私募中位Proxy alpha为9.8%，公募为4.2%。

Proxy因子回归系数矩阵图使用 Large(300-500)、Small(1000-500)、LowerSmall(2000-1000)、Micro(微盘-2000)、Dividend(红利-500) 五个 proxy 因子，对产品相对500的周度超额做静态回归，颜色代表回归系数大小，星号代表显著性。它的重点不是绝对收益，而是看超额更偏向哪个“规模/风格锚点”：如果 Small、LowerSmall、Micro 同时较高，说明产品更明显地下沉到更小市值和微盘；如果 Dividend 为正且显著，则说明组合更偏红利防御。****整体看，多数私募在****Small** **与** **LowerSmall** **上有更显著的正暴露，表明私募超额的一个重要来源是中小盘乃至更小盘方向的结构性偏离；而真正显著的** **Micro** **暴露只集中在少数产品，说明“微盘强化”并不是所有私募都依赖的统一打法。****

**0****4**

**路径层：同质化才是赛道真正的风险**

  

  

只看结果和来源，还不足以解释一只产品到底值不值得长期研究。因为即便收益成立、归因也说得通，不同产品之间的“走法”仍然可能很不一样：有的更接近行业共识，有的则保留了更多非共同部分。路径层真正要补上的，就是这部分差异。

在这一层里，PCA（主成分分析）的作用，不是给产品做收益排名，而是把样本中那些“大家共同在赚的模式”先抽出来，再看单个产品和这些共同模式的关系。换句话说，PCA 在这里更像一个****路径结构和共识度识别工具****：它帮助我们判断，哪些产品更像在复制行业共同模式，哪些产品保留了更多不能被共同模式解释的部分。

从整体样本看，前 1 至前 5 个主成分的累计解释度约为：K=1 时 44.9%，K=2 时 56.0%，K=3 时 62.3%，K=5 时 68.8%。这说明 ****500** **指增样本内部确实存在较明显的共同结构，但共同模式之外，仍保留了一部分未被前几主成分吸收的非共同波动。****

  

![](assets/013.png)

基于这一结果，本文进一步使用前 5 个 PCA 因子的累计解释度 r2\_top5 来刻画产品的“共识程度—非共同部分”差异。横轴表示前1个共同因子对产品收益的解释度，反映其对第一共同模式的依赖程度；纵轴表示前5个共同因子对产品收益的累计解释度。累计 R² 越高，说明产品收益越像行业共同模式的组合，共识度越高；累计 R² 越低，则说明产品保留了更多不能被共同模式解释的非共同部分，结构上相对更独特。需要强调的是，****这里的****“独特性”并不直接等于** **alpha** **更强，它只是说明该产品与行业主流共同模式的重合度更低。****

样本内像 JK、SF、WB、ZS、YF 这些点，基本都落在右上区域，说明它们更接近“行业共识打法”——不是说它们不好，而是说它们的收益结构和当前主流模式重合度更高；而像 LS、JF、GY1、XS、YH、HS 这些落在左下或偏左下区域的产品，则说明它们被共同模式解释得更少，收益里保留了更多“非共同部分”，结构上会更显得有自己的东西。

  

![](assets/014.png)

从稳健性看，r2\_top5 作为“共同模式解释度”指标整体稳健。滚动窗口下，其相对全样本排序的 Spearman 相关中位数为 0.925，bootstrap 下中位数为 0.887，说明该指标能够较稳定地区分产品的“共识程度—非共同部分”差异；leave-one-out 检验中，中位数高达 0.998，也表明其并非由个别极端样本驱动。但与此同时，bootstrap 5% 分位降至 0.556，且产品层面 90% 区间宽度中位数约 24.4 个百分点，说明该指标更适合用于分层和分组，而不适合用于非常细的名次比较。****换句话说，****PCA** **更适合帮助我们识别“谁更像共识打法、谁更保留非共同部分”的大致层次，而不宜据此对相近产品做过度精细的排序。****

  

**小结**

在共识度识别之外，如果进一步把结果层、归因层和路径层的关键信息合并到同一张图里，就能看到更接近配置语境的产品画像。下面这张图已经把产品的大致配置画像拉开了：右上区域更像“高质量且差异化强”的重点候选，如JF、SQ、TW、HJ，左上区域更像“高质量但偏共识型”的稳态产品，如YF、PF、JH。

  

![](assets/015.png)

**方法说明：**横轴取独特性分数，纵轴取质量分数 steady\_score 的分位值，点大小表示年化超额，颜色表示配置角色。质量分由 IR、年化超额、周胜率和超额回撤等权构成；独特性同时考虑相关性、PCA共同模式依赖与CNE风格解释度。气泡大小代表年化超额，越大说明超额收益水平越高；气泡颜色代表配置角色，蓝色偏核心底仓类，橙色偏差异增强类。

  

**我们简单评述几个代表产品（建议结合产品的定性尽调以及商务条款进行判断）：**

SQ：综合质量非常靠前，结果层最均衡，年化超额 14.5%、IR 3.06、超额回撤仅 -3.9%；归因层上 CNE alpha 较高而 CNE R2 偏低，说明并非单纯依赖显性风格暴露；Proxy 端虽然也呈现小盘下沉与弹性成长特征，但 PCA 前5因子 R2 仅约 60%、共同模式依赖不算高，更像“高质量且保留独立 alpha”的核心跟踪对象。

TW：结果层非常干净，年化超额 10.3%、IR 2.52、超额回撤仅 -2.9%，滚动 52 周为正比例达到 100%；CNE 端 alpha 为正、R2 较低，PCA 前5因子 R2 约 52%，独特性分数在样本中靠前，说明其超额并不高度依赖行业共同模式；结合 Proxy 的更小盘、弹性成长暴露，它更像“可解释、可持续、适合做差异增强”的产品。

JF：结果层最强之一，年化超额 23.3%、IR 2.04，而且滚动 52 周为正比例达到 100%；归因层是典型的残差 Alpha 驱动，CNE alpha 很高而 CNE R2 很低，PCA 前5因子 R2 仅约 40%，共同模式依赖很弱；Proxy 上虽同样受益于小盘下沉和弹性成长环境，但整体仍更像“真 alpha 型高弹性品种”，最值得持续跟踪。

YF：结果层与路径层都很强，年化超额 16.7%、IR 1.77、周胜率 72.6%、滚动 52 周为正比例 100%；CNE 上仍可归入残差 Alpha 驱动，但 PCA 前5因子 R2 约 88%，说明它对共同模式的参与度较高；因此更适合定义为“高质量、可持有、但并不算最独特”的核心底仓型产品。

JH：结果层非常突出，年化超额 17.7%、IR 1.91、超额回撤控制也较好；CNE alpha 高、R2 中等，说明既有真实 alpha，也有一定风格参与；Proxy 和风格位置都显示其对小微盘链条适应度较强，而 PCA 前5因子 R2 约 82%，意味着它更像“主流共同模式里的高效执行者”，适合放在组合核心而非纯差异化仓位。

HJ：综合质量居前，年化超额 15.1%、IR 2.02，结果层在超额回撤方面有一点缺陷；归因层上 CNE alpha 较高，CNE R2 不算特别低，但仍保留了较强残差 alpha 特征；PCA 前5因子 R2 约 62%，共同模式依赖不高不低，配合 Proxy 上的微盘邻近和弹性成长特征，更像“结果和来源都讲得通”的高质量增强型产品。

KD：结果层很强，年化超额 16.4%、IR 1.83，路径稳定性也较好；但从归因层看，CNE R2 与 PCA 前5因子 R2 都不低，Proxy 和风格位置也更明显地指向小微盘/流动性链条，因此它更像“高质量风格型产品”，适合在看多小盘下沉时配置。

PF：年化超额 18.0%、IR 1.83，结果层同样足够强；只是 CNE 与 PCA 两端都显示其公共模式参与度偏高，Proxy 端的小微盘风格暴露也更鲜明，因此更适合放在“风格主线承接者”而非“独立 alpha 补充者”的位置来理解。

中欧：在公募样本里更值得优先看，结果层虽然不如头部私募，但年化超额 5.9%、IR 1.38、超额回撤仅 -4.0%，路径相对平顺；CNE alpha 在公募中相对更好，CNE R2 和 PCA 前5因子 R2 也不算高，独特性在公募里较突出，属于“公募里更有自己东西”的产品。

长城：结果层在公募中较完整，年化超额 6.4%、IR 1.58，回撤和持续性也不差；归因层上主要还是盈利预期因子驱动，但 CNE alpha 仍为正，PCA 前5因子 R2 约 48%，共同模式依赖不高，放在公募内部看，是一只相对均衡、可继续跟踪的增强型产品。

  

**0****5**

**配置层：费后收益，才是真正拿到手的东西**

  

  

****走到配置这一步，问题其实已经不再只是****“谁的超额更高”，而是：在结果层、归因层、路径层都看过之后，这份收益到底能不能真正落到投资者手里。****前面几层分析解决的是“这只产品看起来好不好”，配置层要解决的则是“这份好，经过费率、业绩报酬和持有约束之后，还剩下多少”。

  

![](assets/016.png)

在当前样本超额中枢假设下(公募alpha 4.2%，私募毛alpha 10.9%)，我们讨论三种常见收费模式：公募费后收益、私募超额提成20%和私募绝对收益提成20%。在目前这组超额水平下，****私募超额收费模式的费后收益整体始终优于公募****，因为收费只针对alpha，不会明显侵蚀beta收益；而****私募全额收费模式只在****beta****不高时更有优势****，随着基准收益走强，收费对总收益的侵蚀越来越明显，大约当****beta****超过****29%****后****，费后收益会被公募反超。

右图是在回答“私募要做到多少毛alpha，费后才能追平公募”。在给定公募alpha为4.2%的情况下，****私募如果采用超额提成****20%****模式，只要毛****alpha****维持在约****5.25%****左右，就能持续保持竞争力****，而且这个门槛基本不随beta变化；但如果采用****全额提成****20%****模式，随着****beta****强化，私募要追平公募所需的毛****alpha****会不断上升。****例如，假设基准beta为10%，私募全额收费大约需要做到7.6%左右的毛alpha才能追平公募。即beta越强，全额收费对私募竞争力的侵蚀越明显。

也正因为如此，500 指增的研究不能停留在表面的收益排名。结果层告诉我们，哪些产品具备更强的超额能力与更好的稳定性；归因层帮助我们区分，这些收益到底更依赖风格暴露，还是更来自可持续的异质 alpha；路径层进一步提示我们，哪些收益更稳、哪些更拥挤、哪些更具有独特性。只有把这些问题都看清楚之后，再去讨论费后收益，配置判断才真正完整。

换句话说，配置层并不是附加题，而是前面所有分析最终落地的地方。因为投资者真正买到的，不是报表上的毛收益，也不是图表里的纸面 alpha，而是扣除管理费、业绩报酬之后，仍然能够留下来、并且值得长期持有的那部分回报。对 500 指增来说，真正更值得研究、也更值得配置的，从来不是某一段时间跑得最快的产品，而是那些在结果、来源、路径和费后口径下都更经得起推敲的产品。

  

**0****6**

**结  语**

  

  

回到这篇文章本身，我们真正想推进的，其实不是一个简单的“谁更强”的结论，而是一种更接近投资决策的研究方式。把 500 指增的研究，尽量放进一个更可拆解、可讨论、也更接近投资决策的分析框架里：先看结果是否成立，再看收益从哪里来，再看路径是否稳、是否拥挤，最后再看这些收益在费后口径下还能剩下多少。 只有沿着这条线往下看，500 指增产品之间那些原本容易被混在一起的差异，才会慢慢变得清楚。

当然，这样的分析也一定有边界。样本区间、市场风格、费率规则、产品数量和可得数据，都会影响我们最后看到的图景。也正因为如此，这篇文章更像是一份阶段性的研究记录，而不是一份可以替代长期定性跟踪与最终配置判断的标准答案。
