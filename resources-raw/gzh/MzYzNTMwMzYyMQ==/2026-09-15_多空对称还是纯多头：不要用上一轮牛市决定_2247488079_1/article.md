# 多空对称还是纯多头：不要用上一轮牛市决定下一轮策略

FundTalk Quantis因子工作室 2026-09-15 14:01 浙江

过去几年，一个越来越明显的现象是，很多投资人开始偏好纯多头策略。

这种偏好并不难理解。

如果市场长期处于上涨环境，纯多头策略的持有体验通常更好：上涨时参与，下跌时减仓，最差不过退到空仓。相比之下，多空对称策略可能在一次中等幅度调整中翻空，结果市场很快重新上涨，模型又不得不止损、翻多。

于是从净值曲线上看，纯多头经常显得更顺滑，也更符合直觉。

投资人自然会问：既然很多资产长期来看本来就是上涨的，为什么还要允许模型做空？

尤其是经历了一轮持续数年的多头市场之后，这个问题会越来越有吸引力。

**但这里可能隐藏着一个典型的策略选择错误：我们正在用上一轮牛市的市场结构，决定下一轮应该配置什么策略。**而 Long-only 和 Long/Short 真正的区别，恰恰只有在市场状态发生明显改变时，才会充分体现出来。

SECTION 01

一、Long-only和Long/Short，赚的并不是同一种钱

纯多头趋势策略，大致可以理解成：资产长期风险溢价，加上一层趋势择时。

资产上涨时持有，趋势转弱时减仓，趋势进一步恶化时退到现金。它真正改善的是持有资产的路径。

如果一个资产长期从100涨到200，中间经历几轮调整，纯多头趋势策略可以尽量参与主升段，同时在趋势恶化时降低风险。所以它隐含的前提仍然是：我认为这个资产长期值得持有，只是希望通过趋势模型改善买入和持有的过程。

多空对称策略则不同。它并不预设资产长期必须上涨。趋势向上时做多，趋势向下时做空。它试图赚取的不是单纯的资产风险溢价，而是价格持续运动本身所形成的趋势收益。

这个区别在牛市中并不一定明显。假设一个资产长期从100涨到200，那么Long-only和Long/Short大部分时间都会持有多头，甚至Long-only还可能表现更好。因为市场每发生一次中等幅度调整，多空对称模型都有可能产生一次错误做空：+1 → 0 → -1 → 止损 → +1；而Long-only只需要：+1 → 0 → +1。

所以在一个长期上涨、但中间频繁调整的市场里，做空这个额外自由度完全可能成为一种成本。这也是为什么过去几年，越来越多投资人开始觉得：“好像没有必要做空。”

但如果市场从100不是涨到200，而是跌到50，情况就完全不同了。纯多头策略能够做到的最好结果，是逐步退出市场：100%多头 → 降仓 → 空仓。也就是说，它最多做到“不参与下跌”。

多空对称模型则可以继续：多头 → 空仓 → 空头。一旦下跌趋势足够持续，熊市本身就会变成收益来源。

**因此，两者真正结构性的区别是：面对长期熊市，Long-only最理想的状态通常是少亏甚至不亏；Long/Short则有可能直接从熊市中赚钱。**

SECTION 02

二、2010—2015年的商品熊市，是一个非常好的历史案例

今天回头看这一点，最典型的案例之一，就是2010-2020年代前半段的大宗商品市场，2011-2015南华商品指数腰斩。

从2011年前后开始，很多商品逐步进入长期熊市。其中有中国需求增速下降、全球产能扩张、美元走强、能源供给增加等多重因素。如果观察广义商品指数，会发现2011年以后相当长时间都处于明显承压状态。

原油尤其典型。2014年下半年开始，国际油价从100美元以上一路跌到几十美元。铁矿石、工业金属和很多其他商品也经历了持续时间很长的下跌。

对于Long-only商品配置来说，这是一段非常不友好的环境。即便模型拥有趋势过滤功能，最成功的操作通常也只是：越来越少持有这些商品。也就是说，Long-only可以成功规避熊市，却很难把熊市本身转换成收益，大概率这个过程还是会通过磨损的方式亏不少钱。

但就在这样一个商品大熊市环境里，全球最知名的CTA管理人之一元盛——Winton Capital Management——并没有出现与商品指数同步的长期亏损。

Winton当时最接近经典CTA形态的策略叫做 Winton Futures Program，更早以前称为 Winton Diversified Program Without Equities。美国SEC公开文件披露的历史业绩显示：2010年约+14.27%；2011年约+6.68%；2012年约-3.24%；2013年约+7.98%；2014年约+15.23%；2015年约+1.72%。

也就是说，在大宗商品整体并不景气、甚至经历长期熊市的阶段，元盛的系统化期货策略仍然能够获得相当可观的累计收益。

当然，不能简单把这些收益理解为“元盛靠做空商品赚了很多钱”。Winton本质上是一个跨资产CTA，同时交易商品、债券、外汇、股指等大量全球市场。例如2014年就是非常典型的趋势年份：原油大跌、美元走强、债券上涨，多类资产同时形成持续趋势。

**所以这个案例真正证明的不是“空商品一定赚钱”，而是：一个多空对称、跨资产的趋势系统，可以在传统Long-only资产缺乏上涨beta的环境中，继续寻找收益来源。**

如果当时持有的是Long-only商品组合，最重要的问题是“怎么少亏”；但对于Long/Short CTA，问题变成了“这轮下跌趋势能不能成为我的收益来源”。这就是策略结构的差异。

SECTION 03

三、为什么牛市越长，投资人越容易低估做空的价值

有意思的是，投资人通常并不是在熊市里放弃做空。恰恰相反，真正容易放弃Long/Short的，往往是在持续多头市场之后。

原因很简单。假设过去五年一个资产总体上涨了100%，期间每年都出现过一次10%—20%的调整，但每次都很快创新高。

那么纯多头模型可能不断重复：持有 → 减仓 → 重新持有；而多空模型可能不断重复：持有 → 减仓 → 做空 → 被反弹止损 → 重新做多。

时间一长，净值上会非常明显：Long-only吃到了长期beta；Long/Short却不断为“错误做空”付成本。此时投资人自然会问：既然做空过去几年一直在拖累收益，为什么不直接删掉？

**这个逻辑听起来完全合理，但其中有一个隐含假设：未来的市场依然会像过去几年一样。**

如果下一轮市场不是“跌15%以后快速创新高”，而是“跌20%以后继续跌20%，然后再跌20%”，两类策略的表现就会迅速分化。纯多头已经降到了0，再也没有新的收益来源；多空策略却可以继续增加空头暴露。

这也是为什么，做空的价值非常像保险。长期没有发生火灾时，保险费看起来永远是一笔成本；真正发生火灾以后，才会突然发现，此前那笔长期看似没有贡献的支出，恰恰对应着组合中最稀缺的保护。

SECTION 04

四、但这并不意味着Long/Short一定优于Long-only

如果文章写到这里就得出“多空对称更好”的结论，同样是错误的。

Long-only拥有非常现实的结构优势。很多资产确实存在长期向上的漂移。股票有企业盈利增长；黄金存在货币和通胀长期支撑；商品也受到长期名义价格变化影响。因此，Long-only天然站在长期beta的一边。

如果一个市场未来继续表现为：长期上涨 + 中间快速回撤 + 回撤后迅速修复，那么Long-only完全可能长期跑赢Long/Short，因为它避免了一个非常重要的错误来源：做空一个长期上涨的资产。

多空策略的额外自由度，只有在趋势足够持续时才会转化为价值。如果市场频繁反转，额外自由度反而意味着更多whipsaw。

**所以真正的结论从来不是Long/Short比Long-only高级，而应该是：两种策略针对的是不同的市场状态。**

Long-only更适合获取资产长期上涨的风险溢价，并改善回撤；Long/Short更适合在不预设方向的情况下捕捉持续趋势。一个依赖“资产长期上涨”，另一个依赖“价格存在持续趋势”。这两者不是一回事。

SECTION 05

五、真正需要警惕的是：策略选择也会顺周期

很多投资人在资产配置时，会认真警惕追涨杀跌。但在选择策略时，反而经常犯完全相同的错误。

过去五年Long-only表现更好，于是更多资金进入Long-only；过去五年做空信号经常失效，于是逐渐降低做空权重；过去五年资产长期上涨，于是开始认为Long/Short已经过时。

这其实就是另外一种形式的追涨。只不过追的不是某个资产，而是过去几年最适应当前市场状态的收益函数。

如果2010—2015年的商品熊市发生在今天，投资人的策略偏好可能完全相反。经历连续几年商品下跌以后，投资人也许会重新发现：原来“能够做空”本身就是一种稀缺能力。

**所以一个很值得警惕的现象是：市场越久没有出现长期熊市，投资人越容易降低对Long/Short的估值；而当长期熊市真正出现以后，这种能力的价值又会突然上升。这本质上也是一种典型的风险定价周期。**

SECTION 06

六、对于组合管理而言，问题更不能只看单策略收益

如果只观察一只产品，Long-only过去几年可能确实比Long/Short漂亮。

但对于FOF或者多资产组合而言，更重要的问题不是“哪只产品过去收益更高”，而是：整个组合已经拥有了什么，又缺少什么？

假设一个组合中已经有股票多头、红利、微盘、海外权益、黄金和商品多头。这些资产和策略名称看起来非常不同，但它们可能共享一个重要特征：资产上涨的时候，它们普遍更容易赚钱。

此时再加入一个Long-only趋势策略，虽然可以改善择时，但并没有从根本上改变组合的方向属性。它仍然属于“上涨更舒服，下跌少亏”。

但真正的Long/Short CTA提供的是另一种收益函数：持续下跌也有机会赚钱。

从单策略角度看，它过去几年可能并不占优；但从组合角度看，这种收益来源可能反而更加稀缺。

所以评价Long/Short，不能只看它自身的Sharpe，还应该看：它为整个组合补充了什么市场状态下的盈利能力。

**如果一个组合已经有大量Long beta，那么Long/Short的边际价值，往往比它单独的历史收益率更值得关注。**

SECTION 07

七、纯多头还是多空对称，最终应该怎么选？

这个问题没有一个统一答案。

首先，要看这笔资金承担什么任务。

如果目标是获得资产长期上涨收益，同时尽量降低回撤，那么Long-only是非常合理的设计。它本质上是：Beta + Timing。

但如果目标是构建一个尽可能不依赖资产长期上涨的绝对收益来源，那么Long/Short的结构更加完整，因为它并不需要提前假设未来十年资产价格一定向上。

其次，要看组合缺少什么。如果组合本身已经充满了风险资产，那么再增加Long-only，边际分散价值可能有限。

反过来，一只最近几年表现普通的Long/Short CTA，如果能够在长期熊市、强美元周期、商品大跌或者其他极端趋势环境里提供正收益，它对组合的意义可能远远高于表面的Sharpe。

**最后，还要问一个最重要的问题：如果下一轮市场和上一轮完全不同，我希望这笔钱在组合里扮演什么角色？**

如果商品重新经历一次类似2011—2015年的持续熊市怎么办？如果股票不再是跌20%以后半年创新高，而是进入持续三年的下跌怎么办？如果未来又出现一次类似2014年的跨资产大趋势怎么办？

一旦把这些问题加入策略选择框架，Long-only与Long/Short之间的权衡就会变得完全不同。

SECTION 08

结语

过去几年多头市场表现很好，自然会让越来越多投资人喜欢纯多头策略。这种偏好本身没有问题。真正值得警惕的是，把最近几年的优势误认为长期结构性优势。

2010—2015年的商品熊市，以及同期元盛这类经典CTA的表现，提供了一个很好的历史提醒：当市场长期单边下跌时，“能不能做空”并不是一个细节，而可能直接决定两种策略拥有完全不同的收益空间。

**Long-only的优势，是在上涨世界中更加高效地获取长期风险溢价；Long/Short的优势，则是在不预设方向的情况下，把上涨和下跌都转换为潜在收益来源。**

前者更适合一个长期向上的世界；后者真正的价值，往往要等到一个长期熊市出现以后，才会重新被认识。

结论 · CONCLUSION

投资中最容易犯的错误之一，就是在一个策略最不需要的时候放弃它，然后在它最有价值的时候重新买回来。

所以面对纯多头和多空对称的选择，真正值得记住的原则也许只有一句：不要用上一轮牛市，决定下一轮应该拥有什么策略。
