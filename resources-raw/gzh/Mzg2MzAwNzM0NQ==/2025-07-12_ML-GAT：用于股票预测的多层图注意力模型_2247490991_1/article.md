![](assets/001.png)

对股票市场的波动性进行研究一直是学术界与工业界关注的焦点，而准确预测股票走势则极具挑战性 。现有的研究方法在构建图网络时，大多侧重于聚合历史价格特征，却忽视了新闻、时事等其他信息对预测结果的影响 。同时，许多基于图的学习模型依赖于人工构建的股票关系，这种方式无法充分捕捉现实世界中股票间复杂的相互作用 。

基于这些挑战，本研究提出了一种新颖的、用于预测股票市场趋势的多层图注意力网络（Multilevel Graph Attention Network, ML-GAT）。该模型的核心工作流程是：首先，通过独立的特征提取模块初始化股票节点的表征；其次，利用从知识图谱Wikidata转换的同构图，通过ML-GAT模型更新股票节点信息，有选择性地聚合多种关系类型的信息；最终，将聚合后的节点表征输入至一个专门的预测层，以完成股票趋势的预测 。本研究在标准普尔500指数（S&P 500）的423支股票和沪深300指数（CSI 300）的286支股票上进行了实验验证 。

与五个主流基准模型的对比结果表明，ML-GAT在预测任务中展现了当前最先进的性能 。相较于表现最佳的基准模型，ML-GAT的F1分数和准确率分别提升了11.82%和12.6%，同时，模拟交易的日均回报率和夏普比率分别提升了5.06%和94.81% 。更重要的是，该模型所学习到的股票间联系具有可解释性，且与现实世界的商业互动相符 。

### **相关工作**

#### **股票市场预测**

学术界针对股票市场预测提出了多种方法 。早期的主流方法侧重于技术分析，将历史股价作为输入，利用支持向量机（SVM）、随机森林（RF）等传统机器学习算法进行建模 。随着计算能力的提升，深度学习技术因其能有效处理股票市场的高度非线性和非平稳性而被广泛应用，例如卷积神经网络（CNN）、循环神经网络（RNN）和长短期记忆网络（LSTM）。尽管这些复杂模型在时间序列建模上表现出色，但多数研究仅局限于金融时间序列本身，忽略了更全面的信息 。

#### **金融文本表示**

研究表明，金融新闻对股价趋势有显著影响 。随着自然语言处理（NLP）技术的发展，从金融文本中提取特征的技术取得了巨大进步 。早期研究多采用词袋模型对文本信息进行向量化 。近年来，词嵌入技术（如Word2Vec和GloVe）的性能得到提升，能够更好地捕捉文本的深层语义特征 。本研究则引入了BERT模型，它基于Transformer架构，能通过自监督学习充分捕捉句子中的双向关系 。尽管已有研究使用BERT预测股价，但将其与图神经网络方法进行融合尚未得到探索 。

#### **图神经网络**

传统的股票预测模型难以完全反映股票之间复杂的关联性 。鉴于金融市场信息的非欧几里得特性，研究者开始引入图神经网络（GNN）来学习公司间的分布表示 。例如，有研究基于真实投资事件构建相关公司图，并通过图卷积网络（GCN）捕捉公司间关系以提升预测准确性 。然而，现有的大多数工作未能深入研究何种关系数据对股票趋势预测任务更为有益 。因此，本研究利用图注意力网络，有选择性地聚合来自不同关系类型的数据信息，以解决这一问题 。

### **研究方法**

本章首先介绍模型的整体框架，随后详细阐述模型如何对金融市场中的文本、数值和关系这三个维度的数据进行建模 。该框架基于公开可用的企业关系数据，避免了依赖成本高昂的关系建模路径 。

![](assets/002.png)

#### **整体框架**

模型的整体框架如图1所示，主要包含三个核心部分：特征提取层、图建模层和预测层 。

1.  **特征提取层 (Feature Extraction Layer):** 对原始数据进行处理，通过不同的特征提取模块（LSTM用于价格，BERT用于新闻）获得不同的特征向量 。
    
2.  **关系图建模层 (Relation Graph Modeling Layer):** 将提取的特征向量聚合，形成一个包含价格和文本特征的股票关系网络图。随后，利用核心的ML-GAT模块处理该图 。
    
3.  **预测层 (Prediction Layer):** 接收来自ML-GAT处理后的结果，进行最终的趋势预测 。
    

#### **A. 特征提取模块**

在构建股票市场图时，每家公司的股票被视为一个节点，节点的特征代表了该公司在股价变动下的当前状态 。

**3) 关系提取模块 (Relation Extraction Module)**

-   **目的:** 从公开的Wikidata数据中提取企业间的关系 。Wikidata是一个包含多种实体和关系类型的异构图，而本研究只关注与股票相关的公司节点 。
    
-   **挑战:** 这些公司间的关系类型多样且网络非常稀疏 。
    
-   **方法:** 受相关研究启发，采用元路径（meta-paths）方法来处理异构图，将其转换为一个只包含股票（公司）节点的同构图 。具体而言，使用最多2跳（hops）的元路径来引导异构网络中的随机游走过程，从而有效捕捉目标节点间的结构关系 。
    

#### **B. 关系图建模 (ML-GAT)**

关系图建模模块的功能是更新由关系提取模块转化而来的同构图中的股票节点表示 。为此，本研究提出了一个基于GNN的新颖模型——ML-GAT 。如图2所示，ML-GAT通过在不同层面添加多层注意力机制，并为信息筛选分配不同的权重值，从而能够从不同节点收集不同类型的关系信息，并过滤掉对趋势预测无效的信息 。

**1) 第一层：状态注意力层 (State Attention Layer)**

### **实验**

本章通过大量实验来验证所提方法的有效性，并与近年来金融领域的一些流行方法进行比较 。

#### **A. 数据收集与准备**

-   **价格数据:** 实验数据涵盖了标准普尔500指数中的423支美国公司股票和沪深300指数中的286支中国公司股票 。价格数据分别来源于Yahoo Finance和中国股票市场与会计研究（CSMAR）数据库 。由于关系数据来自Wikidata，部分在Wikidata中没有与其他公司存在关联的股票被排除在外，因此股票数量少于指数成分股总数 。详细的数据集时间跨度见表1 。
    
-   **金融新闻数据:** 从Yahoo Finance等网站提取了近15万篇与目标股票相关的金融新闻文本 。
    
-   **公司关系数据:** 关系数据来源于Wikidata，它是一个包含大量公司实体和关系的知识库 。通过最大2跳的元路径，本研究从Wikidata中提取了9种一阶关系和62种二阶关系 。
    

#### **B. 实验设置**

-   **标签定义:** 根据股价变动率将训练数据划分为三类：“上涨”（）、“盘整”和“下跌”（）。
    
-   **交易策略模拟:** 为了衡量模型的盈利能力，设计了一个简单的交易策略：每日根据模型的预测概率进行决策。若“上涨”概率最高，则用当前所有可用资金买入该股票；若“下跌”概率最高，则卖出该股票；否则，不进行任何交易 。
    
-   **超参数设置:** 模型在TensorFlow中实现，使用Adam优化器，学习率为5e-4，权重衰减为5e-5，批大小为32，共训练100个周期 。为防止过拟合，每层末尾应用了值为0.5的Dropout 。所有实验均独立重复10次以确保结果的稳健性 。
    

#### **C. 评估指标**

-   **分类性能:** 采用分类任务中广泛使用的**准确率（Accuracy）**和**F1分数（F1-score）** 。
    
-   **盈利能力:** 采用**日均回报率（Average daily return）**和**夏普比率（Sharpe ratio）** 。夏普比率在计算时，使用13周期国库券利率作为无风险利率 。
    

#### **D. 基线方法**

本文选择了以下五个模型作为基准进行比较：

1.  **MLP:** 一个包含两个隐藏层的简单多层感知机 。
    
2.  **CNN:** 包含3个卷积层的卷积神经网络 。
    
3.  **LSTM:** 包含2层的经典长短期记忆网络 。
    
4.  **GCN:** 包含2个卷积层的图卷积网络 。
    
5.  **TGC:** 一种时间图卷积模型，它使用LSTM编码股票状态，再输入GCN探索公司间关系 。TGC与ML-GAT的关键区别在于，TGC对邻居节点信息进行同等聚合，而ML-GAT能区分不同关系类型并赋予不同权重 。
    

#### **E. 不同关系数据效果分析**

在进行正式预测任务前，研究首先探讨了不同关系类型对预测的影响 。实验使用了一个基础的GCN模型，独立测试每一种关系类型，以公平衡量其影响程度 。

-   **发现:** 并非所有关系数据都能带来正面效果 。在最差的情况下，引入关系数据反而会显著降低预测性能 。实验结果显示，表现最好的关系类型比最差的关系类型在F1分数上高出19.11% 。
    
-   **结论:** 基于这一发现，后续的主要实验均采用在此筛选出的10种最佳关系来构建股票关系图 。

#### **G. 新闻成分的影响**

为了验证新闻数据的作用，研究对比了包含和不包含BERT新闻特征提取模块的ML-GAT模型。

-   **结果:** 如图3所示，加入BERT模块后，模型的F1分数、准确率和日均回报率分别提升了18.08%、11.54%和2.3% 。
    
-   **意外发现:** 在夏普比率上，不包含新闻模块的模型表现稍好 。
    
-   **可能原因:** 研究推测这源于新闻文本数据的稀疏性 。市场新闻的分布不均（有时一天内新闻繁多，有时则无重要新闻）导致其不足以持续稳定地推断出最优的投资回报策略 。

### **结论与展望**

本研究成功提出了一个用于股票趋势预测的多层图注意力神经网络模型（ML-GAT）。该模型通过特定的特征提取模块，将金融市场数据、新闻以及公司关系数据整合到一个基于图注意力网络的模型中，弥补了现有预测方法在先验知识方面的不足 。ML-GAT的核心优势在于通过多层注意力机制，有选择性地筛选和聚合不同类型的信息，从而学习到对预测任务更有用的节点特征表示，最终提升预测的准确性 。

![](assets/008.png)

实验结果清晰地表明：

1.  引入股票间的关系数据通常对趋势预测任务有积极影响 。
    
2.  仅仅引入关系是不够的，**有选择性地聚合**不同类型的关系信息（如ML-GAT所做）比同等对待所有信息（如GCN）能取得更好的效果 。
    
3.  从金融新闻中提取的特征向量对预测有显著的正面贡献，验证了将新闻事件纳入模型的优越性 。
    

未来的工作将从以下几个方面继续改进：

-   **特征工程:** 探索更适合金融领域的编码工具，例如用更先进的NLP技术处理金融新闻，以更精确地捕捉股票变化过程中的多维度特征 。
    
-   **因子优化:** 对获取的多维特征进行因子优化分析，筛选出最重要的技术指标用于预测，以实现更高的准确率 。
    
-   **关系网络构建:** 改进股票间关系网络的构建方法，探索除Wikidata之外的更多数据源和构建方式，例如使用多元霍克斯过程（multi-Hawkes Process）来初始化股票间的相关图 。
    
-   **应用拓展:** 将该模型应用于股票市场的风险防范和量化投资，并将其泛化到其他金融领域的预测任务中 。
