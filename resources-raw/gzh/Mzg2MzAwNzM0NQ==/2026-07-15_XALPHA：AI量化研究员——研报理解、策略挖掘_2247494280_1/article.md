在大资管和量化私募领域，利用机器学习和遗传算法进行自动因子挖掘已经成为常态。然而，传统黑盒搜索或纯统计驱动的LLM代码生成，在面对低信噪比、非平稳的金融市场时，往往暴露出严重的过拟合问题——回测指标优异，实盘迅速衰退。这一局限性促使量化研究界思考：AI能否像人类研究员一样，先阅读学术文献与研报，提出有经济学逻辑的假说，再编写代码、严格排查数据泄露，并从失败的实验中汲取教训？

## 一、 真实因子挖掘的核心痛点

在量化研究的日常工作中，自动因子挖掘主要面临三个工程与学术层面的痛点：

1.  **缺乏经济学逻辑与金融合理性**：传统遗传算法或暴力搜索生成的因子公式往往极其繁复，难以进行合理解释。这些因子往往仅在样本内具备统计特征，在样本外表现极不稳定。
    
2.  **隐蔽的数据泄露与未来函数（Data Leakage）**：LLM 在生成 Python 因子代码时，极易写出带有隐性未来函数的逻辑。例如在计算 rolling 均值时无意中引入了未来的样本，或在代码中使用了未进行 shift 的收盘价。这种泄露在常规的静态代码解析中很难被完全捕捉。
    
3.  **经验无法累积与冷启动困难**：现有的 LLM 因子挖掘框架通常将每次生成视为独立事件。即使某类因子逻辑在回测中屡屡碰壁，系统也会在后续的挖掘中不断重复类似的错误，无法像人类研究员一样通过“错误日志”建立起避免死胡同的研究直觉。
    

XALPHA 的核心出发点，要在因子的“假说设计”（Hypothesis）与“代码实现”（Code）之间建立一套具备金融常识和反思能力的闭环系统，同时在工程上设计严苛的漏底防御机制。

## 二、 XALPHA 的核心架构与多脑协同

XALPHA 的系统架构由一个知识吸收层和三个“大脑”模块协同构成。这种设计规避了盲目的黑盒搜索，转而采用自顶向下的研究逻辑：

![](assets/002.jpg)

#### 1\. RMA（Report-to-Memory Absorption，研报到记忆吸收层）

系统首先需要“读研报”。为了防止 LLM 被研报中的低效信息误导，RMA 建立了严格的 A/B/C 三层分类法：

-   **A层（OHLCV 可行性筛选）**：这是硬件级过滤。由于系统的因子执行沙盒仅提供每日的开盘价、最高价、最低价、收盘价及交易量（OHLCV），任何依赖日内 Tick 数据、逐笔委托数据、甚至基本面和舆情数据的研报片段，在A层都会被判定为 DROP。这确保了后续生成的假说在数据源上是绝对可实现的。
    
-   **B层（机制家族分类）**：将通过筛选的有效片段归类到 16 个粗粒度的金融机制中，例如“趋势与动量”、“波动率期限结构”或“价量交互”。
    
-   **C层（研究原型构建）**：进一步细化为 48 个具体的研究原型（Research Archetypes）。例如，在动量机制下，会细分为“趋势启动”、“趋势持续”和“动量衰竭”。这些原型不仅是文本标签，还包含了对应的多源研报研究路径。
    

![](assets/003.jpg)

#### 2\. Macro Brain（宏观规划大脑）

Macro Brain 负责周期性的研究路线规划。在每个挖掘周期开始时，它会读取当前累积的全局记忆与历史反馈。 它支持三种规划模式（固定主题、粗粒度引导、记忆驱动）。在记忆驱动模式下，Macro Brain 会分析此前周期中表现优秀（GOOD）和失败（BAD）的因子特征，识别当前研究图谱中的空白区域，决定本周期应该主攻哪个 C层研究原型，并生成具体的假说候选池，从而控制了因子挖掘的探索方向，防止挖掘空间迅速饱和。

#### 3\. Micro Brain（微观执行与进化大脑）

Micro Brain 是因子的具体实现和进化温床。它接收 Macro Brain 输送的假说，然后生成、验证并进化因子代码：

-   **严格的验证管线**：
    

1.  **AST Gate**：通过抽象语法树（AST）进行静态检查，直接拦截语法错误、不合规库导入、以及明显的静态未来泄露（如负数位移等）。
    
2.  **TriAlign-Judge（三向对齐评审）**：由专门的 Agent 审查“假说想法、代码逻辑、金融合理性”这三者在语义上是否高度一致。如果代码实现偏离了假说，该因子会被驳回重修。
    
3.  **数值验证**：在实际历史数据上运行代码，丢弃 NaN 比例超过 30% 或数据截面变异性过低的因子。
    
4.  **动态单元测试（漏底防御）**：针对未来泄露，Micro Brain 设计了“截断与未来噪声扰动测试”。通过在未来收益序列中注入随机噪声，观察在  时刻计算出的因子值是否发生改变。如果因子值随未来噪声而变，说明代码中存在隐性的未来函数泄露，系统会立即定位并尝试修复。
    

-   **进化算子**：验证通过的因子会通过变异（Mutation）、交叉（Crossover）和精简（Refinement）进行多代演化。为了防止种群退化，每个cycle会触发“新颖性注入”（Novelty Injection），利用 Cross Brain 的短期记忆生成一批全新机制的种子因子加入种群。
    

#### 4\. Cross Brain（跨周期反思与归因大脑）

因子的表现不能只看一个简单的回测得分，还需要知道其成功或失败的深层逻辑。

-   **Factor-to-Archetype Attribution （FAA, 因子-原型归因）**：变异或交叉后的子代因子，其核心逻辑可能已经偏离了父代。Cross Brain 会重新读取子代因子的最终代码，通过 FAA 将其重新归类到正确的 B/C 层原型中，防止反馈污染。
    
-   **经验提炼**：将进入 Elite（精英池）的因子提炼为 GOOD 记忆，提取出其在何种波动率或流动性环境下表现更优的逻辑；将未通过正常筛选门的因子归纳为 BAD 记忆，记录其失效的假设或过度拟合的结构，用于指导下一周期的宏观规划和微观种子注入。
    

## 三、 实实证检验与性能表现

论文在 CSI300 指数上进行了详尽的实证检验。

#### 1\. 实验设置

-   **数据空间**：CSI300 标的股。
    
-   **时间划分**：训练集为 2011年1月1日至2020年12月31日，验证集为 2021年1月1日至2021年12月31日，测试集为 2022年1月1日至2025年12月31日。
    
-   **预测目标**：10个交易日后的未来经调整开盘价至开盘价收益率。
    
-   **基准模型**：利用 Ridge 脊回归在训练集和验证集上训练生成的因子组合，在测试集上采用 Qlib 进行回测。交易成本设定为open side 0.05%，close-side cost 0.15%，每笔订单最低单边 5 元。组合构建采用 Top-50/Drop-5 的多头替换策略。
    

#### 2\. 核心指标对比

从论文公布的实验结果来看，XALPHA 的多项关键指标在 CSI300 测试集上超越了代表性基准：

![](assets/004.png)

-   **预测能力与稳定性**：XALPHA 取得了 0.0619 的 IC 和 0.0748 的 RankIC。 l XALPHA 的 RankICIR 达到了 0.4043，远高于其他基线，说明其因子的预测力在时间截面上具有更强的持续性。
    
-   **组合业绩**：在扣除交易成本后，XALPHA 实现了 17.95% 的年化收益率（AR）和 14.43% 的超额年化收益率（AER）。其超额收益的信息比率（IR）达到了 **1.5368**，相比 R&D-Agent(Q) 的 0.4062 以及常规机器学习基线，展现出显著的风险收益比优势。
    

#### 3\. 因子多样性分析

量化团队往往面临 AI 挖掘因子同质化严重（仅为参数或微小算子变体）的困境。XALPHA 在因子多样性上的实验结果如下：

-   **单主题内相关性**：在单一主题（如 `vol_regime_breakout_interaction`）下，挖掘出的 50 个精英因子之间的平均绝对相关性仅为 0.234，其中 68.0% 的因子对相关性低于 0.3。
    
-   **跨主题相关性**：当跨越 6 个不同的周期主题（共 60 个因子）时，因子对的平均绝对相关性进一步降至 0.142，中位数仅为 0.099，有 87.1% 的因子对相关性低于 0.3。
    

这说明 Macro Brain 的研究主题轮动机制有效地引导了 Micro Brain 在因子空间的不同象限中进行探索。

## 四、 典型精英因子代码解析

以下是 XALPHA 实际挖掘出的一个典型精英因子代码：`regime_overshoot_pressure_decay_20d_ma20_vol20`。

该因子的核心逻辑是：在市场经历超跌（downside overshoot）后，会产生与当前波动状态相关的反转压力，且在高波动率环境下反转压力消退更快。

```
def regime_overshoot_pressure_decay_20d_ma20_vol20(df):    close = df['close']        # 1. 估算中周期价格锚点与波动率状态    ma20 = close.rolling(20, min_periods=10).mean()    ret = close.pct_change()    vol20 = ret.rolling(20, min_periods=10).std()    high_vol = (vol20 > vol20.rolling(60, min_periods=30).median()).astype(float)        # 2. 在高波动状态下收紧超跌阈值    threshold = (0.90 * high_vol + 0.95 * (1 - high_vol)) * ma20    overshoot = (close < threshold).astype(float)        # 3. 将超跌事件转化为累积压力值，并以绝对收益率加权    pressure = (overshoot * ret.abs().fillna(0.0)).rolling(20, min_periods=1).sum()        # 4. 让反转压力在高波动环境下消退得更快    slow_decay = pressure.ewm(span=15, adjust=False, min_periods=1).mean()    fast_decay = pressure.ewm(span=5, adjust=False, min_periods=1).mean()    decayed = high_vol * fast_decay + (1.0 - high_vol) * slow_decay        # 5. 扣除历史基准，计算异常压力得分    factor = decayed - decayed.expanding().quantile(0.75)    factor.name = 'regime_overshoot_pressure_decay_20d_ma20_vol20'    return factor
```

整个因子展现出清晰的逻辑链条：

1.  提取 20 日均线作为价格参考，用 20 日收益率标准差相对其 60 日中位数的大小判定高波动状态。
    
2.  动态调节超跌判定边界。高波动状态下要求价格跌破均线 10% 以上，而低波动状态下仅要求跌破 5%。
    
3.  计算价格低于该自适应阈值的超跌事件，结合绝对收益率进行加权，累加 20 天窗口的“超跌压力值”。
    
4.  在高波动环境下采用半衰期较短的 EWMA 快速衰减，在低波动下采用慢速衰减。
    
5.  因子代码极其干净，不包含任何莫名其妙的嵌套算子。系统通过复杂度折让公式  限制了冗余代码的生成，该因子的 AST 复杂度分数为 14.788。
    

## 结语

XALPHA 通过结构化的研报记忆体系与自省式的演化验证管线，尝试将 AI 因子挖掘推向了更为理性的“假设驱动”轨道。其高信息比率的实证结果表明，在严苛的未来泄露排查和金融逻辑对齐约束下，AI 具备挖掘出兼具可解释性与样本外鲁棒性因子的可行性。
