在A股市场，做事件驱动策略的研究员经常遇到类似的困扰：上市公司发布的“临时公告”分类极为粗糙。在交易所或各大金融终端上，很多公告都被统一归类为“重大合同”或“其他公告”。然而，“重大合同”标签之下，可能包含普通的、利润率极低的工程分包，也可能包含与行业巨头的里程碑式战略合作；至于“其他公告”，则是一个更庞杂的垃圾桶，里面往往塞满了关键的诉讼进展或重大投资变动。这种分类上的粗糙给量化策略带来了极大的噪声，降低了多头/空头策略的信噪比。

这一痛点在美股市场同样显著。作为美股最关键的实时披露源，Form 8-K filings自带的32个项目代码（Item Codes）面临完全相同的分类瓶颈。例如，Item 5.02同时混杂了“核心CEO离职”与“常规独立董事退休”两类在市场敏感度上完全不同的事件；而Item 8.01（其他事件）则是一个巨大的“大杂烩”，诸如临床试验结果、并购完成或监管决定等能引起股价剧烈波动的事件，往往都被打包扔进了这个无明确定义的分类中。

针对这一问题，本文提出了一种基于轻量级指令微调大语言模型的双阶段事件提取系统。该系统针对含有119个事件类型的细粒度三级分类体系，通过“约束生成 + 模糊N-gram引用验证”与“独立第二阶段重评分”机制，在292,984份8-K文档（跨越2022年1月至2026年6月）中成功提取出601,088个带定位引文和质量评分的细粒度事件标签。**这套方案通过将“事件提取”与“可靠性评分”拆分为两个独立的处理阶段，构建起一个高度校准的精密度-召回率调节阀。同时，它利用无大模型参与的标准化异常回报率（SAR）事件研究，在金融市场层面直接验证了这套细粒度分类相比官方代码具有更强的方差解释力，为事件驱动策略提供了高信噪比的替代数据。**

## 代码粗糙与模型幻觉

在多因子选股和事件驱动策略中，上市公司公告通常被视作“事件Alpha”的重要来源。然而，直接使用官方项目代码进行横截面回归或事件窗口期超额收益回测时，信号的信噪比往往不尽如人意。

这种粗糙性在两个维度上损害了因子的预测能力：

1.  **经济学意义的混淆**：Item 5.02（高管及董事变动）在法律披露上属于同一类，但在资本市场看来，CEO离职带来的管理层重组预期，与常规董事更替的财务影响存在质的差别。
    
2.  **非结构化信息的流失**：Item 8.01作为自愿披露的兜底代码，涵盖了医药公司的研发里程碑、科技公司的核心专利进展等。如果只看Item 8.01，量化系统根本无法对其进行合理的信息分类和风险暴露控制。
    

引入大语言模型（LLM）进行大规模信息抽取，是一个显而易见的解决思路。但将LLM直接应用于生产环境的量化管线，会立刻遭遇两个行业公认的工程难题：

-   **无法保证严格对齐**：通用大模型生成的结果难以天然受限在量化因子库所需的固定事件词表（Vocabulary）内，后期清洗成本极高。
    
-   **无法审计与幻觉问题**：大模型时常出现无中生有（幻觉）或者曲解上下文的情况。在没有追溯机制的情况下，一旦量化系统根据错误提取的事件进行调仓，可能引发不可控的尾部风险。
    
-   **内省评分失效（Overconfidence）**：如果让提取模型在生成事件的同时自己给出一个置信度分数，模型往往表现出极度的自负。它们通常把大约75%的标签都评为最高分，导致这个置信度评分沦为毫无筛选能力的二值化标志（Binary Flag），无法用于交易组合的风险过滤。
    

## 核心方法

为了建立一条可审计、高精度的量化信号抽取流水线，方案设计了由两个阶段构成的处理系统。

```
[8-K 原始文本]        │       ▼┌────────────────────────────────────────┐│ 第一阶段：事件提取与结构可靠性保证      ││ 1. 约束生成 (Schema Constraint)        │ ──> 保证事件标签必须在119个分类内│ 2. 模糊N-gram引文校验 (Quote Grounding) │ ──> 强制提取原文，消灭无中生有└────────────────────────────────────────┘       │       ├─ (未通过校验则触发重试，上限3次)       │       ▼  [提取出的事件标签 + 对应原文引言 (Quote)]┌────────────────────────────────────────┐│ 第二阶段：独立评分 (Grader Model)      ││ * Grader仅阅读引言与分类定义，评估匹配度│ ──> 产生 calibrated 质量得分 (1-5)└────────────────────────────────────────┘       │       ▼[高质量细粒度事件标签体系 (Score 1-5)]
```

### 第一阶段：事件提取与结构可靠性验证

这一阶段的主要任务是在单次调用中识别出8-K filings中的潜在事件，并为其定位支撑引言。模型运行在零温（Temperature = 0）下，采用较小规模的商用指令微调模型以控制计算成本。这套系统并非依靠模型规模来保证可靠性，其核心在于外围的结构化校验机制。

1.  **Schema 限制（Constrained Output）**：提取出的事件标签必须与三级分类法中的119个叶子节点（Tertiary Event Types）精确对齐。如果模型输出了不属于分类树的标签，系统会截获此项错误并将其作为反馈，强制模型重新尝试（最多尝试3次）。
    
2.  **模糊 N-gram 引文验证（Quote Grounding）**：模型在抽取事件时，必须同时返回一段该事件在8-K原文中的引言（Quote）。验证器将这段引文切分为重叠的4词（4-word）序列，只有当至少40%的4-word序列能够精确匹配8-K原文时，该引文才被系统采纳。这在底层机制上降低了LLM编造引言的概率。
    

### 第二阶段：独立评分（评分与提取解耦）

这是该方案在工程方法论上的重要发现：**要获得一个真正可用、单调校准的置信度指标，必须将评分步骤与提取步骤完全解耦。**

系统在第二阶段启用了一个独立的打分模型（Grader Model）。为了彻底排除非相关上下文对评分的干扰，并降低计算资源消耗，第二阶段重评分并未输入完整的文档，它仅输入被引用的原文片段与对应的分类定义。

打分模型需要根据引言片段对事件发生的清晰度进行1至5分的评级：

-   **5分**：引言明确、无歧义地证实了该细粒度事件的发生（例如：高管辞职已生效）。
    
-   **1分**：引言根本没有提及该事件，或者指向了一个完全不同的范畴。
    

实验结果显示，这种“重新阅读引言”的方法成功使分数值分布在整个1至5的区间内，形成了一个平滑的可靠性调节阀。这个评分并非单纯反映生成概率，它提供了一个可调的可靠性度量。与之相反，若直接在第一阶段生成标签时让模型输出置信度评分（单阶段消融实验），模型会表现出极高的内省分值，绝大部分输出都在4分和5分，丧失了过滤低质信号的能力。

## 结果评估

评估工作分为两条互相独立的路径：使用高阶模型（Opus 4.8）进行的内部一致性审计，以及完全不依赖任何大模型的金融市场异常回报检验。

-   **Correct**：事件真实发生且分类合理。

### 2\. 外部经济学验证（事件研究法）

在真实的股票市场上，这种分类方法的差异是否伴随着显著的定价反应差异？

#### 验证结果 B：横截面波动方差解释力的提升

通过对不同标签方案对 SAR 变动方差的解释力（R-squared）进行对比，进一步确认了该标签系统的信息增量：

-   仅使用 **SEC 官方 Item Codes** 进行分类，对市场反应方差的解释力为 15.0%。
    
-   仅使用本方案提取的 **LLM 细粒度事件标签**（Tags），方差解释力达到 15.9%。
    
-   当两者结合时，解释力提升至 16.3%。
    
-   **增量对比**：在已有 Item Codes 的基础上加入 LLM Tags，能够将方差解释力提高 **1.30个百分点**；而在 LLM Tags 的基础上仅加入官方 Item Codes，方差解释力仅能提高 **0.41个百分点**。这意味着，这套基于大模型的细粒度分类几乎完全覆盖了官方代码所包含的所有定价相关信息，并且提供了显著的信息增量。
    

此外，在所有细粒度标签中，市场定价反应最剧烈的15个事件类型中，有9个（包括临床试验结果、并购完成和交易撤回等）大部分情况下都归属于没有具体业务指向的 Item 8.01 兜底代码下。这从侧面反映了该系统对从非结构化文本中挖掘隐藏 Alpha 信号的实用价值。

## 结论

公告文本作为金融市场最核心的非结构化数据源之一，长期以来面临分类粗糙、信噪比低的问题。传统的分类系统无法刻画公告背后的实际经济学意义，而简单的 LLM 直接抽取又容易受到幻觉和难以校准的置信度影响。

本文介绍的方法证明了以下三点：

-   通过“Schema 限制”与“模糊 N-gram 引言验证”等外围规则，能够有效纠正轻量级模型生成时的越界与幻觉行为。
    
-   将事件抽取和质量评分剥离为独立的两阶段运行，通过仅基于 Quote 进行重读打分，能够生成单调校准的置信度评分，使量化研究员可以通过调节阈值灵活平衡精密度与召回率。
    
-   金融市场事件研究（SAR）表明，大模型抽取的细粒度标签所解释的资产价格波动方差显著超越传统的官方披露代码，为事件驱动策略挖掘隐藏 Alpha 提供了更精准的数据支持。
    

在实际落地过程中，由于单段引文打分可能存在上下文盲区，且日度回报无法完全捕捉日内高频价格反应，在复现本方案时，应结合自身的交易频段对局部上下文输入和价格窗口进行精细化微调。
