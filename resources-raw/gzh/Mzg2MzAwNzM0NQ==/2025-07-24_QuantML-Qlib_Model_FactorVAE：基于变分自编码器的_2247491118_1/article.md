近期收到许多读者的提问，大家似乎都对 FactorVAE 很感兴趣。本文我们将对其核心思想进行系统性介绍，并且在 QuantML-Qlib 中实现这一前沿算法。

FactorVAE 是一种先进的深度学习模型，专门用于预测股票市场的横截面收益率。模型源自AAAI 2022清华发表的论文。该模型的核心思想是将传统的**动态因子模型 (Dynamic Factor Model, DFM)** 与**变分自编码器 (Variational Autoencoder, VAE)** 相结合，旨在捕捉金融市场中复杂的非线性关系和潜在的驱动因子。

![](assets/001.png)

#### **核心理念**

传统的量化投资模型（如 Fama-French 三因子模型）通常假设股票收益是由少数几个可观测的、线性的因子（如市场、规模、价值）驱动的。然而，真实的市场关系远比这复杂和动态。

FactorVAE 对此进行了改进，其核心假设是：

1.  **潜在因子驱动**：股票的未来收益是由一组数量较少、无法直接观测的**潜在因子 (latent factors)** 驱动的。
    
2.  **非线性关系**：这些潜在因子与股票的自身特征（如历史价格、波动率、市盈率等）之间存在复杂的**非线性关系**。
    
3.  **动态变化**：这些因子的影响力和它们自身的特性是随时间动态变化的。
    

* * *

#### **模型架构**

`FactorVAE` 是一个基于**变分自编码器（Variational Autoencoder, VAE）**思想的深度学习模型，专门用于从**时间序列数据**（如股票的多因子数据）中学习**潜在因子**（Latent Factors）及其动态。它通过一个**编码器-解码器**的结构来学习数据的有效表示，并利用一个**预测器**来对潜在因子进行预测。

![](assets/002.png)

该模型由以下几个核心模块组成：

1.  **特征提取器 (`FeatureExtractor`)复现代码**:
    
    `class FeatureExtractor(nn.Module):   """特征提取器，使用GRU提取股票的潜在特征"""   def __init__(self, num_latent, hidden_size, num_layers=1):       super(FeatureExtractor, self).__init__()       self.num_latent = num_latent       self.hidden_size = hidden_size       self.num_layers = num_layers              self.normalize = nn.LayerNorm(num_latent)       self.linear = nn.Linear(num_latent, num_latent)       self.leakyrelu = nn.LeakyReLU()       self.gru = nn.GRU(num_latent, hidden_size, num_layers, batch_first=True)      def forward(self, x):       # x: (batch_size, seq_length, num_latent)       # 应用线性变换和LeakyReLU激活       # 添加层归一化       x = self.normalize(x)       out = self.linear(x)       out = self.leakyrelu(out)       # GRU前向传播       stock_latent, _ = self.gru(out)       return stock_latent[:,-1,:] # stock_latent[-1]: (batch_size, hidden_size)   `
    

-   **作用**: 从每个资产（如股票）的历史特征序列中提取一个紧凑的、固定长度的潜在状态向量 (`stock_latent`)。
    
-   **技术**: 核心是一个 **GRU (Gated Recurrent Unit)** 网络。GRU 能够有效处理序列数据，捕捉时间依赖性。
    

3.  **因子编码器 (`FactorEncoder`)复现代码**:
    
    `class FactorEncoder(nn.Module):   """因子编码器，将股票潜在特征编码为因子分布"""   def __init__(self, num_factors, num_portfolio, hidden_size):       super(FactorEncoder, self).__init__()       self.num_factors = num_factors       self.linear = nn.Linear(hidden_size, num_portfolio)       self.softmax = nn.Softmax(dim=0) # 修复bug: dim=1 -> dim=0              self.linear_mu = nn.Linear(num_portfolio, num_factors)       self.linear_sigma = nn.Linear(num_portfolio, num_factors)       self.softplus = nn.Softplus()          def mapping_layer(self, portfolio_return):       # portfolio_return: (batch_size, 1)       # 映射层       mean = self.linear_mu(portfolio_return.squeeze(1))       sigma = self.softplus(self.linear_sigma(portfolio_return.squeeze(1)))       return mean, sigma      def forward(self, stock_latent, returns):       # stock_latent: (batch_size, hidden_size)       # returns: (batch_size, 1) (单期收益率)       # 构建投资组合       weights = self.linear(stock_latent)       weights = self.softmax(weights) # (batch_size, num_portfolio)          # 权重与收益率相乘       if returns.dim() == 1:           returns = returns.unsqueeze(1)       # 确保数据类型一致       returns = returns.float()       portfolio_return = torch.mm(weights.transpose(1,0), returns) # portfolio_return: (M, 1)              return self.mapping_layer(portfolio_return)   `
    

-   **作用**: 学习从所有股票的潜在状态中提炼出市场级别的**宏观经济因子 (`factor_mu`, `factor_sigma`)**。这是 VAE 的**编码器**部分。
    
-   **技术**: 首先，它将所有股票的潜在状态通过一个线性层和 Softmax 聚合，构建成若干个**投资组合**。然后，将这些投资组合的收益率映射成宏观经济因子的分布（均值和方差）。
    

5.  **因子解码器 (`FactorDecoder`)复现代码**:
    
    `class FactorDecoder(nn.Module):   def __init__(self, alpha_layer, beta_layer):       super(FactorDecoder, self).__init__()          self.alpha_layer = alpha_layer       self.beta_layer = beta_layer      def reparameterize(self, mu, sigma):       eps = torch.randn_like(sigma)       return mu + eps * sigma      def forward(self, stock_latent, factor_mu, factor_sigma):       # 注意: alpha_mu, alpha_sigma -> (N), (N)       alpha_mu, alpha_sigma = self.alpha_layer(stock_latent)       beta = self.beta_layer(stock_latent)          factor_mu = factor_mu.view(-1, 1)       factor_sigma = factor_sigma.view(-1, 1)          # 将factor_sigma中的零值替换为小值       factor_sigma[factor_sigma == 0] = 1e-6       mu = alpha_mu + torch.matmul(beta, factor_mu)       sigma = torch.sqrt(alpha_sigma**2 + torch.matmul(beta**2, factor_sigma**2) + 1e-6)          return self.reparameterize(mu, sigma)   `
    

-   `AlphaLayer`: 学习每个股票的\*\*特异性收益 (α)\*\*。
    
-   `BetaLayer`: 学习每个股票对宏观因子的\*\*暴露度 (β)\*\*。
    

-   **作用**: 根据学习到的宏观经济因子和每个股票自身的特性，**重构**（或预测）单个股票的收益率。这是 VAE 的**解码器**部分。
    
-   **技术**: 遵循了经典的因子模型思想 `R = α + β * F + ε`。
    

8.  **因子预测器 (`FactorPredictor`)复现代码**:
    
    `class FactorPredictor(nn.Module):   """因子预测器，预测因子的分布参数"""   def __init__(self, hidden_size, num_factor):       super(FactorPredictor, self).__init__()              self.hidden_size = hidden_size       self.num_factor = num_factor       self.attention_layers = nn.ModuleList([AttentionLayer(self.hidden_size) for _ in range(num_factor)])              self.linear = nn.Linear(hidden_size, hidden_size)       self.leakyrelu = nn.LeakyReLU()       self.mu_layer = nn.Linear(hidden_size, 1)       self.sigma_layer = nn.Linear(hidden_size, 1)       self.softplus = nn.Softplus()      def forward(self, stock_latent):       # 只以股票潜在特征作为输入 (N, H)              for i in range(self.num_factor):           attention_layer = self.attention_layers[i](stock_latent)           if i == 0:               h_multi = attention_layer           else:               h_multi = torch.cat((h_multi, attention_layer), dim=0)       h_multi = h_multi.view(self.num_factor, -1)          h_multi = self.linear(h_multi)       h_multi = self.leakyrelu(h_multi)       pred_mu = self.mu_layer(h_multi)       pred_sigma = self.sigma_layer(h_multi)       pred_sigma = self.softplus(pred_sigma)       pred_mu = pred_mu.view(-1)       pred_sigma = pred_sigma.view(-1)       return pred_mu, pred_sigma   `
    

-   **作用**: 独立于**当前**的实际收益率，仅根据所有股票的潜在状态，对宏观经济因子进行**先验预测** (`pred_mu`, `pred_sigma`)。
    
-   **技术**: 使用了\*\*多头注意力机制 (`AttentionLayer`)\*\*。每个 "头" 关注股票池中的不同方面，最终聚合信息来预测一个宏观因子。
    

### 模型核心特点

1.  **结合 VAE 和因子模型**:
    

-   **重构损失**: 确保解码器能用学习到的因子准确重构股票收益率。
    
-   **KL散度**: 约束 `FactorEncoder`（后验）和 `FactorPredictor`（先验）产生的因子分布尽可能接近，使模型更具泛化能力。
    

-   模型的核心是 VAE 框架，通过最小化**重构损失**和**KL散度**来学习。
    
-   `FactorDecoder` 的设计明确遵循了金融因子模型 `R = α + β * F`，使得模型的输出具有很强的**金融可解释性**。
    

4.  **动态特征提取**:
    

-   使用 GRU 网络处理时间序列数据，能够捕捉股票特征的动态变化，这比仅使用截面数据的模型更强大。
    

6.  **分层学习结构**:
    

-   **资产层**: `FeatureExtractor` 学习单个资产的表示。
    
-   **市场层**: `FactorEncoder` 和 `FactorPredictor` 从所有资产中提炼共性因子。
    
-   **重构/预测层**: `FactorDecoder` 结合宏观因子和个体特性进行预测。

9.  **注意力机制的应用**:
    

-   在 `FactorPredictor` 中引入注意力机制，可以动态地为不同的股票分配权重，从而更智能地聚合信息来预测宏观因子，而不是简单地对所有股票一视同仁。
