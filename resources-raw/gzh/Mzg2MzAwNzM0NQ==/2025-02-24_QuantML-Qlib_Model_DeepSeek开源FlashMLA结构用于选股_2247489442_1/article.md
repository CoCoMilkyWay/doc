今天DeepSeek开源了其高性能推理加速框架FlashMLA，FlashMLA是专为NVIDIA Hopper架构GPU（如H800/H100）设计的创新技术，旨在优化大语言模型（LLM）在变长序列处理场景下的推理效率。 本文我们将FlashMLA融入进QauntML-Qlib框架。

##   
FlashMLA介绍  

###   
一、核心功能特性  

####   
1\. 动态序列长度支持  

-   **分页KV缓存管理**：通过`block_table`数据结构实现动态内存分配，支持`num_blocks x page_block_size`的分块缓存机制（默认块大小64）
    
-   **自适应任务调度**：`tile_scheduler_metadata`实现动态负载均衡，通过`get_mla_metadata`预计算调度策略，支持可变长度序列的并行处理
    

####   
2\. 高效注意力计算  

-   **混合精度计算**：BF16主计算配合FP32累加，利用Hopper架构的Tensor Core特性
    
-   **分块Softmax优化**：实现`max_scale_exp2_sum`算法，采用指数基2计算和分块归约策略，避免数值溢出
    
-   **双缓冲内存加载**：通过`smem_k`双缓冲设计隐藏内存延迟，提升SM利用率
    

####   
3\. 硬件级优化  

-   **SM90架构深度优化**：
    

-   使用TMA（Tensor Memory Accelerator）指令加速数据加载
    
-   基于GMMA（Grouped Matrix Multiply Accumulate）指令的矩阵计算
    
-   异步拷贝（`cp.async`）与Warpgroup级同步机制
    

-   **共享内存复用**：通过`SharedStorageMLA`联合体实现不同计算阶段的内存复用
    

###   
二、关键技术实现  

####   
1\. 内存子系统优化

####   
2\. 计算流水线优化

###   
四、架构设计亮点  

1.  **分层调度系统**：
    

-   全局级：`num_sm_parts`划分SM资源
    
-   批次级：`block_table`管理KV缓存
    
-   块级：`TileSchedulerMetaData`动态调度
    

3.  **数值稳定性设计**：
    

  
`// Softmax数值稳定实现   const float max_scaled = (max(mi) == -INFINITY) ?        0.f : max(mi) * float(M_LOG2E);   tensor(mi,ni) = exp2f(tensor(mi,ni)*scale - max_scaled);   `

1.  **自适应内核选择**：
    

  
`template<typename T, int Headdim>   void run_mha_fwd_splitkv_mla(Flash_fwd_mla_params &params) {       static_assert(Headdim == 576);  // 硬编码优化特定头维度   }   `

###   
五、应用场景  

1.  **大语言模型推理**：适合70B+参数模型的KV缓存管理
    
2.  **长序列处理**：支持动态扩展的序列长度（实测支持16K+ tokens）
    
3.  实时对话系统：微秒级响应延迟表现
    

###   
六、使用限制  

1.  硬件要求：
    

-   必须使用Hopper架构GPU（H100/H200）
    
-   需要CUDA 12.3+环境
    

3.  模型约束：
    

-   头维度固定为576（Q）和512（V）
    
-   当前仅支持BF16精度
    

该框架通过硬件特性深度挖掘和算法-架构协同设计，在动态序列场景下实现了相比传统Attention实现2-3倍的性能提升，是LLM推理部署的重要加速方案。其设计理念对新一代Attention算法开发具有重要参考价值。

##   
FlashMLA加入QuantML-Qlib  

首先从github下载官方代码：

  
`git clone https://github.com/deepseek-ai/FlashMLA.git   `

安装FlashMLA:

  
`python setup.py install   `

环境要求：Hopper GPU、CUDA 12.3+、PyTorch 2.0+,注意目前FlashMLA只支持Hopper架构的GPU。

选股模型的代码已经加入QuantML-Qlib，地址为：examples/benchmarks/DeepSeek/pytorch\_transformer\_flashmla.py

运行examples/benchmarks/DeepSeek/run.py 即可启动程序。由于手边没有Hopper架构GPU（欢迎大佬提供测试），目前只完成了模型代码，暂时无法测试结果。
