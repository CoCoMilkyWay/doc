过去几年，量化似乎陷入了一种“算力军备竞赛”：模型结构越做越花哨，注意力机制越搞越复杂，试图用庞大的端到端神经网络去榨取那一丝微弱的非线性Alpha。

但实盘的教训往往是残酷的——回测夏普动辄破3，一上实盘直接变负。原因很简单，在极低信噪比（SNR）的金融时序环境里，过于自由的神经网络往往不是在挖掘规律，而是在极其精细地“记忆噪音”。面对动辄跳水的样本外（OOS）表现，深度学习在横截面选股上的出路究竟在哪？

最近，一篇由 RiskX 和 Hanyang 大学团队新鲜开源的论文《Vector-Quantized Discrete Latent Factors Meet Financial Priors》给出了一个现实且极具工程实操感的答案：**纯连续的潜变量（Continuous Latent Representations）根本无法提供足够的正则化，往往会沦为噪音的放大器。** 别再迷信纯连续的黑盒炼丹了，与其无脑增加网络自由度，不如强行给模型套上一个“离散信息瓶颈”，同时老老实实把传统的金融先验知识当成网络训练的锚。

为了解决这个问题，他们提出了一个名为 PRISM-VQ 的两阶段模型。该模型最核心的思路是：放弃端到端的黑盒炼丹，强行引入向量量化（Vector Quantization, VQ）作为信息瓶颈，把股票压入有限的“离散微观结构原型”中；同时，硬性注入 13 个经典的金融先验因子作为模型训练的“锚点”。

PRISM-VQ 有两个核心结构：一是“空间结构”与“时序动态”的**两阶段剥离训练**，彻底避免了特征空间的动态坍塌；二是通过 VQ 逼迫模型进行聚类，从根本上压制了高频无效波动。

### 一、这篇论文真正想解决的量化痛点是什么？

在介绍具体网络结构前，我们必须先对齐问题背景。如果你在实盘中用过基于深度学习的横截面选股模型（无论是早期的 MLP、LSTM，还是后期的 Transformer、各种图谱网络），你一定遇到过以下三大痛点：

**痛点一：连续空间的过拟合与极低信噪比灾难**我们喂给模型的 Alpha158 特征，本质上是大量高相关性、包含严重测量噪音的弱信号。传统 Autoencoder 或者 VAE 类模型（如 CAE、FactorVAE），其潜空间（Latent Space）是连续的。连续空间的问题在于它具有近乎无限的表达能力。当 SNR 极低时，连续潜变量会本能地去记忆那些偶然出现的“噪音峰值”，导致模型在 Out-of-Sample（样本外）表现出极其脆弱的泛化性。我们需要的不是无限精度的表达，而是**强迫模型去粗取精的“信息瓶颈”**。

**痛点二：动态因子载荷（Factor Loading）与市场非平稳性（Regime Shifts）**传统的多因子模型（如 Fama-French）假设因子载荷在一段时间内是线性的、相对静态的。但在真实市场中，同一类股票在“牛市动量主导”和“熊市红利低波主导”时的因子敏感度是完全不同的。现在的深度学习模型试图用时序注意力机制（Temporal Attention）来捕捉动态变化，但由于缺乏对横截面微观结构（Cross-sectional Structure）的显式建模，模型往往会把局部的价格波动误认为是整体市场 Regime 的切换。

**痛点三：对已证实金融知识（Domain Priors）的傲慢无视**很多前沿的 AI 选股模型喜欢把一切交给数据，输入量价特征后直接预测收益率。但事实上，像市值（Size）、价值（Value）、动量（Momentum）、盈利（Profitability）这些已经被金融学界和业界反复验证过的先验知识，是极为宝贵的“锚”。如果纯靠网络去硬学，模型大部分的参数容量都会被浪费在“重新发明轮子”（重新发现动量和市值效应）上，而无法去挖掘真正的增量非线性 Alpha。

PRISM-VQ 这篇论文，就是极其针对性地在解决这三个问题：**用 VQ 解决噪音过拟合，用结构条件 MoE（混合专家系统）解决非平稳动态载荷，用 JKP 因子库强行约束网络学习路径。**

### 二、PRISM-VQ 的核心技术设计拆解

PRISM-VQ 的核心是一个**两阶段（Two-Stage）解耦架构**。这是一个非常聪明的工程选择。很多研究员喜欢端到端（End-to-End）一把梭，但同时优化 VQ Codebook 和下游动态时序预测，极大概率会导致 Codebook 坍塌（即所有股票都被分到某几个死板的聚类里）。

我们来看看这两个阶段分别做了什么。

#### 阶段一：空间学习（Spatial Learning）——寻找离散的横截面原型

在这个阶段，模型的目标是：在固定的截面时间点 ，把  只股票压缩成离散的结构代码（Discrete Codes）。

1.  **特征提取**：输入是一段时间的序列特征（论文中是回溯窗口  天的 Alpha158 因子，特征维度 ）。模型首先用 GRU 提取单票的时序表征，然后用一个横截面 Transformer（Cross-asset Transformer，1层，2个注意力头）让所有股票在截面上互看，交换信息。
    
2.  **VQ 信息瓶颈（核心）**：这一步最关键。模型不输出连续的 embedding，而是维护了一本大小为  的“密码本”（Codebook）。对于每一只股票的连续表征，模型会计算它和这 512 个密码的距离，并强制**捕捉（Snap）**到最近的那一个密码上。
    

-   **量化启示**：这就相当于强制把全市场几千只股票，强行聚类到 512 个离散的状态里。不管你这只股票今天的微小波动是什么，只要宏观结构没变，你的离散 Code 就不变。这极大地过滤了特质性噪音（Idiosyncratic noise）。
    

4.  **Contrastive Learning（语义拉扯）**：仅仅靠欧氏距离最近邻匹配是不够的，论文加入了一个 InfoNCE 风格的对比损失函数。它强制当前股票的表征不仅要靠近选中的 Code，还要和其他 511 个无关的 Code 尽可能推远。这使得 VQ 不仅仅是几何上的就近，更是“语义”上的严格切分。
    
5.  **注入专家先验的 FiLM 重构**：为了让这 512 个离散密码保留有用的信息，模型必须进行特征重构（重构回 Alpha158）。但这里有一个极其精妙的设计——**重构不是只靠离散 Code，而是用 13 个 JKP 全球因子（如应计利润、动量、投资、低风险等）作为条件输入（Conditioning）。**
    

-   具体做法是使用 FiLM（特征线性调制）层，把这 13 个因子的值（回看 20 天的累积收益）作为仿射变换的  和 。
    

训练完阶段一后，这本大小为 512 的离散密码本**被彻底冻结**。

#### 阶段二：时序学习（Temporal Learning）——结构条件驱动的动态 MoE

进入第二阶段，时间轴动了起来。模型此时的目标是：根据股票历史的离散 Code 演变，预测未来的动态因子载荷，从而预测收益率。

1.  **结构 Token 的注入**：在时序 Transformer 处理单只股票的动态序列时，模型会把这只股票在阶段一算出来的离散 Code，作为一个“结构 Token（Structure Token）”拼在输入序列的最前面。这里引入了 RoPE（旋转位置编码）来处理时序相对位置。
    
2.  **离散代码路由的 MoE（结构条件选路）**：传统的 MoE（混合专家网络）通常是把连续向量输入给一个 Gating 网络，计算每个专家的权重。但 PRISM-VQ 做了一个非常硬核的改动：**Gating 网络的输入仅仅是这只股票当天的离散 Code，与当天的连续波动无关。**
    

-   也就是说，你是哪一类股票（你的 VQ Code 是什么），直接决定了你应该调用哪几个“专家”来计算因子载荷。
    
-   论文在 CSI 300 上用了 2 个专家（Top-1 激活），在 S&P 500 上用了 8 个专家（Top-4 激活）。
    

4.  **Base-Modulation 分解生成载荷**：模型并不直接暴力输出最终的收益率，而是保持了因子模型的优雅结构，输出 （截距）、（专家先验因子的载荷）和 （隐因子的载荷）。
    

-   载荷的生成采用分解逻辑：时序基线（Base）加上 MoE 算出来的残差调制（Modulation）。这种残差预测结构在训练时远比直接预测绝对数值稳定。
    

### 三、从实验室到实盘

脱离了精美的网络架构图，我们必须回到真实的测试集数据上来。论文使用了 2022 年到 2024 年严格样本外（Out-of-sample）的数据进行测试。预测目标是 5天前向收益率（Open(t+1) to Close(t+5)）。

![](assets/002.png)

#### 1\. 能否作为横截面选股的强 Baseline？

**直接给出答案：能，且尤其在低效与高效市场的反差中表现出了强韧性。**在 CSI 300（A股沪深300）上，PRISM-VQ 的每日 RankIC 均值达到了 **0.0646**，RankICIR 达到 0.4224。作为一个纯以 Alpha158 为量价输入的模型，这个数字是非常扎实的。相比之下，传统的 XGBoost 只有 0.0496，近期比较火的 Transformer 变体 DTML 是 0.0625。 真正令人侧目的是在 S&P 500（美股标普500）上的表现。美股的信噪比远低于 A股，几乎是所有量价模型的坟墓。在这个极其有效的市场上，很多深度模型完全学不到东西（比如 GRU 的 RankIC 只有 0.0057，VAE 只有 0.0043）。而 PRISM-VQ 把 S&P 500 的 RankIC 拉到了 **0.0141**。虽然绝对值看着小，但在美股大盘股圈子里，日均 0.01+ 的 RankIC 且 IR 能稳在 0.1208，已经具备了非常实质性的组合构建价值。

#### 2\. 消融实验里的秘密：没有信息瓶颈，美股根本没法做

我在阅读论文的 Ablation Study（Table 2）时，看到了最能佐证这篇论文核心价值的数据： 如果把核心的 **VQ Codebook** 去掉，退化成普通的连续表征模型：

-   在 CSI 300 上，RankIC 从 0.0646 跌到 0.0472（下降了 26.9%）。
    
-   **在 S&P 500 上，RankIC 直接从 0.0141 跌成了负数（-0.0024）！**
    

这个对比极其刺骨。它说明在 A股，市场无效性较强，哪怕你用连续空间硬拟合，哪怕过拟合了部分噪音，还是能刮出一点 Alpha 利润。但在美股这样极其有效、被各种机构高频机器来回洗过的市场里，微小的真实信号完全被噪音淹没。如果不设置极其严苛的“离散信息瓶颈”强迫降维过滤，连续神经网络就会 100% 陷入对噪音的拟合，导致样本外直接破产。

#### 3\. 组合构建的真实费后表现（Transaction Cost Check）

论文测试了 TopK-DropN 的组合构建逻辑（买入信号最强的 K 只股票，每天最多只调换 N 只）。默认 K=30, N=5，相当于单边日换手被硬性限制在了 16.6% 左右。 在这个带有明显换手限制的约束下，并施加了默认 5/15 bps（开盘买入 5个基点，收盘卖出 15个基点）的交易成本：

-   CSI 300：年化收益（AR） 30.77%，最大回撤（MDD） 19.24%，Sharpe Ratio **1.57**。
    
-   S&P 500：年化收益（AR） 14.42%，最大回撤（MDD） 16.16%，Sharpe Ratio **0.67**。
    

论文甚至跑了 Extreme 极限成本（20 bps 开仓 / 40 bps 平仓）测试，发现 Sharpe 虽然滑坡，但仍能保持正向。

#### 4\. MoE 的专家到底在干什么？

论文在 S&P 500 启用了 8 个专家（）。图表 6 的激活热力图揭示了一个很有趣的现象： 专家 6 和 专家 7 几乎长期霸占了 16%-20% 的算力，是典型的“全天候专家”；而专家 2 平均激活率只有约 7%，并且只在特定时间段发生尖峰脉冲（Spikes），是一个罕见市场状态下的“特种兵”。这证明离散 VQ Code 的引入，确实成功指挥了 MoE 实现了不同市场 Regime 下的任务解耦，而不是所有专家都在和稀泥。

### 四、必须警惕的复现陷阱与潜在限制

即便这篇论文的数据和逻辑非常漂亮，如果我们要把 PRISM-VQ 直接搬到实盘研究体系中，仍然有几个深水区需要谨慎趟过：

**第一，VQ Codebook 的“死码（Dead Codes）”问题极其难调**论文附录中轻描淡写地提到了一句：“使用指数移动平均（EMA）维护代码分配，并定期通过概率锚定重新初始化未充分利用的代码。”**复现时需要重点检查这里：** 凡是玩过 VQ-VAE 的工程师都知道，如果不做极高技巧的干预，网络训到最后往往只有 20 多个 Code 处于活跃状态，剩下的全部“死亡”（再也没有样本落进去）。EMA 衰减率怎么设、重启频率多高、重启时是用 K-means 聚类中心还是随机样本，这些工程细节将直接决定阶段一能否收敛。一旦 Codebook 坍塌，阶段二的 MoE 就会退化为单网络。

**第二，辅助 Loss 的“玄学调参”**模型在第一阶段除了 VQ Loss 和对比损失，还加了一个预测未来 1-9 天收益率的多周期辅助损失（Multi-horizon auxiliary prediction）。虽然论文给的权重极低（），但实盘经验表明，这种横跨多周期的辅助信号往往具有非常大的“梯度统治力”。如果不加这个 Loss 还能有类似表现，那说明 VQ 本身立住了；如果极其依赖这个  的 Loss，说明 VQ 编码的语义空间仍然不够稳健。

**第三，对 JKP 13因子的过度依赖**论文使用 13 个 JKP 全球因子作为金融先验（规模、动量、低风险、应计利润等）。这要求你的因子库必须有高质量、无未来函数（No-look-ahead）的基础因子建设支撑。如果你喂给阶段一 FiLM 的先验因子本身计算有误或发生共线性灾难，将直接污染整个离散密码本的几何空间。此外，模型对 JKP 因子采用 20 天滚动累计收益作为输入，这部分是否能和高频量价信号（比如分钟级特征）适配，存在极大的疑问，目前它显然更适合日频（Daily）的底层架构。

**第四，表征的长期跨周期漂移（Transition Dynamics）**附录给出了 VQ 状态转移矩阵。在月度视角下，CSI 300 的 Code 对角线持留率只有 4.9%（高于随机的 1%），S&P 500 是 7.4%。这说明股票在微观结构中的“跳跃”是非常频繁的。这种低持续性（Persistence）意味着，你的交易系统换手率天生就会被模型高频的状态切换所推高。如果你在做周频以上的相对低频中性策略，这套模型输出的打分可能会显得“过于神经质”。

### 结尾

研究无论是第一阶段通过 VQ 构建的**离散信息瓶颈**，通过 FiLM 强行注入**金融因子先验**作为约束，还是第二阶段将表征学习与时序动态进行**两阶段隔离**，这都是实盘研究中非常高级的对抗过拟合的工程手段。特别是对于那些深陷“加深网络反而让 OOS（样本外）夏普率下降”泥潭的金融 AI 工程师来说，这篇文章提供了一个极其清晰的解题路径：别再想着怎么让 Transformer 更深了，先想想怎么把喂给 Transformer 的数据维度，用 VQ 狠狠地捏碎并重塑成几个有意义的离散状态吧。
