我们都知道，现在的 LLM（大语言模型）写 Python 代码已经很溜了。但是，如果你扔给它一个几百兆的 CSV 文件，让它“从头到尾做一份完整的因子分析报告”，大多数模型（即使是 GPT-4）往往会顾此失彼：要么代码跑不通，要么分析逻辑断层，要么只能完成第一步清洗就停下了。

目前的解决方案通常是堆“工作流（Workflow）”——人工写死一步步的 Prompt，让模型按部就班地走。但这太僵硬了，缺乏灵活性。

今天给大家介绍的这篇人大与清华团队的论文 **《DeepAnalyze: Agentic Large Language Models for Autonomous Data Science》**，搞出了一个 **80亿参数（8B）** 的模型，在全自动数据科学任务上，取得了相当不错的结果 。

对于我们这些整天和数据、回测、因子挖掘打交道的量化人来说，它解决了一个核心痛点：**LLM 写代码虽然快，但一遇到复杂的、长链路的数据分析任务就容易“幻觉”或者“卡壳”。**

## 核心卖点：不仅是聊天，而是“自主编排”

现在的很多 Agent 是“提线木偶”，依靠预设的工作流（Workflow-based）。而 DeepAnalyze 的核心在于 **Agentic（代理式）** —— 它具备**自主编排（Autonomous Orchestration）** 和 **自适应优化（Adaptive Optimization）** 的能力 。

简单说，它不仅仅是回答你的问题，它会像一个真实的数据分析师一样：

1.  **自己规划**要做什么。
    
2.  **自己写代码**去跑数据。
    
3.  **自己看报错**，修代码，再跑。
    
4.  直到搞定任务，输出一份**分析师级别的报告** 。
    

最离谱的是，它只有 8B 参数，却在多个基准测试上超越了基于 GPT-4-Turbo 的系统，综合得分仅次于 GPT-4o 。

## 它是如何工作的？

DeepAnalyze 没有把表格数据硬塞进 Prompt 里（那样 Token 爆炸且效果差），而是模拟了人类的操作模式 。

它引入了 5 个专用的动作指令（Action Tokens），这就像是给了模型 5 把特定的“工具”：

1.  **`<Analyze>`** ：负责思考、规划、反思。比如：“我先看看这数据长啥样，然后决定用什么模型。”
    
2.  **`<Understand>`** ：专门用来阅读和理解结构化数据（Schema、表格内容）。
    
3.  **`<Code>`** ：生成 Python 代码（Pandas, Sklearn 等）。
    
4.  **`<Execute>`** ：执行代码，并接收环境给出的结果或报错。
    
5.  **`<Answer>`** ：输出最终结论。
    

模型会在这些动作之间**自主循环**：思考 -> 写代码 -> 看结果 -> 再思考 -> 再写代码... 直到任务完成。

## 它是如何训练出来的？

这是我最喜欢的部分。论文团队没有一上来就让模型学复杂的全流程，而是借鉴了人类的学习路径，设计了一套 **“课程代理训练（Curriculum-based Agentic Training）”** 。

![](assets/005.png)

### 第一阶段：基础

就像刚入行的初级分析师，先练基本功。

-   **练什么**：推理能力、看懂表格的能力、写代码的能力。
    
-   **怎么练**：使用了大量包含推理过程（Chain-of-Thought）的数据进行微调 。
    
-   **黑科技**：在生成训练数据时，他们用了一种**“关键词引导（Keyword-guided）”**的方法，强迫“老师模型”在推理时多关注数据细节（比如插入 "Wait", "Let me check" 这样的词），以此生成高质量的推理轨迹 。
    

### 第二阶段：实战演练

基本功练好了，开始做项目。

1.  **冷启动**：先用合成的交互数据教模型怎么把上面的 5 个动作串起来 。
    
2.  **强化学习（RL）**：把模型扔到真实环境里去试错。使用了 **GRPO** 算法进行策略优化 。
    

-   **奖励机制很有趣**：如果格式不对直接扣分；如果任务完成了给分；如果是写报告这种开放任务，会引入“LLM裁判”来给报告的丰富度、可读性打分 。
    

## 战绩如何？

光说不练假把式。DeepAnalyze-8B 在 12 个基准测试上进行了评估：

1.  **全流程数据科学（DataSciBench）**：综合得分 61.11%。相比之下，Llama-3.1-8B 只有 29.69%，甚至 Claude-3.5-Sonnet 也只有 52.29%。它仅次于 GPT-4o（64.51%） 。
    
2.  **数据建模（DSBench-Modeling）**：在机器学习建模任务上，成功率 90.63%，而且成本是 **$0**（相比 GPT-4 Agent 的高昂 API 费用） 。
    
3.  **开放式研究（DABStep-Research）**：这是最难的。给一堆数据，不给具体指令，让模型自己挖掘洞察并写报告。DeepAnalyze 在内容和格式上都拿了最高分，完全碾压了那些不知道该干嘛的闭源模型 。

## 启发

读完这篇论文，我觉得有几个点对我们很有启发：

1.  **低成本的“RA（研究助理）”要来了**：8B 的模型不仅能跑在服务器上，甚至高端一点的本地电脑都能跑。这意味着我们可以在本地部署一个专门的数据清洗和初步挖掘 Agent，不用担心数据泄露给 OpenAI。
    
2.  **结构化数据理解需要专门训练**：论文证明，如果去掉专门的 `<Understand>` 动作，模型对表格的理解能力会大幅下降 。我们在做私有化微调时，也应该注意这一点——通用推理不等于数据理解。
    
3.  **开放式研究的可行性**：DeepAnalyze 最让我惊讶的是它处理 **"Open-ended Research"** 的能力 。这意味着我们可以给它一份财报数据或行情数据，让它“自己去发现点什么”，这或许是挖掘 Alpha 的新思路。
    

**最后总结：** DeepAnalyze-8B 证明了，通过合理的架构设计（Action Tokens）和科学的训练方法（课程学习+强化学习），小参数模型在特定领域（数据科学）完全可以战胜通用的巨型模型。
