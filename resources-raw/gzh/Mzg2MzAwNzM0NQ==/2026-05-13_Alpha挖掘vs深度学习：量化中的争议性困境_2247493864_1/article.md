量化领域里,关于以线性方法论为主导的 alpha mining 与非线性模型的 deep learning 之间的争论,从未停歇。争论的焦点要么是"DL 黑盒不可解释,监管和 risk 都过不了关",要么是"alpha mining 因子早就拥挤干净了,不学 DL 就死路一条"。

Tensor Systems 的 Jimmy 总最近把一份内部的深度研究分享给我们——_Alpha Mining versus Deep Learning Approaches：A Controversial Dilemma in Quantitative Trading_。 这篇论文是我今年读到的关于Alpha Mining和Deep Learning介绍最详细的文章。论文在五个维度上——可持续性、稳健性、护城河、regime adaptability、agentic LLM fit 详细对比了两种方法论优劣势。

![](assets/001.png)

如果要一句话概括研究结论的话：DL 在散户主导、非线性、缺基本面锚点的市场上结构性占优；alpha mining 在机构主导、因子拥挤度尚未饱和的市场上仍是更高效选择；A 股、加密、商品短周期偏 DL，美股机构那一档偏 alpha mining。

等文章发表之后我们再详细解读，这次我先重点介绍一些的核心结论。

## 一、Alpha mining 不是只有"自动搜索"

**1.1 Alpha Mining的扩展定义**

学术界过去这些年讲 alpha mining 几乎全在讲 genetic programming、symbolic regression 这一支，让人误以为 mining = 自动搜索。真实的Alpha Mining应该涵盖任何通过系统化发现、严格假设构建或专家领域分析产生独立可测试、人类可解释信号的研究驱动过程。涵盖四个分支：

-   **系统化/计算Alpha Mining**：采用遗传编程、符号回归、穷举因子搜索，输出具有闭式表达式的信号公式。
    
-   **主观与研究驱动Alpha Mining**：由经验丰富的研究者观察市场现象，阐述经济机制，将其操作化为量化信号。例如基于分析师行为理论的盈利修正信号、基于委托代理问题的内部人持股信号、基于产业链传染逻辑的供应链信号。宏观与主题观点经操作化后亦属此类。
    
-   **市场微观结构Alpha Mining**：利用价格形成机制而非基本面或宏观变量，包括订单流不平衡、买卖价差动态、日内时间模式、开盘竞价与收盘定盘价动态。此类Alpha天然正交于基本面信号，且因来源具有结构性而非行为性，衰减速度较慢。
    
-   **另类数据与情绪Alpha Mining**：利用卫星图像、信用卡交易流、网站流量、财报电话会议文本、社交媒体情绪等数据。Agentic LLM的出现使该分支假设生成速度远超人类研究者容量，显著扩展了假设空间。
    

四个分支共享：可解释、可独立测试、可加性叠加、可审计、可入库。

在真正的量化研究中，大多数生产因子是从研究员的主观假设开始，再做严格统计检验后落库——不是自动搜出来的。把这类研究排除在 mining 之外，会让讨论失真。

**1.2 从原始Alpha到信号再到组合**

Alpha Mining流水线包含三个顺序阶段：

1.  **信号标准化**：原始Alpha分数经截面排名标准化（映射至\[-1,1\]）或截面z-score标准化，随后进行因子中性化，剔除共同因子暴露，得到残差信号。再通过基于信息系数（IC）半衰期的衰减乘数进行缩放；当IC低于阈值时，信号自动退役。
    
2.  **组合Alpha构建**：对K个标准化、衰减调整、中性化后的信号，通过IC加权/ICIR、信号层面的均值-方差优化（二次规划）或LASSO回归，求解组合权重ω，构建复合Alpha向量。
    
3.  **组合构建**：复合Alpha向量作为收益预测进入优化器层，求解带换手率、杠杆、因子中性化与头寸限制约束的均值-方差优化问题，输出目标组合权重。
    

显式、可审计的流水线是Alpha Mining可解释性优势的核心：复合Alpha的每个分量均可追溯至特定原始Alpha及其权重与IC历史。DL系统将上述全流程压缩为单一联合优化映射，以透明度为代价换取端到端梯度对齐。

**1.3 DL Alpha生成**

DL Alpha生成指参数化神经网络将高维输入特征矩阵（价格、成交量、基本面、另类数据、情绪数据）直接映射至收益预测、组合权重或交易动作，无需从业者预先指定预测关系的函数形式。其核心属性包括：端到端学习、动态加权（跨时间、制度与工具隐式调整特征重要性）、高容量（可表征非线性、长程与截面依赖）、不透明性（预测结果缺乏直接可解释性）。

## 二、护城河

论文有一个观点很有意思：**DL 系统护城河随时间二次方增长，alpha mining 是线性增长**。

具体分以下几个机制：

1.  **架构创新复利**：一项新的正则化技巧（如 Lipschitz 约束）、一种新训练流程（curriculum learning）、一种新结构（RegimeNAS），会同时改善所有未来训练出来的模型，并提升对所有历史数据的利用率。
    
2.  **冷存储模型库（cold storage）**：训练好的模型快照按市场环境打标签存档，当前环境与某段历史相似时，把对应快照重新激活或做集成。
    
3.  **计算可扩展性**：模型可以更大、训练可以更频繁、NAS 搜索空间可以更大、对抗模拟可以更逼真——每一项都吃 GPU。
    

## 三、可微优化器层

经典两阶段范式:预测网络训练目标是 MSE(预测收益 − 实际收益),优化器事后应用。预测准确但实际组合表现差是常态——预测模型不知道交易成本、不知道因子暴露、不知道头寸约束。

而端到端训练把组合绩效指标(已实现 Sharpe、扣成本收益)直接作为损失,梯度通过优化器回传到预测网络:

```
∂L_portfolio / ∂θ = ∂L_portfolio / ∂w* · ∂w* / ∂μ̂ · ∂μ̂ / ∂θ
```

其中 ∂w\*/∂μ̂ 是优化器解关于其收益输入的 Jacobian——可微求解器要算的就是这个 Jacobian。Jacobian 高灵敏度的资产是那些"更好预测最直接改善组合绩效"的资产,把预测网络的学习能力聚焦到最关键的位置。这是 端到端（E2E） 训练相对两阶段范式的实质优势,不只是工程美感。

作者把当前端到端训练的可微优化器层拆成四类：

**1\. CVXPYLayers(通用凸规划)**

声明式 CVXPY 语法,QP、SOCP、SDP 都能包装成可微层。梯度走 KKT 隐式微分:求解器解出原始-对偶解 (w\*, λ\*, ν\*) 后,对 KKT 系统 F(w\*, λ\*, ν\*; θ) = 0 关于 θ 隐式求导,得到 ∂w\*/∂θ。代价是要求解 O((n+m)³) 的线性系统。

研究原型首选,语法直观。N > 500 资产或多期 T > 5 立方瓶颈就受不了。

**2\. qpth / OptNet(专门 QP)**

限定到二次规划 min (1/2) w^T Q w + c^T w s.t. Aw=b, Gw≤h。固定块结构 KKT,可以 Cholesky 分解 + GPU 批处理加速。

实际生产组合约束(多头限制、杠杆、换手、因子中性、头寸上限)基本是线性,QP 形式够用。**单期 QP 的生产首选**。

局限:非二次目标(CVaR、风险平价)要凸重构或近似。CVaR 可转线性约束 + 辅助变量的 LP 形式,可以走 CVXPYLayers;风险平价非凸,要先做凸松弛再走 QP。

**3\. IPMO + MDFP(多期端到端)**

朴素 KKT 在多期下要 O((nT)³),实操不可能跑。MDFP (Mirror-Descent Fixed-Point) 把 KKT 替换成镜像下降不动点方程:

```
w* = prox_{ηf}(w* − η∇g(w*))
```

不动点方程可以做隐式微分,不需要因式分解 (nT × nT) KKT 矩阵。关键性质是\*\*每次迭代成本对 T 弱增长(实践近次线性)\*\*——多期端到端训练唯一计算可行的方案。

代价:截至 2025 年没有现成库,要自己实现 mirror-descent 更新、收敛检查、Jacobian-vector product。论文标 implementation difficulty 是 high,同意。

回报:多步交易成本可以内化到训练目标里。这是和单期 QP 训练的本质差异——单期 QP 只能优化 single-step 组合质量,IPMO 能把整段 rebalancing 路径都规划进来。对换手敏感策略,差异明显。

**4\. ADMM unrolling(GPU 友好)**

把 ADMM 的 K 次迭代展开成 K 个可微计算图节点。每次 ADMM 子问题闭式解(ℓ1 惩罚的 soft-thresholding、单纯形约束的投影),逐迭代廉价、可沿 batch 维度并行。梯度通过所有迭代经标准 backprop,不需要隐式微分。

代价:固定迭代次数(典型 20-50)有 truncation bias——可能没收敛到位。

优势:完全原生 GPU,随 batch size 扩展极好。对高频重训周期吸引力大。

## 四、YAND

YAND(Yau's Affine-Normal Descent)目标是把组合优化器扩展到完整 MVSK:

c₁ 到 c₄ 是投资者对均值、方差、偏度、峰度的偏好系数。"Unrestricted"指不依赖因子限制或参数化收益族,直接基于样本矩工作。

![](assets/002.png)

**它怎么躲掉张量诅咒**。这是 YAND 工程上最有价值的贡献。

高阶矩组合优化的核心壁垒不是统计而是几何:coskewness 张量按 O(n³) 存、cokurtosis 按 O(n⁴) 存。n=50 就不能玩,n=5000 物理不可能。

YAND 的核心 trick在于 MVSK 目标及其所有导数可以完全通过中心化收益矩阵 A = R - 1μ^T ∈ R^{T×n} 与投影组合收益向量 z(x) = Ax ∈ R^T 表达:

₂²

₃

₄²

显式张量方法需要 O(n⁴) 存储, 而YAND 只需要 O(Tn)。

**A 股实证**:在清洗后的 RESSET 5 分钟 A 股面板(n=5440 只股票、T=66412 时间段)上,YAND-MVSK 跑出:

-   **q=0.40 中等收益目标**: 年化 36.24% → 41.68%,Sharpe 1.332 → 1.619,1% CVaR 改善、最大回撤下降。
    
-   **q=0.60 激进收益目标**: MV 和 MVSK 都收敛到角点解,差距消失。
    

YAND 效果虽然很好，但是现在还没法接入 E2E， 原因在于：

1.  论文只导了对决策变量 w 的 oracle(∇f、Hessian-vector product、third-order action),没有导任何输入参数 θ 的 ∂w\*/∂θ。MVSK 的 KKT 涉及三阶项,做隐式微分不平凡。
    
2.  YAND 是变深度 Newton 法,迭代次数依赖问题实例,不能像 ADMM unrolling 那样固定 unroll。
    
3.  单纯形可行性机制涉及条件分支——trial step 越界就投影回来并激活 reduced-dim face solver。branching 不可微。
    

然后作者给了一个理论路径:严格内部解情况下(w > 0 分量级成立、无激活约束),KKT 退化为 ∇\_w f(w; μ, A) = λ𝟙,可以一次 Hessian-vector product 在 O(Tn) 成本内做出 ∂w\*/∂μ 的隐式微分。和 CVXPYLayers 对凸规划的做法是一类思路。

**比较：YAND与端到端优化**：因YAND在两阶段范式中运行（单独预测μ，然后优化），与E2E系统的比较非关于孤立优化器质量，而是关于两阶段与联合训练差距的成本，以及YAND的高阶矩能力是否补偿。

YAND在尾部风险塑造为主要目标之处具有结构性优势：A股证据显示在中等收益目标处Sharpe较均值-方差提升+22%，这是当前E2E DL优化器层结构盲目的一维组合质量。E2E系统在联合预测-分配对齐、训练期间交易成本内部化、动态制度适应性方面保留优势——这些均为YAND静态分配设计所缺乏。

**混合可能性**：最实际有趣的含义是一种分阶段混合：E2E训练（带QP层进行均值-方差）的DL预测网络在推理时将其收益预测μ̂输入YAND作为终端分配步骤。这将：(i) 保留E2E训练通过QP层使预测与组合绩效对齐；(ii) 在推理时应用YAND的高阶矩重塑；(iii) 受益于YAND在分配阶段对大规模宇宙的可扩展性。成本在于训练-测试不匹配：预测模型在训练时与QP优化器对齐，但在推理时 feeding YAND-MVSK优化器。

## 五、市场结构原则

市场微观结构会决定哪种范式具有结构性优势，作者在股票，商品期货以及加密市场分别进行了测试，最终归纳出**市场结构原理**的一般性原则：

-   DL相对于系统化Alpha Mining的优势，与（a）散户/行为参与度、（b）价格动态中的非线性与非平稳性程度、（c）基本面锚的缺失程度、（d）线性因子空间的因子拥挤程度成正比。

### 六. 结论

这篇研究对Alpha Mining与DL量化Alpha生成方法进行了全面多维比较，简单总结论文的结论：

1.  **无 universally 优越的范式**。每种范式的相对优势由市场微观结构、组织能力与投资期限决定。市场结构原理为范式选择提供了原则性基础。
    
2.  **DL在行为市场中的优势是结构性的**。在由散户参与、非线性动态与缺失基本面锚主导的市场（加密货币、中国A股、短周期商品期货）中，DL架构在结构上更适合捕捉主导性预测模式。该论断关乎模型架构与市场动态的对齐，而非模型质量的绝对主张。
    
3.  **工程化良好的DL系统复合其护城河**。通过冷存储库、制度感知架构搜索、自适应交易机制层与端到端组合优化，DL系统积累随每个市场周期增长的机构记忆与流水线深度。该复合动态在Alpha Mining中无直接对应，后者的护城河主要取决于库规模与流程质量。
    
4.  **Agentic LLM是Alpha Mining的乘数器**。Agentic LLM的自然语言界面与系统化Alpha发现的假设驱动、迭代性质紧密对齐。对DL系统，LLM扮演有用但边缘的角色。
    
5.  **混合架构是长期均衡**。最优系统组合系统化与DL组件，由制度感知元模型动态加权其贡献。具体混合比例取决于组织能力与市场结构。
    
6.  **知识诚实要求承认证据质量**。论文引用的大部分证据来自学术回测与预印本，而非经核实的实盘绩效数据。结构性论点由理论与实证模式支持，但从业者应对具体绩效主张保持适当怀疑。
