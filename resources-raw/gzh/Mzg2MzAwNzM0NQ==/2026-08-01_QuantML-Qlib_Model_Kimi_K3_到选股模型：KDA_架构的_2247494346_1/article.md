经过这段时间的实际使用，大家对 Kimi K3 的能力应该已经有了比较直观的感受。无论是代码、工具调用，还是长任务处理，它的整体表现都已经进入第一梯队。

与其他几家不同,KIMI的预训练很有特色，这次我们尝试将KIMI的底层结构应用于选股模型，测试其模型的表现。

## K3 模型结构

K3 总参数为 2.8T，每个 token 激活约 104B 参数，共 93 层，其中 69 层使用 Kimi Delta Attention（KDA），24 层使用 Gated MLA。模型包含 896 个专家，每个 token 选择 16 个，另外保留 2 个共享专家；视觉侧使用 MoonViT-V2，权重采用 MXFP4、激活采用 MXFP8。参数很多，但每次计算只走一小部分路径。

![](assets/001.png)

这套结构可以拆成四个部分。

KDA 负责连续记忆。标准全注意力保留历史 token 的键和值，再让新 token 与历史逐一计算关系，序列拉长以后，KV cache 和计算量都会上升。KDA 类似lstm, 把历史压入固定大小的状态，新的信息通过 delta rule 写入，同时利用更细的通道级门控决定不同信息的衰减速度。直观地说，它不再把所有旧内容原样放在桌面上，而是持续更新一份内部状态。

Gated MLA 负责精确检索。有限状态适合保存连续信息，但压缩一定会损失细节，因此 K3 没有把全注意力完全移除。69 层 KDA 与 24 层 Gated MLA 交错使用，一个偏向低成本的状态更新，一个保留对特定历史位置的访问能力。Kimi Linear 论文此前训练的 48B 总参数、3B 激活参数模型也采用了 KDA 与 MLA 的混合结构；论文报告在 1M 上下文下，KV cache 最多减少 75%，解码吞吐最高达到 6 倍。这些数字来自论文环境，不能外推到所有实现和序列长度。

Attention Residuals 处理层间信息传递。普通 Transformer 按固定残差路径把上一层输出交给下一层，AttnRes 允许后续层从更早的表示中选择需要的信息，减少深层网络里信息被连续变换后逐渐稀释的问题。

Stable LatentMoE 负责扩展容量。896 个专家不需要同时运行，每个 token 只激活其中 16 个，模型容量与单次计算量因此被拆开。KDA、Gated MLA、AttnRes 和稀疏 MoE 解决的是不同问题，K3 的能力来自它们的组合，单独拿出 KDA，得到的只是其中一条技术线索。

## 从百万 token 到 60 个交易日

股票时序与长文本有一个相似点：历史信息的价值不相等。最近几天的量价变化通常更直接，较早的数据有时仍然有用，但需要根据市场状态衰减。KDA 的通道级门控恰好提供了这种归纳偏置，不同特征可以保留不同长度的记忆。

这次我们在 Qlib 中实现了一个浅层 Kimi Linear 模型，只保留与短时序有关的部分：KDA 递推状态、细粒度衰减门、delta-rule 写入、Q/K/V 的因果 depthwise 卷积、RMSNorm、输出门控和 SwiGLU。模型输入为一只股票最近 60 个交易日的特征序列，取最后一个时点的表示预测未来 5 日收益。

同时我们采用transformer作为对比，将其参数量与 Kimi Linear 的参数量基本设置一致。
