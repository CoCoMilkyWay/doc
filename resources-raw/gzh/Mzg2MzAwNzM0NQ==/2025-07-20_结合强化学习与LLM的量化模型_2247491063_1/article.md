在快速演变的金融市场格局中，有效的决策工具对于管理由经济指标和市场动态驱动的复杂性至关重要 。算法交易策略因其自主执行交易的能力而备受瞩目，其中深度强化学习（Deep Reinforcement Learning, DRL）已成为通过持续市场互动优化交易行为的关键方法 。然而，基于强化学习（RL）的系统面临重大挑战，特别是在适应不断变化的时间序列数据和整合非结构化文本信息方面 。

为应对这些局限性，大型语言模型（LLM）的最新进展提供了新的机遇 。LLM 具备分析海量数据的能力，能够提供增强的洞察力，从而补充传统的市场分析 。本研究提出了一种创新方法，将六种不同的 LLM 整合到算法交易框架中，并开发了一种名为 **Stock-Evol-Instruct** 的创新指令生成算法 。该算法使 RL 代理能够利用 LLM 驱动的洞察力来微调其日常股票交易决策策略 。通过使用 Silver (SLV) 和 JPMorgan (JPM) 的真实世界股票数据进行的实证评估，证明了该方法具有超越传统交易模型的巨大潜力 。本研究通过弥合 LLM 和 RL 在算法交易中的差距，为金融技术开辟了新的前沿，为未来自主交易系统的发展奠定了基础 。

* * *

#### **第一章：引言**

金融市场受到经济指标和投资者行为等复杂因素的共同影响，需要精密的决策工具来应对其固有的波动性 。算法交易策略能够自动化执行股票交易决策，已成为现代金融市场的关键机制 。这些由先进计算算法驱动的策略能够自主运行，并引起了投资者和金融分析师的极大关注 。信息技术和机器学习的进步进一步革新了算法交易，使其能够在没有直接监督的情况下做出更精确、更及时的决策 。然而，这些系统相关的潜在风险依然深远，因为设计不佳的算法可能导致灾难性的财务后果 。一个关键挑战在于这些算法动态适应持续变化的价格时间序列的能力，这要求开发更智能、更灵活的决策框架，以在不断变化的市场环境中保持效能 。

传统的算法交易策略，如趋势跟踪和均值回归，长期以来为现代交易方法提供了结构性支柱 。然而，机器学习——特别是监督学习和强化学习（RL）——的出现，彻底改变了这一领域 。监督学习模型擅长通过分析结构化的历史数据来预测股票趋势，而 RL 则通过与市场持续互动来优化交易决策，通过迭代反馈循环完善策略 。RL 的自适应性特别适合于复杂环境，例如涉及复杂模式识别的环境，并已证明在推进算法交易系统中起着关键作用 。

尽管潜力巨大，RL 仍面临重大挑战，包括处理不规则间隔的价格时间序列数据、从广阔的搜索空间中高效选择特征，以及机器学习模型固有的复杂性 。为应对这些挑战，基于“方向性变化”（Directional Change, DC）的事件驱动方法利用内在时间更准确地捕捉市场动态，为传统方法提供了一个有前景的替代方案 。

与此同时，大型语言模型（LLM），如 OpenAI 的 GPT 系列，凭借其巨大的参数空间和多样化、精心策划的训练数据集，正迅速成为金融领域内的强大工具 。这些模型在自然语言处理（NLP）任务中表现出卓越的能力，并擅长分析大量的金融数据，包括新闻、投资者通讯和监管报告 。尽管 LLM 在金融领域的应用前景广阔，但其整合仍处于探索阶段 。

本研究深入考察了六种不同的 LLM，包括 LLaMA-2、LLaMA-3、Mistral-7B、Falcon-7B、OpenELM 和 GPT-4o 。这些 LLM 通过整合真实世界的新闻，根据 LLM 驱动的洞察力动态调整交易代理的行为，从而作为深度强化学习（DRL）方法的代理 。此外，本研究引入了一种全面的基于 NLP 的微调方法，使 LLM 能够模拟类似人类的交易决策 。

本研究的核心贡献如下：

-   **首先**，实现了基于深度Q网络（DQN）和双重深度Q网络（DDQN）的 RL 代理用于算法交易 。
    
-   **其次**，整合了 LLM，结合股票相关新闻作为代理，通过利用 LLM 的决策来调节 DRL 代理的行为，从而实现了对 LLM 在算法交易中的实证验证 。
    
-   **第三**，引入了一种名为 **Stock-Evol-Instruct** 的新颖指令生成算法，专门设计用于生成针对股票市场预测的 NLP 数据集 。该算法根据历史金融数据、市场趋势和新闻动态调整指令，从而创建更符合真实世界市场条件的数据集 。
    
-   **第四**，微调了两个开源 LLM（Mistral-7B 和 LLaMA-3-8B），使其作为完全基于 LLM 的交易代理，能够模拟类似人类的市场交易决策 。
    

#### **第二章：相关工作**

RL 在投资组合管理中常面临泛化能力差、忽视市场影响以及对因果关系考虑不足等挑战 。为缓解这些问题，研究者们开发了如 LOB-GAN 生成模型等工具，通过模拟金融市场为 RL 代理创造逼真的训练环境 。此外，利用多代理系统（MAS）构建的股票市场模拟器也准确复制了关键市场指标 。

向基于 DRL 的算法交易的转变是显而易见的。例如，有研究引入了结合人类反馈的奖励驱动 DDQN 算法，在六个数据集上实现了高达 1502% 的累积回报 。同样，多代理双重深度Q网络（MADDQN）在平衡风险与回报方面取得了 23.08% 的平均累积回报 。

近期，基于 LLM 的框架在金融决策中展现了变革性潜力 。FinGPT 是一个面向金融领域的开源 LLM，它采用以数据为中心的方法，为研究人员和从业者提供可访问和透明的资源 。其他框架如“总结-解释-预测”（SEP）引入了可解释的股票预测，通过自反思代理和近端策略优化（PPO）在准确性和投资组合构建方面超越了传统方法 。FinMem 引入了具有分析、记忆和决策组件的代理，实现了个性化、可解释和适应性强的交易策略 。

新闻驱动的方法也备受关注。LLMFactor 和 MarketSenseAI 等模型利用 LLM 解读财经新闻和宏观经济因素，在市场预测方面取得了显著成果 。而由反思驱动的系统（如 FinAgent）和由辩论驱动的方法则通过多模态输入、自适应反思机制以及代理间辩论，进一步提升了自动交易的回报和准确性 。这些贡献共同凸显了 LLM 在重塑金融交易和决策领域的效能 。

#### **第三章：方法论**

本研究的框架旨在将 DRL 与 LLM 相结合，通过利用历史市场数据和实时新闻来优化股票交易决策 。整个流程始于作为交易代理基础的 DRL 方法，随后构建了一个利用股票数据和技术指标引导决策的交易环境 。LLM 在此框架中扮演关键角色，它们通过分析财经新闻生成可操作的见解，从而增强交易代理的能力 。为了进一步提升这些能力，本研究提出了 **Stock-Evol-Instruct**，一种旨在为基于 NLP 的代理量身定制高质量股票市场预测数据集的创新指令生成算法 。

##### **3.1 使用 DQN 和 DDQN 的强化学习**

DQN 和 DDQN 是 DRL 中的基础算法，广泛应用于算法交易等序列决策问题 。交易代理的目标是通过选择三种可能行动（买入、卖出或持有）之一来最大化长期回报 。

-   **DQN (Deep Q-Network)**: 在 DQN 方法中，使用单个 Q 网络  来估计在当前市场状态  下采取行动  的价值 。网络参数  基于观测到的奖励和状态转换进行更新。其目标 Q 值的计算方式为 ，其中  是奖励， 是折扣因子 。由于使用同一网络选择和评估最佳动作，DQN 容易出现 Q 值过高估计的问题 。
    
-   **DDQN (Double Deep Q-Network)**: 为解决 Q 值过高估计问题，DDQN 算法采用了两个独立的 Q 网络：一个主网络  和一个目标网络  。主网络用于动作选择，而目标网络提供更稳定的目标值 。DDQN 的更新使用了以下目标函数： 。通过将动作选择（由主网络完成）与价值评估（由目标网络完成）解耦，DDQN 减少了在 DQN 中发现的 Q 值过高估计 。
    

在每个时间步，代理使用 \-greedy 策略选择一个动作：以概率  探索（选择随机动作），以概率  利用（选择最大化 Q 值的动作）。随着时间推移， 的值会衰减，使代理从探索转向利用 。执行动作后，代理将经验元组  存储在经验回放缓冲器中，以减少连续转换之间的相关性，从而提高学习的稳定性 。

##### **3.2 交易环境**

交易环境算法经过精心设计，旨在促进稳健的交易决策 。初始设置为 10,000 初始资金，零持股和零利润 。对于每个动作，算法会计算关键性能指标，包括当前价差（PD）和移动平均差（MA）。

当 LLM 被整合时，决策过程得到显著增强 。奖励结构会根据 LLM 提供的专家指导进行动态调整 。

-   如果代理的买入动作得到 LLM 的证实，奖励将**加倍** 。
    
-   如果 LLM 建议卖出，奖励同样**乘以二**，从而强化高置信度的决策 。
    
-   如果 LLM 建议持有，则分配一个固定的正奖励，以鼓励在动荡的市场中保持谨慎 。
    

相反，当代理的行动与 LLM 的建议不一致时，奖励将基于价格指标计算，并对无效行动施加惩罚 。为了防止奖励值出现极端波动，所有奖励值都被裁剪到 \[-1, 1\] 的范围内 。

##### **3.3 利用 LLM 进行新闻分析以辅助交易**

本研究的主要目标是基于对新闻头条的分析来预测股票市场行为 。研究利用 LLM 解读与特定股票（SLV 和 JPM）相关的新闻，以确定最佳行动方案 。为此，采用了多种提示技术，包括零样本学习、指令遵循和基于范例的提示 。

-   **提示设计**:
    

1.  **零样本预测 (Prompt 1)**: 向 LLM 提供最少的上下文，仅基于新闻标题做出“买入”、“卖出”或“持有”的决策 。
    
2.  **基于指令的预测 (Prompt 2)**: 在零样本提示的基础上增加额外指令，强调情感分析的重要性并忽略不相关的标题 。
    
3.  **基于范例的预测 (Prompt 3)**: 引入人工标注的范例，为 LLM 提供先前基于相似标题的决策案例，以增强其泛化能力 。
    

-   **用于交易预测的 LLM**: 为了测试这些提示，研究选择了一系列在零样本和少样本提示方面表现出色的 LLM，包括 OpenAI 的 GPT-40、Meta 的 LLaMA-2-7B 和 LLaMA-3-8B、Mistral-7B、Falcon-7B 以及 OpenELM 。
    

##### **3.4 交易代理**

交易代理的目标是创建一个完全基于 NLP 的系统，该系统能解读市场时间序列数据和新闻信号，以做出明智的股票交易决策 。为实现这一目标，本研究开发了一个多步骤流程，包括生成高质量的提示模板、评估其质量，并通过 **Stock-Evol-Instruct** 方法对其进行演进，以增强模型的性能 。

-   **提示生成与评级**: 首先，设计了一系列提示模板，引导 LLM 生成交易决策指令 。这些模板基于以下标准：**价格变动**（当日开盘价与收盘价的比较，以及收盘价与2日移动平均线的对齐情况）和**新闻预测**（将新闻情绪作为影响因素）。通过这种方法生成了20个不同的提示变体 。 受 LLM-as-a-Judge 框架的启发，研究再次使用 LLM 来评估这些提示模板的质量，评分范围为1到100 。只有评分超过80分的9个高质量提示被保留下来用于后续步骤 。
    
-   **Stock-Evol-Instruct：基于股票的自动指令数据演进**: 该方法受到 WizardLM 中提出的 Evol-Instruct 方法的启发，旨在为基于股票市场的代理微调生成高质量数据 。它包含三个核心步骤：**指令演进**、**响应生成** 和 **淘汰演进** 。
    

1.  **指令演进**: Stock-Evol-Instruct 使用 LLM 通过两种方式演进指令：“深度演进”和“广度演进” 。**深度演进**通过增加约束、引入依赖关系、具体化抽象概念和增强推理步骤来使指令更复杂和困难 。**广度演进**则旨在扩大主题覆盖范围，增加数据集的多样性 。
    
2.  **响应生成**: 一个关键的创新点在于，此步骤**不使用 LLM 生成响应**。相反，它采用一个**基于规则的决策系统**作为生成“买入/卖出/持有”决策的“真值” 。该规则系统基于价格变动（收盘价与开盘价的比较）和短期趋势（收盘价与2日移动平均线的比较）进行判断 。
    
3.  **淘汰演进**: 此步骤用于过滤掉演进过程中产生的有问题的指令，例如那些因 LLM 幻觉而包含未知占位符的指令 。
    

-   **在股票演进指令上微调 LLM**: 最后，将演进后的高质量指令数据集用于对 LLM（特别是 Mistral-7B 和 LLaMA-3-8B）进行有监督的微调 。这种方法确保了微调后的 LLM 足够稳健，能够处理股票市场决策的复杂性，从而创建一个能有效分析数值数据和文本新闻的 NLP 交易代理 。

#### **第四章：结果**

##### **4.1 实验设置**

-   **评估指标**: 采用两个关键指标：\*\*投资回报率 (Return on Investment, ROI)**，用于衡量投资相对于其成本的盈利能力，以及**夏普比率 (Sharpe Ratio, SR)\*\*，用于评估投资或交易策略的风险调整后回报 。
    
-   **数据集**: 使用了 Silver (SLV) 和 JPMorgan (JPM) 两支股票的时间序列数据和相应的财经新闻 。数据被划分为训练集和测试集，以模拟真实的交易条件，并确保模型在未见过的数据上进行测试 。
    
-   **基线模型**: 采用了两个基线模型进行比较：**FinRL**，一个纯粹基于 DRL 的自动化交易策略开发库 ；以及 **FinGPT**，一个在交易数据集上微调的开源金融 LLM 。
    

##### **4.2 Q-Learning 与 LLM 在股票市场数据上的评估**

对 Q-Learning 模型和 LLM 在股票市场数据上的评估（详见附录 H，表3）揭示了它们在交易决策中的表现 。

-   **LLM 优于传统 RL**: 将 LLM 与 RL 模型相结合，通常表现优于单独的传统 RL 模型 。例如，GPT-40 模型与 DDQN 结合，在使用 Prompt-2 的情况下，对 SLV 股票实现了 2.43 的夏普比率，显示出明显优势 。这表明利用 LLM 可以增强交易策略的决策过程，特别是通过提供更丰富的上下文理解和更好地适应市场信号 。
    
-   **ROI 与 SR 的不一致性**: 一个值得注意的现象是，高夏普比率并不总能转化为正的投资回报率 。例如，Mistral-7B 与 DDQN 的组合在 JPM 股票上产生了 2.29 的夏普比率，但 ROI 却为 -10.39% 。这凸显了不能仅依赖 SR 作为性能指标的重要性；ROI 提供了关于交易策略整体盈利能力的关键背景信息 。
    
-   **模型与提示的协同作用**: 结果表明特定 LLM 和提示之间存在复杂的协同作用 。例如，Falcon-7B 模型在多种提示下表现良好，尤其是在与 DDQN 结合用于两种股票时，使用 Prompt-2 对 SLV 股票实现了 2.18 的夏普比率 。这表明某些模型-提示组合可以更有效地利用市场信息，从而带来更好的交易结果 。
    

总的来说，这些发现强调了在开发能够驾驭复杂金融市场的稳健交易代理时，精心选择模型和设计提示的重要性 。通过指令数据集对 LLM 进行微调对于优化其在交易场景中的性能至关重要 。

##### **4.3 交易代理在真实世界测试集上的结果**

经过微调的交易代理在指令数据集和真实世界分割数据上进行了测试，表现出强大的竞争力。

-   **对于 JPM 股票**:
    

-   **LLaMA-3** 实现了 81.53 的高 F1-Score，表明其在识别有利可图的交易方面具有很强的能力 。然而，其 ROI 为 23.78%，虽然为正，但低于 Mistral-7B 。
    
-   **Mistral-7B** 的 ROI 高达 \*\*53.15%\*\*，尽管其精确率和召回率较低，但这似乎表明它识别出了数量更少但利润更高的交易 。这说明虽然 LLaMA-3 在交易预测方面准确性更高，但 Mistral-7B 可能在优化实际财务结果方面更胜一筹 。
    

-   **对于 SLV 股票**:
    

-   两个模型的表现都有所提升，**Mistral-7B** 在召回率和 F1-Score 方面均优于 LLaMA-3 。
    
-   Mistral-7B 的 ROI 达到了 \*\*48.36%\*\*，略高于 LLaMA-3 的 44.93%，再次凸显了 Mistral-7B 微调后的强大盈利能力 。
    

-   **与基线模型的比较**:
    

-   **FinRL**（纯 RL 代理）在 JPM 和 SLV 上的 ROI 分别仅为 0.04% 和 7.33%，表明仅依赖股票时间序列数据时盈利能力有限 。
    
-   **FinGPT**（开源微调模型）在 JPM 和 SLV 上的 ROI 分别为 -8.28% 和 -20.58%，显示出在利用自然语言数据实现持续盈利方面存在挑战 。
    

这些结果证明了使用指令数据集对 LLM 进行微调在交易任务中的价值 。LLaMA-3 较高的 F1-Score 突显了其在预测交易方面的一致性，而 Mistral-7B 在两只股票上都获得更高的 ROI，则强调了其将预测转化为实际利润的能力 。

* * *

#### **第五章：讨论与局限性**

-   **提示设计的关键作用**: 结果分析指出，提示设计在优化 LLM 在交易应用中的性能方面起着至关重要的作用 。不同提示和模型之间 SR 和 ROI 的差异表明，量身定制的提示可以显著影响 LLM 与 RL 策略结合的有效性 。
    
-   **LLM 的性质**: LLM 在处理特定领域的任务（如股票市场交易）方面表现出强大的能力 。微调过程表明，虽然像 GPT-40、LLaMA 和 Mistral 这样的 LLM 擅长综合基于新闻的见解，但它们在交易场景中的性能仍然受益于基于代理和指令的微调改进，例如本研究提出的 Stock-Evol-Instruct 框架 。
    
-   **SR 与 ROI 的不一致性**: SR 和 ROI 之间的不一致性可能源于多种因素 。SR 衡量风险调整后的回报，但可能无法完全反映交易策略的整体盈利能力，特别是在高风险可能导致巨大收益或损失的情况下 。而 ROI 只关注盈利能力，忽略了风险 。当模型在风险调整后表现良好（高 SR）但未能实现持续的正回报（低 ROI）时，就会出现差异 。
    
-   **局限性**: 本研究的一个主要考虑因素是用于指令生成的初始提示数量有限（仅20个）。虽然更大规模的提示集可能增强交易决策的多样性，但本研究有意限制了范围，其主要目标是在受控环境中评估和微调 LLM 。未来工作的一个有前景的方向是扩大提示数量，特别是利用各种 LLM 来生成提示，以进一步探索模型如何适应更复杂的市场情况 。
    

#### **第六章：结论**

将 LLM 整合到算法交易中，代表了在动态金融环境中增强决策过程的一项有前景的进步 。随着金融市场变得日益错综复杂和动荡，LLM 提供动态、类人交易策略的能力为金融行业的创新提供了新的机遇 。

本研究通过将 RL 技术与来自实时财经新闻的 LLM 驱动的见解相结合，证明了像 LLaMA 和 Mistral 这样的微调模型可以有效地充当交易代理，对市场变化做出类似人类的决策 。此外，提出的 **Stock-Evol-Instruct** 方法专为生成高质量指令数据集而精心设计，通过适应真实世界股票市场条件的复杂性，增强了 LLM 的性能 。通过对 SLV 和 JPM 等案例研究股票的严格实证验证，本研究的结果表明，将 NLP 驱动的模型整合到基于 RL 的交易系统中，不仅提高了交易代理的准确性，还增强了它们的适应性，为未来更复杂的交易策略铺平了道路 。
