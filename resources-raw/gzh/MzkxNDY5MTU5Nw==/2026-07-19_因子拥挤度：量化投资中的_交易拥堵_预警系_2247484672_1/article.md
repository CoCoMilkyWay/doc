## 二、什么是拥挤度？

**因子拥挤：** 由于跟踪、投资某种因子的资金过多，导致该因子的未来收益率、稳定性下降。将这一个现象称为因子拥挤。

**因子拥挤度：** 用来刻画“因子拥挤”现象程度的大小指标（度量），称之为：“因子拥挤度”。例如：最近的小市值因子，过去一年表现都还不错，但是最近出现了因子拥挤。

通过定义、文献我们发现，既然是用来形容刻画这种收益率、稳定性的下降。那么，“因子拥挤度”一定具备下面的性质：

1.  "因子拥挤度"在中长期其实具有一定的则是效果。
    
2.  “因子拥挤度” 与未来因子收益率呈现负相关性，与未来收益的波动率成正相关性。
    
3.  高“因子拥挤度”的因子，未来更加容易出现大幅回撤 。
    

**因子从有效到拥挤的经历的几个过程：**

-   **初期**：少数机构发现某个因子有效，超额收益丰厚
    
-   **扩散**：研报发布，更多人跟进
    
-   **拥挤**：大量资金涌入，因子选出的都是同一批股票
    
-   **失效**：买入推高价格，卖出砸盘，因子收益消失甚至反转
    

具体**因子拥挤**表现为：

-   多头组和空头组的估值价差收窄
    
-   因子选出的股票相关性升高
    
-   短期收益过高（透支了未来收益）
    
-   市场对因子的持仓集中度上升
    

## 三、因子拥挤度算法

### 3.1 估值类：价差收窄

**核心逻辑**：多头（便宜股）和空头（贵股）的估值差距缩小，说明便宜货被买贵了。

**指标**：

-   **估值价差(PB)** ：空头均值多头均值
    
-   **估值价差(PE)** ：空头均值多头均值
    

**案例：**

-   正常情况：价值因子选出的便宜股 PB=1.5，贵股 PB=5.0，价差 = 1.20
    
-   拥挤时：便宜股被炒到 PB=3.0，贵股=5.0，价差缩窄为 0.51
    

**预警阈值**：价差Z-score > 1.5时，拥挤度偏高，注意：这是是在时序上的z-score

### 3.2 相关性类：股票开始"齐涨齐跌"

**核心逻辑**：如果多头组的股票走势高度一致，说明它们被同一批资金买入（拥挤）。

**指标**：

-   **配对相关性（原始）**：计算多头组内股票的日收益率相关性
    
-   **配对相关性（特质）**：剔除市场因素后的相关性（更纯粹）
    
-   **两两相关性（中信建投版）**：统计多头组中两两相关系数>0的比例
    

**计算方法**：

```
# 1. 根据因子值选出多头组（前10%）long_stocks = factor_panel.iloc[-1].nlargest(n_group).index# 2. 提取这些股票过去60天的收益率returns_long = returns_panel[long_stocks].iloc[-60:]# 3. 计算相关系数矩阵corr_matrix = returns_long.corr()# 4. 取平均（排除对角线）pairwise_corr = corr_matrix.values[np.triu_indices_from(corr_matrix, k=1)].mean()
```

**预警阈值**：相关性 > 0.6时，拥挤度高

### 3.3 收益/动量类：涨太快是危险信号

**核心逻辑**：短期暴涨往往意味着透支了长期收益。

**指标**：

-   **长期累计收益（36月）**：过去3年的因子累计收益
    
-   **因子动量（6月）**：过去半年的因子累计收益
    
-   **因子离散度**：多头组内个股收益的分散程度（低 = 拥挤）
    

**从项目运行结果中发现**：

> 长期收益过高的因子，未来12个月收益显著下降。相关系数达到 -0.42（负相关！）

### 3.4 波动率类：多头比空头还要惊心动魄

**核心逻辑**：正常情况下，空头（高风险股）波动率应该更高。如果多头波动率超过空头，说明被炒作了。

**指标**：

-   **波动率比率（多头/空头）**：多头组收益空头组收益
    
-   **波动率比率（多头/市场）**：多头组收益市场收益
    
-   **截面波动率**：因子值本身的波动性
    

**预警阈值**：多头波动率 > 空头波动率时（比率>1），拥挤

### 3.5 结构类：持仓集中在少数股票

**核心逻辑**：PCA主成分分析，如果第一主成分解释了大部分收益（80%+），说明多头组实际上就是几只票在涨，其他都是陪跑（拥挤）。

**指标**：

-   **资产集中度**：第一主成分的方差占比
    

**计算过程**：

```
# 1. 构建多头组的收益率协方差矩阵cov_matrix = returns_long.cov()# 2. PCA降维pca = PCA(n_components=1)pca.fit(cov_matrix)# 3. 解释方差比率centrality = pca.explained_variance_ratio_[0]  # 越高 = 越集中 = 越拥挤
```

### 3.6 其他类：换手率和成长性

**换手率拥挤度**：

-   多头组换手率异常升高 → 被频繁交易 → 拥挤
    

**成长指标**：

-   同时考虑盈利增速和营收增速，两者都高 → 成长股拥挤
    

### 3.7 复合拥挤度：集大成者

单个指标可能有噪音，我将16个指标做Z-score标准化后取平均，得到**复合拥挤度**：

```
composite = np.nanmean([    valuation_spread_PB,        # 1. 估值价差PB    valuation_spread_PE,        # 2. 估值价差PE    pairwise_corr_raw_LS,       # 3. 配对相关性(多-空)    pairwise_corr_raw_LPS,      # 4. 配对相关性(多+空,原始)    pairwise_corr_idio_LPS,     # 5. 配对相关性(多+空,特质)    pairwise_cross_corr,        # 6. 两两相关性    long_term_return_36m,       # 7. 长期收益36月    factor_momentum_6m,         # 8. 因子动量6月    factor_dispersion,          # 9. 因子离散度    vol_ratio_long_short,       # 10. 波动率比率(多/空)    vol_ratio_long_market,      # 11. 波动率比率(多/市场)    cross_sectional_vol,        # 12. 截面波动率    asset_centrality,           # 13. 资产集中度    turnover_crowding,          # 14. 换手率拥挤度    growth_indicator,           # 15. 成长指标    # 以上15个指标，复合拥挤度本身是第16个], axis=0)
```

#### 为什么需要做复合拥挤度？

**1\. 多维度覆盖**

-   估值维度：捕捉价格拥挤
    
-   相关性维度：捕捉资金拥挤
    
-   收益维度：捕捉透支拥挤
    
-   波动维度：捕捉风险拥挤
    
-   结构维度：捕捉持仓拥挤
    

**2\. 互相验证**

-   单一指标可能误判（如市场整体波动加大）
    
-   多指标同时预警 → 可信度高
    
-   不同券商的研报算法互补
    

**3\. 适应不同市场环境**

-   牛市：估值类指标更敏感
    
-   熊市：波动类指标更有效
    
-   震荡市：相关性类指标更稳定

## 五、如何应对因子拥挤？

**1：拥挤度进入预警区**

-   降低该因子权重50%
    
-   加大止损纪律
    
-   观察1-2周，看是否回落
    

**2：拥挤度进入危险区**

-   暂停使用该因子
    
-   已有持仓考虑部分减仓
    
-   切换到低拥挤因子
    

**3：所有因子都拥挤**

-   市场可能处于极端状态（如抱团）
    
-   考虑降低整体仓位
    
-   等待拥挤度释放（通常需要一次回调）
    

**4:与其他择时信号结合**

拥挤度不是唯一信号，建议组合使用：

-   **因子IC走势**：IC持续下降 + 拥挤度高 → 强烈卖出信号
    
-   **市场情绪**：VIX升高 + 拥挤度高 → 暴跌风险
    
-   **资金流向**：北向资金流出 + 拥挤度高 → 抱团瓦解
    

## 六、总结

因子拥挤度是量化交易中的"风险雷达"，它不能告诉你什么时候买，但能提醒你什么时候该小心。

**记住这句话**：

> 当街上的人都在谈论某只股票时，专业投资者早已离场。

拥挤度量化了这个"常识"，让我们能够更早、更客观地做出判断。
