> **摘要：**把过去20个交易日的14项指标交给神经网络，能否学到对未来收益有用的时序结构？我们围绕这个问题设计了三组连续实验：20日输入预测下一交易日、20日输入预测未来一周，以及保留完整时序位置的因果TCN。本文从标签、网络、滚动训练和交易执行开始，把整套算法与代码一步步讲清楚，再用最近5年的样本外结果回答它到底学到了什么。

## 技术背景

之前我们讨论了卷积神经网络算法用于识别K线走势后上涨的概率，并且通过这个概率构造截面选股策略，从而解决了选股问题。那么另外一个比较重要的问题：CNN是否能够作为择时算法？

从技术分析的角度讲， 择时大多数情况都是通过技术指标，例如：Bolling、MACD、RSI、ADX 等等，通过其金叉死叉、超卖超买等方法去进行择时。那么如果我们直接将他们扔给卷积神经网络，是不是就能够得到一个有效的这是策略呢？整体就是下图中的意思：一部分时间持仓一部分时间空仓。

![](assets/001.jpg)

本文我们参考了券商的研报，将14个技术指标预测沪深300、中证1000、创业板指数。未来一周的涨还是跌，预测上涨就持有，预测下跌就空仓。交易周期为一周。原文是对未来一天做预测，我们认为这不合理，并且参数存在过拟合，当时方法我觉得还是值得研究一下。重要的是研究过程。但是其中也有很多的细节：

-   14个指标分别是什么？
    
-   CNN到底有几层、卷积核多大、输入窗口多长？
    
-   其他
    

更关键的是，报告明确提到：在测试阶段，用 `Find_Optimal_Cutoff()` 寻找分类阈值；dropout、batch size、epochs、学习率，也都是看回测夏普、回撤和胜率之后挑出来的，所以他们的结论就是一个凑出来的，至于参数敏感吗？没有说，从我们实践出来的结果看，大概率是。

**个人不是很赞成这种行为，研究阶段我们注重算法本身吧，作为一个学习、研究的案例是个不错的选择。**

所以这次我没有追求把追求净值曲线作为第一目标。相反，我做了**4套明确标注参数来源、严格按时间切分、阈值不接触测试标签的卷积神经网络实验方案。**

**目的就是让大家明白整个的验证流程，希望你能够从这个研究过程中获得收益。不仅仅是结果输出。**

## 算法设计与原理

### 1\. 我们要解决什么问题？

这套策略做的事情很明确：每天收盘后读取指数最近20个交易日的市场状态，输出未来收益为正的概率；到了调仓时点，再把概率转换成“持有指数”或“空仓”。

它不是预测指数会涨到多少点，也不是让CNN凭空发现经济周期。它本质上是一个监督学习分类器：

![从日线行情到未来一周仓位的完整算法链](assets/002.jpg)

从日线行情到未来一周仓位的完整算法链

图1：训练期只负责学习参数，验证期负责早停和概率阈值，未来测试期冻结使用。

**注意点：防止未来函数** 四个时间点必须一一对应：特征截止日、信号日、进入日和收益结束日。只要其中一个位置错了，漂亮曲线就可能来自未来数据。

### 2\. 14项指标如何组成模型输入？

我们将指标分为五类：

市场信息

指标

直观含义

趋势位置

WMA、EMA、SAR

价格位于趋势线的上方还是下方

动量强弱

MOM、ROC、RSI、CMO

上涨或下跌的速度和持续性

趋势质量

DX、ADX

当前方向是否足够明确

波动状态

Bolling带宽、ATR

市场正在收缩还是扩张

偏离与快慢线

Bolling位置、CCI、MACD Signal

价格偏离及短中期变化

**注意点：有些指标中带有价格量纲，为了训练的准确性，我们需要对指标做一些预处理。**

直接输入EMA、WMA或ATR的绝对数值，会让模型受到指数点位影响。3000点和6000点下完全相同的形态，数值尺度可能差一倍。因此，价格型指标先改写为相对表达：

```
stationary = pd.DataFrame({    "bollinger_position": (close - lower) / (upper - lower),    "bollinger_width": (upper - lower) / close,    "wma_distance": close / wma - 1,    "ema_distance": close / ema - 1,    "sar_distance": close / sar - 1,    "macd_ratio": signal_macd / close,    "mom_ratio": mom / close,    "atr_ratio": atr / close,})
```

CCI、CMO、DX、ROC、RSI和ADX等比例指标也缩放到近似范围。这样每个样本就得到一个`14×20`矩阵：纵轴是指标，横轴是过去20个交易日。

图中为了阅读，对每一行做了窗口内标准化；正式训练使用的StandardScaler只在训练期拟合，然后原样应用到验证和测试数据。

### 3\. 标签必须和实际持仓一致

一周策略在  日收盘后生成信号，于  日收盘进入，并在  日收盘结束本次持仓：

![过去20日输入、下一交易日执行和5交易日持有的时间线](assets/004.jpg)

过去20日输入、下一交易日执行和5交易日持有的时间线

图3：训练标签与实盘持仓使用同一段未来5交易日收益，相邻周度持仓首尾相接。

信号日已经使用了t日收盘数据，所以不能再假设以同一个收盘价成交。进入价格后移一天，虽然会牺牲一些回测表现，却让这套规则真正可执行。

### 4\. 基础CNN究竟学习什么？

基础网络使用两层一维卷积：

```
self.network = nn.Sequential(    nn.Conv1d(14, 32, kernel_size=3),    nn.ReLU(),    nn.MaxPool1d(2),    nn.Conv1d(32, 16, kernel_size=3),    nn.ReLU(),    nn.AdaptiveAvgPool1d(1),    nn.Flatten(),    nn.Dropout(0.015),    nn.Linear(16, 2),)
```

卷积核沿20日时间轴移动，寻找连续增强、波动收缩、动量反转等局部组合。经过第一层卷积、池化和第二层卷积后，单个局部表示大约覆盖8个交易日。

但`AdaptiveAvgPool1d(1)`会把剩余时间位置平均成一个向量。这让模型容易回答“某种形态是否出现过”，却不容易区分它发生在20日前还是最近几天。这个问题会在第三组实践里专门处理。

## 训练与实践：三种设计循序渐进

三组实验都使用相同的**14项平稳化指标、20日输入、滚动学习和5个固定随机种子。** 我们一次只改变一个关键问题：预测期限，或者时序编码器。

### 共同训练协议

每个年度测试折之前保留5年开发数据：前48个月训练、后12个月验证，再把模型冻结到未来12个月。

![48个月训练、12个月验证和12个月冻结测试](assets/005.jpg)

48个月训练、12个月验证和12个月冻结测试

图4：测试年度结束后窗口向前滚动一年，所有年度结果连续保留。

**每折的训练步骤为：**

1.  只在48个月训练数据上拟合StandardScaler；
    
2.  使用Adam和CrossEntropyLoss更新模型；
    
3.  至少训练10轮，最多55轮；
    
4.  验证损失连续8轮没有超过`1e-4`的改善时早停；
    
5.  恢复验证损失最低的模型权重；
    
6.  只在验证集按Youden J确定概率阈值；
    
7.  未来一年冻结模型、Scaler和阈值。
    

每折训练5个随机种子：`0、1、7、42、2022`。最终对五个模型的上涨概率取平均，而不是根据未来收益选择最好的一次。

### 实践一：20日输入，预测未来1日

第一组把未来一个可实现交易日收益作为二分类标签：t日形成信号，t+1收盘进入，t+2收盘结束。本组最终按日调整目标仓位。

它的优点是样本数量多、更新快；缺点是标签很短，市场微观噪声、隔夜信息和随机波动都可能主导涨跌方向。

在中证红利最近5年样本外数据上，这组CNN收益为**8.71**%，AUROC为 **0.5043**。 显然，效果一般，在我们的认知内，没有能够复现研报中的高收益，因为我们没有刻意的去调整参数，追求高收益。**我们采用了我们认为合理的改进方式去推进结果往优秀的方向发展。**

### 实践二：20日输入，预测未来一周

第二组保留基础CNN，将标签改成未来5个交易日收益方向。训练样本仍然每天生成，因此相邻标签会重叠；实际回测只取每5个交易日一次的信号，使持仓收益互不重叠。

```
for index in range(window - 1, len(data) - holding_period - 1):    entry_index = index + 1    exit_index = entry_index + holding_period    forward_return = (        data.loc[exit_index, "close"]        / data.loc[entry_index, "close"]        - 1.0    )    feature = data.loc[        index - window + 1:index,        FEATURE_COLUMNS,    ].to_numpy(dtype=np.float32).T
```

训练集最后几条标签可能跨入验证期，所以时间切分不能简单“一刀切”。程序要求训练标签在验证集第一条信号之前完成，验证标签在测试集第一条信号之前完成，并至少清除5个日度样本。

最终交易信号每5日选取一次：

```
weekly = (    daily_predictions    .sort_values("signal_date")    .iloc[::5]    .reset_index(drop=True))assert pd.to_datetime(weekly["entry_date"].iloc[1:]).reset_index(drop=True).equals(    pd.to_datetime(weekly["return_date"].iloc[:-1]).reset_index(drop=True))
```

在中证红利上，本组最新5年收益为 **25.84**%，AUROC为 **0.5779**。

**同样的，收益我们肯定也不满意。于是，想到了对时序编码器做调整，于是映入了TCN**

### 实践三：用因果TCN保留时序位置

第三组保持20日输入和未来5日标签不变，只替换时序编码器。

我们采用4个因果残差卷积块，dilation依次为`1、2、4、8`。kernel size为3时，有效感受野为：

31日感受野已经覆盖完整20日输入。所谓“因果”，是指时间位置t的中间表示只能读取t及其左侧历史，不能读取右侧位置。模型最后不再做全局平均，而是只读取最后一个时间位置的32维状态进行分类。

![基础CNN与因果TCN的时序信息处理方式](assets/006.jpg)

基础CNN与因果TCN的时序信息处理方式

图5：基础CNN通过池化和全局平均换取平移不变性；TCN保留完整顺序，并让最近时点承担最终决策。

核心实现并不长：

```
class CausalResidualBlock(nn.Module):    def __init__(self, channels, dilation, dropout):        super().__init__()        self.left_padding = 2 * dilation        self.conv = nn.Conv1d(            channels, channels,            kernel_size=3,            dilation=dilation,        )        self.dropout = nn.Dropout(dropout)    def forward(self, x):        z = nn.functional.pad(x, (self.left_padding, 0))        z = self.dropout(torch.relu(self.conv(z)))        return torch.relu(x + z)class TimingTCN(nn.Module):    def forward(self, x):        states = self.temporal_blocks(self.input_projection(x))        latest = states[:, :, -1]        return self.classifier(latest)
```

我们还做了因果性测试：只修改输入后半段，前半段编码结果必须逐值不变；模型保存后重新加载，测试概率也必须逐值一致。

## 四、改进措施：下一步应该修哪里？

### 1\. 同时保留全局状态与最近状态

TCN只读取最后时点，解决了全局平均丢失位置的问题，却可能走向另一个极端：过分依赖最近状态。下一版可以把“最后时点表示”和“带时间权重的Attention Pooling”拼接，让模型同时看到完整20日背景与最近变化。

### 2\. 把概率排序与交易决策分开

AUROC衡量排序，策略收益来自阈值后的离散仓位。TCN的结果说明这两件事不是一回事。可以在验证集内部增加第二层决策校准：

-   先用交叉熵训练概率模型；
    
-   再用独立验证子区间校准概率；
    
-   最后根据扣费后收益、回撤或目标暴露确定阈值；
    
-   最终测试期仍然不能参与选择。
    

这比直接围绕测试收益改阈值更严格，也更接近量化平台的模型与策略分层。

### 3\. 标签不只保留正负

二分类会丢掉收益幅度和一周内路径。可以采用多任务学习，同时输出：

1.  未来5日收益方向；
    
2.  未来5日收益数值或分位数；
    
3.  未来一周最大不利波动。
    

分类头负责方向，回归头负责收益强弱，风险头约束“预测会上涨但路径很危险”的情况。

### 4\. 增加真正不同的信息源

14项指标都来自相同OHLC。继续堆叠更多均线，只是在重复变换同一信息。更值得加入的是市场广度、成交量结构、指数成分股上涨比例、波动率和风格相对强弱。这些变量才可能提供新的解释维度。

### 5\. 保留日度训练，但处理标签相关性

日度生成5日标签能扩大训练覆盖，却使相邻样本高度相关。可以在损失函数中降低连续重叠样本的权重，或者采用以5日为块的batch采样。这样仍保留每日市场状态，又不让模型把五份近似标签误认为五份独立证据。

## 六、总结

通过本文其实你就已经可以对CNN在量化中的应用有很大的了解，你也可以看到其实在时序预测上表现一般，但是我们给出了一个作为研究者，我们应该怎么去思考问题，怎么去改进模型与策略，我想这个才是最重要的。

因此，当前最值得保留的不是某条孤立净值，而是一套可以继续演化的实验框架：同一份输入、同一滚动协议、一次只改变一个设计，再让最新样本外数据回答问题。
