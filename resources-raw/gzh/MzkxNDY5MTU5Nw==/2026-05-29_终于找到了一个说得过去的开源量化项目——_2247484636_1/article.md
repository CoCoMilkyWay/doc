## 技术背景

最近，笔者也写了很多的关于因子挖掘的文章，但是对于普通的投资者来讲，这些内容的门槛还是有一点偏高，最近，笔者也一直思考如何从根本上降低这个量化的门槛，我们也在尝试开发一些工具来达到这个目的，后期会逐步的推出。

近日，在研究过程中，发现了一个好不错的github开源项目：QuantaAlpha。整体项目交互、算法可以给到很高的评价。当然，任何项目都有不足之处，包括这个项目也是存在一些不太合理的地方，但是整体还是错的项目。

本文的主要内容：介绍QuantaAlpha的开源项目，项目地址：https://github.com/QuantaAlpha/QuantaAlpha。项目的主要思路，尤其团队与几所大学共同发表的文章为基础：《QuantaAlpha: An Evolutionary Framework for LLM-Driven Alpha Mining》

## 项目介绍

该框架将大语言模型与进化算法深度融合，通过多智能体协作模拟专业量化研究员的工作流程，将因子挖掘的完整研究过程纳入进化体系，覆盖假设生成、因子构建、代码实现、回测检验、迭代优化全环节，实现因子挖掘过程的白盒化、可溯源和高效率。

**核心创新：**

-   **轨迹级进化：**将每轮完整的因子研究流程视为一条“挖掘轨迹”，通过轨迹级的变异与交叉操作实现跨轮次的经验继承与定向改进，而非传统的随机组合。
    
-   **多智能体协作：**通过 Idea Agent、Factor Agent、Evaluation Agent 三类智能体分工协作，将抽象投资假设转化为可执行因子代码，并施加以语义一致性、复杂度和冗余性三重约束。
    
-   **逻辑驱动的因子生成：**因子挖掘由假设驱动，先有明确金融逻辑，再生成因子表达式和代码，从根本上解决了传统遗传规划“先生成公式再补逻辑”导致的可解释性不足问题。
    

## 框架核心分析

![](assets/001.jpg)

### 1 整体架构

QuantaAlpha 搭建了“提出假设 → 构建因子 → 回溯检验 → 迭代优化 → 因子池维护”的全流程自动化闭环体系：

1.  **初始假设**：LLM 基于价量背离、波动率状态、动量反转、市场微观结构等经典量化研究维度，生成 10 个具备明确金融逻辑、相互独立且彼此互补的初始投资假设，每个假设方向独立开展因子挖掘。
    
2.  **因子实现**：三类智能体协同工作。Idea Agent 将粗粒度研究假设细化为可落地执行的结构化投资假设；Factor Agent 采用“符号化表达 + 抽象语法树（AST）”的方式，将假设转化为标准数学表达式，经结构校验后编译为可执行代码，同时施加语义一致性、复杂度和冗余性三重约束；Evaluation Agent 基于 Qlib 回测框架开展标准化回测，评估 IC、RankIC、年化收益、最大回撤等核心指标。
    
3.  **迭代优化**：由 LLM 主导进化方向。变异通过自反思定位低奖励的次优决策节点，仅对问题部分做精准修正；交叉从历史表现优异的多条挖掘轨迹中提取各自的核心逻辑片段，在投资假设层面进行逻辑组合与重构。
    
4.  **因子筛选**：设置 RankIC 排序、与池中因子绝对相关系数 ≤ 0.7、因子池容量上限三档门槛，择优纳入。
    

### 2 五大核心升级

QuantaAlpha 相比传统遗传规划实现了全维度技术升级：初始种群从随机生成转为 LLM 结合金融逻辑驱动；进化方式从随机排列转为轨迹级逻辑定向修复；进化对象从进化单一公式转为进化完整研究过程；冗余管控从单一数值约束转为结构化去重、复杂度限制与语义校验的多维管控；可解释性从先公式后逻辑转为先逻辑后公式。

## 技术细节

### 1\. 算子体系

论文采用 6 大类算子构建因子：时间序列算子（移动平均、标准差、相关系数等）、截面算子（横截面排名、标准化等）、数学算子（加减乘除、对数、平方根、指数、符号函数等）、技术指标算子（RSI、MACD、KDJ 等经典技术指标）、逻辑算子（条件判断、布尔运算等）、辅助算子（日期处理、分组聚合等）。

### 2\. 三重约束

Factor Agent 通过三种机制保障因子质量：1）语义一致性约束，验证“市场假设 → 数学表达式 → 可执行代码”三者逻辑统一；2）复杂度约束，控制符号表达式长度（≤250 字符）、自由参数占比（<50%）、底层原始特征数量（≤6 个）；3）冗余性约束，通过结构匹配过滤高度相似因子。

### 3\. AST 结构化去重

QuantaAlpha 引入抽象语法树技术，将因子公式转化为树形结构节点，通过计算树形结构相似程度量化因子核心逻辑的重合度。即便因子数值相关性低，若核心计算逻辑高度相似仍判定为冗余并过滤，从根本上解决了“换汤不换药”的结构性冗余问题。

## LLM 策略与调用机制

### 1\. 多智能体分工

QuantaAlpha 流水线一共调用了 7 次 LLM，每次扮演不同的角色，干不同的活儿，形成了一套精密的分工协作体系。完整的 7 次 LLM 调用序列包括：

-   **第 1 次**：LLM 作为研究主管，生成 10 个相互独立的初始投资假设。提示词中注入价量背离、动量反转、波动率状态等经典量化研究维度的先验知识。
    
-   **第 2 次**：Idea Agent 对每个假设进行细化，输出包含逻辑机制、参数范围、窗口期设定的结构化假设。
    
-   **第 3 次**：Factor Agent 将结构化假设转换为数学表达式，验证逻辑一致性。
    
-   **第 4 次**：Factor Agent 将数学表达式编译为代码并实施三重约束检验。
    
-   **第 5-6 次**：变异操作中，LLM 回溯整条轨迹，定位失效步骤并生成修正方案。
    
-   **第 7 次**：交叉操作中，LLM 从多条优质轨迹中提取逻辑片段进行组合重构。
    

### 2\. 提示工程策略

1.  **角色注入**：明确 LLM 扮演量化研究员或因子工程师，注入专业身份认知。
    
2.  **结构化输出**：要求输出符合 JSON 格式，包含逻辑描述、参数表、数学表达式三部分，便于后续程序解析。
    
3.  **思维链引导**：在变异任务中要求 LLM 先进行“反思—定位—修正”三步思考再输出。
    
4.  **约束嵌入**：在每次生成中显式嵌入语义一致性、复杂度和冗余性约束条件。
    
5.  **示例示范**：在初始化阶段注入 2-3 个完整的因子挖掘示例作为 few-shot 示范。
