本篇介绍：Vector。

Vector（向量）对金工同学肯定不会陌生，但对刚刚入行的同学原理都懂，但对应到具体场景上如果没有涉及过，就不知道具体表现是什么。

  

在量化投资中，一个 **Vector（向量）** 代表在**某一个特定时间点**（或某个调仓日），**一组股票（投资域/Universe）** 的**某一个特定属性**的数值集合。这是专业的定义，我们逐步分解理解：

-   **一个时间点**：所有计算都是基于“截面数据”（Cross-Sectional Data），即在某个时间切片上，横向比较所有股票。
    
-   **一组股票**：你的投资范围，例如“沪深300成分股”或“全A股”。
    
-   **一个属性**：这可以是一个**因子**（Alpha Factor），如动量、估值、质量；也可以是**原始数据**，如收益率、市值、市盈率。
    

  

假设在20250831这个调仓日，我们的投资域是3只股票： `[贵州茅台, 宁德时代, 招商银行]`。

我们关注的属性是“市盈率（PE）”。从数据库中提取数据后，我们得到：

`pe_vector = [35.2, 65.8, 12.5]`

这就是一个 **Vector**。它代表了在 `20250831`这个时间点上，三只股票市盈率的截面数据。

### Vector实现从数据到决策，因为单个数据点（如茅台的PE是35.2）没有决策意义。只有当它被组织成Vector，并在截面上一**比较**时，才能产生交易信号。

-   **比较产生信号**：
    
    我们看到 `pe_vector = [35.2, 65.8, 12.5]`。通过比较可知，招商银行（12.5）的估值相对最低（最便宜），宁德时代（65.8）的估值相对最高（最昂贵）。
    
-   **信号指导决策**：
    
    一个简单的“价值因子”策略可能会据此**做多**招商银行（低PE），**做空**宁德时代（高PE），对贵州茅台（中位数PE）则保持中性。
    
-   **Vector是信号的载体**：
    
    整个量化策略的产出，本身也是一个Vector——**目标持仓权重向量**。
    

**决策输出也是一个Vector：**

基于PE因子的简单权重向量可能是：`weights = [-0.1, -0.5, +0.6]`

这表示：做空10%的茅台，做空50%的宁德时代，做多60%的招商银行。

注：为简化示例，暂不考虑归一化。

  

有了以上的向量化数据，量化投资中就可以进行下一步工作，因子是Vector，信号是Vector，最终的持仓权重也是Vector。整个量化策略的研究和执行过程，就是一系列Vector操作（标准化、排序、合成、缩放等）的组合。理解并熟练运用Vector操作，是打开量化投资大门的钥匙。

  

下面看worldquant提供的两个Vector相关的算子：

  

1.vec\_avg(x)

计算一个投资域（Universe）内所有股票在某个因子（`x`）上的平均值。它代表了该因子在**当前市场横截面**上的“中枢”或“平衡点”。结合3个量化投资实际中3个场景理解。

场景 1：构建市场中性组合（多空对冲）

这是 `vec_avg(x)`最直接、最重要的应用。

通过减去均值，可以快速将一个因子信号转换为一个多空均衡的投资组合权重。

-   **逻辑**：`   `
    
    `目标权重 = x - vec_avg(x)`
    
-   决策：
    

-   因子值大于平均值的股票，获得正权重（买入）。
    
-   因子值小于平均值的股票，获得负权重（卖出）。
    
-   所有权重的总和自动为 **0**（`vec_sum(目标权重) = 0`），实现了市场中性。
    

**比如在动量因子策略中：**

假设在调仓日，3只股票的动量因子（过去12个月收益率）如下：

mom\_vector = \[0.15, -0.05, 0.08\]（即15%, -5%, 8%）

1.  **计算因子均值**：
    
    ```
    vec_avg(mom_vector) = (0.15 + (-0.05) + 0.08) / 3 = 0.18 / 3 = 0.06
    ```
    
    `   `
    
      
    

-     
    

3.  **生成原始权重**：
    
    ```
    raw_weights = mom_vector - 0.06 = [0.15-0.06, -0.05-0.06, 0.08-0.06] = [0.09, -0.11, 0.02]
    ```
    
    `   `
    
      
    

-     
    

5.  **解读**：
    

-   做多 **0.09** 单位动量最强的股票。
    
-   做空 **0.11** 单位动量最弱的股票。
    
-   对动量接近平均的股票进行微幅做多 **0.02** 单位。
    
      
    

7.  **验证市场中性**：
    
    `vec_sum([0.09, -0.11, 0.02]) = 0.0`

#### 场景 2：因子标准化前的中心化处理

  

在合成多个因子或计算Z-Score之前，必须消除不同因子的基准差异（即减去均值），使它们都具有相同的中心（0）。

-   **逻辑**：`中心化后的因子 = x - vec_avg(x)`
    
-   **目的**：为后续的缩放处理（如除以标准差）做准备，确保不同因子具有可比性。
    

**比如合成价值与质量因子：**

假设我们有价值因子（市盈率倒数 `e_p`) 和质量因子（ROE\`），需要合成一个新因子。

```
e_p_vector = [0.05, 0.02, 0.03]
```

`   `

1.  **中心化处理（去均值）**：
    

-   `e_p_centered = e_p_vector - vec_avg(e_p_vector) = [0.05, 0.02, 0.03] - 0.033 ≈ [0.017, -0.013, -0.003]`
    
-   `roe_centered = roe_vector - vec_avg(roe_vector) = [0.15, 0.08, 0.20] - 0.143 ≈ [0.007, -0.063, 0.057]`
    

3.  **合成（向量运算）**：
    
    `combined_alpha = e_p_centered + roe_centered ≈ [0.024, -0.076, 0.054]`
    
4.  **解读**：
    

-   中心化后，因子值围绕0波动。正值表示该股票在此因子上高于平均水平，负值则表示低于平均水平。
    
-   合成后的因子 `combined_alpha`可以直接用于构建权重（如场景1）。

#### 场景 3：作为动态基准线，计算相对价值

  

因子值本身是绝对值，减去均值后得到的相对值更能反映股票在当前市场中的位置。

-   **逻辑**：`相对值 = x - vec_avg(x)`
    
-   决策：判断一只股票的因子表现是“好于市场平均”还是“差于市场平均”。
    

**比如评估估值偏离度：**

继续使用市盈率的例子：`pe_vector = [35.2, 65.8, 12.5]`

1.  **计算市场平均市盈率**：
    
    `vec_avg(pe_vector) = (35.2 + 65.8 + 12.5) / 3 = 113.5 / 3 ≈ 37.83`
    
2.  **计算相对估值**：
    
    `relative_pe = pe_vector - 37.83 = [35.2-37.83, 65.8-37.83, 12.5-37.83] ≈ [-2.63, +27.97, -25.33]`
    
3.  **解读**：
    

-   贵州茅台：估值比市场平均水平 **低2.63**。
    
-   宁德时代：估值比市场平均水平 **高27.97**，显得非常昂贵。
    
-   招商银行：估值比市场平均水平 **低25.33**，显得非常便宜。
    
-   这个“相对估值”向量比原始市盈率向量更能直接用于交易决策。

## 2.vec\_sum(x)

##   

## vec\_sum(x)：在某个调仓日，计算投资域（Universe）内所有股票在某个向量（`x`）上的**代数和**。它衡量的是投资组合的**净头寸**或**净风险敞口**（Net Exposure）。

##   

-   **`vec_sum(权重向量)`**：结果 > 0，表示整体为**净多头**；结果 < 0，表示整体为**净空头**；结果 = 0，表示**市场中性**。
    
-   **`vec_sum(abs(权重向量))`**：这是更常用的操作，它衡量的是**总头寸**或**总风险敞口**（Gross Exposure），即所有头寸（多头和空头）的绝对值之和。这是风险管理和资金分配的核心。

结合3个量化投资实际中3个场景理解。

#### 场景 1：计算并控制投资组合的总风险敞口

这是 `vec_sum(abs(x))`最重要、最核心的应用。在生成原始信号权重后，必须控制其总风险，使其符合预设的风险预算。

-   **逻辑**：`缩放后的权重 = (x / vec_sum(abs(x))) * target_exposure`
    
-   **目的**：无论原始信号强度如何，最终组合的总风险都被精确控制在同一水平，便于策略回测和实盘管理。
    

**比如将组合总风险缩放至1个单位：**

假设我们通过某个因子生成的原始权重向量为：

`raw_weights = [0.5, -0.3, 0.8, -0.4]`

1.  **计算当前总风险敞口**：
    
    `current_exposure = vec_sum(abs(raw_weights)) = |0.5| + |-0.3| + |0.8| + |-0.4| = 0.5 + 0.3 + 0.8 + 0.4 = 2.0`
    
    _这意味着根据原始信号，我们需要投入总共2个单位的资金。_
    
2.  **计算缩放因子**（目标是缩放到1个单位）：
    
    `scaling_factor = target_exposure / current_exposure = 1.0 / 2.0 = 0.5`
    
    `   `
    
3.  **应用缩放，得到最终权重**：
    
    `final_weights = raw_weights * scaling_factor = [0.5 * 0.5, -0.3 * 0.5, 0.8 * 0.5, -0.4 * 0.5] = [0.25, -0.15, 0.4, -0.2]`
    
    `   `
    
4.  **验证最终风险敞口**：
    
    `vec_sum(abs(final_weights)) = |0.25| + |-0.15| + |0.4| + |-0.2| = 0.25 + 0.15 + 0.4 + 0.2 = 1.0`
    
    _成功将总风险控制在1个单位。_
    

####   

#### 场景 2：验证策略的市场中性

对于市场中性策略，我们需要确保多头和空头的总力量相互抵消，使组合对市场整体涨跌没有暴露。

-   **逻辑**：检查 `vec_sum(权重向量) == 0`（或非常接近0）。
    
-   **目的**：确保策略的收益来源是选股能力（买入的股票比卖出的股票表现更好），而不是赌市场的方向。
    

**比如检查权重向量是否市场中性：**

假设一个策略生成的权重向量为：`weights = [0.9, -0.5, 0.4, -0.8]`

1.  **计算净敞口**：
    
    `net_exposure = vec_sum(weights) = 0.9 + (-0.5) + 0.4 + (-0.8) = 0.0`
    
2.  **解读**：
    

-   净敞口为0，这是一个**完美的市场中性**组合。
    
-   多头总头寸：`0.9 + 0.4 = 1.3`
    
-   空头总头寸：`|-0.5| + |-0.8| = 1.3`
    
-   多空双方力量完全相等。
    

####   

#### 场景 3：计算组合的净暴露方向

有时策略可能允许有一定的净敞口，以表达对市场的某种观点。`vec_sum(x)`可以快速量化这个观点的强度。

-   **逻辑**：直接观察 `vec_sum(权重向量)`的值和符号。
    
-   **目的**：监控组合的整体偏向（偏多或偏空）。
    

**比如判断组合倾向：**

假设三个不同策略的权重向量如下：

-   **策略A（乐观）**：`   `
    
    `weights_a = [0.6, 0.7, 0.5, 0.3]`\-> `vec_sum(weights_a) = 2.1`(**显著净多头**)
    
-   **策略B（中性）**：`   `
    
    `weights_b = [0.8, -0.5, 0.6, -0.9]`\-> `vec_sum(weights_b) = 0.0`(**市场中性**)
    
-   **策略C（悲观）**：`   `
    
    `weights_c = [-0.4, -0.7, 0.2, -0.3]`\-> `vec_sum(weights_c) = -1.2`(**显著净空头**)
