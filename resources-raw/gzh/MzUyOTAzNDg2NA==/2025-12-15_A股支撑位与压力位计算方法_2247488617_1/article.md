### 一、滚动中点范围法（适配震荡市）

#### 这是普遍采用的。通过固定时间窗口（如 30 个交易日）的最高价、最低价计算中间价，再根据价格波动幅度推导支撑 / 压力位，适合 A 股区间震荡的中小盘股。计算公式如下：

```
中点 =（窗口内最高价 + 窗口内最低价）/ 2
```

代码示例：

```
import numpy as np
```

#### 在窗口选择上，如果是震荡市建议用 20-30 日，趋势市可扩大至 60 日（适配 A 股牛熊转换周期），适用沪深 300 成分股等流动性充足的标的，避免小盘股停牌影响。

### 二、斐波那契回撤法（适合趋势反转）

#### 基于A股近期涨跌波段（如15个交易日），按斐波那契比例（23.6%/38.2%/50%/61.8%/78.6%）划分回调支撑位，精准捕捉趋势反转点。示例代码如下：

```
import numpy as np
```

#### 重点关注 61.8%（强支撑 / 压力）和 38.2%（弱支撑 / 压力），配合 A 股龙虎榜数据：若支撑位出现机构净买入，反转概率提升。

### 三、波峰波谷识别法（波段交易核心）

通过数学方法识别 A 股 K 线中的局部高点（压力位）和局部低点（支撑位），无需主观判断，适配 A 股 “追涨杀跌” 的波段特征。示例底代码如下：

```
import numpy as np
```

#### 其中，order 参数按建议参考，A股小盘股用 3-5，权重股用5-8（权重股波动更平缓），适合 A 股 T+1 交易的日内波段，支撑位低吸、压力位高抛。

### 四、枢轴点分析法（日内交易参考）

#### 和第一点类似，但基于日内计算，基于前一交易日的高低收盘价计算枢轴点，衍生出两层支撑 / 压力位，适配A股日内交易（如集合竞价后判断当日区间）。计算公式如下：

```
枢轴点（P）=（前高 + 前低 + 前收）/ 3
```

#### 代码示例如下：

```
import pandas as pd
```

#### A 股集合竞价后，若开盘价在 P 上方，R1 为第一压力；若在 P 下方，S1 为第一支撑，使用时需要避开 ST 股（涨跌停 5%），支撑 / 压力位需缩小比例。

### 五、K 均值聚类法（识别密集成交区）

#### 通过机器学习聚类算法，找到 A 股价格密集成交的区间中心，这些中心就是强支撑 / 压力位（成交越密集，支撑 / 压力越强）。示例代码如下：

```
import numpy as np
```

#### 聚类数选择：股价 10 元以下选 3-4 个聚类，50 元以上选 5-6 个；强支撑 / 压力：聚类中心对应的成交量越大，有效性越强（可结合成交量筛选）。

### 六、成交量轮廓法（量价共振核心）

#### 通过统计不同价格区间的成交量，找到“成交密集区”（高成交量对应的价格），这些区域是强支撑 / 压力位（表示买卖双方博弈最激烈）。代码如下：

```
import numpy as np
```

#### 适合A 股主力建仓、主力卖出的判断参考（高成交量区间若被突破，大概率是趋势启动信号），结合l2数据可细化到逐笔成交，提升支撑 / 压力位精度。

### 七、多项式回归法（非线性趋势适配）

#### 用多项式曲线拟合 A 股非线性价格走势，曲线的拐点即为支撑 / 压力位，适配 A 股政策驱动下的非对称波动。代码示例如下：

```

```

A 股震荡市用 3-4 度，趋势市用 5-6 度，结合成交量，拐点处放量突破则支撑 或压力位失效进步判断拐点。
