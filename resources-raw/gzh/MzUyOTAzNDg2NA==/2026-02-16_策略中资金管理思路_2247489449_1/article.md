在策略回测或实盘时，如何使用资金是需要在策略逻辑中明确的。

不同的策略对于资金管理的思路肯定不一样。但从一般思路出发，假设策略为了平稳考虑，一般使用半仓交易情况下，则大致思路如下：

1.确定T日可用的开仓总账户资金

```
T日账户资金 = min(总资产 × 仓位上限比例, 可用资金)
```

其中仓位上限，可以按照策略风险偏好设定，比如设置为50%，则策略资金管理思路就是半仓运行。在长期仓位上限和短期可用现金之间取最小值，确保资金安全。

2.确定每只股票的开仓资金金额

```
单票目标资金 = T日账户资金 ÷ 计划买入股票数量(N)
```

根据策略信号动态T日待调仓买入的股票数量，例如当日选股数量，或按固定数量，一般通过等金额分散，避免单只股票过度影响组合。

3.确定单只股票的委托数量

```
理论股数 = 单票目标资金 ÷ 委托价
```

其中委托价使用最新价或者策略制定的具体价格。

4.按最小交易单位调整单只股票委托数量

根据不同的市场板块，确定交易最小单位。

```

```

在A股交易中，由于最小交易单位的限制，我们需要将理论股数调整为合规的委托数量。如果采用向上取整或四舍五入，例如将653.59股取整为700股，则实际占用资金（700×25.5=17850元）将超过分配给该股票的资金（16666.67元），可能导致总仓位超出计划或可用资金不足。因此，向下取整（floor，Python的一个math方法）是最安全、最合规的方法，它确保每一笔委托都在资金预算内，严格遵守风险控制原则。

5.确定实际资金占用

```
实际占用资金 = 实际委托股数 × 成交价
```

当某只股票因理论股数小于最小单位而无法买入时，需将原分配给它的资金释放，重新分配给其他可买入的股票。常见的再分配方式：

-   **等额再分配**：将释放的资金平均分给其他可买入股票（需重新计算股数并再次检查最小单位）。
    
-   **优先级分配**：按信号强度或预期收益排序，优先满足高优先级股票，剩余资金再依次分配。
    
-   **现金留存**：将无法使用的资金留作现金，用于后续交易日或逆回购。
    

  

6.示例数据

假设总资产100万元，仓位上限50%，可用资金60万元，当日选出4只股票：

-   股票A（主板）：股价25.50元
    
-   股票B（科创板）：股价180.00元
    
-   股票C（创业板）：股价18.20元
    
-   股票D（科创板）：股价250.00元
    

**1）计算过程**：

-   **账户资金** = min(100万×50%, 60万) = 50万元
    
-   **初始单票目标资金** = 50万 ÷ 4 = 12.5万元
    

**2）逐股计算**：

-   **股票A**（主板，最小100股）：  
    理论股数 = 125000 ÷ 25.50 ≈ 4901.96股 → 实际股数 = floor(4901.96/100)×100 = 4900股  
    占用资金 = 4900 × 25.50 = 124950元
    
-   **股票B**（科创板，最小200股）：  
    理论股数 = 125000 ÷ 180.00 ≈ 694.44股 → 实际股数 = floor(694.44/200)×200 = 600股  
    占用资金 = 600 × 180.00 = 108000元
    
-   **股票C**（创业板，最小100股）：  
    理论股数 = 125000 ÷ 18.20 ≈ 6868.13股 → 实际股数 = 6868.13//100×100 = 6800股  
    占用资金 = 6800 × 18.20 = 123760元
    
-   **股票D**（科创板，最小200股）：  
    理论股数 = 125000 ÷ 250.00 = 500.00股 → 实际股数 = 500//200×200 = 400股  
    占用资金 = 400 × 250.00 = 100000元
    

**总占用资金** = 124950 + 108000 + 123760 + 100000 = 456710元，剩余现金约43290元（可留作后续使用或逆回购）。

若某科创板股票理论股数小于200（例如股价极高），则实际股数为0，需将12.5万释放并重新分配。
