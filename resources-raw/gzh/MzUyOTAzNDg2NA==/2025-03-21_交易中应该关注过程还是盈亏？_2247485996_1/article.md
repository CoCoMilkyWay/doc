#   

# 我相信每一个刚刚开始进行投资交易的个人，都会为了浮动盈亏而紧张过。每一笔交易都会让自己感觉到是一种“成败攸关”的抉择。

#   

# 赚钱了我们情绪高涨，感觉自己领悟到了交易的法门；亏损了则把头埋在沙子里，觉的这市场真的没发参与了，要么账户也懒得的看了，要么清仓走人。

#   

# 在这种交易过程中，我们几乎没有任何投资体系或者逻辑参与，而是由我们自己的“情绪”主导。

#   

# 这种情绪可能来自各种层面的信息，市场火热起来了，自己看到了群里的某个聊天，或者是朋友推荐的一个好股等等，驱动我们按下买入或者卖出按钮的择时操作几乎不来自我们自身发出的指令。

#   

# 在这样的交易过程中，长期以往就会煎熬，因为无法“知行合一”，往往买了，迎来大跌，卖了迎来大涨，多被伤害几次，就心灰意冷不想玩了，等下次牛市来的时候，在喧嚣中又忍不住蠢蠢欲动。

#   

# 因此，我们要做好投资，就必须要形成自己的投资体系。这句话几乎从我刚入行的就在听，可那时候，根本就听不进去，学习了所谓的：资金管理、仓位管理也根本get不到点在那，做不到。

#   

# 同时，对大a的投资者，大家往往自嘲：学的越多，感觉自己懂的越懂，亏的越多。比如有一次在小区，我在b站刷一个Kaggle预测波动率的视频，旁边一个阿姨很认真的在直播间听一个人讲市场，听的激动的时候，还跺脚，感觉应该是击打到自己的投资灵魂了。

#   

# 我不知道这个市场到底谁赚钱了，但大家真的都很可爱，都以最真诚、感人的“认真劲头”成为彼此的“对手方”。

#   

# 直到自己真正的了解了专业的投资过程，我才慢慢的发现，我们构建的所谓投资体系思维最核心和最重要的就是：更多的关注投资的过程，而不是盈亏。（教科书的原话好像是：**你无法控制市场，但你可以控制交易过程。）**

#   

# 过程是因，盈亏是果，太多的追求盈利和担心亏损会阻碍自己做出明智的投资决策，所以切莫本末倒置。

#   

# 当然我自己目前也没有做到......但我深深意识到这是有道理的。胜利和失败只是短期投资中的噪音。重要的自己如何始终如一地坚持一个合理的计划并正确执行它。目标不是赢得每笔交易；而是随着时间的推移做出正确的决定。

#   

# 至于这个过程，如果大家了解过，学习过，肯定是各有各的道，有做etf做的非常好，有打板打的好，也有做技术指标做的好的，也有看新闻联播赚钱的，也有量化玩家，高频玩家等等。

#   

# 有的朋友后台留言说，技术指标都是过时的东西，有什么用。这个我非常的认可，技术指标确实是“画图”，特别是这几年的市场风格切换的非常快，节奏非常快，靠这些图，和经验主义沉淀的窗口大小可能真的“无用”，而更微观层面的订单流、市场交易行为才是当下有用的，但要注意的是：这种判断，不是来自别人的结论，而最好是来自的摸索探究后形成才能有用。

#   

# 就上面说的不同投资成功的道，关键点是长期以往的坚持自己一个投资方式，并在实盘中不断的验证，修正，最终成功的几率都比较大。就以我自己比较了解的量化投资方式来说，如果你见这个行业的人见的多了，并不是每个能赚到钱的都有幻方那样的机房，那样的人才，1个人，3、4个人，靠着一个策略，靠一套系统稳定盈利（不论多少）的也很多，按我自己多见的，做成功靠谱的基本上都是经历了牛熊洗礼的一套系统，哪怕是下跌市场收益不行，但赶上去年10月份的行情，有这样成熟投资体系的，一定是能吃到大肉的。

#   

# 如果具体来说，可以有一些具体的思路仅供参考：

##   

## 脱离结果：将自己的情绪与单笔交易的结果区分开来。赢钱并不意味着自己是天才，输钱也不意味着我是失败者。这个只是一个数据而已；这种思维转变会让自己摆脱情绪的起伏。不再纠结于盈亏，而是要习惯性开始问自己：

##   

-   ## 我是否遵循了交易计划？
    
-   ## 我是否遵守了规则？
    
-   ## 根据我掌握的信息，这是一个好的决定吗？”
    
-   ## 这个交易决策来自我自己的脑子吗？
    
-   ## 这个交易操作我是否有情绪左右？
    

##   

一旦自己转移“盈亏”的注意力，就会意识到自己的流程存在漏洞。就会想着加强自己投资策略逻辑，为买入和卖出制定了更明确的规则，并开始关注风险。

比如，如果事先制定具体的交易规则，哪怕最简单的，每天固定时间买入，在某个止损和止盈条件下马上卖出，就可以设置成条件单，或者做成程序化，然后就不管它们了。不再因为恐惧而调整止损，也不会因为自己的贪婪而改变目标。

这样简单的规则就可以帮助自己避免冲动交易，并在长期坚持中不断的修正、沉淀自己的计划。目标不是看我赚了多少钱或亏了多少钱，而是看我如何坚持我的计划。还是那句废话：贵在坚持。

如果通过量化方式做投资，一个非常好的点就是：可以回测。

通过回测可以让我们快速验证一个想法的定量结果（当然，不管好坏都是历史上的表现，不代表未来，单总比拍脑袋要好。），根据历史数据模拟交易，调整不同的参数和逻辑，查看在不同市场条件下的表现，这样就不会盲目地进行实盘交易。即使在连续亏损时也能坚持投资计划。因为我们知道策略是经过测试和验证的，没有达到预期，也能找到问题在哪里，随着时间的推移，通过不断分析回测和实盘的差异，不断修正决策，让回测和实盘达到更一致的结果。

通过这种改变：

-   可以减轻自己的压力：当你不再总是担心利润时，交易压力就会减小。我并不是说这很容易，但专注于交易过程可以帮助你保持冷静，即使在亏损的情况下也是如此。
    
-   ## 更好的决策：当你专注于遵循计划而不是追逐利润时，你不太可能做出冲动的决定。你可以头脑清醒地进行交易，并坚持有效的方法。
    
-   ## 长期成功：当你打持久战时，短期的得失并不那么重要。关注过程可以确保你的行动可持续且有效。
    

##   

市场不可预测，总是有赢有输。

但如果专注于**过程**而不是**利润**，你将能够更明智地进行交易，压力更小，长期来看结果也更好。

对我来说，这种心态的转变改变了一切。我不再纠结于结果，而是开始专注于做出正确的决定。可能不是能百分百盈利，但真正的回报是我在这一过程中获得的控制感和自信。

如果大家也是在情绪化交易或者感觉还没找到自己所谓的体系，那可以尝试上面说的：多关注自己的交易过程如何进行，而不要总盯着自己的收益是红的还是绿的。这可能不会在一夜之间解决投资的所有问题，但一定是长期成功的基础。

期望大家都能找到自己的“过程”。
