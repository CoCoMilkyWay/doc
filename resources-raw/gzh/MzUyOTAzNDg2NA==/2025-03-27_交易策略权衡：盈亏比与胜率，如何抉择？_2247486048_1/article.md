对CCI策略的收益进行优化的初步思路基本上包括：CCI指标周期参数、CCI指标超卖阈值、止盈参数、止损参数等，完成基本条件优化后，再考虑增加策略的逻辑（一般情况下，复杂化策略未必是好事），在动手之前，我们先了解一些量化策略分析的基本概念。

任何量化交易策略的本质都是对市场规律的数学抽象，举两个例子：

概率思维：力图将看似无序的价格波动转化为概率分布，例如趋势行情一般符合尖峰肥尾分布；震荡行情一般具有正态分布的特征等。

非线性映射：通过特征工程找到市场相关的信息，如基于订单流不平衡构建特征，预测短期方向；通过波动率的形态判断行情级别等。

量化策略的核心在于平衡：胜率、盈亏比与交易次数的动态关系（当然还有仓位、策略市场容量、收益率等等因素，这里先不考虑）。胜率、盈亏比与交易次数是交易系统中的重要因素，它们相互关联、相互影响，共同决定了交易的最终结果。

-   胜率：是指在一定交易次数中，盈利交易次数所占的比例。例如，进行了100次交易，其中有60次是盈利的，那么胜率就是60%。对量化来说，就是提高对目标的预测能力，需要反直觉的认识是：胜率高并不一定意味着能获得高额利润。比如每次盈利的金额较小，而亏损的金额较大，即使胜率较高，最终也可能出现亏损。
    
-   盈亏比：指平均盈利与平均亏损的比例。比如，平均每次盈利1000元，平均每次亏损500元，那么盈亏比就是2:1，所以盈亏比决定了单次交易的收益风险，较高的盈亏比意味着在盈利时能够获得较大的利润，而在亏损时能够控制损失在较小范围内，这对于一个策略能否实现长期稳定盈利至关重要。
    
-   交易次数：指在特定的交易时间段内，投资者进行买入或卖出操作的总次数。
    

  

三者相辅相成的关系大概如下：

-   胜率和盈亏比的关系：
    
    胜率和盈亏比之间存在一定的权衡关系。通常情况下，追求高胜率可能会导致盈亏比下降，因为为了提高胜率，可能会选择较为保守的交易策略，盈利空间相对较小；而追求高盈亏比则可能需要承担更高的风险，从而导致胜率下降。
    
      
    
-   交易次数和胜率的关系：
    
    交易次数越多，胜率就越能稳定地反映交易策略的真实水平。当交易次数较少时，胜率可能会受到偶然因素的影响，具有较大的波动性。随着交易次数的增加，偶然因素的影响会逐渐减小，胜率会趋近于一个稳定的值，这个值更能代表交易策略的实际盈利能力。
    
      
    
-   交易次数和盈亏比的关系：
    
    交易次数的增加会使平均盈利和平均亏损的计算更加准确，从而更真实地反映出盈亏比。同时，交易次数的增加也会增加盈利和亏损的机会，这就要求交易者在每次交易中都要严格控制风险，以确保盈亏比保持在一个合理的水平。如果在大量交易中不能有效控制亏损，即使有较高的胜率，也可能因为亏损过大而导致最终结果不理想。
    
      
    
-   交易次数与盈利的关系：
    
    在胜率和盈亏比一定的情况下，交易次数越多，盈利的可能性就越大。但这并不意味着盲目增加交易次数就能获得更多利润。如果交易成本较高，过多的交易次数会增加交易成本，从而侵蚀利润。
    

  

综上，胜率、盈亏比与交易次数是相互依存、相互影响的关系。交易者需要在三者之间找到一个平衡，制定出适合自己的交易策略，同时通过不断的实践和总结经验，提高自己的交易水平，以实现长期稳定的盈利。

下面再分别说下胜率、盈亏比与交易次数的计算方法：

1.胜率

```
胜率 = 盈利交易次数÷总交易次数×100%
```

假设某投资者在一段时间内进行了50次股票交易，其中有30次交易是盈利的，那么根据公式可得，该投资者的胜率 = 30÷50×100% = 60%。

2.盈亏比

```
盈亏比 = 平均盈利金额 ÷ 平均亏损金额
```

例如，某投资者在一系列交易中，盈利交易共有20次，总盈利金额为20000元，那么平均盈利金额 = 20000÷20 = 1000元；亏损交易有10次，总亏损金额为8000元，平均亏损金额 = 8000÷10 = 800元（取绝对值）。则该投资者的盈亏比 = 1000÷800 = 1.25。

3.交易次数

```
无论交易是盈利还是亏损，每进行一次完整的买卖操作，就计为一次交易次数。
```

比如，投资者在一个月内进行了股票交易，买入操作15次，卖出操作15次，因为每次买入并卖出算一次完整交易，所以交易次数为15次。如果是双向交易市场，如期货市场，买入开仓后卖出平仓算一次交易，卖出开仓后买入平仓也算一次交易，将所有这样的完整操作次数相加，就是总的交易次数。
