-   4点0分0.15秒，美国商业通讯社（PR Newswire）向高频交易公司和彭博社等交易终端机发布财报新闻。
    
-   4点0分0.20秒，高频交易公司以122美元价格卖掉80万美元的Ulta股票。

-   4点0分0.464秒，道琼斯发布新闻；

-   4点0分1秒，汤森路透发布Ulta财报新闻。
    
      
    

如上，在0.85秒时间内，市场上肯定没有那个人通过人工方式看到这篇财报。

# 把上述高频交易方式，可以概括为事件驱动。事件驱动交易是一种系统性方法，它将**现实世界中的事件**（例如财报发布、经济数据、产品发布、监管决策和并购传闻）转化为**可重复的交易规则**。您无需直接预测价格，而是模拟市场通常如何对_特定催化剂_做出反应，并围绕这些反应构建入场、出场和风险管理。

![](assets/002.png)

  

事件作为信息冲击，核心作用体现在两方面：一是**重新定价预期**，改变市场对资产价值的判断；二是**加速订单流**，引发集中交易行为。以下从事件类别、所需数据（及质量控制）、战略原型三大维度，对事件驱动交易的核心要素进行系统整理。

事件按影响范围可分为四大类，每类包含明确的核心触发项，且具有独特的 “反应模式”（速度、方向、衰减 / 持续性），可通过研究加以利用。

![](assets/003.png)

数据是事件驱动策略的基础，需覆盖 “事件本身 - 价格行为 - 参考信息” 三大维度，同时通过严格的质量检查确保有效性。

![](assets/004.png)

  

数据质量直接决定策略有效性，需通过四大关键步骤控制：

-   时间戳对齐：内部统一将所有数据（事件、价格、新闻）的时间戳转换为 UTC 时间，同时存储原始时区信息供审计；严禁直接比较未统一时区的原始时间戳，避免时间差导致的信号错误。
    
-   重复数据删除：同一事件可能被多来源联合发布，需去重处理 —— 优先保留 “最先到达的信息” 或 “可信度最高的来源”；通过 “URL 哈希 + 标题相似性算法” 识别重复内容，确保数据唯一性。
    
-   时序逻辑校验：确保新闻 / 事件的时间戳早于对应的交易条形图时间戳（即 “信息先于交易”）；若出现 “条形图时间早于事件时间” 的异常数据，需直接屏蔽，避免用 “未来数据” 回测。
    
-   规避幸存者偏差：数据范围需基于 “事件发生时已知的标的池”（而非当前存续标的）；回测时必须包含已退市、已除名的标的，确保样本完整性。
    

  

通过四个策略原型基于不同事件逻辑设计，涵盖 “趋势跟随”“均值回归”“情绪捕捉” 等核心思路，各有明确的信号、假设与时间窗口。

A）盈利意外反应

交易 “实际收益与预期的偏差”，捕捉市场对盈利惊喜的即时反应

标准化惊喜度 S = (实际值−一致预期)/ 误差标准差；可叠加 “收入惊喜”“指导增量” 作为辅助信号

1\. 正 S（盈利超预期）→短期价格上涨2. 负 S（盈利不及预期）→持续抛售3. 两者均可能在一段时间后均值回归

事件发布后（盘前 / 盘后）、下次开盘时

B）新闻情绪动量

捕捉短时间内 “片面新闻流” 的推动作用，跟随情绪驱动的趋势

1\. 用 NLP 模型解析新闻标题 / 正文，生成情绪得分（正面 / 负面 / 中性）2. 按 “来源可信度”“信息新颖性” 加权；情绪得分随时间衰减

新鲜、强烈的片面新闻流（全正面 / 全负面）会推动价格上涨 / 下跌 15-90 分钟，之后趋势开始衰减

新闻发布后的 15-90 分钟内

C）事件研究均值回归

利用事件引发的 “过度反应”，捕捉价格向合理区间的回调机会

盘中跳空幅度 > k×ATR（平均真实波幅）；若 T 分钟内无后续推动行情，则触发 “向 VWAP（成交量加权平均价）回归” 信号

部分事件（如无实质影响的消息）会引发市场过度跳空，缺乏持续动力，价格将向 VWAP 修正

跳空后 T 分钟内（无后续行情时）

D）引导 / 语调模型

解析管理层 “语言倾向”，交易次日的波动预期

用文本分析模型提取管理层评论、指导性语言的关键特征：1. 情绪倾向（积极 / 消极）2. 不确定性（模糊表述比例）3. 特异性（具体数据 / 时间的提及程度）

管理层语言的 “积极 / 消极倾向”“不确定性” 直接影响市场对次日波动的预期，可通过语言特征预判波动方向 / 幅度

管理层表述发布后的次日

  

事件驱动的流程如下：

\[提取\] → \[规范化\] → \[事件标记器\] → \[特征构建器\]            
       → \[信号引擎\] → \[风险/投资组合\] → \[执行\] → \[监控\]

  

![](assets/005.png)

-   **提取：**用于新闻的 Websocket/API；用于日历/收益的预定作业。
    
-   **规范化：**时间戳为 UTC、重复数据删除、地图行情指示器、按场地/会话过滤。
    
-   **事件标记器：**对事件类型进行分类，链接到工具，丰富共识、部门、浮动、空头利息。
    
-   **特征构建器：**计算意外、情绪、新颖性、流动性指标、波动性制度。
    
-   **信号引擎：**输出目标位置/分数的确定性规则或 ML 模型。
    
-   **风险/投资组合：**每个名称的限制、行业上限、总额/净额、波动性目标、终止开关。
    
-   **执行：**场地选择、限制/市场逻辑、与 alpha 半衰期相关的紧迫性；对于大牌使用 IOC/POV。
    
-   **监控：**延迟计时器、滑点归因、规则违规、损益解释。

-   **标记化和清理：**小写，剥离代码/样板，保留否定（“不”，“错过”，“降级”）。
    
-   **词典情绪：**财务调整词典（Loughran-McDonald）用于快速基线。
    
-   **模型情绪：**对标记的金融标题的变压器进行微调，以适应极性/制度。
    
-   **新颖性：** Jaccard 或嵌入余弦与同一股票代码的最后 N 个标题；折扣重复。
    
-   **来源可信度：**按历史预测来源或官方文件加权。
    
-   **时间衰减：** `decay(t) = exp(−t / τ)`反映短暂的半衰期。
    
-   _综合得分：（_  
    `news_score = w1*sentiment + w2*novelty + w3*source_weight`然后按分钟衰减）。
    

  

模型最终绩效：

![](assets/007.png)

·**输入：**实际每股收益/收入、共识、私下预测（如有）、指导（当前和之前）、意外历史。

·**标准化：**行业/市值区间内的 Z 分数意外情况，用于跨名称比较。

·**催化剂极性：**上行惊喜 + 上调指引 > 一次性 EPS 超出预期。

·**时机：**盘前和盘后发布的表现不同——流动性和利差很重要。

·**漂移与逆转：**

·小小的积极惊喜经常会在盘中和 T+1 期间**出现。**

·极端的惊喜可能会**引起过度反应**，在第一个小时之后，吸引力就会逐渐消失。

**简单的规则草图**

·如果`S_EPS > 1.0`AND `S_REV > 0`AND 指导被提出 → 在第一流动性打开时做多；在k·ATR 处追踪停止；通过关闭或反转信号退出。

·如果`S_EPS < −1.0`OR 指引下跌 → 做空流动性较差的股票，但风险较小。

## 通过回测事件策略，进步验证：

##   

![](assets/008.png)

·**不向前看：**仅使用事件时间戳**之后**可用的数据。

·**延迟预算：**添加实际延迟（API、解析、决策、订单路由）。即使 200-500 毫秒的延迟也可能影响标题的填充。

·**会议意识：**将会议前/会议后的表现与常规会议分开。

·**滑点模型：**价差感知；影响随着订单规模和紧急程度参数而增长。

·**异常值：**限制极端回报或对特征进行缩尾处理；在评估中保留尾部风险。

·**制度分裂：**通过波动性制度（VIX 四分位数）、流动性桶和部门进行测试。

·**多重比较控制：**通过预先定义假设来避免 p 值操纵；使用样本外月份。

**事件研究模板**

1.收集事件并根据`t=0`事件发生时的情况调整当日回报。

2.计算与市场/行业模型相比的平均**累积异常回报 (CAR) 。**

3.按意外十分位数、情绪、流动性和一天中的时间进行切片来观察形状。

## 根据事件量身定制的风险管理

·事件发生后，根据 ATR 或 CAR 阈值进行**硬停止。**

·如果滑点 > 阈值、进料变得陈旧或订单拒绝激增，**则启动终止开关。**

·按名称/部门**限制持仓；避免在同一催化剂上堆叠相关风险敞口。**

·**随着盘中波动率的变化，波动率目标的**规模也会增加或减少。

·**保持时间规则**与阿尔法半衰期一致（新闻保持时间为几分钟到几小时；制导漂移保持时间为几小时到几天）。

## 短半衰期 alpha 的执行策略

·**分期：**立即进入部分，在微支撑附近完成限制；避免追逐薄书。

·**场地选择：**为了确定性，最好选择灯光明亮的场地；尽可能使用中点/挂钩订单。

·**排队优先级与价格改善：**对于流动性名称，紧密被动订单；对于稀缺机会，跨越价差。

·**回归保护：**如果价格迅速回升至事件发生前的 VWAP，则趋于平缓。

## 生产中需要跟踪的指标

-   按事件类型和意外十分位数划分的**命中率和分布。**
    
-   **Alpha 衰减曲线**：自事件发生以来每分钟的损益。
    
-   **实施不足**：决策时出现失误。
    
-   **延迟预算**：摄取→决定→路由→交换ACK。
    
-   **停止/恢复行为**：波动停止的结果。
    
-   **误报**：利用重复或过时的标题进行交易。
    

##   

## 整合：分步构建计划

1.  **选择一个事件系列**（例如收益）和一个市场（例如美国股票）。
    
2.  **收集干净的数据**：符合共识的历史收益+日内数据；确保时间戳的完整性。
    
3.  **运行事件研究**：将收益对齐`t=0`，通过意外十分位数可视化 CAR。
    
4.  根据您可以解释的效果（漂移与消退）**起草规则。**
    
5.  **使用延迟和滑点进行回测**；跨制度进行前向验证。
    
6.  **实施最低限度的执行**：采用现实订单逻辑的纸面交易。
    
7.  **生产强化**：监控、风险防范、警报、日志、重放。
    
8.  一旦管道稳定，**就扩展到其他事件（指导文本、行业新闻、宏观印刷）。**

## 常见陷阱（及解决方法）

-   **在看到新闻稿之前就进行交易。**添加延迟缓冲；仅对事件发生后开启的柱线进行操作。
    
-   **忽略交易时段差异。**盘前/盘后流动性较弱；减少交易规模或跳过。
    
-   **过度拟合单一收益季。**跨多个年份和波动范围进行验证。
    
-   **重复报道引发的情绪漂移。**删除重复内容并降低新颖性权重。
    
-   **对微型股的规模设定过高。**根据日均交易量和价差设定仓位上限；执行最低流动性门槛。

## 最后的想法

事件驱动交易在您对催化剂有**精准把握、对时机有严谨要求**、对数据安全**有严格要求**时，效果最佳。从单一事件类型入手，构建可靠的管道，然后再添加诸如基于 NLP 的情绪模型或引导语气模型等复杂功能。通过仔细的测试和稳健的执行，您可以将混乱的新闻标题和收益信息转化为结构化、可重复的交易优势。

上面是一个基于传统的NLP思路，我们在概要看一个基于AI的思路：Stony Brook团队推出QuantAgent，首个纯价格驱动的多智能体LLM高频交易框架。

  

QuantAgent的突破在于，它首次证明了无需依赖任何新闻或社交媒体文本，仅凭价格数据本身（OHLC：开盘价、最高价、最低价、收盘价），就能利用LLM构建出一个有效的高频交易决策系统。该框架基于“价格本身经常包含短期交易的充分信息”这一假设，通过多智能体LLM架构，直接从原始价格序列中提取技术指标、识别图表形态、分析趋势动量，从而规避了文本信号固有的延迟与噪声问题，实现了价格驱动决策。

下图指标代理（IndicatorAgent）构成了此框架的初始分析模块，负责将原始的开盘价、最高价、最低价、收盘价（OHLC）序列转换为结构化的定量信号。

指标代理是我们系统中第一个模拟专业交易环境工作流程的代理，重点是从原始价格数据中提取定量信号。在高频交易（HFT）环境中，决策必须既快速又基于数据，技术指标以简洁的方式突出市场动向和情绪的变化。它们通过将开盘价、最高价、最低价、收盘价（OHLC）数据转换为信号，即((O, H, L, C) to S)，其中S代表可解释的交易信号，来帮助揭示市场动向和情绪的细微变化。指标代理通过以快速且可解释的方式总结技术面情况，为决策制定提供支持。

![](assets/009.png)

下图中模式代理（PatternAgent）的工作流程：上游大语言模型（LLM）调用工具，将原始价格走势转换为带有标注的概图，突出关键走势（例如，先急剧下跌后回升）。然后，下游大语言模型将此模式图与标准形态库（如双重底、双重顶、V 型反转和看跌旗形）进行比对，以识别最接近的形态。经识别的模式及其分析会被转发至后续模块，以补充数值指标。

![](assets/010.png)

下图TrendAgent的工作流程：与LLM绑定的草图工具将最近的蜡烛图数据转化为带有注释的支撑和阻力线的趋势图(例如，K线在向下倾斜通道内振荡，然后突破支撑线)。然后，生成的图表由LLM进行处理，它将模式提炼为三个结构化的输出:预测、推理和信号，供下游交易逻辑使用。

![](assets/011.png)

下图RiskAgent的工作流程：雷达图汇总了来自上游代理、趋势、指标和模式的输入，跨越多个风险维度，包括动量强度、趋势确定性、模式可靠性、突破可能性、支撑/阻力稳健性以及波动性风险。这些维度共同捕捉了市场不确定性的多维特性，平衡了方向性确信与潜在不稳定性的考量。DecisionAgent随后整合这些信号，计算出一致的风险回报比率，并附上相关推理，这被转化为一个区域图，具体标出止盈和止损水平，以指导执行。

![](assets/012.png)

下图决策代理的工作流程：该LLM首先汇总关键的上游证据，例如MACD看涨交叉、稳定的历史柱状图、上升的变化率曲线以及突破阻力后的双重底部形态。然后，它将这些输入整合为结构化的输出:方向性决策、详细的论证、带有入场和防护级别的交易设置以及交易后反思指导方针。最后，该LLM生成可执行的指令例如带有时间框架和理由的“黄金期货做多信号”，并准备立即提交至市场。

![](assets/013.png)

框架的最后一个阶段是决策代理，它作为推理和执行层发挥作用。如上图所示，它整合上游代理的输出，以决定是建立多头还是空头头寸。由于不允许持有，该代理预测未来三个蜡烛图期间的市场短期走向，并生成与整体系统观点一致、可直接执行的决策。

具体而言，决策代理会从指标代理、模式代理和趋势代理接收一个综合的信号状态，并据此输出一个结构化的交易决策，其中包括预测的走向(做多或做空)、简明扼要的理由，以及根据市场背景计算出的风险回报比率。该代理会整合各种不同的证据，并评估上游信号的致性，只有在多数信号一致且得到确认信号(如指标交叉、完成的突破形态或价格与主要趋势边界之间的互动)的强化时，才会采取行动。这种层次分明的推理方式能够过滤掉杂或冲突的输入，从而得出自信且高质量的判断。因此，其输出不仅在高频环境下执行时表现最优，而且比传统基于规则的系统生成的结果更加稳健且易于理解。
