1.VAR模型

即向量自回归（Vector Autoregression ）模型，是一种在经济、金融研究中广泛应用的计量经济模型，1980年由克里斯托弗·西姆斯（Christopher Sims）提出 。以下是关于它的详细介绍：

### 基本原理：

它将单变量自回归模型推广到多元时间序列领域 。在VAR模型里，系统中的每一个内生变量都被视为系统中所有内生变量滞后值的函数，用模型中所有当期变量对所有变量的若干滞后变量进行回归。比如一个包含两个变量 ( Y\_{1t} ) 和 ( Y\_{2t} ) 的VAR(1)模型（滞后阶数为1 ），可以表示为： ( Y\_{1t} = c\_1 + \\alpha\_{11}Y\_{1t - 1} + \\alpha\_{12}Y\_{2t - 1} + \\varepsilon\_{1t} ) ( Y\_{2t} = c\_2 + \\alpha\_{21}Y\_{1t - 1} + \\alpha\_{22}Y\_{2t - 1} + \\varepsilon\_{2t} ) 其中 ( c\_1 )、( c\_2 ) 是常数项，( \\alpha\_{ij} ) 是系数，( \\varepsilon\_{it} ) 是误差项 。

### 模型构建：

-   **变量与滞后阶数确定**：需要明确纳入模型的变量，以及合适的滞后阶数 ( p ) 。滞后阶数 ( p ) 代表用于预测变量当前值的过去观测值数量 。一般通过Akaike信息准则（AIC） 、Schwarz贝叶斯信息准则（SBIC）等滞后选择技术来确定最优滞后阶数，AIC和SBIC值越低，表明模型拟合效果越好；也可用似然比检验比较不同滞后阶数的模型 。
    
-   **参数估计**：通常使用普通最小二乘法（OLS）对模型中的每个方程进行回归，估计出各个系数，这些系数体现了变量间的动态关系 。
    

### 模型应用：

-   **预测**：用于预测相互关联的时间序列系统。因为模型中每个方程右侧不含当期变量，所以在进行样本外一期预测时，无需对解释变量在预测期的取值做预测，对样本外近期预测较为准确，但做样本外长期预测时，只能大致预测变动趋势，对短期波动预测效果欠佳 。
    
-   **动态关系分析**：通过脉冲响应函数（IRF） ，追踪一个变量受到单位冲击或新信息影响时，其他变量随时间的响应情况，洞察变量间的动态交互和传导机制 。比如分析油价冲击对GDP的影响 。还能通过构建置信区间评估估计的不确定性 。
    
-   **因果关系检验**：借助Granger因果检验，探究变量间的因果关系。例如判断货币供应量与通货膨胀之间是否存在Granger因果关系 。
    

### 模型特点：

-   **优点**：不依赖先验经济理论，从数据本身出发构建模型，能捕捉多个时间序列变量间的动态关系，提供对经济系统更全面的理解；具有灵活性，可根据研究问题和数据特征扩展，纳入更多变量 。
    
-   **缺点**：随着变量和滞后阶数增加，参数数量大幅增长，可能导致自由度变小，估计误差增大；模型基于历史数据构建，当经济结构或数据生成过程变化时，预测和分析效果可能受影响 。
    

### 2.Granger因果检验概念

Granger因果检验用于判断一个时间序列是否能帮助预测另一个时间序列。如果变量X的过去值对变量Y的当前值有显著影响，就说X Granger - 导致Y。它不是真正意义上的因果关系，而是基于预测的统计关系。

### 结果解读

-   **滞后阶数（number of lags）**：这里展示了从滞后1阶到滞后10阶的检验结果。滞后阶数表示使用过去多少期的数据来进行预测。
    
-   **检验方法及统计量**
    

-   如滞后1阶时，chi2 = 0.2521，p = 0.6156 ，p值大，不能拒绝原假设。
    
-   滞后2阶时，chi2 = 29.4876，p = 0.0000 ，p值小，拒绝原假设，存在Granger因果关系。
    

-   以滞后1阶为例，F = 0.2498，p = 0.6176 。F统计量用于检验约束条件下的模型与无约束模型的差异。p值大于常用的显著性水平（如0.05 ），说明在滞后1阶时，不能拒绝原假设，即一个变量不能Granger - 导致另一个变量。
    
-   当滞后阶数为2时，F = 14.5170，p = 0.0000 ，p值远小于0.05，说明在滞后2阶时，拒绝原假设，存在Granger因果关系。
    

-   **ssr based F test（基于残差平方和的F检验 ）**：
    
-   **ssr based chi2 test（基于残差平方和的卡方检验 ）**：
    
-   **likelihood ratio test（似然比检验 ）**：原理是比较两个嵌套模型的似然函数值。例如滞后1阶时，chi2 = 0.2520，p = 0.6157 ，不显著；滞后2阶时，chi2 = 28.2257，p = 0.0000 ，显著。
    
-   **parameter F test（参数F检验 ）**：和ssr based F test类似，滞后1阶时不显著（F = 0.2498，p = 0.6176 ），滞后2阶时显著（F = 14.5170，p = 0.0000 ） 。
    

###  结论

-   当滞后阶数较小时（如1阶），各检验的p值较大，没有足够证据表明变量间存在Granger因果关系。
    
-   随着滞后阶数增加（如2阶及以后的部分阶数 ），多个检验的p值小于0.05，说明在这些滞后阶数下，变量间存在Granger因果关系。这表明使用过去多期的数据时，一个变量的过去值对另一个变量的当前值有显著的预测能力。
