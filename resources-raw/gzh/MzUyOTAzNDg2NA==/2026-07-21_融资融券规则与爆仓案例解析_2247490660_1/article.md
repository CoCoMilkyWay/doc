特殊的环境下，利好利空的因素很多，高价格，高估值，高杠杆到底是登高的阶梯，还是不断积累的风险，很少有人能预判，因为何为高，何为低，没有任何标准可度量。事后看一切可能都合理。所以精力回归到策略本身，轻易的猜底，猜顶相对都不可控。同理融资融券业务也一样，高和低都是相对的。只能作为参考的镜子，而不能成为投资的尺子。

  

融资交易，俗称“做多”，是指投资者向证券公司借入资金买入证券的行为。投资者看涨某只股票，但自有资金不足，可以向券商借钱买入，到期还本付息。

**融券交易**，俗称“做空”，是指投资者向证券公司借入证券并卖出的行为。投资者看跌某只股票，可以向券商借入股票卖出，待股价下跌后再买回还券，赚取差价。

融资融券的本质是**杠杆交易，**用少量自有资金撬动更大规模的投资，收益和亏损都被放大。

1.融资保证金比例

融资保证金比例是投资者融资买入证券时自有资金与融资金额的比例，2026年1月14日，沪深北交易所将融资保证金最低比例从80%上调至100%，2026年1月19日起施行。此次调整仅适用于新开融资合约，存量合约及展期仍按原比例执行。按新规新开融资合约的杠杆率从1.25倍降至1倍，计算公式如下：

```
融资保证金比例 = 保证金 ÷（融资买入证券数量 × 买入价格）× 100% 
```

融资比例越低，投资者可撬动的融资金额越大，杠杆效应越显著；比例越高，融资杠杆越低，风险相对可控。调整前投资者投入80万元保证金，可融资100万元，杠杆率1.25倍。调整后同样融资100万元需投入100万元保证金，杠杆率回落至1倍。 历次调整记录如下：

-   2006年：融资保证金比例试点设定为50%，最高可达2倍杠杆。
    
-   2015年11月：为抑制市场过热，从50%上调至100%，降低杠杆风险。
    
-   2023年8月/9月：为活跃市场，从100%下调至80%，增加融资规模。
    
-   2026年1月：再次上调至100%，以防杠杆过高、市场过热
    

  

2.维持担保比例

维持担保比例是融资融券风控体系的核心监控指标，也是券商判断账户风险、触发预警、追保、强平的唯一核心依据，官方标准计算公式如下：

```
维持担保比例 =（现金 + 信用账户证券市值 + 其他合规担保物价值）÷（融资买入负债金额 + 融券卖出证券市值 + 应付利息及各项费用）× 100%
```

**简单可以理解为自己账户整体可担保总资产除以欠券商的全部负债总额。比例越高，说明资产被负债大，账户安全垫越厚、风险越低；比例持续下跌，说明资产比负债要小了，代表账户杠杆风险急剧上升。证券公司按交易所统一底线规则，设置各自具体的融资融券业务的风控规则：**

  

风控档位

维持担保比例

核心规则含义

提取线

300%

比例≥300%时，超出部分的现金、证券可转出信用账户；低于300%禁止提取担保物

警戒线

150%

风险预警档位，账户**禁止新增融资买入、禁止新增融券开仓**，但原有持仓、杠杆负债不会被处置，账户正常交易，仅限制新开杠杆仓位，属于风险提醒档位。

追保线（补足目标线）

140%

触发平仓预警后，账户必须补足至该比例及以上，才算解除风控限制

常规平仓线（底线）

130%

T日收盘后，维持担保比例 **低于130%**，触发正式追保平仓流程。客户必须在 **T+1日16:00前** 通过入金、转入证券、卖出持仓降杠杆等方式，将维持担保比例 **提升至140%（追保线）及以上**。超时未达标，券商有权直接强制平仓，直至账户比例重回安全区间。该档位为温和风控，给予完整一个交易日的缓冲时间。

紧急/即时平仓线（增设）

115%/110%

极端风险线，2026年多家头部券商升级两融风控，在交易所130%底线之上增设**极端风险即时平仓线**，收紧低位风险账户的处置节奏，T日收盘维持担保比例＜115%，触发极速追保机制；客户需在 **T+1日上午收市前（11:30前）** 将比例提升至 **130%及以上**。半日窗口期未达标，券商T+1日午盘后直接启动强制平仓。

在交易所法定底线的基础上，不同证券公司基于融资融券业务开展的自身风控考量，会增设各自的风控线，以便杜绝极端行情穿仓风险，但少数中小券商仍仅执行130%单一平仓线，其中几个典型券商如下：

-   DFZQ：115% 即时平仓线（全账户通用，2026.5.18生效）
    
-   YHZQ：115% 最低维持担保比例线，跌破次交易日可直接强平
    
-   GSZQ：115% 次日紧急平仓线（仅限科创板、创业板高波动账户，非全账户）
    
-   GTHT：110% 极端紧急平仓线（行业最低容错线）
    
-   ZSZQ：110% 提前追保预警线

站在后视镜视角复盘某利本轮下跌的杠杆资金轨迹：行情初期就有资金提前预判风险抢跑，7月1日融资净卖出6.75亿元，7月2日再净卖出7.52亿元，两日合计离场14.27亿元；彼时股价仅回落至893元、811元，相对980元历史高点回调10%-17%。这批出逃资金有可能是6月26日前后在980元高位融资进场的筹码，见顶后提前止损兑现。也有可能是正常的卖出。7月3日、7月6日又有资金逆势加杠杆，分别融资净买入5973万元、7.48亿元，刚好接在935元阶段次高点。之所以只能事后看清资金分歧，是身处行情当下，没人能判断存储赛道高涨的融资进场潮是上涨起点还是行情尾声；无论后续股价上涨或下跌，市场都能配套一套自洽解读。

  

结合融资余额变化可清晰划分两个资金出逃阶段：7月1日至7月14日属于有序离场阶段，区间融资余额合计减少11亿元，这段下跌过程仍有持续买盘承接，每日融资买入规模维持数亿至十几亿区间，抛压以投资者主动偿还融资为主；分水岭出现在7月15日一字跌停后，7月15日至7月17日融资余额大幅缩水20.84亿元，三天融资买入合计仅5.83亿元，如果场内承接近乎枯竭，则抛压可能会转变为跌破两融风控线带来的批量强制平仓，行情就从有序减仓彻底转为杠杆资金踩踏（假设这种极端场景。）。

  

最新行情拐点源于7月14日晚间披露的 2026 年半年报预告：公司上半年业绩整体大幅增长，但二季度净利润环比下滑5.74%-29.65%，打破市场对存储周期持续高增的一致预期。叠加年内涨幅超7倍、估值严重透支，资金选择利好兑现集中出货。7月15日集合竞价该股直接封死一字跌停，收盘价662.40元，盘中全程无开板，当日最高封单资金达67亿元，卖一挂单10.02万手。此后7月15、16、17、甚至今天，基本都在集合竞价阶段直接锁死一字跌停，个股流动性被锁死，如果真有融资盘触发了强平风控，那就会出现在卖盘。

  

高杠杆资金既能在行情上行阶段助推股价快速拉升，一旦行情转弱，极易触发平仓负反馈风险。经历过 2015 年市场行情的投资者都清楚，当年大规模杠杆集中强平曾引发千股跌停的惨烈局面。个股一旦在集合竞价阶段出现集中抛售、流动性直接封死跌停，场内抛压便不再是投资者主动止损，而是券商风控系统自动批量挂出强制平仓单，进而催生 “越跌越触发强平、强平再加剧下跌” 的死亡负反馈螺旋。

```
股价下跌
```

融资融券本质是一把双刃剑，上涨阶段能放大收益、抬升股价，下跌阶段却会成倍放大亏损，极易触发平仓负反馈循环；若股价缓慢下行，投资者尚有减仓、补仓缓冲空间，可一旦遭遇一字跌停锁死流动性，场内抛压不再是投资者主动止损，而是券商风控系统自动批量挂出平仓单，形成越跌越强平、越平越下跌的死亡螺旋，2015 年杠杆集中强平引发千股跌停的惨烈行情早已印证这一巨大隐患。

巴菲特曾将过度杠杆比作酗酒，少量无碍、过量则会酿成大祸；芒格早年试水杠杆套利后，也深知下跌行情里杠杆会同步放大损失；格雷厄姆在《聪明的投资者》中将重仓杠杆博弈归为投机行为，点明投资最大风险并非股价波动，而是杠杆带来的本金永久性损失；彼得・林奇也提醒，投入股市的资金必须是即便全部亏损也不影响日常生活的闲钱；而利弗莫尔更是杠杆的鲜活反面教材，纵使交易天赋出众，仍因频繁重仓杠杆多次巨额亏损乃至彻底破产，《股票作手回忆录》完整记录了杠杆对交易者的毁灭性冲击；大道也同样直言，真正看懂投资的人无需依靠杠杆提速收益，不懂投资的人加杠杆只会亏得更快、更惨，人生只需成功富一次，守住财富远比短期暴利重要。

跨越数十年，一众投资大师对杠杆风险的警示，在2026年7月A股硬科技赛道，特别是存储、光、PCB这些高光赛道希望不要发生。目前硬科技对指数的影响太大，太直接了。

世界杯四年才有一场盛大狂欢，但投资这条路，从来没有短暂的赛程，只有日复一日的沉淀、细碎打磨与长久积累。

经历此番回撤与亏损，大家完全不必沉溺当下的失落煎熬，每一次账面折损，都是打磨认知、提升交易心性的契机。倘若心底仍保有对市场的热爱，整理好心情再出发，市场永远不缺重来的机会；如果身心早已疲惫不堪，满心压抑煎熬，也不必勉强硬扛，及时离场休整也是清醒的选择。

很多时候想得太多、执念太深，反而容易当局者迷，消磨掉自身的判断力与悟性。适时与市场保持距离，暂时抽身沉淀，换一种旁观者的视角重新审视交易，或许便能走出固有的思维困局，寻找到更平稳、长久的投资之路。
