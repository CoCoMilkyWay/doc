逻辑回归（Logistic Regression ）是一种主要用于二分类（0/1 结果或假/真）的有监督机器学习模型。与预测连续型目标变量的线性回归模型不同，逻辑回归模型预测的是离散型目标变量。它主要用于分类任务。

  

逻辑回归本质：一种通过优化偏置项β₀和回归系数β₁...βₙ来最小化预测误差的分类算法。其核心优势包括：  

-   简单易用：无需复杂调参，适合初学者；  
    
-   训练高效：在大数据集上训练速度快；  
    
-   透明可解释：模型内部计算逻辑清晰，优于黑箱模型；  
    
-   数据友好：小规模数据即可有效训练。
    

  

![](assets/002.jpg)

Linear Regression VS Logistic Regression

  

逻辑回归预测的目标变量具有介于0到1之间的概率值。实际中通常使用一个阈值（threshold value），比如默认0.5，用于将预测结果划分到两个不同的类别中：

-   如果预测概率值 小于 阈值，则预测结果的类别 = 0 。
    
-   如果预测概率值 大于 阈值，则预测结果的类别 = 1。
    

  

逻辑回归被视为有监督机器学习中用于分类的基础模型。对于单个输入变量x，用于预测y 的逻辑回归函数是下面的sigmoid function。

![](assets/003.png)

上述公式中：

-   x：输入变量（自变量）
    
-   β0：偏置
    
-   β1：回归系数
    
-   y：目标变量（因变量）
    

_

_

Logistic regression function with multiple inputs x1, x2,.. xn

  

  

其中上述公式中：

-   y：目标变量（因变量，需预测的输出值）
    
-   xᵢ：自变量（第i个输入特征，i ∈ \[1,n\]）
    
-   β₀：偏置项（截距项，线性方程的常量偏移）
    
-   β₁...βₙ：回归系数（各特征对应的权重参数）

## 5\. intercept\_scaling

## 6\. tol

  

容差参数(tol)控制模型训练的停止条件：

-   数学意义：当损失函数的变化量小于该值时停止迭代
    
-   默认值：1e-4（0.0001）
    
-   取值范围：典型值在1e-5到0.1之间
    
-   双刃剑效应：值太小 → 训练时间长，可能过拟合；值太大 → 提前停止，欠拟合风险
    

代码示例：

```
import numpy as np
```

结果分析：

![](assets/026.png)

可以看出：

-   容差0.2时达到最佳平衡（准确率-效率trade-off）
    
-   超严格容差（<1e-5）使训练时间增加8倍，仅提升0.7%准确率
    
-   容差>0.5时模型性能显著下降
