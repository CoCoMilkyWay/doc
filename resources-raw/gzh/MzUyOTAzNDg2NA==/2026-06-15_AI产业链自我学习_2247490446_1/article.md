“网上”得来终觉浅，绝知此事要躬行。

围绕AI的热点扑风捉影，虽然不能像一级市场的先知，二级市场的专业人员的提前挖掘能力，但任何时候，即使观后镜总结都不算晚，行情总会过去，行情总归回来。

先提出一个自我思考问题：

AI，大模型，邬，有色？光模块，晶圆制造，液冷，GPU这些乱七八糟，生冷专业的名词到底是逻辑，市场是想到那追到那，还是有沿着一定的路径演化？（参考上篇：[近10年A股半导体及AI硬件方向](https://mp.weixin.qq.com/s?__biz=MzUyOTAzNDg2NA==&mid=2247490434&idx=1&sn=df4812ac8b09d6d6d1ac02a2eec3e3bb&scene=21#wechat_redirect)）

具身智能、机器人、智能驾驶、航空航天这些和AI、半导体、芯片存在什么样的联系？

先不着急上结论，沿着这个问题逐步展开：

1.最上游是什么？

自然资源与基础化工。

最上游的传导逻辑是：

**天然矿产以及基础原料 → 粗加工大宗商品 → 高端电子专用材料 → 电子元器件 → 各类电子设备**越往后附加值、技术壁垒越高，从传统资源 / 化工，一步步切入半导体、电路板、电子制造。

按二级市场的主题概念细化为：有色、硅、基础化工、玻纤4大细分产业链(tips：若要分析，可以把下面内容输入AI，让给出对应的龙头公司。)。

①有色金属产业链

路径为：普通有色矿 → 粗金属 → 电子级高端金属耗材

上游：原生有色金属矿（自然资源）

-   铜、锡、金、铝、钨、钽、钼、稀土 
    
-   开采、冶炼出普通粗金属（传统有色品类）
    
-   注：需要同步考虑有色自身的外部环境、供需关系、价格变化，比如稀土。
    

  

中游：粗金属再提纯 / 配比 / 加工，变成电子制造刚需材料：

-   高纯金属：把普通金属提纯到超高纯度，半导体 / 芯片必备
    
-   合金：多种金属混合，提升导电、耐热、耐磨性能
    
-   键合丝：芯片内部引脚连接线
    
-   焊料：电路板焊接用锡焊材料
    
-   溅射靶材：芯片、面板镀膜核心材料
    

  

②硅产业链（，硅基材料主线）

半导体核心基材是芯片最核心的基底材料链，一步一步拉晶、切片：

-   硅矿（天然矿石，最上游资源）
    
-   硅矿提纯 → 多晶硅（工业初级硅料）
    
-   多晶硅拉晶 → 单晶硅棒（高纯度晶棒）
    
-   晶棒切割打磨 → 硅片
    

  

③基础化工→电子化学品

半导体材料主线上游是基础化工原料，基础化工原料变成半导体电子化学品，成为半导体两大核心材料：

-   基础化工品：氢氟酸等大宗化工原料
    
-   深加工成电子特气：芯片刻蚀、清洗、掺杂必须用特种气体
    
-   深加工成光刻胶树脂：光刻胶核心基材，芯片光刻环节核心材料
    

  

④玻纤

这是所有电子产品的 “骨架线路板”，从玻纤、覆铜板、PCB（电路板大产业链，应用最广）整条链路贯穿消费电子、工控、汽车电子，路径为：玻纤原料 → 电子布 → 板材 → 电路板（电子设备核心载体），最终PCB装进手机、电脑、家电、汽车、服务器等所有电子设备中。

-   玻璃纤维纱：基础玻纤原料，传统建材和工业材料
    
-   普通玻纤纱升级成电子级玻璃纤维布（电子布）：专门用于电子电路，绝缘、耐高温、高精密
    
-   电子布 + 树脂压合：覆铜板 CCL（电路板基材大板）
    
-   覆铜板蚀刻、走线、打孔 ：PCB 印制电路板（成品线路板）
    

  

2.半导体核心材料与设备

选择ETF时，经常会看到半导体材料和半导体设备，因此尽量从底层逻辑就能区分清楚，其中材料就分为前道材料和后道材料，这样才能区分热点概念到底是情绪市场驱动，还是自身在半导体生产中重要性高且占比较大（比如上周的wf6，某上市公司不得澄清：2025 年六氟化钨相关收入仅占公司总营收的 0.13%。）：

①半导体材料（晶圆制造材料 + 封装材料）

其中前序晶圆制造材料占比最大(约为2/3)，包括：

-   硅片（衬底 / 晶圆）：12 寸 / 8 寸硅片、外延片、SOI、SiC/GaN（第三代半导体）
    
-   光刻胶：g 线 /i 线、KrF、ArF（干式 / 浸没）、EUV 光刻胶，以及配套的光刻胶树脂、感光剂、显影液、剥离液
    
-   电子特气（半导体 “血液”）：刻蚀 / 沉积气：六氟化钨、三氟化氮、氨气、氯气，其中光刻气包括Ar/F/Ne 混合气，掺杂气包括硼烷、磷烷、砷烷。
    
-   光掩模（光罩 / Reticle）：把设计图案转移到硅片
    
-   溅射靶材（PVD 用）：其中金属靶包括铝、铜、钛、钽、钨、钴、金、银，合金靶包括TiW、TaN、CoPt 等。
    
-   CMP抛光材料：抛光液、抛光垫、清洗液
    
-   湿电子化学品（高纯试剂）：超纯水、双氧水、氨水、盐酸、硫酸、氢氟酸等
    
-   其他前道材料：前驱体（ALD/CVD 用）、高纯掺杂剂、硅溶胶、扩散源等
    

  

其中后道材料主要用于芯片封装成型、连接与保护，包括：

-   环氧塑封料
    
-   封装基板
    
-   引线框架
    
-   键合丝
    
-   焊料球
    
-   底部填充胶
    
-   胶带载带等
    

  

②半导体设备

同样，半导体设备也可以分为几个类型：

-   前道晶圆制造核心设备（芯片制造核心环节）
    

-   光刻设备：晶圆图案化核心，含全品类光刻机、涂胶显影设备
    

-   刻蚀设备：按版图刻蚀晶圆材质，分干法、湿法刻蚀，制程关键设备
    

-   薄膜沉积设备：晶圆表面镀膜，包含CVD、PVD、ALD三大主流工艺设备
    

-   离子注入设备：对硅片掺杂，改变半导体导电性能
    

-   CMP抛光设备：晶圆多层工艺后全局平坦化，保障先进制程良率
    

-   清洗设备：贯穿全流程，去除晶圆杂质、颗粒，保障工艺洁净度
    

-   量测/检测设备：贯穿晶圆制造全流程，负责膜厚、套刻、缺陷、微观形貌检测，是把控制程精度、提升良率的核心设备。
    
-   后道封测设备：涵盖芯片切割、研磨、键合、塑封、电性测试、分选等封装测试全流程设备。
    
-   辅助设备：包含晶圆传输、真空、废气处理、高纯流体输送、超纯水制备等配套设备。
    

  

这部分理解起来非常不容易，能把各种环节的关系，各种专业的中英文名词都对齐，确实不容易。

3.芯片设计

这部分理解起来相对容易点了，主要可分为逻辑芯片和存储芯片：

逻辑芯片：CPU/GPU/AI（如寒武纪、海光信息、华为海思等），新增英伟达（GPU）、苹果（自研）、特斯拉（FSD）作为终端驱动源头。

存储芯片：DRAM/NAND（如兆易创新、长江存储、长鑫存储），内存接口芯片，如澜起科技（DDR5内存接口）。

4.晶圆制造

这部分芯片代工核心环节，相对来说也好理解，其中主要原因都是大家耳熟能详的公司，数量有限，不会鱼龙混杂。台积电、三星、中芯国际、华虹等。

晶圆制造是半导体产业链核心环节，依托各类半导体设备与材料，完成芯片晶圆代工生产，行业头部格局清晰，核心厂商包含台积电、三星、中芯国际、华虹等。

当前行业工艺持续向立体化、3D堆叠迭代，摆脱传统平面芯片制程局限，核心先进3D工艺涵盖两大方向：

一是立体晶体管工艺，从FinFET（鳍式场效应晶体管）进阶至GAA（环绕栅极晶体管），通过立体结构突破芯片物理尺寸限制，大幅提升先进制程的算力与能效，适配7nm及以下先进制程；

二是3D NAND堆叠工艺，通过垂直堆叠存储单元的3D架构，替代传统平面存储结构，极大提升存储芯片容量、密度与性能，是高端闪存芯片的核心制造工艺。头部厂商依托自研3D先进工艺，主导全球高端芯片、存储芯片制造市场。

5.封装与测试

-   传统封装：以基础塑封、引脚互联、外形封装为主，侧重芯片保护、电气引出与物理固定，技术成熟、应用广泛，适配常规芯片量产需求。
    
-   先进封装：依托立体集成、异构互联技术提升芯片性能与集成度，代表方向包括3D 封装（TSV、Chiplet）、玻璃基板封装载板等，是当下技术升级主流。
    

  

6.模组与组件

-   光模块及光器件：光模块、光器件是光信号收发与传输的核心部件，作为AI服务器、数据中心的通信枢纽，承担设备间高速数据交互工作，是算力网络高效运转的基础。
    
-   PCB印制电路板：为电子元器件提供电路载体与物理支撑，服务器、显卡等算力硬件均需专用PCB板材，保障电路稳定导通与设备正常运行。
    
-   服务器组装：完成各类硬件配件的集成装配，产出整机服务器设备，是搭建数据中心、承载AI算力运算的核心硬件终端。
    
-   液冷散热：面向数据中心、AI服务器机房的散热解决方案。AI算力设备运行功耗高、发热量大，液冷相比传统风冷散热效率更高，可有效控制机房温度、保障高密度算力集群长期稳定运行，是当前大型算力基础设施的主流散热技术。
    

  

7.终端品牌及产业链

从产业链角度，目前主要还是靠：英伟达、苹果、特斯拉来驱动。

-   英伟达产业链：英伟达设计GPU（委托台积电制造、先进封装CoWoS），组装成AI服务器（用到光模块、PCB、液冷），拉动上述环节。传导：AI需求->英伟达GPU->台积电先进制程/CoWoS封装->设备/材料->PCB/光模块。
    
-   苹果产业链：苹果设计A/M系列芯片（台积电代工，先进封装InFo），拉动消费电子PCB（鹏鼎控股等但没要求加），零部件，需体现。
    
-   特斯拉产业链：特斯拉自研FSD芯片（三星/台积电代工），拉动车规芯片、传感器、PCB。
