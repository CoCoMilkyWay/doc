继续以中证1000ETF的复盘为例，先看5档行情：在4月8日14.37:30时，盘口如下。

![](assets/001.png)

以5档行情来看：

```
total_ask = 25243 + 3874 + 32120 + 265865 + 18555 = 345,657
```

此刻盘口等于：极端卖压（-0.96接近理论最小值-1）

```
thickness_ratio = 345657 / 6692 ≈ 51.7
```

从买卖档位厚度比来看，卖方挂单量是买方的51.7倍。

卖二档出现巨量挂单265,865手，占卖方总量的77%，此档位形成很大的阻力位（是不是大资金故意设置的“订单墙”？我们后面在tick数据中继续分析。），买一档仅1手挂单，价差达0.001（约0.046%），若大单砸穿买一，可能引发链式反应（买二至买五总挂单仅6,691手）。

在这种盘口下，博弈双方的优劣如下：

-   从挂单量特征来说：345,657 vs 6,692，很明显卖方占据优势，但此时买五档价格较卖一低0.3%，买方存在买入机会，买方用少量资金即可推动价格上涨0.3%：从2.189到2.185。
    
-   从价格弹性特征来说：卖方突破卖二需消耗77%卖单，大约需要5800多万资金，卖方若想推动价格下跌，必须投入大量资金吃掉该档位，否则价格将被钉在2.191下方；
    
    买方则少量资金便可拉升到2.185价位：从当前价2.189到2.185（买四档）仅需吃掉：买一（2.189）：1手、买二（2.187）：850手、买三（2.186）：2,144手、买四（2.185）：2,185手，总共约5,180手
    
-   从订单分布看：卖方集中在卖2档，而买方比较分散。
    

  

买卖方在此刻拉升成本对比：

```
# 买方拉升到2.185 vs 卖方突破卖二
```

此时，作为卖：

-   若持有空单，可挂单在卖二档（2.191）附近止盈，利用大单掩护退出。
    
-   若想新建空单，需等待卖二档挂单量减少至<10万手再行动。
    

  

作为买：

```
# 最小成本试仓方案（吃掉买二档）
```

用约1,860资金测试市场反应，若买三档（2.186）挂单快速补充则停止买入。

需要注意的是：当前买一/卖一价差仅0.001（0.046%），但买一档仅1手挂单，实际成交概率极低，吃单可能触发算法交易的反向操作。

在此时刻点，如果我们继续往下观察，则需要关注两点：

-   卖二档265k手订单的撤单速度（若10分钟内减少>50%则预示压单失效）。
    
-   买一档挂单量能否恢复到正常水平（通常应>100手）。
    

  

ETF的买一/卖一价差仅为0.001（0.046%），我们假设ETF的交易成本为0.042%

```
单边成本 = max(0.02% * 成交额, 5) + 0.001% ≈ 0.021%
```

则会产生：0.004%的收益：

```
0.046% - 0.042% = 0.004%
```

但是因为1档流动性不足，可能无法成交，若尝试吃单到买二档（850手），价差扩大至0.003（0.137%），但：

```
新价差收益率 = (2.190-2.187)/2.187 ≈ 0.137%
```

假设在理想情况下，这里我们正好可以看下高频中交易次数的影响：假设单次操作最大理

论收益：0.004%（年化约1.5%），那么需T日完成250次交易才能覆盖5%的年化目标.

以上从5档粗浅的数据中我们可以看到一个非常典型的“**流动性陷阱”盘面结构。**
