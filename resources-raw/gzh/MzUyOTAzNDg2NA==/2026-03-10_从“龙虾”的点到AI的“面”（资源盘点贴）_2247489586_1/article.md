# \[写作初衷\]

我们都说勇敢的人先享受世界，

面对AI，心怀探索与好奇的人，终将拥抱AI的无限可能。

当下的AI大模型领域，更新迭代快得让人目不暇接，

前一个概念还未完全吃透嚼烂，

新的理念已悄然登场；

前一款工具还没来得及熟练掌握，

更便捷的替代品便已问世。

若始终置身事外，不亲身参与其中，对AI的理解永远只会停留在“夹生饭”的状态：人云亦云，无法形成自己的判断，也难以真正分辨各类信息与知识的价值。

但换个角度看，这或许是一种幸运：我们可以选择“躺平”，静静等待那个最易用、最简洁、性价比最高的工具出现，省去盲目试错的成本。

于是我们很容易陷入两难：投入精力追热点、试新工具，往往力不从心；可一旦停下脚步，又会被莫名的焦虑裹挟，生怕错过任何一个重要节点。

其实，破解这种焦虑的最简单方式，莫过于回归自身：围绕自己工作、生活中与AI相关的场景，搭建属于自己的AI知识体系，将每一次了解到的最新信息，有序归纳到这个体系之中。

这样一来，既能保持对AI领域的持续关注与深度理解，又能避免因错失某个热点、未试用某款工具而陷入内耗。

这样，我们才能从AI的信息丛林中抽出身来，投入到用AI真正解决具体问题、落地实际产品、赋能日常生产上，而不是耗费大量时间，反复安装OpenClaw、编译调试各类开源代码，在无意义的试错中消耗自己的热情与精力。

我个人把围绕AI需要关注的知识分为：硬件及资源（云服务器、MaaS平台、codeing plan等）、IDE编程工具及Agent工具、知识即垂类开源项目（个人仅关注资管投研、量化投研、Alpha系统、高频交易等）。后续会在此框架下每周通过Openclaw机器人采集最新动态。

# 一、硬件及资源

硬件、云平台、大模型API会越来越五花八门，很容易这里充个会员，哪里充个会员，可能还没怎么用发现就到期了。所以先了解下大概涉及那些硬件、资源，然后按照自己的实际需求选择具体的，长期用就行。

不管是基于开发环境、自己搭建的系统部署环境还是安装小龙虾，选择什么硬件都需要结合自己的具体需求。比如小龙虾既可以安装到自己的电脑、手机上，也可以购买云服务器。最终看自己做什么，对安全的容忍和担心度、预算、以及技术操作上的难易度等综合考量。

## 2\. OpenClaw及类似工具

## 🔍 OpenClaw介绍

OpenClaw（龙虾）是近期爆火的开源AI智能体工具，与传统对话式AI不同，它能真正“动手”操作电脑，执行整理文件、发送邮件、管理日程等具体任务，实现了从“动口”到“动手”的跨越。因其强大的自动化能力，被网友称为“最强AI助手”。

![图片](assets/002.webp)

马总的疑问也是大多数普通养虾人的疑问：没有想到会这么火（冇估到会咁火爆）。

![](assets/003.png)

继上周线下免费安装活动圆满落幕之后，腾讯再度发力、连发 3 箭，火速上线三大举措：企业微信正式接入 OpenClaw，同步推出类 OpenClaw 产品 WorkBuddy，与此同时，更打造 QClaw 产品，全面支持一键安装与本地部署，动作迅猛、布局紧凑。虽然wb不断的报问题，但挡不住大家使用的热情。同时也感谢鼓掌又给了大家一次免费领鸡蛋的机会，用领的鸡蛋好好养虾。

![](assets/004.png)

按最新信息，字节跳动扣子平台上线类 OpenClaw 社区 InStreet 论坛；火山引擎推出 ArkClaw 云上 SaaS 版；阿里开源团队版 HiClaw；支付宝借 Tbox 开放 OpenClaw 免费体验；小米手机龙虾Xiaomi Miclaw 开启小范围封测。英伟达推出NemoClaw智能体。

这次可能和去年年初大家热火朝天接入Deepseek大模型还不一样，上次更多的是B端用户在行动，这次可能是全民行动。到底能推成一个什么新的局面和结果，都很难猜。

特别提醒：冲浪有风险，养虾需谨慎。一定要注意安全和个人账号等隐私风险，媒体上第一批养虾受害者、龙虾吃电脑事件已出现。

## 1\. AI相关基础知识

这里推荐阿里一篇非常好的文章：[Skills：从编程工具的配角到Agent研发的核心](https://mp.weixin.qq.com/s?__biz=MzIzOTU0NTQ0MA==&mid=2247558666&idx=1&sn=5c7df3f5568be3c1cd9fa720feca1862&scene=21#wechat_redirect)。

以Skill来说，ClawHub、GitHub Skill 库、Claude Skills、社区 Skill 库各有数千个，合起来形成了万级 Skill 生态，这也说明 AI 正从模型竞争转向以 Agent + Skills 为核心的能力生态竞争。

在Agent研发场景中，Skills真正使命是解决模型泛化能力与用户具象意图之间的鸿沟。大语言模型具有强大的泛化能力，但企业用户需要的是确定性的、可靠的、可控的专业能力。Skills正是连接这两端的桥梁。

Skills与传统的Agent开发方案对比，可以更清晰地理解其价值。

传统开发模式是"硬编码"思维：为Agent预先定义所有可能的行为，编写大量的if-else逻辑来处理不同情况。这种模式下，Agent的能力是固定的、封闭的，扩展新能力需要修改核心代码。Skills模式则是"声明式"思维：Agent不需要知道如何执行每个能力，只需要知道存在哪些能力、如何调用它们。Skill的实现与Agent的逻辑解耦，新增能力只需要注册新的Skill，不需要修改Agent本身。

也可以把这些概念综合起来看：

-   大模型 → 负责“会想”（AI的大脑） 
    
-   MCP → 负责“能连”（AI的接口标准） 
    
-   Skill → 负责“会做”（AI的经验包） 
    
-   Agent → 负责“去干”（AI的执行者） 
    
-   OpenClaw → 负责“把这一切装进一个能跑的系统里”（AI的运行平台，你个人的AI助理，数字人）
    

  

用一个比喻总结最形象：大模型像发动机，MCP像标准接口，Skill像驾驶经验，Agent像司机，而OpenClaw就是一辆把所有零件都组装好的车——你不用自己动手拼，上车就能开。和我们接触最多的Claude Code、CodexAI编程助手相比，OpenClaw等于是个人AI助手平台。

  

大模型是整个体系的底层核心，比如Claude、GPT、Gemini，你可以把它理解成一个知识渊博、理解力强，还能写代码、写文案的超级大脑。

MCP全称Model Context Protocol，是Anthropic提出的一套协议，用人话讲，就是AI世界的“USB接口标准”。 以前的AI工具，要连接外部能力全靠“量身定制”：接网页搜索一套接口，接飞书一套接口，接GitHub、数据库又是另一套，不仅开发麻烦，维护起来更是一团乱。

MCP的核心作用，就是统一这种连接方式——它提供一套标准化的通信规范，不管是浏览器、飞书、搜索工具，还是数据库，只要遵循这个标准，就能被AI轻松调用。

SKILL这是最容易和MCP搞混的概念，但两者完全不同：MCP是“连接层”，解决AI能不能调用工具；Skill是“知识层”，解决AI调用工具后，能不能把事做好。 Skill就像一份“工作说明书”或“经验包”，它会明确告诉AI：遇到某类任务，该按什么步骤做、优先用哪些工具、输出格式是什么、要避开哪些坑。

普通AI对话，是你问一句、它答一句，全程需要你引导；但Agent不一样，你给它一个目标，它会自己拆步骤、调工具、查结果、再推进，直到把事情做完，全程不用你盯。 比如你说：“帮我整理最近7天AI圈最火的10个话题，生成摘要，发到飞书群。” 一个合格的Agent会自己跑完整个流程：调用搜索工具找信息→筛选排序内容→生成结构化摘要→排版格式→调用飞书MCP发送到指定群，形成完整闭环。

说白了，Agent不是单一模型或工具，而是“模型+工具+规则+流程”的组合体，是能自主完成复杂任务的“行动单元”。

OpenClaw的定位就很清晰了：它不是大模型，不是MCP，也不是Skill市场，而是一个开源、可自部署的个人AI助手平台，由前PSPDFKit创始人Peter Steinberger发起，MIT协议开源，数据本地运行，隐私更有保障。 OpenClaw的核心价值，就是把前面提到的所有能力“打包整合”，做了一件事：让普通人不用自己拼零件，就能直接用AI干活。具体来说，它主要承担了这几个角色：

-   上接模型：兼容Claude、GPT、本地模型，不绑定任何厂商，你想用哪个就用哪个；
    
-   下接工具：通过MCP协议，接入浏览器、飞书、搜索等各类外部工具；
    
-   中装Skills：5700+社区Skills，一行命令就能安装，快速提升AI能力；
    
-   连接网关：支持飞书、Telegram、Discord等20+消息平台，让AI直接进入你日常使用的软件，不用再打开专门的网页或命令行。
    

Openclaw的火，感觉也是一种必然。

过去大家比的是“谁更会写、谁更会答”。

现在感觉比的是“谁能接更多工具”（MCP爆火）、“谁能沉淀经验”（Skill爆火）、“谁能连续执行任务”（Agent爆火）、“谁能把这些能力整合成可用系统”（OpenClaw爆火）。

 这和移动互联网早期很像，光有强大的操作系统不够，还得有应用生态、开发者支持和场景适配。

现在AI圈正在走同样的路，而OpenClaw，就是第一个把“AI干活”这件事做到开箱即用的平台。 

其实这些概念，本质上都是为了同一个目标：让AI不再只是一个聊天框，而是变成能真正帮我们干活的“数字员工”。（就如证券行业涨乐等证券类APP也是此目标。）

而OpenClaw的爆火，正是因为它第一个实现了这种“开箱即用”的可能。
