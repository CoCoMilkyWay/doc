高频做市型网格交易策略：HFT Market-making Grid，以市场最新中间价为定价核心，按照预设固定价差间隔均匀排布多层买卖挂单，实时跟随盘面价格波动持续执行撤单与重挂操作，始终维持交易网格紧贴当前市价动态调整，通过双向持续提供流动性主动承接市场成交，依托单笔成交的做市返佣作为核心盈利来源，在震荡行情中稳定赚取流动性做市收益。

策略本质是：网格形状不变、间距不变、档数不变，只有整体位置跟着市场中间价左右移动，永远紧贴盘口流动性做市。

# 核心规则：

-   以**盘口中间价 mid\_price** 为中心锚点
    
-   固定网格间距 `grid_interval`，单边固定20档挂单
    
-   行情波动 → 中心价偏移 → 整体网格**整体平移**
    
-   偏离新中心的旧网格订单直接撤单，重新挂新网格

### 网格移动示例：

### 状态1：初始平稳行情

```
                卖单区 🔴mid+0.8  ————mid+0.7  ————mid+0.6  ————mid+0.5  ————mid+0.4  ————mid+0.3  ————mid+0.2  ————  半价差边界————————【mid_price 中间价】————————mid-0.2  ————  半价差边界mid-0.3  ————mid-0.4  ————mid-0.5  ————mid-0.6  ————mid-0.7  ————mid-0.8  ————                买单区 🟢
```

单边满20档，整齐围绕中间价排布

### 状态2：行情快速上涨，中间价上移

```
【旧中心】    🔴旧卖单网格（全部撤单）    🟢旧买单网格（全部撤单）                新卖单区 🔴新mid+0.8  ————新mid+0.7  ————……新mid+0.2  ——————————【新mid_price 向上偏移】——————新mid-0.2  ————……新mid-0.7  ————新mid-0.8  ————                新买单区 🟢
```

-   价格上涨 → 盘口买卖一抬高 → 计算出新`mid_price`
    
-   原有全部网格偏离中心，判定失效**批量撤单**
    
-   以新中间价为基准，重新向下生成20档买单、向上生成20档卖单
    
-   网格**整体向上平移**，档位间距、档数完全不变
    

###   

### 状态3：行情下跌，网格整体下移

```
                旧网格全部撤销——————【新mid_price 向下偏移】——————                新买单区整体下移                新卖单区同步下移
```

逻辑一致：中心价下移 → 旧网格作废 → 整套网格同步向下平移


回测分析：

-   网格密度不决定交易频次：疏密网格交易次数差异极小，市场价格波动幅度才是成交次数的核心驱动因素。  
    
-   持仓限额具备强约束效果：仓位上限可有效管控整体敞口，实际持仓小幅超限，源于订单撮合与成交延迟导致。  
    
-   持仓容量直接拉高交易活跃度：最大持仓越大，可承接挂单档位越多，捕捉流动性机会更多，交易频次同步显著提升。  
    
-   回测性能规律：默认参数订单管理逻辑最重耗时最高；缩减网格数、压低持仓上限后，订单运算量下降，回测速度大幅加快。
