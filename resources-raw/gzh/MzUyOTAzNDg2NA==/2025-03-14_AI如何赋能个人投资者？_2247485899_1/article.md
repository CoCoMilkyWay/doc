# 最近一直关注买方、卖方等金融机构的AI落地成果，以及金融科技公司或创业公司，通过AI赋能个人投资的具体应用落地。

#   

# 但就目前来说，AI赋能相对之前的纯软件工具来说，肯定是向前迈了一个台阶，而不是一步，但离大多数普通投资者“用户”心里的那个“智”还有很长的距离，他们需要的是最傻瓜式的“智”，而不是还需要由他们自己参与创造的“智”。

#   

# DeepSeek爆火后，买方和卖方都发公告，完成了DeepSeek的接入或部署，但不管是买方就AI在其资产管理业务中的具体应用案例，还是卖方为个人投资者AI赋能的案例，目前从公开信息还，还非常少。

#   

# 昨天某大厂在一场路演中讲到了“智能投顾”的案例，还是挺有收获的，主要思想是：

#   

# 1）AI搜索能应用于个性化的资讯推荐，对C端用户分客群输出资讯专题、系列资讯推荐、早报、收评等。做到分客群智能完成信息分发策略；

#   

# 2）通过AI搜素，应用到智能的投顾内容总结。根据用户(如客户经理)多样化的提问内容，结合证券公司内容库和公域信息输出总结性回复及引用来源，同时能做到灵活设定査询内容来源、自主定义输出结构。通过定义Agent，覆盖投顾服务场景下多种需求，如个股解读、智能研报汇总等，助力IC效能升级。

#   

# 3）基于用户对热点概念的追逐情绪，提前挖掘投资板块或标的的交易机会，提高投资收益，减少个人投资者与机构投资者之间的信息差，探索新媒体数据在市场交易择时中的影响。

#   

# 以上思路中提出了3个核心亮点：聚合、热度、个性化策略。

1）聚合逻辑：更全更快自动更新;基于全网内容(含权威媒体、财经达人和研报)实时监测洞察。

2）热度定义：真实用户热度计算;基于相关概念特定时间周期内，在抖音上的传播和声量。

3）个性化策略：历史数据回测;基于历史热点数据和个性化持仓的策略回测，持续对策略的持仓进行收益跟踪分析。

#   

# 按上面的思路，基本上做到对咨询信息的进一步加工和应用，并通过AI和个人投资决策直接打通。特别是第3点，如果能应用落地，我觉的对我们个人投资者来说是有用的。公募等资管机构依赖的就是成熟的投研体系，支撑投研体系的就是一套研究业务流程以及投研管理系统，作为投研系统最底层，就是比我们散户更多的数据（如基本面、行情、舆情、卖方的研报）等等。而通过AI赋能，个人投资者需要构建这些“不可能”做的基础设施，也可能得到一个想要得到的信息。

#   

# 举个例子，之前我们想分析A股上市公司的年报，人工读麻烦，就会想着靠程序做一个系统，但之前依赖OCR解析技术，很多专业软件公司做的都很难实际应用，更别说个人了，而现在有了DeepSeek就完全不一样了。我们只需要输入提示词即可，这种变化某种层面就是革命性的。

#   

```
请帮我分析XX公司2023年报中的财务数据
```

这个作者开源的一个研报本地化工具：https://github.com/austin-starks/FinAnGPT.git，有兴趣的同学倒是可以看看，核心是功能是：

-   通过SimFin获取收益报告和报告日期的市场数据
    
-   将这些财务数据输入大型语言模型 (LLM) 进行分析
    
-   将最终评分和报告保存到数据库
    

  

通过上面3个具体案例，我们再来思考下：AI到底能为我们个人投资带来什么这个问题。

以我们熟悉的量化视角来说，不管是通过聚宽等量化平台写代码做回测，还是通过果仁网通过鼠标点点做量化，对大多数人来说，核心的问题还是：我不知道怎么开始，而且他们还要花时间和精力来学习一个软件，等于是双重的困难，一开始的热情要不在平台功能不会用上浇灭了，要么在苦苦卡着的BUG破碎了。软件这个时候只是个工具，需要人用来产生价值。
