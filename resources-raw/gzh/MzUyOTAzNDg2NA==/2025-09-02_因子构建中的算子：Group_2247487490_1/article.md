今天是本系列的最后一篇：Group。

在量化投资中，**Group（分组）** 的概念绝非可有可无，而是现代多因子模型不可或缺的基石。

它解决了一个根本性难题：**如何确保我们发现的“Alpha”是真正的选股能力，而不是来自某种静态风险暴露。**

**为了更直观地理解这个问题及其解决方案，我们可以参考以下DS给出的逻辑图，它揭示了因子研究中的“虚假Alpha”陷阱以及分组处理如何提供解决方案：**

![](assets/001.png)

在量化投资的金融数据中存在强烈的**组内相关性**。例如：

-   **行业效应**：科技股同涨同跌。
    
-   **市值效应**：小盘股风格高度一致。
    
-   **国家/地区效应**：同一市场的股票受相同宏观环境影响。
    

  

如果一个因子（如低市盈率PE）只是偶然在某个行业（如银行）整体偏低时表现好，那么这个因子可能只是**间接暴露了行业风险**，而非真正的选股能力。

**分组操作的目的，就是在控制行业、市值等变量后，考察因子能否在组内区分出好坏股票**。

比如在量化中：

-   **原始因子**：`rank(pe_ratio)`（全市场市盈率排名）
    
-   **分组后因子**：`group_rank(pe_ratio, industry_group)`（行业内市盈率排名）
    

后者剥离了“行业”这个共性因素，提取了“行业内相对估值”的特异性信息，这才是真正的选股能力。

worldquant给出的Group分类下的算子分为**数据处理**和**因子构建**两大类：

#### **1\. 数据处理类：解决NaN值和填充问题**

-   **`group_backfill(x, group, d, std=4.0)`**
    

-   **作用**：**组内时序填充**。当某个股票的数据为NaN时，用**同组其他股票**过去`d`天的**温莎化均值**来填充。
    
-   **为何重要**：保证数据完整性，避免因数据缺失导致股票被误剔除，且填充值来自同类股票，更合理。
    
-   **示例**：某银行股今日PE数据缺失，则用银行行业内其他股票过去5天的平均PE（剔除极端值）来填充。
    

#### 

#### **2\. 因子构建类：控制变量后构建纯Alpha**

-   **`group_neutralize(x, group)`** - **最核心、最常用**
    

-   **作用**：**组内去均值**。确保因子在每个组内的均值为0。
    
-   **为何重要**：彻底消除因子在组层面的系统性暴露。是获取**纯多头Alpha**的关键。
    
-   **示例**：对估值因子`pe_ratio`按行业中性化后，得到的因子在每个行业内的平均值为0。这意味着组合同时做多和做空不同股票，对行业因素免疫。
    

-   **`group_zscore(x, group)`** & **`group_scale(x, group)`**
    

-   **作用**：**组内标准化**和**组内缩放**。
    
-   **为何重要**：使因子值在每个组内具有相同的分布（均值为0、标准差为1，或范围在\[0,1\]），便于不同组之间的因子值合并与比较。
    
-   **示例**：不同行业的波动率绝对值差异很大（科技股波动率天然高于公用事业股）。组内标准化后，我们比较的是股票在各自行业内的“相对波动率”，而不是绝对波动率。
    

-   **`group_rank(x, group)`**
    

-   **作用**：**组内排名**。
    
-   **为何重要**：直接找出组内的相对强者和弱者。
    
-   **示例**：不看全市场，只看“在科技行业内部，哪些股票的动量排名最高？”。
    

-   **`group_mean(x, weight, group)`**
    

-   **作用**：计算**组内均值**。
    
-   **为何重要**：常用于计算行业指数或风格指数的值。
    

**下面详细逐个解释。**

**1.group\_backfill(x, group, d, std = 4.0)**

此算子核心目的：当某个标的在某个日期的数据缺失（NaN）时，**使用同组其他标的在同一时间点的历史数据来智能填充**。

### 在量化投资中通过此方式对数据处理后：

1.  **稳健填充**：温莎化处理避免了极端值对填充结果的过度影响
    
2.  **行业一致性**：使用同行业数据填充，保持行业特征
    
3.  **时效性保证**：只使用近期数据，避免使用过时信息
    
4.  **防止数据窥探**：不使用未来数据，符合回测要求
    

**在量化投资中的典型应用场景**：

-   财务报表数据缺失填充
    
-   价格数据异常值处理
    
-   因子值缺失的智能补全
    
-   构建一致的数据集用于回测
    

这种填充方法比简单使用均值或中位数填充更加稳健和合理！

#### 参数详解：

-   **`x`**: 需要填充的数值列（可能包含NaN）
    
-   **`group`**: 分组列（如行业、板块、国家等）
    
-   **`d`**: 回溯窗口天数（只在过去d天内寻找数据）
    
-   **`std`**: 温莎化处理的标准差倍数（默认4.0）
    

#### 执行逻辑（分步说明）：

**步骤1：识别缺失值**对于每个日期、每个标的，检查 `x` 是否为 NaN。

**步骤2：寻找填充数据源**如果发现缺失值，则：

1.  找到**同一分组**（相同 `group` 值）的所有其他标的
    
2.  在这些同组标的中，寻找**相同日期**的 `x` 值
    
3.  只考虑**过去d天内有数据**的值（确保时效性）
    

**步骤3：温莎化处理（Winsorization）**对找到的所有非NaN值进行温莎化处理：

1.  计算这些值的 **均值 (mean)** 和 **标准差 (stddev)**
    
2.  设定上下限：
    

-   上限 = mean + std × stddev
    
-   下限 = mean - std × stddev
    

4.  将所有超出 \[下限, 上限\] 范围的值**截断**到边界值
    

-   小于下限的值 → 设为下限
    
-   大于上限的值 → 设为上限
    

**步骤4：计算填充值**用温莎化处理后的所有值的**均值**来填充原始NaN值。

**2.group\_mean(x, weight, group)**

**这个算子，我们必须先看官方解释：**

**group\_mean(x, group) operator can be used to calculate harmonic mean of datafields. Harmonic mean gives equal weight to each value in terms of their reciprocal contribution and is considered a better method for calculating average for fundamental ratios and factors.**

**因为要注意一个概念：调和平均数（Harmonic Mean）**

调和平均数是几种 Pythagorean 平均数之一（另外两种是算术平均数和几何平均数）。对于一组包含 `n`个正数的数据集 `[x1, x2, ..., xn]`，其调和平均数 `H`的计算公式为：

**`H = n / ( (1/x1) + (1/x2) + ... + (1/xn) )`**

**直观理解**：调和平均数本质上是所有数值的**倒数**的**算术平均数**的**倒数**。它给每个数据点在其倒数（reciprocal）方面赋予相等的权重。

**算数平均数**  
(Arithmetic Mean)

`(P/E₁ + P/E₂ + P/E₃) / n`

`(10 + 40 + 25) / 3`

**25.0**

**误导性结果**：  
• 它简单地平均了三个P/E值。  
• 严重受**高估值 outlier**（股票B, P/E=40）的影响，拉高了平均值。  
• **完全忽略了股票的规模权重**。一只小盘股的高估值让整个组合看起来都很贵，这不符合投资现实。

**加权平均数**  
(Weighted Mean)  
(按市值加权)

`(MC₁×P/E₁ + MC₂×P/E₂ + MC₃×P/E₃) / Total MC`

`(90×10 + 10×40 + 50×25) / 150`  
`= (900 + 400 + 1250) / 150`  
`= 2550 / 150`

**17.0**

**准确的“组合P/E”**：  
• 这是**最正确**的方法，反映了投资组合的**真实整体估值**。  
• 计算的是**总市值 / 总收益**：`150 / 11.25 = 17.0`。  
• 它考虑了每只股票在组合中的**权重**（市值），大盘股权重高，小盘股权重低。结果是真正的“组合市盈率”。

**调和平均数**  
(Harmonic Mean)

`n / (1/P/E₁ + 1/P/E₂ + 1/P/E₃)`

`3 / (1/10 + 1/40 + 1/25)`  
`= 3 / (0.1 + 0.025 + 0.04)`  
`= 3 / 0.165`

**18.18**

**“等权投资”的平均估值**：  
• 它假设你对每只股票**投资了相同的金额**（例如每只投50亿），而不是按市值加权。  
• 其经济含义是计算**平均收益率（E/P）的倒数**。  
• 结果介于算术和加权平均之间，**避免了极端值的影响**，比算术平均更稳健。  
• 适用于计算**比率指标的平均基准**。

### **如何在实际中选择：**

平均数

核心思想

**算数平均数**

平等对待每一个原始数据点

对**绝对数值**求平均（如温度、年龄）；对方差均匀的数据集进行快速估算。

**任何比率或速率**（如P/E、速度、密度）的平均计算，会严重失真。

**加权平均数**

根据重要性赋予数据点不同权重

计算**投资组合**的整体指标（如组合P/E、组合收益率）。计算指数。任何需要反映个体权重的情况。

需要忽略权重、平等看待每个个体时。

**调和平均数**

平等对待每个数据点的**倒数（贡献率）**

计算**比率和速率**的平均值（如P/E、P/B、速度）。为“等权投资”策略提供基准。对异常值更稳健。

数据集中包含**零或负数**（倒数无意义）。数据集方差很小，此时与算术平均差异不大。

**结论：**

-   如果你想知**道一个按市值加权投资组合的真实整体估值**，请使用**加权平均数**。
    
-   如果你想计算一个**行业或分组的估值基准**，并且希望平等看待组内每只股票（而不是其市值大小），请使用**调和平均数**。它在量化因子建模中极为常用。
    
-   在处理比率时，**尽量避免使用算数平均数**，因为它会产生误导性结果。
    

-   P/E比率的倒数 E/P 是收益率概念，调和平均相当于收益率的算术平均的倒数
    
-   更符合投资逻辑：先平均收益率，再转化为估值。

### 为什么需要加权调和平均？

#### 1. **双重合理性**

-   **数学合理性**：调和平均适合比率数据
    
-   **经济合理性**：权重反映经济重要性（如市值权重）
    

#### 2. **更贴近投资实践**

`# 实际投资中，大市值股票影响更大   # 加权调和平均同时考虑：   # 1. 市盈率作为比率的数学特性（调和平均）   # 2. 市值作为经济重要性的权重影响   `

#### 3. **风险调整的估值参考**

`# 大市值股票的估值对市场影响更大   # 加权调和平均给予这些股票适当权重   # 提供更贴近实际市场状况的估值参考   `

**4.group\_rank(x, group)**

此算子核心目的**在分组内进行相对排名**，将每个分组内的标的基于数值x进行排序，并转换为0.0到1.0之间的均匀分布排名分数。

## 数学定义

对于每个分组内的数据：

分组排名在分组内的排名分组内标的数量

其中排名通常按照升序排列（最小值排名为0，最大值排名为1）。

## 算法流程

### 输入处理

1.  **按分组列分组**：将数据按照指定的group列进行分组
    
2.  **组内排序**：对每个分组内的x值进行排序
    
3.  **计算百分比排名**：将排序位置转换为0.0到1.0之间的均匀分布
    

### 输出结果

-   每个分组内的排名独立计算
    
-   所有输出值在\[0.0, 1.0\]范围内
    
-   每个分组内均匀分布

## 统计解释

### Z-score的含义

-   **Z-score = 0**：值等于分组均值
    
-   **Z-score = +1**：值比分组均值高1个标准差
    
-   **Z-score = -1**：值比分组均值低1个标准差
    
-   **Z-score = ±2**：在正态分布中约覆盖95%的数据
    
-   **Z-score = ±3**：在正态分布中约覆盖99.7%的数据
    

### 概率解释（假设正态分布）

-   |Z| < 1：约68%的数据（常见情况）
    
-   1 < |Z| < 2：约27%的数据（相对异常）
    
-   |Z| > 2：约5%的数据（显著异常）
    
-   |Z| > 3：约0.3%的数据（极端异常）
    

## 量化投资中的应用

### 1\. 异常值检测

`# 检测行业内的异常收益率   returns_zscore = group_zscore(收益率, 行业)      # 识别极端值   extreme_returns = returns_zscore[abs(returns_zscore) > 3]   `

### 2\. 因子标准化

`# 将不同行业的因子值标准化到相同尺度   value_zscore = group_zscore(市净率, 行业)   quality_zscore = group_zscore(ROE, 行业)      # 现在因子值可以直接比较和组合   composite_factor = value_zscore + quality_zscore   `

### 3\. 风险模型输入

`# 准备行业中性的标准化因子暴露   factor_exposure = group_zscore(因子值, 行业)      # 输入到风险模型中，避免行业偏差   risk_model.fit(factor_exposure)   `

### 4\. 相对价值策略

`# 构建行业内相对价值指标   pb_zscore = group_zscore(市净率, 行业)      # 做空高估值(Z-score高)，做多低估值(Z-score低)   trading_signal = -pb_zscore  # 负号表示低估值为正信号   `

## 优势特点

### 统计优势

1.  **分布保持**：完全保持原始数据的分布形状
    
2.  **可解释性**：以标准差为单位，统计意义明确
    
3.  **概率基础**：基于正态分布假设，有概率解释
    
4.  **线性变换**：保持数据的相对关系和距离
    

### 投资优势

1.  **跨组可比**：不同分组的数据可以在相同尺度上比较
    
2.  **风险度量**：Z-score的大小直接反映异常程度
    
3.  **组合构建**：便于设置基于统计显著性的阈值
    
4.  **模型输入**：适合作为机器学习模型的输入特征
    

## 注意事项

### 数据要求

1.  **分组样本量**：每个分组应有足够数量的标的（建议至少10个）
    
2.  **分布假设**：Z-score的解释依赖于正态分布假设
    
3.  **极端值影响**：标准差计算对极端值敏感
    

### 应用限制

1.  **非正态数据**：对于严重偏态的数据，Z-score解释力下降
    
2.  **小样本问题**：分组内样本太少时，统计量估计不准确
    
3.  **动态变化**：需要定期重新计算均值和标准差
    

## 高级应用

### 滚动Z-score计算

`# 使用滚动窗口计算动态Z-score   rolling_zscore = []   for window in rolling_windows(数据, 窗口大小=60):       window_zscore = group_zscore(window['x'], window['group'])       rolling_zscore.append(window_zscore)   `

### 多层级分组

`# 先按国家分组，再按行业分组   double_group_zscore = group_zscore(因子值, [国家, 行业])      # 更精细的标准化处理   `

### 加权Z-score

`# 使用市值加权的均值和标准差计算   def weighted_group_zscore(x, weights, group):       weighted_mean = group_mean(x, weights, group)       weighted_std = sqrt(group_mean((x - weighted_mean)**2, weights, group))       return (x - weighted_mean) / weighted_std   `

## 总结

`group_zscore(x, group)` 是一个**基于统计学的分组标准化方法**，通过：

1.  **分组内标准化**：以分组均值为中心，标准差为单位
    
2.  **分布保持**：完全保持原始数据的分布特性
    
3.  **统计解释**：提供基于概率的异常检测框架
    
4.  **跨组可比**：使不同分组的数据能够在相同尺度上比较
    

这是量化投资中**因子处理、风险控制、异常检测、模型构建**的重要工具，特别适用于需要统计严谨性和概率解释的应用场景。
