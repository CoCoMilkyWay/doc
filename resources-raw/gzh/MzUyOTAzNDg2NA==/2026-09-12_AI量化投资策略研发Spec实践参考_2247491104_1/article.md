用AI做一个简单系统，我家2年级娃都玩的很溜，自己给自己做背单词程序，做数学计算，甚至设计小游戏，比我的产出还高。

但工作中要做一个成熟的可上线的工程体系的项目，比如一个上线投产的交易系统，一个需要实盘的从0到1的策略，那就不能使用：想到那开发到那的这种聊天室编程（学名vibe coding）

而需要采用基于基于SDD的AI编程范式，这样各个层面都规范和可控的进行。具体可参考之前文章[AI时代软件工程新范式：SDD规约驱动开发](https://mp.weixin.qq.com/s?__biz=MzUyOTAzNDg2NA==&mid=2247490816&idx=1&sn=8113f881db086617ce0e58dbd6f4527e&scene=21#wechat_redirect)

  

类比到 AI 出现之前的纯人肉编程，这一点其实非常好理解。

  

在没有 AI 的时代，构建大型项目，团队资源上必须配置齐全：架构设计、产品、前端、后端、测试等角色缺一不可。具体落地上，我们一直倡导不要“一句话需求”，而是要做设计文档、详细设计文档，出详细设计稿。即使后来到了敏捷开发，也没有彻底打破这些软件开发的底层逻辑。

  

到了 AI 编程时代，不一样，也一样。

  

不一样，是因为从开发资源上看，只有 1 个人类。你需要自己管理 N 个 agent 帮你同时干活。所以这一个人，不再是过去的全栈工程师，而是现在所说的 FDE，甚至超越 FDE。

  

我一直说，在 AI 时代，如何定义自己的价值，就是要时刻想着自己是不是一个合格的 OPC：你所需、所负责的事，是否可以随时作为一个类似公司的个体存在。如果是，那就在一定程度上驾驭了 AI；如果不是，且没有客观原因，那对 AI 就仅仅停留在工具层面。

下面以使用AI做量化策略的实践为例，我们要完成一个完整的策略，第一步不是从直接让AI写策略开始，而是先确定整个项目的开发规范和约束，然后分别产生设计，审议审议，拆分任务，约定好测试案例和报告，这样，你只需要通过手机端向AI编程工具下达指令：

```
【开始M1】
```

然后你就等着验收结果。而且可以同时可以并发多个不交叉任务。

两点声明：

1.本文给出的是思路，不是标准答案，是需要使用时举一反三的，更不要纠结具体示例中的数据。

2.随着AI的智力不断提升，这种约束是否可行，是否具有较高的性价比，现在还不好说，因为太多的约束一方面增加了token的消耗，另外一方面可能限制了模型的泛化。

下面开始：

如果你比较懒，可以从下面这种笼统的提示词开始，然后有感觉了或者在策略开踩坑中让AI不断帮你完善，比如最经常遇到的：红色表示涨，绿色表示跌，你可能需要反复让AI修正这个问题，你就可以让AI做为一个准则写入规范。

```
我要启动一个新的量化项目：{项目背景}。 
```

如果你稍微懂一些量化策略开发的细节，那可以从下面较为详细的提示词开始： 

```
你现在是一名资深量化研究员兼量化工程负责人。
```

如果不想一次生成全部，也可以按模块分别精细化进行，示例如下：

### 示例1：建立 Spec 骨架

```
请为我的量化项目生成一份 Spec 规范文档骨架，包含以下章节标题和每节要写的内容要点：总体原则、关键定义、基础数据规范、因子构建规范、标签构建规范、因子验证流程、组合构建规范、回测与仿真规范、工程与实验管理、里程碑与验收标准、附录检查清单。先不要展开细节，只要骨架和每节要点。
```

### 示例2：填充数据与因子规范

```
基于以下项目背景，展开 Spec 中的「基础数据规范」和「因子构建规范」两章：项目背景：{...}要求：包含数据源、字段表、质量门禁、数据版本、因子定义卡、命名规范、预处理顺序、因子输出表。
```

### 示例3：填充验证流程

```
基于以下项目背景，展开 Spec 中的「因子验证流程」：项目背景：{...}必须严格按 11 步顺序：1 相关性【阻断】、2 单调性、3 中性化IC、4 成本敏感性【阻断】、5 容量、6 延迟、7 多因子合成、8 分时段稳健、9 极端行情压力、10 时间样本外、11 股票池样本外。每一步写清：目标、方法、判断标准、输出物。特别强调步骤1和步骤4为阻断门禁。
```

### 示例4：填充组合、回测、工程

```
继续展开 Spec 中的「组合构建规范」「回测与仿真规范」「工程与实验管理」三章：要求：包含股票池、权重优化、约束、成本模型、合成规则；事件驱动回测、涨跌停/停牌处理、延迟成交、可成交价、输出指标；目录结构、实验记录字段、测试类型。
```

### 示例5：生成里程碑与检查清单

```
基于前面生成的 Spec，输出：1. 里程碑与验收标准表（第1–4周任务、交付物、门禁）2. 最终实盘门禁3. 附录检查清单（因子定义、验证、工程）
```

## 确定了SPEC后，再和AI沟通具体任务时就可以使用。比如每次新因子或新策略开发时，提示词如下：

```
本项目已有一份总规范 SPEC.md，核心门禁为：- 步骤1 因子相关性分析【阻断】- 步骤4 换手率与交易成本敏感性【阻断】所有任务必须服从总 SPEC，不得绕过门禁。下面请为【具体任务】生成一份子 Spec，包含：目标、输入、输出、方法、判断标准、交付物、与总 SPEC 的挂接点、检查清单。
```

## 下面是一些细化的提示词实践：

## 1\. 数据分析 子 Spec 提示词

```
你是资深量化数据工程师。请为我的量化项目生成《数据分析 子 Spec》。【项目背景】- 市场/品种：{如 A股中证500}- 数据频率：{如 Level-2快照 + 逐笔 + 1min + 日频}- 研究样本：{如 20240603–20250924}- 数据源：{如 快照、逐笔、分钟线、财务、行业、指数成分}【子 Spec 必须包含】1. 目标   - 确认数据可用性、覆盖率、质量，为因子构建提供可信输入。2. 输入   - 原始数据表、字段清单、数据版本号。3. 数据质量检查   - 时间戳单调、去重、时区统一   - 价格>0、买卖价差≥0、量额≥0   - 停牌、涨跌停、ST、新股标记完整   - 复权因子一致，避免除权跳空   - 缺失率、异常率、覆盖率日报   - PIT 检查：财务、行业、指数成分必须当时可得4. 描述性分析   - 分布、分位数、极值、自相关   - 按市值/行业/流动性分组统计   - 缺失与异常的时间分布5. 数据血缘与版本   - 数据版本：DATA_YYYYMMDD_YYYYMMDD_v1   - 记录来源、清洗规则、运行时间、作者6. 输出物   - 数据质量报告、字段字典、缺失/异常清单、数据版本说明7. 判断标准（门禁）   - 关键字段覆盖率 ≥ {如 99%}   - 异常率 ≤ {如 0.1%}   - 无未来函数，PIT 通过   - 不通过不得进入因子构建8. 与总 SPEC 的挂接点   - 输出供「因子构建」使用；数据版本写入每个因子表血缘9. 检查清单   - [ ] 数据版本锁定   - [ ] 字段字典完整   - [ ] 质量门禁通过   - [ ] PIT 通过   - [ ] 报告可审计【输出要求】先输出子 Spec 文档，再输出「数据分析检查清单」，最后列出还需补充的信息。
```

## 2\. 因子构建及分析 子 Spec 提示词

```
你是资深量化研究员。请为我的量化项目生成《因子构建及分析 子 Spec》。【项目背景】- 市场/品种：{如 A股中证500}- 因子频率：{如 1min / 日频}- 持有期：{如 60s / 5min / 1d}- 研究样本：{如 20240603–20250924}- 候选因子：{如 imbalance_l1、micro_price_dev、zdl_vwap_rtn20、tradeprice_over_mid、boll_lower@80、mid_mean_dev@20}【子 Spec 必须包含】1. 目标   - 构建可复现因子，并完成质量验证，筛出可进入组合的因子。2. 因子定义卡   - 因子名、类别、公式、输入字段、频率、窗口、Universe、预处理、输出表、版本3. 命名规范   - {类别}_{窗口}_{变换}_{版本}4. 预处理顺序   - 原始值 → 去极值(MAD) → 缺失处理 → 标准化(Z-Score/Rank) → 中性化 → 截断5. 标签构建   - r_{t,H} = exec_price_{t+D+H}/exec_price_{t+D} - 1   - D 覆盖 1s、5s、10s、30s   - 同时保存 mid-to-mid 收益用于研究对比6. 因子验证流程（严格按总 SPEC 11 步）   第一优先级：   - 步骤1 因子相关性分析【阻断】     目标：确认头部因子不是同一信号     方法：60日每日因子值/排名的截面相关矩阵；Pearson + Spearman     重点：imbalance_l1 vs micro_price_dev；zdl_vwap_rtn20 vs tradeprice_over_mid；boll_lower@80 vs mid_mean_dev@20     判断：|corr|>0.7 警惕，|corr|>0.9 重复   - 步骤2 分组单调性     分5–10组，看单调性、极端组依赖、剔除top/bottom 1%后IC   - 步骤3 市值/行业中性化后IC     残差重算IC，下降过大说明风格暴露   第二优先级：   - 步骤4 换手率与交易成本敏感性【阻断】     成本：万1、万3、万5、千1；计算扣费后净IC/净ICIR   - 步骤5 容量分析     按成交额分位、ADV约束、资金容量上限   - 步骤6 执行延迟影响     延迟1s、5s、10s、30s重算IC   第三优先级：   - 步骤7 多因子合成     低相关(|corr|<0.3)等权/IC加权/最大化ICIR   - 步骤8 分时段稳健性     上涨/下跌/震荡、高/低波动、不同月份   - 步骤9 极端行情压力测试     大涨/大跌/流动性危机日IC、回撤、单日巨亏   第四优先级：   - 步骤10 时间样本外   - 步骤11 股票池样本外7. 输出物   - 因子表、因子定义卡、相关矩阵、分组收益、中性化IC、成本敏感性表、延迟衰减曲线、合成因子报告8. 判断标准（门禁）   - 步骤1、步骤4 为阻断项   - 扣费后净IC>0   - 分组单调   - 样本外同号9. 与总 SPEC 的挂接点   - 因子版本写入实验记录；通过门禁才进入模型训练10. 检查清单   - [ ] 因子定义卡完整   - [ ] 无未来函数   - [ ] 相关性矩阵已看   - [ ] 高相关已合并/正交化   - [ ] 分组单调通过   - [ ] 中性化IC通过   - [ ] 扣费净IC通过   - [ ] 延迟衰减通过   - [ ] 样本外通过【输出要求】先输出子 Spec 文档，再输出「因子构建及分析检查清单」，最后列出还需补充的信息。
```

## 3\. 模型训练 子 Spec 提示词

```
你是资深量化建模研究员。请为我的量化项目生成《模型训练 子 Spec》。【项目背景】- 市场/品种：{如 A股中证500}- 因子频率：{如 1min / 日频}- 持有期：{如 60s / 5min / 1d}- 研究样本：{如 20240603–20250924}- 输入因子：{已通过步骤1和步骤4门禁的因子列表}- 模型类型：{如 线性/GBDT/神经网络/集成}【子 Spec 必须包含】1. 目标   - 用通过门禁的因子训练预测模型，输出可交易信号。2. 输入   - 因子表（版本锁定）、标签表、Universe、样本外切分方案3. 样本切分   - 时间序列切分，禁止随机打乱   - 训练/验证/测试：{如 70/15/15}   - 保留最近30天完全不用，作为最终样本外4. 标签   - r_{t,H} = exec_price_{t+D+H}/exec_price_{t+D} - 1   - D 与因子验证一致5. 特征处理   - 去极值、标准化、中性化   - 缺失值处理规则   - 禁止使用未来信息6. 模型训练   - 模型选择、超参搜索空间、交叉验证方式   - 正则化、早停、防过拟合   - 特征重要性/归因7. 模型评估   - IC/RankIC/ICIR   - 分组收益、多空收益   - 扣费后净IC、净ICIR（成本：万1、万3、万5、千1）   - 延迟1s、5s、10s、30s后的IC   - 分时段稳健性、极端行情表现8. 模型风险   - 过拟合检测：训练/验证/测试IC对比   - 特征稳定性：PSI、因子漂移   - 集中度：单因子贡献、单票暴露9. 输出物   - 模型文件、超参记录、特征重要性、评估报告、实验ID10. 判断标准（门禁）   - 测试集扣费后净IC>0   - 净ICIR>{如 0.3}   - 样本外同号   - 无单一因子贡献>50%   - 延迟30s后仍有效或衰减可接受11. 与总 SPEC 的挂接点   - 只使用通过步骤1、步骤4的因子   - 模型输出进入回测，回测结果反哺模型12. 检查清单   - [ ] 样本切分正确   - [ ] 无未来函数   - [ ] 超参记录完整   - [ ] 扣费净IC通过   - [ ] 延迟衰减通过   - [ ] 样本外通过   - [ ] 实验ID记录【输出要求】先输出子 Spec 文档，再输出「模型训练检查清单」，最后列出还需补充的信息。
```

## 4\. 回测 子 Spec 提示词

```
你是资深量化回测工程师。请为我的量化项目生成《回测 子 Spec》。【项目背景】- 市场/品种：{如 A股中证500}- 因子频率：{如 1min / 日频}- 持有期：{如 60s / 5min / 1d}- 调仓频率：{如 每日 / 每60s}- 研究样本：{如 20240603–20250924}- 信号来源：{模型输出或因子合成}- 成本假设：{万1、万3、万5、千1}【子 Spec 必须包含】1. 目标   - 在贴近实盘约束下评估策略净值、风险、容量与可交易性。2. 输入   - 信号表、因子版本、模型版本、Universe、交易日历、成本模型3. 回测框架   - 事件驱动，禁止用收盘价未来函数   - 信号延迟 D 后成交（1s、5s、10s、30s）   - 使用可成交价：VWAP/对手价/开盘价，不用理想中间价4. 交易约束   - 涨跌停不能成交   - 停牌剔除   - ST、新股、流动性差剔除   - 单票权重上限、行业/市值中性   - 换手约束5. 成本模型   - 佣金、印花税、过户费、滑点、冲击成本   - turnover = 0.5 * sum|w_t - w_{t-1}|   - cost = turnover * (commission + tax + slippage + impact)   - net_ret = gross_ret - cost6. 回测输出   - 净值、超额净值、夏普、最大回撤、卡玛   - IC/RankIC/ICIR、分组收益、多空收益   - 换手率、成本占比、容量曲线   - 归因：行业、市值、因子贡献7. 稳健性与压力测试   - 分时段：上涨/下跌/震荡、高/低波动、不同月份   - 极端日：大涨/大跌/流动性危机   - 最大回撤、单日巨亏、尾部风险8. 容量分析   - 按成交额分位分组   - 单票单日交易额 ≤ 20日ADV的1%–5%   - 估算资金容量上限9. 样本外   - 时间样本外、股票池样本外   - 禁止用样本外反复调参10. 判断标准（门禁）   - 扣费后净IC>0   - 净ICIR>{如 0.3}   - 样本外同号   - 容量满足目标资金   - 延迟30s后仍有效或衰减可接受   - 极端日无爆雷11. 与总 SPEC 的挂接点   - 只用通过步骤1、步骤4的信号   - 回测结果写入实验记录，作为实盘门禁依据12. 输出物   - 回测报告、净值曲线、成本敏感性表、容量曲线、压力测试报告、实验ID13. 检查清单   - [ ] 事件驱动   - [ ] 无未来函数   - [ ] 涨跌停/停牌处理正确   - [ ] 延迟成交已建模   - [ ] 成本模型完整   - [ ] 扣费净IC通过   - [ ] 容量评估通过   - [ ] 样本外通过   - [ ] 实验ID记录【输出要求】先输出子 Spec 文档，再输出「回测检查清单」，最后列出还需补充的信息。
```

# \[完整示例\]量化投资策略研发 Spec 规范文档 v1.0

**文档状态**：草案/可执行  
**适用场景**：A 股中高频/日频 Alpha 因子研究、组合构建、回测与实盘可行性评估  
**研究样本**：20260603—20260924，股票池示例：中证 500  
**核心目标**：建立从数据到因子、验证、组合、回测、仿真的标准流程，防止虚假结论，确保因子可复现、可交易、可审计。

## 1\. 总体原则

1.  **PIT 原则**：所有数据、财务、行业、指数成分必须使用当时可得信息，禁止未来函数。
    
2.  **可复现**：数据版本、代码版本、因子版本、实验参数必须记录。
    
3.  **先验证后合成**：单因子未通过质量门禁，不进入多因子合成。
    
4.  **成本优先**：IC 高不代表可交易，扣费后无 alpha 的因子直接淘汰。
    
5.  **样本外优先**：最终结论必须经过时间样本外和股票池样本外验证。
    
6.  **门禁制**：步骤 1 和步骤 4 为阻断项，不通过不得进入组合构建。

## 5\. 标签构建规范

标签必须可交易、无未来函数：

```
r_{t,H} = exec_price_{t+D+H} / exec_price_{t+D} - 1
```

-   `D`：执行延迟，如 1s、5s、10s、30s。
    
-   `exec_price`：可成交价，如 VWAP、盘口对手价、开盘价。
    
-   同时保存 mid-to-mid 收益用于研究对比。
    
-   标签频率必须与因子频率、持有期一致。

## 6\. 因子验证流程与门禁

以下与你给出的 11 步完全对应，并作为标准研发流程。

### 第一优先级：因子质量验证

#### 步骤 1：因子相关性分析【阻断项】

**目标**：确认头部因子不是同一信号的不同表达。  
**方法**：

-   计算 60 日每日因子值或排名的截面相关矩阵。
    
-   同时计算日内同时间截面相关。
    
-   Pearson 看原始值，Spearman 看排名。
    
-   重点检查：
    

-   `imbalance_l1` vs `micro_price_dev`
    

**判断标准**：

-   `|corr| > 0.7`：警惕。
    
-   `|corr| > 0.9`：基本重复，必须合并或剔除。
    
-   高相关处理：保留经济含义强、换手低、容量大、延迟敏感低者，或做正交化。
    

**输出**：相关矩阵、聚类树、VIF、因子保留/合并建议。

#### 步骤 2：分组单调性检验

**目标**：确认 IC 不是被极端值驱动。  
**方法**：

-   按因子值分 5—10 组。
    
-   看各组未来收益是否单调。
    
-   检查是否只有极端组有 alpha。
    
-   检查多空收益是否主要由空头端贡献。
    
-   剔除 top/bottom 1% 后重新计算 IC。
    

**判断**：分组收益 Spearman > 0.7；中间组有区分度；剔除极端值后 IC 稳定。

#### 步骤 3：市值/行业中性化后的 IC【第一周门禁】

**目标**：排除小市值、行业风格暴露。  
**方法**：

```
f_i = alpha + beta_mkt * log(mktcap_i) + sum_k gamma_k * industry_{ik} + eps_i
```

用残差 `eps_i` 重新计算 IC。  
**判断**：中性化后 IC 大幅下降或符号反转，说明 alpha 主要来自风格，不是因子本身。建议保留 >50% 且同号。

* * *

### 第二优先级：可交易性分析

#### 步骤 4：换手率与交易成本敏感性【阻断项】

**目标**：确认扣除成本后仍有 alpha。  
**方法**：

-   计算每日调仓单边/双边换手。
    
-   假设成本：万 1、万 3、万 5、千 1。
    
-   计算扣费后的净 IC、净多空收益、净 ICIR。
    

```
turnover_t = 0.5 * sum_i |w_{i,t} - w_{i,t-1}|cost = turnover * (commission + tax + slippage + impact)net_ret = gross_ret - cost
```

**关键问题**：

-   60s 持有期因子换手可能极高。
    
-   `boll_lower@80` 换手应低很多。
    
-   扣费后净 IC 必须 > 0，否则淘汰。
    

#### 步骤 5：容量分析

**方法**：

-   按成交额分位分组，只交易前 20% 流动性股票。
    
-   看 IC 随流动性筛选的变化。
    
-   单票单日交易额不超过 20 日 ADV 的 1%—5%。
    
-   估算策略资金容量上限。
    

#### 步骤 6：执行延迟影响

**方法**：

-   信号触发后延迟 1s、5s、10s、30s 成交。
    
-   重新计算 IC，看衰减速度。
    
-   对 60s 持有期因子尤其关键。
    

**判断**：延迟后 IC 衰减过大，说明不可实盘。

* * *

### 第三优先级：组合构建

#### 步骤 7：多因子合成

**方法**：

-   先做步骤 1 相关性。
    
-   对低相关因子 `|corr| < 0.3` 做等权、IC 加权或最大化 ICIR 合成。
    
-   对比合成因子与单因子的 IC、ICIR、换手、回撤。
    

**预期**：若头部因子相关性低，合成后 ICIR 显著提升。

#### 步骤 8：分时段稳健性

**方法**：

-   按上涨/下跌/震荡、高波动/低波动、不同月份分段。
    
-   看各段 IC 是否保持同号。
    
-   同号比例低于 60% 需警惕。
    

#### 步骤 9：极端行情压力测试

**方法**：

-   找出大涨、大跌、流动性危机日。
    
-   检查极端日 IC 是否异常。
    
-   多空组合最大回撤、单日巨亏风险。
    

* * *

### 第四优先级：样本外验证

#### 步骤 10：时间样本外

-   向前扩展至 2024 年更早数据。
    
-   保留最近 30 天完全不用，作为最终验证。
    
-   禁止用样本外反复调参。
    

#### 步骤 11：股票池样本外

-   换股票池：中证 1000 vs 中证 500。
    
-   随机抽样 Bootstrap。
    
-   确认不是特定 500 只股票的偶然。
    

* * *

## 7\. 组合构建规范

1.  **股票池**：剔除 ST、停牌、涨跌停、新股、流动性差股票。
    
2.  **因子处理**：去极值、标准化、中性化。
    
3.  **权重优化**：均值-方差、风险平价或打分排序。
    
4.  **约束**：
    

-   行业、市值中性。
    
-   个股最大权重。
    
-   换手约束。
    
-   跟踪误差约束。
    

6.  **成本模型**：佣金、印花税、过户费、滑点、冲击成本。
    
7.  **合成规则**：低相关因子等权/IC 加权；高相关先正交化或聚类选代表。

## 8\. 回测与仿真规范

### 8.1 回测要求

-   事件驱动，不能用收盘价未来函数。
    
-   涨跌停不能成交，停牌剔除。
    
-   信号延迟 D 后成交。
    
-   使用可成交价，不用理想中间价。
    
-   记录每日换手、成本、容量、持仓。
    

### 8.2 回测输出

-   净值、超额净值、夏普、最大回撤、卡玛。
    
-   IC/RankIC/ICIR、分组收益、多空收益。
    
-   换手率、成本占比、容量曲线。
    
-   归因：行业、市值、因子贡献。
