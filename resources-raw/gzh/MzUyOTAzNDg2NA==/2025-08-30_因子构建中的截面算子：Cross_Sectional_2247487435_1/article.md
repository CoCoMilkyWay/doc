#### **1\. normalize(x, useStd=false, limit=0.0)**

计算指定日期所有有效阿尔法值的平均值，然后用每个元素减去该平均值。核心目标是对输入向量进行**中心化**或**标准化**处理，可选截断限制，以消除量纲影响并控制数值范围。

  

若useStd=true，则计算处理后值的标准差，并将每个归一化元素除以此标准差。

若limit不等于0.0，则对结果阿尔法值进行限幅处理（范围在-limit至+limit之间）。

  

  

示例：

假设某日期输入x的值为\[3,5,6,2\]，均值=4，标准差=1.82

  

normalize(x, useStd=false, limit=0.0) = \[3-4, 5-4, 6-4, 2-4\] = \[-1, 1, 2, -2\]

  

normalize(x, useStd=true, limit=0.0) = \[-1/1.82, 1/1.82, 2/1.82, -2/1.82\] = \[-0.55, 0.55, 1.1, -1.1\]

  

计算过程如下：

1.  **中心化（默认）**：
    

-   计算所有有效值的均值 `mean(x)`，每个元素减去均值：  
    xnormalized\=x−mean(x)
    

3.  **标准化（useStd=true）**：
    

-   在中心化基础上，除以标准差 `std(x)`：  
    xstandardized\=x−mean(x)std(x)
    

5.  **截断限制（limit≠0）**：
    

-   将结果强制限制在 `[-limit, +limit]` 范围内。
    

#### **2\. quantile(x, driver="gaussian", sigma=1.0)**

对原始向量进行排序，平移排序后的阿尔法向量，并应用分布转换（高斯分布、柯西分布、均匀分布，gaussian, cauchy, uniform，三者知识延伸参考文末。）。若驱动方式为均匀分布，则直接将每个阿尔法值减去该阿尔法向量的均值。

具体来说，该算子对输入的原始阿尔法向量进行排序，排序后的阿尔法值将位于\[0, 1\]区间内，平移排序后的阿尔法向量。该算子有助于减弱异常值的影响。

  

对于排序阿尔法向量中的每个阿尔法值，按以下方式进行平移：

  

1）Alpha\_value = 1/N + Alpha\_value \* (1 - 2/N)，此处假设阿尔法向量中包含N个有效值。平移后的阿尔法值将位于\[1/N, 1-1/N\]区间内

  

2）使用指定驱动分布对排序阿尔法向量中的每个阿尔法值进行分布转换。驱动分布可选用"gaussian"（高斯）、"uniform"（均匀）或"cauchy"（柯西）

  

注：其中Sigma参数仅影响最终值的缩放比例。

  

#### **3\. rank(x, rate=2)**

该算子针对给定股票，将其输入数据x的值在所有投资标的中进行排序，并返回均匀分布在0.0到1.0之间的浮点数。当rate参数设为0时，将执行精确排序。该算子有助于减弱异常值影响、降低回撤，同时提升夏普比率。

其中rate参数的默认值为2。

  

示例：

Rank(close); Rank(close, rate=0) # 执行精确排序

X = (4,3,6,10,2) => Rank(x) = (0.5, 0.25, 0.75, 1, 0)

-   `rate=0`：可能得到排名 `[2, 3, 1]`，然后转换为 `[0.5, 1.0, 0.0]`

#### **4\. scale(x, scale=1, longscale=1, shortscale=1)**

该算子将输入值(x)按目标规模(booksize)进行缩放。该算子有助于减弱异常值影响。

可通过指定附加参数'scale=booksize\_value'来调整目标规模。

还可通过指定参数longscale=long\_booksize和shortscale=short\_booksize分别对多头头寸和空头头寸进行独立缩放。

默认情况下各缩放参数值为1（表示不缩放），除非另行指定。

该算子通过调整Alpha值使所有标的的绝对头寸之和(sum(abs(x)))等于1。

如需缩放至不同规模，可使用Scale(x)\*booksize。

  

### 计算公式：

-   缩放过程使用一个统一的缩放因子（Scaling Factor），公式为：
    

-   **`缩放因子 = scale / sum(abs(x))`**
    

-   然后，将原始输入向量的每个元素乘以这个缩放因子，得到最终结果：
    

-   **`缩放后的值 = 原始值 * 缩放因子`**
    

  

### **计算逻辑如下：**

1.  **默认缩放（scale=1）**
    

-   计算所有标的的绝对头寸之和：`sum_abs_x = sum(abs(x))`
    
-   缩放因子：`scaling_factor = 1 / sum_abs_x`
    
-   最终缩放结果：`scaled_x = x * scaling_factor`
    
-   此时 `sum(abs(scaled_x)) = 1`
    

3.  **指定目标规模（scale=booksize）**
    

-   缩放因子调整为：`scaling_factor = booksize / sum_abs_x`
    
-   最终缩放结果：`scaled_x = x * scaling_factor`
    
-   此时 `sum(abs(scaled_x)) = booksize`
    

5.  **多头与空头独立缩放（longscale & shortscale）**
    
    计算多头部分（x > 0）和空头部分（x < 0）的绝对头寸之和：
    
    分别计算缩放因子：
    
    对多头和空头分别应用缩放：
    
    最终结果满足：
    
      
    

-   多头部分绝对和 = `longscale`
    
-   空头部分绝对和 = `shortscale`
    

-   `scaled_x[x > 0] = x[x > 0] * long_scaling_factor`
    
-   `scaled_x[x < 0] = x[x < 0] * short_scaling_factor`
    

-   `long_scaling_factor = longscale / sum_long`
    
-   `short_scaling_factor = shortscale / sum_short`
    

-   `sum_long = sum(x[x > 0])`
    
-   `sum_short = abs(sum(x[x < 0]))`

示例2：scale(returns, longscale=4, shortscale=3)

  

这个示例的核心目标是：**对输入向量中的多头头寸（正数）和空头头寸（负数）进行独立缩放，使得多头部分的绝对头寸之和等于 `longscale`，空头部分的绝对头寸之和等于 `shortscale`**。实现了对投资组合中**多头和空头方向的独立风险控制**。

  

### 计算公式如下：

缩放过程使用两个独立的缩放因子：

-   **多头缩放因子** = `longscale / sum(多头部分的值)`
    
-   **空头缩放因子** = `shortscale / sum(abs(空头部分的值))`_(注意：空头部分的值是负数，所以取绝对值后再求和)_
    

  

然后，将原始输入向量的**正数元素**乘以**多头缩放因子**，将**负数元素**乘以**空头缩放因子**，得到最终结果。

`returns = [0.02, -0.01, 0.015, -0.03, 0.005]`

（即：2%, -1%, 1.5%, -3%, 0.5%）

我们的目标是使用 `scale(returns, longscale=4, shortscale=3)`对这个向量进行独立缩放。

###   

### 第2步：分离多头与空头头寸

首先，将输入向量分为正数（多头）和负数（空头）两部分。

-   **多头部分 (x > 0)**: `[0.02, 0.015, 0.005]`
    
-   **空头部分 (x < 0)**: `[-0.01, -0.03]`
    

###   

### 第3步：计算各部分的原始总和

计算多头部分所有正数的**原始总和**，以及空头部分所有负数的**绝对值总和**。

-   **多头原始总和 (sum\_long\_raw)**: `0.02 + 0.015 + 0.005 = 0.04`
    
-   **空头原始总和 (sum\_short\_raw)**: `abs(-0.01) + abs(-0.03) = 0.01 + 0.03 = 0.04`
    

###   

### 第4步：计算独立的缩放因子

根据目标规模（`longscale=4`, `shortscale=3`）和各部分的原始总和，分别计算缩放因子。

-   **多头缩放因子 (long\_factor)**: `longscale / sum_long_raw = 4 / 0.04 = 100`
    
-   **空头缩放因子 (short\_factor)**: `shortscale / sum_short_raw = 3 / 0.04 = 75`
    

###   

### 第5步：应用缩放因子

将原始向量中的**正数元素**乘以**多头缩放因子 (100)**，将**负数元素**乘以**空头缩放因子 (75)**。

这个计算过程展示了如何对不同的因子（returns, close）进行独立的风险标准化。通过为不同因子分配不同的 scale值，来实现因子加权。并将标准化后的因子信号融合成一个统一的投资组合构建指令。

  

以上述例子为例：

-   **信号融合**：最终结果 `[9.1957, 4.0145, 7.1232]`是一个**复合Alpha信号**，它同时包含了来自收益率因子的信息 (`returns`) 和来自价格因子的信息 (`close`)。
    
-   **风险配置**：
    

-   收益率因子被赋予了 **1个单位** 的风险预算。
    
-   价格因子被赋予了 **20个单位** 的风险预算。
    
-   这说明在该策略中，**价格因子的权重是收益率因子的20倍**。
    
-   策略通过设置不同的 `scale`参数，明确分配了不同因子在最终决策中的重要性（权重）。
    

-   **最终风险敞口**：
    

-   最终输出的总风险敞口**不再是 1 或 20**，而是两个缩放后信号的风险敞口之和：`1 + 20 = 21`。
    
-   **验证**: `sum(abs([9.1957, 4.0145, 7.1232])) ≈ 9.1957 + 4.0145 + 7.1232 = 20.3334`(由于四舍五入存在微小误差，但理论值应为21)。要得到精确的21，可能需要更精确的计算。
    

#### **5\. winsorize(x, std=4)**

**对输入值x进行winsorize处理，确保x中的所有数值均处于下限和上限范围内。**

`winsorize(x, std=4)`使用基于**标准差（Standard Deviation）** 的方法来确定边界：

-   **计算均值（Mean）和标准差（Std）**：
    
        首先计算输入数据 `x`的均值（µ）和标准差（σ）。
    
-   **设定边界**：
    

-   **上限（Upper Limit）** = µ + `std`\* σ
    
-   **下限（Lower Limit）** = µ - `std`\* σ
    
    其中的 `std`就是函数参数，本例中为 `4`。这意味着边界被设定为均值的上下 4 个标准差处
    

  

对于数据 `x`中的每一个值：

-   如果该值 > **上限**，则将其替换为**上限值**。
    
-   如果该值 < **下限**，则将其替换为**下限值**。
    
-   如果该值介于**下限**和**上限**之间，则保留其原始值。
    

  

**此算子的目的：**

-   **减弱异常值影响**：
    
    通过将极端值拉回至合理的边界，防止个别极端数据点对后续计算（如求均值、构建投资组合等）产生过大的影响。
    
-   **保持数据分布**：
    
    与直接删除相比，温莎化保留了所有数据点的数量，改变了异常值但并未丢弃它们，从而更好地保持了数据的原始分布形态。

#### **6\. zscore(x)**

**Z-score算子是一种数值度量，用于描述某个值与一组值均值之间的关系。Z分数以偏离均值的标准差倍数进行衡量。**

**Z-score的计算公式为：**

```
Z = (x - mean(x)) / std(x)
```

`其中：`

-   x 代表单个数据点
    
-   mean(x) 代表数据集的平均值
    
-   std(x) 代表数据集的标准差
    

根据此定义，**Z-score**分布中的均值始终为0，标准差始终为1。

**Z-score能够准确显示特定数据点偏离均值的标准差倍数：正值表示数据点高于均值，负值则表示低于均值。**

**Z-score**在以下场景尤其有用：

对不同股票或不同数据字段进行归一化处理和比较分析。它使研究人员能够计算特定分数在标准正态分布中出现的概率，并对比来自不同样本（可能具有不同均值和标准差）的两个分数。

该算子有助于减弱异常值的影响。

以下是一个具体的计算示例：假设有一个包含5只股票某日收益率的数据向量 `x`：

```
x = [0.02, -0.01, 0.015, -0.03, 0.005]
```

目标是计算每个收益率的Z分数。

* * *

### 第1步：计算均值（Mean）

首先，计算这组收益率的平均值（µ）。

```
µ = (0.02 + (-0.01) + 0.015 + (-0.03) + 0.005) / 5
```

`   `

### 第2步：计算标准差（Standard Deviation）

接下来，计算这组收益率的标准差（σ）。

1.  **计算每个数据点与均值的差值的平方**：
    

-   `(0.02 - 0.002)^2 = (0.018)^2 = 0.000324`
    
-   `(-0.01 - 0.002)^2 = (-0.012)^2 = 0.000144`
    
-   `(0.015 - 0.002)^2 = (0.013)^2 = 0.000169`
    
-   `(-0.03 - 0.002)^2 = (-0.032)^2 = 0.001024`
    
-   `(0.005 - 0.002)^2 = (0.003)^2 = 0.000009`
    

3.  **计算方差**（上述平方值的平均值）：
    
    `方差 (σ²) = (0.000324 + 0.000144 + 0.000169 + 0.001024 + 0.000009) / 5`
    
    `方差 (σ²) = (0.00167) / 5`
    
    `方差 (σ²) = 0.000334`
    
4.  **计算标准差**（方差的平方根）：
    
    `标准差 (σ) = √0.000334 ≈ 0.01828`
    

###   

### 第3步：计算每个数据点的Z**\-score**

现在，对 `x`中的每个值应用Z-score公式：`   `

```
Z = (x - µ) / σ
```

-   **标准差为1**
    

  

下面验证计算结果：

1.  **计算Z\-score的均值**：

-   结果并不精确等于0，这是因为我们在计算中间步骤（均值和标准差）时进行了四舍五入，产生了微小的计算误差。理论上，它应无限接近0。

-   求平均值（方差）：`(1.192 + 0.300 + 0.676 + 2.683 + 0.074) / 5 ≈ 4.925 / 5 = 0.985`
    
-   求标准差：`√0.985 ≈ 0.992`，非常接近1。同样的，微小误差来自计算过程中的四舍五入。

### 此算子小结：

-   **符号意义**：
    
    正Z\-score（如0.98）表示该股票的收益率高于市场平均收益率（本例中为0.2%）；
    
    负Z\-score（如-1.75）则表示表现远低于平均水平。
    
-   **幅度意义**：
    
    Z\-score的绝对值表示偏离平均程度的强弱。例如，Z\-score为-1.75的股票其表现异常程度远高于Z\-score为-0.66的股票。
    
-   **核心用途**：**标准化**。
    
    将所有不同尺度、量纲的原始数据（如收益率、市值、市盈率）转换为均值为0、标准差1的标准分布，使得不同因子之间具有可比性，便于融合和比较。例如，可以直接将一只股票的收益率Z\-score与其市值Z\-score相加，来构建复合因子。
    
-   **减弱异常值**：
    
    虽然Z\-score本身不会改变数据分布，但它能识别出异常值（通常认为 |Z| > 2 或 3 的值较为异常），为后续处理（如温莎化）提供依据。

附1：gaussian, cauchy, uniform

这三种都是概率分布，描述了数据可能如何分散或聚集。

在量化金融的Alpha因子处理中，应用这些分布通常是为了对因子值进行**标准化**或**归一化**，使其更符合某种统计假设，或者削弱极端值的影响。具体介绍如下：

### 1\. Gaussian / Normal (高斯/正态分布)

-   **俗称**：钟形曲线
    
-   **特点**：最常见和著名的分布。形状是对称的钟形，大部分数据集中在均值附近，极端值（远离均值）出现的概率很低且对称。
    
-   **在Alpha处理中的目的**：将原始Alpha值转换为符合**标准正态分布**（均值为0，标准差为1）的值。这是一种非常标准的标准化方法，使得不同因子之间具有可比性。
    

-   **操作**：通常使用 **Z-Score** 方法：`(原始值 - 均值) / 标准差`
    

###   

### 2\. Cauchy (柯西分布)

-   **特点**：也是对称的钟形，但它的**峰值更尖**，**尾部更肥**。这意味着：
    

-   有更多的数据集中在中心点附近。
    
-   出现极端异常值（远离中心）的概率**远高于**正态分布。
    

-   **在Alpha处理中的目的**：当你的Alpha因子中包含很多**极端值**（或“肥尾”现象）时，使用柯西分布归一化比高斯分布更**稳健**。它不会像Z-Score那样过度压缩极端值，能更好地保留原始信号的尾部特征。
    

###   

### 3\. Uniform (均匀分布)

-   **特点**：所有可能的结果出现的概率都**完全相等**。在一个区间内，数据点均匀分布，没有明显的聚集现象。
    
-   **在Alpha处理中的目的**：将Alpha值的排名转换为一个均匀的尺度。这通常是通过**秩变换**实现的。
    

-   **操作**：先给所有Alpha值排名（Rank），然后将这些排名缩放到一个固定的区间内，例如 `[-1, 1]`或 `[0, 1]`。最终，转换后的值在这个区间内是均匀分布的。
    
-   **好处**：这种方法对极端值**不敏感**，因为它只依赖数据的顺序（排名），而不依赖其具体数值大小。它能确保输出数据被严格限制在某个范围内。

这个算子的本质是一个**分位数变换**：

1.  **非参数化**：它不关心原始价格的具体数值，只关心其排名顺序。
    
2.  **减弱异常值**：因为只依赖于排名，所以即使某只股票价格异常高（如股票D的120），也不会产生巨大的Z-Score（例如，如果用传统的 `(价格-均值)/标准差`计算，D的Z-Score会很大）。经过此变换后，最高价永远被映射为那个固定的截断值（如+1.5），从而有效地控制了异常值的影响。
    
3.  **分布转换**：它将原始数据隐含的分布（通常是未知的）强制转换为我们指定的理想分布（本例中是缩放后的正态分布）。
    

  

附3：经验分位数计算

这个公式 **`(rank - 1) / (N - 1)`** 的背景是用于计算**经验分位数**，特别是在计算**样本数据的累积分布函数（CDF）** 时，所采用的一种标准化排名方法。它的目的是将数据的排名（rank）无损地、线性地映射到 \[0, 1\] 区间上。

下面我们从几个层面来深入理解它的背景和目的：

### 1\. 核心目标：从“排名”到“比例”

我们想知道：对于一个样本中的某个数据点，其值在整体分布中处于什么位置。排名（rank）只能告诉我们它排第几，但无法在不同样本量的数据之间进行比较。

-   **排名（rank）**：股票B排第1，股票D排第5。
    
-   **问题**：第1名在5支股票和在第100支股票中的“地位”是一样的吗？显然不是。我们需要一个**不依赖于样本量（N）** 的、统一的尺度。
    

这个公式就是将“排名”转化为“比例”，回答的是“**有多大比例的数据小于或等于当前这个数据点？**” 这个比例就是我们寻找的经验分位数。

### 2\. 为什么是 `(rank - 1) / (N - 1)`？—— 统计学的分歧与选择

在将排名转换为比例时，并没有一个唯一“正确”的公式，存在几种不同的方法（`(rank - a) / (N - 2a + 1)`，其中 `a`是一个参数）。你的公式 `(rank - 1) / (N - 1)`是其中最常用和直观的一种，有时被称为 **“经验CDF的均值排名”** 或 **“Weibull公式”**。

**我们来拆解这个公式的逻辑：**

假设有 N=5 个数据点，将它们从小到大排列。我们需要为每个点分配一个在 \[0, 1\] 区间内的位置。

-   **最小的点（rank=1）**：我们认为它代表了从 0% 到某个点的累积概率。一个合理的假设是，这个点的位置是**第一个区间的中点**。将 \[0,1\] 区间平均分成 N=5 份，每个区间的宽度是 1/5 = 0.2。
    

-   第一个区间的中点是 `0.2 / 2 = 0.1`。
    
-   使用公式 `(1 - 1) / (5 - 1) = 0 / 4 = 0.0`。这和 0.1 不匹配？别急，看下面。
    

**更直观的理解是“填坑”思想：**

想象有 N=5 个数据点，它们将整个数据范围切分成了 N+1=6 个区间（或叫“坑”）。

`[ 区间1 | 点1 | 区间2 | 点2 | 区间3 | 点3 | 区间4 | 点4 | 区间5 | 点5 | 区间6 ]`

我们想知道每个数据点**之前**累积了多少个区间。

-   对于第一个点（rank=1），它前面有 **1** 个区间（区间1）。总区间数是 `N+1=6`。所以它的累积比例是 `1 / 6 ≈ 0.1667`。
    
-   对于第二个点（rank=2），它前面有 **2** 个区间（区间1和区间2），累积比例是 `2 / 6 = 0.3333`。
    
-   ...
    
-   对于最后一个点（rank=5），它前面有 **5** 个区间，累积比例是 `5 / 6 ≈ 0.8333`。
    

我们发现，这个比例可以用 `rank / (N+1)`来计算。这也是一个非常流行的公式（例如在Excel的 `PERCENTRANK.INC`函数中）。

那么 `(rank - 1) / (N - 1)`是怎么回事？它其实是 `rank / N`的一种调整版本。

**`(rank - 1) / (N - 1)`**

`(1-1)/4 = **0.0**`

`(5-1)/4 = **1.0**`

**将最小值和最大值分别映射到0和1。** 这是一种“保守”的估计，暗示你的样本已经包含了总体中的最小和最大值。在需要严格 \[0,1\] 范围时使用。

**`rank / (N + 1)`**

`1/6 ≈ **0.1667**`

`5/6 ≈ **0.8333**`

**为总体中可能存在的更小或更大值预留了空间。** 这是一种更常见的假设，认为你的样本并未覆盖总体的极端值。这是很多统计软件的首选。

**`(rank - 0.5) / N`**

`(1-0.5)/5 = **0.1**`

`(5-0.5)/5 = **0.9**`

**中位数排名**。将每个数据点视为其所处区间的中点。

### 3\. 在量化金融中的具体应用背景

在您提供的上下文中，使用 `(rank - 1) / (N - 1)`有其**特定的目的**：

1.  **确保严格的范围**：它**强制性地**将排名第一的值映射为 **0**，排名最后的值映射为 **1**。这是一个硬性规定，保证了输出值绝对落在 \[0, 1\] 区间内，没有任何例外。这对于后续的数学处理（如平移、分布变换）非常重要，避免了任何超出边界的情况。
    
2.  **为下一步平移做准备**：接下来的操作是 `Alpha_value = 1/N + Alpha_value * (1 - 2/N)`。这个平移操作的设计**依赖于**输入范围严格是 \[0, 1\]。它才能准确地将输出范围平移并缩放到 \[1/N, 1-1/N\] 这个新的、更紧的区间内，从而为后续应用逆CDF函数（如 `norm.ppf`）时避免得到无穷大（±∞）值做好铺垫。
    

**结论：**

公式 `(rank - 1) / (N - 1)`的背景是**经验分位数计算**的一种方法。在您提供的量化算子背景下，选择这个特定公式（而不是 `rank/(N+1)`或其他）是为了实现一个**非常明确且关键的技术目标**：**生成一个严格在 \[0, 1\] 范围内的、确定性的数值，为后续处理步骤提供稳定且可预测的输入**。这是一个工程上的设计选择，旨在保证算法的鲁棒性。
