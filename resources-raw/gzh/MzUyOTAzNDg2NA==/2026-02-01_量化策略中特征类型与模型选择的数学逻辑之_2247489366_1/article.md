量化投资中，可以是先构建一堆符合一定评定标准的“好因子”，构建模型并预测信号后，再设计什么样的策略。

也可以确定策略目标，然后在确定：基于什么数据，构建什么因子，选择什么合适的模型。

从可行性性上，往往是从后者开始，但刚刚接触学习量化，因为缺乏一个整体的思考，一般可能要从前者一点点摸索的开始。

所以基于数据、因子、模型、策略需要结合起来考虑。

特征数据是量化投资策略的"食材"，而模型则可以看做是"厨艺"。不同的食材需要不同的烹饪方法，同样的，不同类型的数据特征也需要匹配相应的模型。

我一直想给这块的思考找到一个理论支撑，比如做一个周频率的换仓策略，用纯量价因子到底行不行？用10年的数据到底够不够？20个因子好，还是200个因子好等等问题，如果没有一个理论体系支撑，只能瞎猫逮耗子一样不断的“实验”来论证。

所以本文主要目的就是从数学原理角度出发，以市场微观结构和实际案例结合，尝试解析A股量化策略中特征类型与模型选择的内在逻辑。

# 1.特征维度的数学本质思考

在量化投资中，真正的挑战不是特征数量，而是有效信息量。通过PCA方差解释比，可以将抽象的"维度"概念转化为可计算的指标。

维度在数学上的三种等价定义：特征空间的基向量数量、描述系统状态所需的最小独立变量数、样本点在空间中的自由度。看一个示例代码：

```
import numpy as np
```

PCA分析就不展开了，可自行了解。上述代码中提到3个概念：

-   表面维度 = X.shape\[1\] = 原始特征数量
    
-   内在维度 = 解释95%方差所需的主成分数
    
-   维度比例 = 内在维度 / 表面维度
    

```
import numpy as np
```

通过这3个概念，就可以在实际数据中分析特征特点，示例场景如下：

场景1：冗余特征

-   假设有100个特征，但内在维度只有20
    
-   说明80个特征是冗余的（信息重叠）
    

  

场景2：独立特征  

-   假设有100个特征，内在维度接近100
    
-   说明特征之间相对独立，信息含量高
    

  

场景3：噪声特征

-   假设有100个特征，但最后80个主成分只解释5%方差
    
-   说明这些特征大多是噪声
    

  

代码中提到一个名词：维度灾难（Curse of Dimensionality），这是是指在量化投资中**随着特征维度的增加，模型性能不仅不提升，反而可能急剧下降**。参考如下技术指标维度灾难的示例代码：

```
import numpy as np
```

运行结果如下：

```
基础特征数: 5
```

指标

数值

有效内在维度

**最核心的指标：  
通过主成分分析（PCA）计算，能解释95%数据方差的有效特征数仅为4个

10.53%

有效内在维度 ÷ 名义特征维度 = 4 ÷ 38 ≈ 10.53%  
这个比例极低，说明90%左右的特征都是冗余的（比如MA5和MA10高度相关，RSI6和RSI12几乎是重复信息）

虽然这个数值仍很大（样本充足），但揭示了本质：你用38个特征的“复杂模型”，其实只需要4个特征就能达到相同效果

风险等级

因为维度有效率（10.53%）远低于30%的阈值，判定为高风险

### 代码返回的字段中：

-   `dimension_ratio: 0.1053`：维度有效率的小数形式，直观体现特征冗余程度
    
-   `effective_samples_per_dim: 75000.0000`：每1个有效特征能分到7.5万个样本，样本本身不缺，但特征冗余导致模型“做无用功”
    
-   `warning_level: high`：量化策略的核心风险提示——过度堆砌技术指标会导致：
    

-   模型复杂度大幅提升（要训练38个特征）
    
-   过拟合风险剧增（冗余特征会拟合数据中的噪音）
    
-   策略泛化能力下降（实盘表现远差于回测）
    

### 通过上述分析可以看出：

-   **表面假象 vs 本质问题**：样本维度比（7894.74）看似完美，实则是“数字陷阱”，有效内在维度（4）才反映真实的特征价值。
    
-   **核心风险**：90%的技术指标是冗余的，堆砌这些指标只会增加模型复杂度，不会提升策略有效性，反而会显著提高过拟合风险。
    
-   **实践启示**：量化策略开发中，应优先筛选少量高信息密度的核心特征（比如只保留1-2个维度的MA、1个维度的RSI），而非无意义地堆砌所有技术指标。
    

所以在特征选择上：**多不等于好，大力出奇迹缺乏有效的理论依据，冗余的特征只会制造“维度灾难”**。

先看低频策略的低维度特征。

这个计算结果清晰揭示了该模拟A股日频收益率序列的市场记忆特征：

其中市场对历史收益率的有效记忆仅为1天，自相关衰减率达到1/天，意味着每天市场对前一日收益率的记忆会完全衰减，仅有滞后1天的收益率与当日存在显著自相关（相关系数0.193），且该相关性已接近5%的显著性阈值。

这表明该市场呈现出极强的短期记忆特征，超过1天的历史收益率波动对当日价格走势几乎无有效影响，也从本质上解释了为何日频量化策略中过度堆砌长期技术指标（如MA60、MA250等）缺乏实际意，因为市场本身仅能"记住"1天内的走势，更长期的历史信息已无法提供有效增量信号，只会造成特征冗余和维度灾难。

另外，也可以 从量化投资的市场运行逻辑来看，A股日频特征的内在维度有限、有效信息窗口较窄，核心源于三大市场底层特性，且均直接影响量化策略的特征选择与模型构建：

一是价格发现效率，A股日频市场具备相对有效的价格发现机制，各类历史信息（包括短期收益率、技术面信号等）会被市场快速消化并反映在当前价格中，难以通过滞后的历史信息获得持续超额收益；

二是投资者行为约束，市场中多数投资者（无论是个人投资者还是机构散户化资金）的决策周期集中在日度或周度，短期交易行为主导日频价格波动，使得日频特征的有效作用窗口被限制在短期范围内，长期窗口的特征难以捕捉稳定的市场规律；

三是噪声-信号失衡，随着时间窗口不断拉长，市场噪声信号呈平方根速度累积，而能够驱动价格的有效信号仅呈线性增长，两者叠加导致长期窗口的特征信噪比持续下降，有效信息被大量噪声掩盖，进一步印证了日频策略中过度依赖长期历史数据（如长期均线、长期自相关特征）的局限性，也解释了为何市场记忆效应仅能维持极短时间。

高频策略特征维度则相对较高，其原因在于**市场微观结构的复杂性**和**信息传递的级联效应**。

这份高频订单簿复杂度分析结果，清晰反映了当前市场高信息密度、高波动、高维度的高频交易特征，核心是从盘口静态信息分布和价格/量动态变化两个维度，印证了高频特征天然具备高维度的底层逻辑：  

一、订单簿平均信息熵2.1692（偏高）：盘口静态信息高度分散，市场分歧显著 

1\. 熵的数值意义：本次分析的是5档买卖盘，5档的最大理论熵为\`log2(5)≈2.3219\`，本次实际熵2.1692已非常接近理论最大值，说明5档挂单的成交量分布极其均匀，没有出现挂单量集中在买一/卖一的情况。 

2\. 市场含义：盘口挂单分散意味着多空双方对当前价格的分歧极大，没有形成明确的主力挂单方向（既无大单托底也无大单压顶），买卖双方在各档位均有大量挂单博弈，盘口存在丰富的静态信息。 

3\. 量化视角：高信息熵是高频特征高维度的静态基础，分散的挂单分布让每一档的价格/量都具备独立的信息价值，而非像低熵场景中仅买一/卖一有有效信息，这也导致高频策略需要纳入多档位数据才能完整捕捉盘口信号。  

二、动态变化复杂度48.793（极高，远大于0.5的高阈值）：价格/量波动剧烈且无规律，动态信息不可预测性强 动态复杂度的核心逻辑是低自相关+高波动=高复杂度，这个极高的数值意味着两个关键市场特征： 

1\. 高频价格/成交量的自相关性极低：前一个tick的价格/量变化，几乎无法预测后一个tick的走势，盘口变化呈现极强的\*\*随机性和突发性\*\*（符合A股高频市场“微结构噪声多、短期趋势持续性弱”的特点）； 

2\. 价格/量的波动幅度极大：逐tick的中间价变化、成交量变化的标准差很高，盘口存在频繁的挂单撤单、小单成交、档位跳动，属于典型的活跃交易盘口（如开盘集合竞价后、尾盘收盘前的高频特征）。 

3\. 量化视角：高动态复杂度是高频特征高维度的动态核心，高频市场的价格/量变化无显著规律，需要通过大量的时序特征（如tick级涨跌幅、成交量斜率、挂单变化率）、跨档位特征（如买卖盘价差、盘口深度差）才能捕捉短期交易机会，这直接导致高频特征的维度远高于日频特征。  

三、复杂度等级HIGH：高频特征天然具备“高维度、高信息、高噪声”的三重属性，上面的示例代码结果完美解释了为何高频策略的特征维度远高于日频策略，也是高频微观结构模型的核心结论： 

1\. 从静态盘口看，高信息熵让5档买卖盘的每一个档位都有独立信息，无法像日频特征那样通过简单降维压缩； 

2\. 从动态变化看，高复杂度的价格/量波动需要捕捉大量瞬时、高频的时序变化信号，进一步推高了特征维度； 

3\. 但同时要注意：高维度背后是高噪声，高频的高波动和低自相关，意味着特征中包含大量无规律的微结构噪声，这也是高频策略需要更强的正则化、更精细的特征筛选的原因。 

四、对高频量化策略的实操指导意义 

1\. 特征工程：需充分挖掘多档位盘口信息（如各档位挂单量、价差、深度）和tick级时序特征（如价格变化率、成交量累计值），利用高维度特征的信息优势捕捉短期交易机会； 

2\. 模型选择：适合使用对高维度数据适配性强的模型（如轻量神经网络、梯度提升树），同时必须加入强正则化（如L1/L2、早停）抑制高噪声带来的过拟合； 

3\. 交易时机：该类盘口（高熵+高复杂度）通常出现在市场交易活跃时段，是高频套利/做市策略的核心交易窗口，而低熵+低复杂度的盘口则应减少交易，避免噪声导致的无效成交； 

4\. 风险控制：高波动的盘口意味着价格滑点风险更高，需优化挂单策略和成交阈值，避免因盘口突然跳动导致的交易损失。  

如上如果从量化微观结构角度，可以印证高频市场的特征高维度是由盘口静态信息的高度分散和动态价格/量的剧烈无规律波动共同决定的，这既是高频策略能够获得超额收益的核心来源，即高信息密度带来更多交易机会，也是高频策略建模难度远高于日频策略的关键原因，即高维度、高噪声易导致过拟合。
