#### **3. `kth_element(x, d, k)`**

**解释**：该算子通过回溯过去 `d` 天的输入数据，返回第 `k` 个有效值（跳过 `ignore` 列表中的指定标量值）。它也被称为**回填算子（backfill operator）**，常用于处理缺失数据。  

![](assets/004.png)

  

#### **核心逻辑**

1.  **数据筛选**：
    
    从过去 `d` 天的数据中，排除所有出现在 `ignore` 列表中的值（如 `NaN` 或 `0`）。
    
2.  **排序与选择**：
    
    对剩余的有效值排序，返回第 `k` 个值（按从大到小顺序）。
    

**示例**：

用过去 3 天的最大值回填缺失值（`ignore="NAN"`）。

x = \[10, NaN, 8, NaN, 5\]  # 历史数据序列（最新值在右侧）

d = 3, k = 1, ignore = "NAN"

**步骤**：

1.  取最后 `d=3` 天的数据：`[NaN, 8, NaN]`。
    
2.  忽略 `NaN` 后剩余有效值：`[8]`。
    
3.  返回第 `k=1` 大的值：`8`。
    

**输出**：`8`（用于填充当前 `NaN`）。

1.  **缺失值回填**：
    

-   用过去 `d` 天的非缺失值（如 `k=1` 为最大值）填充当前 `NaN`。
    

3.  **异常值替换**：
    

-   忽略异常值（如 `ignore="0 999"`），选择稳健的中间值（`k=2`）。
    

#### **4. `last_diff_value(x, d)`**

**解释**：返回过去 `d` 天中与当前 `x` 值不同的最近一个值。  
**示例**：

-   若 `x` 序列为 `[2, 2, 3, 2]`，当前值为 `2`，则返回 `3`。
    

#### **5. `ts_arg_max(x, d)`**

**解释**：返回过去 d天时间序列中最大值所在的相对位置索引：

-   若最大值出现在**当天**，返回 `0`；
    
-   若最大值出现在**前一天**，返回 `1`；
    
-   依此类推，最大值出现在 `d` 天前则返回 `d-1`。
    

**示例**  
输入：`d = 6`，过去6天数据为 `[6, 2, 8, 5, 9, 4]`（首元素为当天值）

-   最大值 `9` 出现在 **4 天前**（从当天倒序计数：当天=0，前1天=1，...，前5天=5）。
    
-   因此，`ts_arg_max(x, 6) = 4`。
    

**注**

-   数据顺序：输入数组应为 `[今天, 昨天, ..., d天前]`。
    
-   并列最大值：返回最靠近当天的位置索引。
    

#### **6. `ts_arg_min(x, d)`**

**解释**：返回过去 d天时间序列中最小值所在的相对位置索引：（逻辑同 `ts_arg_max`）。  

-   若最小值出现在**当天**，返回 `0`
    
-   若最小值出现在**前一天**，返回 `1`
    
-   依此类推，最小值出现在 `d` 天前则返回 `d-1`
    

**示例**  
输入：`d = 6`，过去6天数据为 `[6, 2, 8, 5, 9, 4]`（首元素为当天值）

-   最小值 `2` 出现在 **1 天前**（当天=0，前1天=1）
    
-   因此，`ts_arg_min(x, 6) = 1`
    

**注**

-   数据顺序：`[今天, 昨天, ..., d天前]`
    
-   并列最小值：返回最靠近当天的位置
    

#### **7. `ts_av_diff(x, d)`**

**解释**：该算子计算当前值x与过去d天均值（ts\_mean）的差值，并自动忽略NaN值参与均值计算。

**示例**输入：d=6，过去6天数据为\[6,2,8,5,9,NaN\]

-   均值计算时忽略NaN：(6+2+8+5+9)/5=6
    
-   当前值x=6
    
-   因此，ts\_av\_diff(x,d)=6-6=0
    

**特点**

1.  NaN安全处理：自动排除NaN值参与均值计算
    
2.  结果解读：正值表示当前值高于近期均值，负值表示低于近期均值
    

#### **8. `ts_backfill(x, lookback=d, k=1, ignore="NAN")`**

**解释**：ts\_backfill算子用于用最近可用的非NaN值替换NaN值。如果数据字段x的输入值为NaN，ts\_backfill算子将检查该数据字段在过去d天内的可用输入值，并输出最近可用的非NaN输入值。如果设置了k参数，则ts\_backfill算子将输出第k个最近可用的非NaN输入值。

  

该算子可以提高权重覆盖率，并有助于降低回撤风险。示例：ts\_backfill(x, 252)

  

-   如果数据字段x的输入值=非NaN，则输出=x  
      
    
-   如果数据字段x的输入值=NaN，则输出=过去252天内x的最近可用非NaN输入值

9. ****`ts_corr(x, y, d)`****

  

**解释**：计算 `x` 和 `y` 过去 `d` 天的相关系数。用于衡量两个变量之间的线性关系。当变量呈正态分布且关系为线性时，该方法的测量效果最佳。引用的是皮尔逊相关系数（Pearson Correlation）的计算公式，具体如下：

1.  **分子部分**：  
      
    计算变量 ( x ) 和 ( y ) 在时间窗口 (\[-d+1, t\]) 内的协方差（偏离均值的乘积和）。
    
2.  **分母部分**：  
    为 ( x ) 和 ( y ) 的标准差乘积，用于标准化协方差，使结果范围在 (\[-1, 1\])。
    

### 关键点：

-   **时间窗口**：公式中 ( i ) 从 ( -d+1 ) 到 ( t )，表示回溯 ( d ) 天的数据。
    
-   **均值**：( \\bar{x} ) 和 ( \\bar{y} ) 分别是 ( x ) 和 ( y ) 在窗口内的均值。
    
-   **应用场景**：常用于金融时间序列分析（如因子相关性计算）。
    

  

**假设我们需要构建一个因子，捕捉股票价格动量与成交量变化的协同效应。使用`ts_corr`计算过去20天收益率与成交量变化的相关系数。**

-   正值(0~1)：量价齐升/齐跌，动量效应显著

#### **17. `ts_quantile(x, d, driver="gaussian")`**

**解释**：基于 `driver` 分布（如高斯分布）计算分位数。

该算子计算时间序列排名（ts\_rank），并对其结果应用驱动分布的反向累积密度函数。驱动分布的可选类型包括："gaussian"（高斯分布，默认）、"uniform"（均匀分布）和"cauchy"（柯西分布）。

注：

1.  核心计算分两步：
    

-   先对数据进行时间序列排名（标准化处理）
    
-   再将排名结果通过指定分布的逆CDF函数转换
    

1.  分布类型说明：
    

-   高斯分布：适用于大多数金融数据
    
-   均匀分布：用于等概率转换
    
-   柯西分布：对极端值更敏感
    

#### **18. `ts_rank(x, d, constant=0)`**

**解释**：对过去 `d` 天的 `x` 排名，返回当前值的排名 + `constant`。  

对每个标的过去d天的x值进行排序，返回当前值的排名加上一个常数（若未指定常数，默认值为0）。

注：

1\. 计算流程分两步：

-   \- 首先在d天窗口内对x值进行排序（升序/降序）
    
-   \- 然后取当前值在序列中的排名位置
    

2\. 常数项作用：

-   \- 默认constant=0时直接返回原始排名
    
-   \- 可调整constant值来平移排名结果（如设为0.5可避免零排名）
    

**示例**：

-   `ts_rank([3, 1, 4], d=3)` 返回 `2`（当前值 `4` 的排名为 1，`1 + constant=0`）。

-   配合 `constant` 参数避免除零错误（如极差为零时）
    

#### **注意事项**

-   **极差为零**：当 `ts_max == ts_min` 时，公式分母为0，建议预判处理：
    
    `scale = if_else(         ts_max(x,d) == ts_min(x,d),         0.5 + constant,  # 中值填充         (x - ts_min(x,d)) / (ts_max(x,d) - ts_min(x,d)) + constant     )`  
    
-   **窗口选择**：短期策略用 `d=5~20`，长期策略用 `d=60~252`。
    

  

#### **21. `ts_std_dev(x, d)`**

**解释**：计算过去 `d` 天的标准差。

#### **22. `ts_step(1)`**

**解释**：返回天数计数器（从起始日开始累加）。

#### **23. `ts_sum(x, d)`**

**解释**：计算过去 `d` 天的和。

#### **24. `ts_zscore(x, d)`**

**解释**：计算 `x` 的 Z-Score（`(x - ts_mean) / ts_std_dev`）。
