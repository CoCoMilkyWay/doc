## 增量计算（Incremental computation）是一种计算方式，它考虑到计算输入在未来可能会发生变化。一旦这些变化出现，增量计算能够高效地更新输出结果，其效率至少要比完全重新进行整个计算高得多。

增量计算在诸多编程领域都有应用，像UI编程、数据流处理、构建系统、编译器开发以及代码编辑器等。或许你之前在实际编程中已经接触过这种计算方式，只是没有意识到它就是增量计算。虽然增量计算应用广泛，但它却很少被当作一种常见的计算范式来看待。人们通常把它当作缓存或记忆化技术的一种临时应用。与之形成对比的是，并发计算、惰性计算和分布式计算等其他计算范式，它们有着更为大众所熟知的命名方式和相关技术。

`function d(x: number, y: number) {     return Math.sqrt(x * x + y * y);   }      const computation = d(1, 2);   `

如果采用增量计算的思路，最终关注的问题是，当部分输入从  1  和  2  变为其他值时，如何最有效地重新计算  d(x, y)  。

在编程中，如上计算函数d(x, y)，它的功能是计算Math.sqrt(x \* x + y \* y)，当前x取值为 1、y取值为 2 ，并得到了一个计算结果。但在实际情况中，输入值x和y不会一直固定不变。

采用增量计算思路时，我们关注的重点就变成了：一旦x和y的取值从 1 和 2 变成其他数值，比如x变成 5，y变成 3，怎样计算d(x, y)才能更高效。

这里的 “高效” 意味着，不希望每次输入值改变都完完全全重新进行整个计算过程。就像做数学题，之前算过的一些步骤，如果在新的计算里还能用，就尽量复用，避免重复劳动，以此节省时间和计算资源。

所以，可以把这个计算分解成基本运算（加法、乘法和平方根），同时使用临时变量保存中间结果，也就是进行缓存。这样做的好处是，当输入部分改变时，能够复用之前已经计算好的部分结果。

最初的计算：

`const op1 = 1 * 1;   const op2 = 2 * 2;   const op3 = op1 + op2;   const op4 = Math.sqrt(op3);   `

当输入从 (1, 2) 变为 (1, 3) 时：

`const op1 = 1 * 1;   const op2 = 3 * 3;   const op3 = op1 + op2;   const op4 = Math.sqrt(op3);   `

可以看到，op1 的计算 1 \* 1 没有改变，所以在新的计算中可以复用这个结果，只需重新计算 op2、op3 和 op4 。

通过上面，我们可以形成增量计算的两个基本原则： 1：当操作的至少一个输入发生变化时，重新执行该操作以获得新的输出。例如，当 y 从 2 变为 3 时，op2 的输入发生了变化，所以要重新计算 op2 。 2：重复上述过程，直到不再有任何变化。也就是说，不断检查每个操作的输入是否改变，若有改变就重新计算，直到所有操作的输入都不再变化为止。

## 2.增量计算在量化投资中的应用

在量化交易场景中，通常需要计算平均值和方差，例如计算移动平均线和波动率指标。当我们需要高频和长期的计算时，需要长期保留历史数据，这既不必要又耗费资源。所以就可以采用增量计算的思路。

但这种计算方式存在不足。它算出的均值和方差是基于全部样本数据的，可在实际的交易策略（比如量化交易中），往往只关注特定时间段内的数据，像过去10天、30天的股价均值和波动情况，而不是从股票上市以来的所有数据。所以这种不考虑固定周期的计算方式，不能直接满足实际策略需求。

再看均值更新公式，新均值的更新量是由新数据和过去均值的偏差，乘以一个特定比率得到的。如果这个比率始终保持不变，就形成了指数加权平均值的计算逻辑。

在指数加权平均里，越新的数据被赋予越高的权重，旧数据权重逐渐降低，相比简单平均能更及时地反映数据的最新变化趋势。比如在跟踪股票价格趋势时，指数加权平均能更快响应股价近期的涨跌变化，则对于动态调整交易策略很有帮助。
